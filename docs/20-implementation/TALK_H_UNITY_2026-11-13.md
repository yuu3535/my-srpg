## 仕様書に無かったので総合担当が決めたこと

- 1行の字の数の上限は 26字（`DialogueView.MaxChars`）。左の外側の人でも吹き出しが画面の右の端を越えない幅。超えたら折り返す（行の頭に「。」などが来ないようにぶら下げる）。
- 立ち絵の無い人（モブ）は舞台の枠を取らない。話しても、立っている人を入れ替えない。
- 見本に出てこない人の立ち絵の高さは 1060、頭の位置は絵の真ん中（見本の4人は仕様書の値）。

## 入っている物

- 吹き出し（角を14px切った枠・銀の線・内側の線・ドット柄・角の菱形）。
  - 置き方は2つ: 通常は頭の上、支援会話は顔の横。
  - 尾は話す人へ向ける。立ち絵の無い人は、右の辺から画面の外へ。
  - 大きさは台詞の長さで伸び縮み。ページをめくっても幅は変わらない。
- 名前札（平行四辺形・上下の線）。携帯端末の名前札は四芒星つき。
- 「次へ」の印:
  - 文字を出している間は、灰色の丸点。
  - 出し終えたら、菱形3つ（跳ねる・色が回る）。ページがあれば「1 / 2」。
- 上のタブ: 章と場所。支援会話ではランク（C B A）と話のタイトル。
- 下のボタン帯（会話ログ・オート・スキップ）。
- 会話ログ:
  - 下から新しい順。今の台詞は名前と菱形が光る。
  - スクロールの目印、CLOSE の星。
  - 開いている間は、吹き出しなどを隠す。
- 立ち絵:
  - 見本と同じ見え方になるよう、透明でない所の高さをそろえて置く。
  - 話している人は明るく 6px 上。黙っている人は明るさ 0.72。
  - 5回たたくと位置の調整パネル（前と同じ）。
- 支援会話モード（`DialogueView.PlaySupport`）: 2人用の位置、顔の横の吹き出し、ランクのタブ、CLOSE の星。
  - 支援会話の台本がまだ無いので、相手選びの画面からはまだつないでいない。
- 開発用: エディターで F8 を押すと、見本 talk_03 などを 40% で重ねる。
