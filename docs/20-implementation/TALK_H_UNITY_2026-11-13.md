## 仕様書に無かったので総合担当が決めたこと

- 1行の字の数の上限は 26字（`DialogueView.MaxChars`）。左の外側の人でも吹き出しが画面の右の端を越えない幅。超えたら折り返す（行の頭に「。」などが来ないようにぶら下げる）。
- 立ち絵の無い人（モブ）は舞台の枠を取らない。話しても、立っている人を入れ替えない。
- 見本に出てこない人の立ち絵の高さは 1060、頭の位置は絵の真ん中（見本の4人は仕様書の値）。

  - 下から新しい順。今の台詞は名前と菱形が光る。

## 支援会話の台本と、デバッグの入口（2026-11-13 追記）

原作者「支援会話は台本できたらそれに差し替えられるようにしておこうか」「デバッグで支援会話見れるページもあった方が確認しやすそう」。

### 台本の置き場と形

- 置き場は `unity-prototype/Assets/Resources/Support/support_talks.json`。台本ができたら、このファイルを差し替える。
- 1つの会話に書くもの:
  - `a`・`b`: 組（相手選びのデータ `support_roster.json` の id。順は問わない）
  - `rank`: C / B / A
  - `title`: 上のタブに出す話のタイトル
  - `draft`: true なら仮の台詞
  - `lines`: 台詞。会話のシナリオと同じ形（`type` は line・narration・phone、`speaker` は表示の名前、`expression` は表情、`text` は本文）
- 今入っているのは、画面を確かめるための仮の2つだけ（アルシェ×アルバス B、アルシェ×アン C）。物語の台詞ではない。
- シナリオの表から書き出す道具（`tools/import_scenario.py`）は、まだ支援会話に対応していない。台本の表ができたら、表の形に合わせて書き出しを足す。

### 流れ

1. 相手選びで「会話する」を押す。
2. 暗転の半ばで、その組・そのランクの台本を流す。
   - 相手選びは閉じる。拠点メニューの中身も出さない。
3. 最後まで読むか、右上の CLOSE で閉じると、相手選びに戻る。
   - そのランクを見たことになり、次のランクは「支援値をためている途中」になる。
   - この記録は、まだゲームを閉じると消える。セーブはまだ。
4. 台本の無い組は、暗転のあと「この組の支援会話の台本は、まだありません」と出る。

### 立ち絵

- アルバスは場面の立ち絵の一覧に入っていないので、`Resources/Talk/Portraits/アルバス.png`（`albas.png` の写し）を探して使う。
- 一覧に無い人は、このフォルダに `〈名前〉.png` を置けば出る。
- 置いたら `portrait_bounds.json` に、絵の透明でない所の範囲を足す。

### デバッグの入口（開発中だけ）

- 入口の画面の「支援会話テスト」（`StartMenu.ShowSupportTest`。公開の形にするときに false）。
- 2Dの探索の回廊で、台本の一覧が出る。
  - 押すとその支援会話を流し、終わると一覧に戻る。見た記録やランクは変えない。
  - 仮の台本には「【仮】」と出る。
- 戻るときは右下の「最初へ」。
