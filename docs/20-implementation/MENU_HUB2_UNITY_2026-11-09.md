# 拠点メニュー Hub2 の Unity への組み込み（1回目）

作成: 2026-11-09 / 総合担当（Claude Code）
依頼: メニュー演出担当「拠点メニュー Hub2 の Unity への組み込みをお願いします」（2026-11-09）
正本: `docs/10-design/ui/MENU_HUB2_SPEC_2026-11-08.md`／開閉の数値: `docs/10-design/ui/MENU_OPEN_MOTION_SPEC_2026-11-06.md`「Hub2 の開閉（正）」／試作: `アイコン素材/携帯端末メニュー画面素材/メニュー開閉演出_比較01/hub2-sweep.html`・`hub2-sweep-model.js`
状態: Unity の 2D の探索（Corridor2D）で開け閉めできる。WebGL の公開版にはまだ入れていない。

## 1. 触り方

1. Unity で `Explore3D` の場面を ▶ → 入口の画面で「探索（2Dの試し）」。
2. 起きたときの会話を終えると、右上に **MENU の星** が出る（会話の途中は出ない＝イベントの場面では開けない）。
3. MENU の星か **Esc** で開く。CLOSE の星か Esc で閉じる。
4. 演出の途中は、画面のどこを押しても・Esc・Enter・スペースで最後まで飛ぶ。
5. 設定（メニューの「設定」か、入口の「設定」）に「端末の演出：あり／短い／なし」を足した。

確認の画像（バッチで撮った物。1688×780）:
- 開いたところ: `docs/40-reviews/hub2_unity_2026-11-09/menu_open.jpg`
- 開閉の途中: `docs/40-reviews/hub2_unity_2026-11-09/tear_frames.jpg`（左上から: 探索の MENU の星／開く・切れ目／開く・裂け目からメニュー／開く・CLOSE の星の着地／閉じる・切れ目／閉じる・裂けて探索へ）

## 3. 正本と違う所・まだの所

| 項目 | 今 | 理由・次 |
|---|---|---|
| 太陽盤 | 試作から書き出した**静止の絵**（`太陽盤とコマンド_アルシェ_出撃選択_透過.png`）＋押せる所。回らない、選ぶと「出撃」以外は光らない | Unity に太陽盤の実装が無い。回る太陽盤は別の作業で作る |
| 押した先 | セーブ・設定はつながっている。身支度・出撃・探索・支援会話・ログ・名声報酬・カード・マップで確認は「まだつながっていません」の知らせ | それぞれの画面ができてから |
| 文字 | 章・場所・メインイベントは見本の固定の文字 | シナリオ連動の案（`docs/30-planning/MENU_TEXT_FROM_SCENARIO_PROPOSAL_2026-11-08.md`）が決まってから |
| 所持金・名声 | 「—」 | お金・名声の仕組みが無い |
| 運命予報 | 止まった1行（流さない）。押すと「次の段階」の知らせ | カード（正本 §3-11）は次の段階 |
| 時間帯アイコン | 無し | 次の段階（正本 §3-6） |
| フォント | ゲームに入っている Noto Serif JP（ブラウザ以外ではパソコンの明朝）。英字も同じ字体。字間は付けていない | フォントの使用条件が決まるまで |
| ORCUS | ごく薄い塗り（正本は輪郭線だけ） | Unity の標準の文字では輪郭線だけを描けない |
| 右のガラス | ぼかし無し。少し濃くした | 正本 §3-1 で WebGL では省いてよい |
| 星 | コードで描いた仮の星（試作と同じ） | 素材 C が見つかったら差し替え |
| 立ち絵 | Unity の会話用の立ち絵（`Art/Portraits/Dialogue/`）から、目の高さをそろえて切り出した仮の絵（`Resources/Menu/card_*.png`） | 胸上の立ち絵が来たら差し替え |
| NEW の札 | いつも出す（見本） | 支援会話の未読の仕組みができてから |
| ホバー | 押したときの色の変化だけ。カードが浮く・星が回るなどは無し | スマホでは使わないので後回し |

## 4. ファイル

- コード: `unity-prototype/Assets/Scripts/Battle/Menu/`（`Hub2Motion.cs` 時刻表と幾何・画面に触れない／`Hub2Menu.cs` 画面と入力／`PolyGraphic.cs`・`TearMaskGraphic.cs` 多角形と切り裂きの切り抜き／`Hub2Textures.cs` コードで作る星・ドット・グラデーション）
