# タイトル画面 — Unity 組み込み（1回目）2026-11-13

正本: `docs/10-design/ui/title/`（仕様書・決めたこと）。入口の画面（StartMenu）を、このタイトル画面に置き換えた。

## 入っている物

- 3つの状態（クリア前・宵空／サタン撃破後・朝焼け／終幕後・褪せた朝焼けと黒い題名）。状態は、いちばん最近のセーブの進み具合で決まる。
- 空の横の動き（90秒で往復）、上下の暗さ、終幕後の周りの暗さ、地平線の光（7秒の脈）。
- 星:
  - 光の筋（4秒の脈）
  - 芯
  - 菱形の輪（120秒で時計回り）
  - 謎文字の輪（200秒で反時計回り）
- 英字題名、題名（7秒ごとに光が通る）、運命予報（謎文字・章ごと）。
  - 開いたときは、それぞれが下から上がりながら現れる。
- タップ待ち（TAP TO START・2.4秒の明滅。y220 から下を押すとメニュー）。
- メニュー:
  - 続きから・はじめから・保管庫（押せない）・設定（拠点メニューと同じ設定画面）。
  - 選んでいる項目の下線は、まん中から伸びる。
  - ← → で選び、Enter で決める。
- 説明の行。
- 演出:
  - はじめから（朝焼け・朝日・「PROLOGUE 祝賀会の朝」。5.2秒）→ 新しいデータの枠 → プロローグ（2Dの探索・自室）。
  - 続きから（オルクス紫黒空・章・場所・日時。3.8秒）→ そのセーブへ。
- 上書きする枠を選ぶ画面と確認（仮の見た目）。空き枠が無いときだけ出る。
- 開発中だけ: DEV 戦闘テスト・DEV 支援会話テスト・DEV 表示（3つの状態を順に切り替え）。エディターでは F8 で見本を重ねる。
- 設定「端末の演出：なし」では、空の動き・輪の回転・光の脈・明滅を止める。

## セーブ（版3）

- `chapter`（章の名前。空はプロローグ）、`progress`（0 クリア前 / 1 サタン撃破後 / 2 終幕後）、`fresh`（はじめからで作ったばかり。読むとプロローグを最初から）。
- 版2までのセーブは、章を「プロローグ」として読む。
- 章ごとの文は `Resources/Title/chapters.json`（日本語の運命予報とローマ字。章が増えたら足す）。
- 物語の進み具合は `GameProgress`（章・状態）。章が進むところ・サタンを倒すところ・エンディングで変える（まだ無い）。

## 素材
