## 1. 地面マップ

下の枠をそのまま全部貼り、画像を2枚添付する（添付1＝下絵、添付2＝地形の配置図）。
共通の前置き（`MAP_UI_ASSET_ORDER_2026-09-26_v3.md` §3.0 のM・P・Kの文）は枠の先頭に入れてある。

```
ダークファンタジーのシミュレーションRPG（百年戦争・スマホの横画面で遊ぶ）の素材を作ってください。
マップは斜め見下ろし（アイソメトリック）で、床の1マスは横128×縦64pxの菱形です。

【共通の約束】
- 1回に1つの素材だけ作る。文字は入れない。
- 色の役割: 青＝味方、赤＝敵・危険、緑＝回復・補助、金＝線・大事なもの、黒紫＝地。
  青・赤・緑をただの飾りに使わない。
- 画風: 暗く落ち着いたダークファンタジー。キャラと盤面は見やすく、はっきりした輪郭で。

添付1（マス目の下絵）を位置合わせの絶対基準として、
スマホの横画面で遊ぶ戦闘画面の、斜め見下ろし（2:1アイソメトリック）の地面マップを1枚作ってください。

【大きさと形】
- 画像は1472×880px。横12マス×縦8マス。1マスは横128×縦64pxの菱形。
- 下絵の菱形の位置・大きさ・角度・盤面の外周を変えない。
- 盤面の下側（左下と右下の2辺）に、厚み約48pxの土と石の断面を付ける。
- 盤面と厚み以外は透明。縁は半透明ににじませず、くっきり切る。

【地形の配置】
添付2（地形の配置図）の色分けどおりに地形を置いてください。添付2は下絵と同じ位置で描いてあります。
- 明るい灰色 … 古い石畳。白い石と黒い石で継ぎ足した補修跡が混ざる。ひびと苔。
  （左の辺に沿って曲がりくねる旧街道と、中央の橋へ向かう道、奥の門前の広場）
- 茶色 … 荷車の轍のある、踏み固めた土の道（右側の広い道）。
- くすんだ緑 … 低い苔と短い下草の空き地。
- 暗い青 … 古い砦の水堀。暗く静かな水と、石積みの岸。水は光らせない。
- 橙の茶色 … 水堀に架かる補修橋の上面。古い石橋に木の板を継ぎ足した跡。
- 石の粒の印があるマス … 膝の高さまでの瓦礫、崩れた石積み（5か所）。1マスの菱形の中に収める。
- いちばん暗いマス … 砦壁の基礎石、または暗い木の根と密な下草（盤面の角と数か所）。
  ここは通れない場所なので、ほかの床より一段暗くする。ただし高い壁や木の幹は描かない。

【見やすさ】
- 通れる床（石畳・土・苔）は、通れない場所（水堀・暗いマス）よりはっきり明るく。
- 画面を縮小しても、マスの区切りの見当がつくくらいに。ただしマス目の線や光る線は描かない（ゲーム側で重ねる）。
- 石畳を全面同じ模様にしない。補修跡・轍・苔で場所ごとに変化を付ける。

【描かないもの】
- 高い木、壁、門、柱、旗、たいまつ、橋の欄干、道標、屋根
- キャラクター、台座、印、UI、文字、マスの番号
- 血、死体（戦争の傷は補修跡・ひび・欠けた石で表す）

【画風と色】
- 落ち着いたダークファンタジーのゲーム背景。細かさより、形と明暗が読めることを優先。
- 床は灰色と鈍い褐色が中心。周りは黒紫と深い緑。
- 青・赤・緑の強い光を飾りに使わない。
```
