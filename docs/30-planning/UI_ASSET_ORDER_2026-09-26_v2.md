## 2. 毎回はじめに貼る文

```
ダークファンタジーのシミュレーションRPG（百年戦争・スマホの横画面で遊ぶ）のUI素材を作ってください。
添付のゲーム画面（黒紫の地に細い金の罫線）の雰囲気に合わせてください。

【雰囲気】
- 上品で落ち着いた、資料や古書のような意匠。派手さより品のよさを優先。
- 地の色は黒に近い深い紫〜紺（#0e0b1a〜#04060e くらい）。
- 線は金（#c8922a〜#d6a740）。飾りは最小限（角に小さな菱形くらい）。

【やってほしくないこと】
- 光沢、つや、金属の立体感、ベベル（面取りの立体表現）
- 光のにじみ、発光、ネオン、グロー、レンズフレア
- 太い縁取り、重たい装飾、宝石
- 素材の外側に落ちる影
- 文字

【書き出し】
- PNG、背景は透明。1回に1つの素材。
- 指定の大きさで作る。ちょうどの大きさで作れない場合も、縦横の比率は必ず守る。
- 絵は画像の端まで使う（周りに余白を残さない）。
```

## 3. 素材ごとの指定

### A5 顔枠（3種）

ゲームでは **36×36px ほどに縮めて**、左端に縦に並べて使う。縮めても形が分かることを最優先にする。

```
味方一覧に並べる、顔アイコンの枠を3種類作ってください（通常・選択中・行動済み）。

- 大きさ: 各144×144px（正方形）。背景も、枠の中（顔が入る部分）も透明。
- 枠: 金の線を1本だけ。線の太さは画像の幅の4%（約6px）。四隅に小さな菱形を1つずつ。それ以外の飾りはなし。
- 通常: 落ち着いた金（#c8922a）。
- 選択中: 明るい金（#f0d08a）。光・にじみは付けず、色の明るさだけで区別する。
- 行動済み: 暗い、灰色がかった金（#6e5a38）。
- 3枚とも、線の太さ・菱形の形と位置は同じにする（色だけ変える）。
```

### B1 ボタン（主・実行）3種

```
「実行」ボタンの枠を3種類作ってください（通常・押した時・使えない時）。

- 大きさ: 各440×80px（横5.5：縦1）。背景は透明。文字は入れない。
- 形: 角をわずかに落とした横長の帯。
- 色: 落ち着いた金〜赤銅の帯（#7a4a1c〜#4e2712 くらい）に、細い金の縁（#d6a740）。**紫は使わない。**
- 飾り: 左右の端から24pxの中に、小さな菱形を1つずつ置いてよい。
  **上下の辺の真ん中には何も置かない**（ゲームが帯の真ん中を横に伸ばして使うため、真ん中は飾りのない単純な線にする）。
- 通常: 上の色のまま。押した時: 全体を少し暗く。使えない時: 彩度を落として灰色に近く。
- 光・つや・にじみ・影は付けない。
```

### B2 ボタン（副・戻る）3種

```
「戻る」ボタンの枠を3種類作ってください（通常・押した時・使えない時）。必ず3枚そろえてください。

- 大きさ: 各440×80px（横5.5：縦1）。背景は透明。文字は入れない。
- 形: B1と同じ形。
- 色: 地はほぼ透明な黒紫（#0e0b1a を不透明度40%くらい）。縁は細い金の線（#c8922a）だけ。
- 飾り: B1と同じく、左右の端から24pxの中だけ。**上下の辺の真ん中には何も置かない。**
- 通常: 上のまま。押した時: 地を少し濃く。使えない時: 縁を暗い灰色に。
- 光・つや・にじみ・影は付けない。
```

### D1〜D6 盤面の範囲マス・選択枠・移動先の印

盤面の1マスに重ねる。ゲームでは **1マス約36pxに縮めて**使う。線がマスの縁ぴったりに来るように、光や線を画像の外にはみ出させない。

```
シミュレーションRPGの盤面の1マスに重ねる印を作ってください。{D1〜D6 のどれか}

- 大きさ: 256×256px（正方形）。背景は透明。
- 1マスに縮めて使うので、線は太めに: 線の太さは画像の幅の6%（約16px）。
- 線の外側の端は、画像の端から2%（約5px）の位置。光や飾りは線の内側に収め、外にはみ出させない。
- 光沢・にじみ・影は付けない（色の面と線だけで見せる）。
```

| 番号 | 素材 | 中身 |
| --- | --- | --- |
| D1 | 移動範囲のマス | 半透明の青の面（不透明度35%）＋青の線（上の太さ）。色 #4d8cff |
| D2 | 攻撃範囲のマス | D1の赤版。色 #e0483c |
| D3 | 補助範囲のマス | D1の緑版（回復・結界など）。色 #3fbf82 |
| D4 | 選択枠（味方） | 面はなし（中央は透明）。青の線だけ＋四隅の内側に小さな金の角飾り |
| D5 | 選択枠（敵・攻撃の相手） | D4の赤版 |

## 4. 提出前に確認すること（ChatGPT自身で）

- [ ] 大きさ（または縦横の比率）が指定どおり
- [ ] 背景が透明（白や灰色が残っていない）
- [ ] 光沢・光のにじみ・影がない
- [ ] 紫を使っていない（B1）
- [ ] ボタンの上下の辺の真ん中に飾りがない（B1・B2）
- [ ] 3種類そろっている（A5・B1・B2）
- [ ] 線の太さが指定どおりで、画像の外にはみ出していない（D1〜D6）
