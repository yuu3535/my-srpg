# 会話のテキストボックスのたたき台 — メニュー画面UIデザインのチャットへの依頼（2026-11-12）

状態: **依頼（たたき台づくり）**。できた案の正式採用は原作者が決める。
書いた人: 総合担当（Claude Code）。
渡す先: claude.ai のプロジェクト「自作trpgをsrpg化計画」の中のチャット「メニュー画面UIデザイン」（Hub2 を作ったチャット）。

## なぜ頼むか

- Hub2（拠点メニュー）のたたき台は、原作者が「今までで一番ハイセンス」と評価した（2026-11-12）。
- そのため、今の会話の枠（銀細工・2026-10-03 採用）が並ぶと古く見える。
- 会話はいちばん長く見る画面なので、戦闘UIより先に会話を Hub2 と同じ見た目の決まりにそろえる。
- 戦闘UIは、そのあとに同じやり方で頼む予定。

## 下の「貼る文」の使い方

- 原作者は、下の枠の中をそのチャットに貼る。
- できれば、今の会話の画面のスクショを1枚添える。
  - 手元にある物: `prototypes/silver-ui-extension/dialogue-phone.png`
  - iPhone で撮った物でもよい。

---

```text
次は、会話（ノベル部分）のテキストボックスのたたき台をお願いしたいです。
Hub2 があまりに良くて、今の会話の枠が古く見えてしまったので、Hub2 と同じ見た目の決まり（字・線の細さ・余白・光り方・色の扱い）でそろえたいです。
（添付: 今の会話の画面のスクショ）

■ 画面
- 横画面専用。キャンバスは Hub2 と同じ 1688×780（実機の目安は 844×390 の2倍）。
- 背景は 2D の探索（オルクス城の回廊など）。その上に左右の立ち絵と台詞の枠を重ねる。
- 会話中は上下に黒い帯が入る（イベントの場面だと分かるように）。帯の色は紫を混ぜない黒。

■ 立ち絵（今の決まり。変えたい所があれば提案してください）
- 画面の左右の端に1人ずつ（最大2人が基本）。膝上くらいまでが見える大きさ。顔は 844×390 の画面で 60〜80px くらい。
- 話していない人は、絵の形の中だけ少し暗くする（透かさない）。
- 立ち絵は全員右向きで描いてあり、右に置くときは左右反転する。

■ 枠に要るもの
1. 本文の枠
   - 今は「上置き」。画面の上のほう、左右の立ち絵の間に置く。立ち絵の顔や体を隠さないため。
   - 下置きなど別の置き方がよければ、比べられるよう並べてください。
2. 名前札
   - 誰が話しているか分かるもの。話す人の側に寄せる。
3. 話す人を指すもの
   - 今は小さな吹き出しの尾。話す人の側を向く。
   - 尾でなくても、どちらが話しているか一目で分かればよい。
4. 長さの違い
   - 短い台詞（1行）と、長めの台詞（2〜3行）で、枠の大きさが変わる。
   - 3行を超えたらページ送りにする。字を小さくして詰めない。
5. 「次へ」の印
   - 押すと次へ進むことが分かるもの。
   - ページ送りのときは、ページ番号も出す。
6. 特別な話し方
   - ナレーション（名前なし。今は斜体）。
   - 携帯端末から聞こえる声（名前は「携帯端末」）。
   - 立ち絵の無い人（名前だけ）。
   - 見た目で区別できるとうれしい。
7. ログのボタン（今は左上）と、ログを開いたときの画面。

■ 文字
- 本文は 1688×780 の画面で 30px 前後（844×390 の 15px）。スマホで読める大きさを下回らない。
- 日本語は Shippori Mincho、英字だけの所は Barlow Condensed（Hub2 と同じ）。

■ 色
- 黒紫と金はオルクスの色で、UI 全体の色ではない。
  - 会話はオルクス城以外の場所でも使う。
  - 場所を選ばない色にしてもらえると助かる。
  - オルクス城のときだけ色が変わる案もあり。
- 景色に色をかけるときは、背景の色相の隣の色か反対の色にする（例: 青空に紫はかけない）。

■ 欲しいもの
- たたき台を2〜3案。オルクス城の回廊の背景の上で、左右に立ち絵がいる状態で。
- 原作者が選んだら、Hub2 のときと同じく Claude Code 向けの仕様書にまとめてほしい。
  - 中身: 座標・寸法・色・線・字、要素ごとの決まり、素材の一覧。
  - Unity（uGUI）の Canvas 1688×780 で組み込みます。
- 動き（枠が出る・名前札が切り替わる・次へ の印の動き）があれば、それも案に入れてください。
```
