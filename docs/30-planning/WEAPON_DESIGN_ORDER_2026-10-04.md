## 1. 流れ

1. **専用武器**（キャラ固有の剣など）: 原作者が ChatGPT と壁打ちして意匠を決め、**武器のデザイン画**（§3）を作る。
2. **汎用武器**（店・モブの兵の武器）: §4 の方針で、国と品質ごとにデザイン画を作る。
3. **戦闘用のSD**: キャラの探索用のSD（1枚目）と武器のデザイン画（2枚目）を添えて、「この武器を持って構える」絵を頼む（SDの発注書 §3.5 に、2枚目を足す）。
4. **全員の戦闘用のSDと武器がそろってから**、AutoSprite（課金）でまとめて動きを作る（原作者 2026-10-04）。§6 のそろったかの確認をしてから。

- 武器を先に決めるのは、戦闘用のSDを頼むときに武器がぶれないようにするため。AutoSprite の動きは武器ごと作り直しになるので、武器が決まる前に動きを作らない。

## 2. 武器の絵の決まり（全部の武器に共通）

盤面のキャラは寄りの画面で約70px。武器はさらに小さい。**小さくても形で分かる**ことをいちばん大事にする。

| 項目 | 決まり | 理由 |
|---|---|---|
| 形 | **シルエット（黒く塗りつぶした形）だけで何の武器か分かる**。鍔・刃先・柄頭などの特徴を大きめに（SDなので誇張してよい） | 70px では細かい模様は消える |
| 大きさ | 片手剣はSDの背の 0.6〜0.7 倍、大きい剣・槍・杖は 0.9〜1.2 倍、短刀は 0.35 倍くらい。**同じ種類の武器は、持ち主が違っても大きさをそろえる** | 盤面で強さの見た目がばらつかない |
| 輪郭 | SDと同じ**太めの濃い紫〜紺の線**（真っ黒にしない）。内側の線は細め | キャラと一体に見える |
| 塗り | SDと同じ**2〜3段のアニメ塗り**。刃の光は1本の白い線くらい | 画風をそろえる |
| 色 | 武器ごとに**1つ目立つ色（差し色）**を決める。持ち主のキャラの色に合わせる | 小さくても誰の武器か分かる |
| 入れないもの | **光・炎・オーラ・刃の軌跡・魔法の輝き**（エフェクトはゲームで重ねる）。文字・数字 | SDの方針と同じ（地面に溶けて見えにくくなる原因だった） |
| 細かさ | 彫り・宝石・模様は**大きく少なく**（宝石なら1つ大きく） | 小さくすると模様がにじむ |

### 国の意匠

| 国 | 金属・色 | 飾り | 使わないもの |
|---|---|---|---|
| オルクス（魔物の国） | 黒〜黒紫の金属、暗い金、深い紫 | 魔物のツノ・蛇・冠・6枚の翼（王家の紋章）、とがった形 | 百合・獅子・十字・鷲（世界観の決まり） |
| アルストロ | 白い鋼・銀、金の縁、青 | 白い石の国らしい、すっきりした直線と円 | オルクスの紋章 |
| どこでもない（旅人・傭兵・古い物） | 鉄・鋼・革・木 | 飾りなし。使い込んだ傷・巻いた布 | 国の紋章 |

## 3. 専用武器

### 3.1 一覧（意匠は壁打ちで決める）

| 持ち主 | 武器 | いま決まっていること | 壁打ちで決めること |
|---|---|---|---|
| **ギュンター** | 片手剣 | オルクスの騎士。右手で持ち、刃先を下に向けて落ち着いて構える（SDの発注書 §4） | §3.3 |
| ベル（幼いギュンター） | 体に対して大きい片刃の剣（新米の剣） | 紫の柄、黒い鍔。背中に背負う（SDの発注書 §4） | ギュンターの剣とのつながり（同じ家の剣か、別の剣か） |
| アルシェ | 黒陽の双剣（2本） | 父上からもらった剣（プロローグ）。名前に「黒陽」 | 形・色・2本の違い、持ち方（双剣） |
| カリマ | 剣 | アルシェと対になる剣か（戦技の設計に「白陽の加護」がある） | 黒陽の双剣と対にするか |
| アルバス | 最初から持っている剣 | 魔法で戦う（SDの発注書では戦闘のとき剣を持たない）。腰に小さな短剣 | 剣と短剣のどちらを戦闘用のSDに持たせるか |
| リングホルム | ぼろい短刀（最初） | 勇者の、初期のぼろい短刀（原作者 2026-10-04）。SDの発注書は片手剣になっている | 短刀にするか、物語の途中で剣に替わるか |

- 決まったら、この表と SDの発注書 §4 の「戦闘のとき」を書き換える。

### 3.2 武器のデザイン画の依頼文（決まった意匠を絵にする）

```
ゲームの戦闘で、キャラクターが持つ武器のデザイン画を1枚描いてください。

【武器】
- 名前: 〈武器の名前〉（〈持ち主〉の武器）
- 種類と大きさ: 〈例: 片手剣。持ち主の背の 0.65 倍くらい〉
- 形: 〈壁打ちで決めた形〉
- 色: 〈金属の色〉、差し色は〈色〉
- 飾り: 〈1〜2か所。大きく〉

【描き方】
- 武器だけを、刃先を上にして真っすぐ縦に置いた正面の絵。右に同じ武器を真横から見た絵を小さく並べる。
- 太めの濃い紫〜紺の輪郭線、2〜3段のアニメ塗り。添付のSDのキャラと同じ絵柄。
- 小さくしても形で分かるように、鍔・刃先・柄頭を大きめに、模様は大きく少なく。
- 光・炎・オーラ・軌跡などのエフェクト、文字は描かない。背景は透明（できなければ真っ白）。
- 1024×1024 の正方形。
```

- 添える絵: 1枚目に持ち主の探索用のSD（画風と大きさを合わせる）。壁打ちで作った意匠の絵があれば2枚目に。

### 3.3 ギュンターの剣（最初）

**壁打ちの出だし（ChatGPT に渡す）**:

```
自作のダークファンタジーのSRPGに出てくる、騎士ギュンターの片手剣の意匠を一緒に考えてください。3案ください。

【ギュンター】
- 魔物の国オルクスの騎士（大人の男性・魔族）。まじめで少し不機嫌そう。右目に黒い眼帯、琥珀色の左目、短い紫の髪。
- 紫の長いコート（銀の縁取り）、白いクラバットに紫の宝石。
- 主人公（王子アルシェ）たちの剣の師で、守り役。幼いころ（ベル）は新米の大きい片刃の剣を背負っていた。

【決まり】
- オルクスの意匠: 黒〜黒紫の金属、暗い金、深い紫。魔物のツノ・蛇・冠・6枚の翼の紋章。百合・獅子・十字・鷲は使わない。
- 盤面ではとても小さく見えるので、シルエットで分かる形（鍔・柄頭に特徴）。差し色は1つ。
- 片手剣。派手すぎない、実直な騎士の剣。コートの銀と紫の宝石に合わせる。

3案それぞれに、名前・形（刃・鍔・柄・柄頭）・色・飾り・物語での意味を書いてください。
```

- 総合担当からの案の種（壁打ちの材料。採用ではない）:
  - **A 銀の縁の騎士剣**: 細身の両刃、黒紫の柄、銀の鍔は翼を閉じた形、柄頭に紫の宝石（クラバットと同じ）。
  - **B ツノの鍔の剣**: 鍔が左右に曲がる魔物のツノの形。刃は鈍い鋼、柄は紫の革巻き。
  - **C ベルの剣を打ち直した剣**: 新米の片刃の剣の名残（紫の柄・黒い鍔）を残し、騎士になって両刃に打ち直した。物語のつながりが出る。
- 決まったら §3.2 でデザイン画 → SDの発注書 §3.5 で戦闘用のSD（1枚目 探索用のSD、2枚目 デザイン画）。

## 4. 汎用武器（店・モブの兵の武器）の方針

- 武器種で強さは変わらない（三すくみなし）。**見た目で分けるのは「国」と「品質（低・中・高）」**。

| 品質 | 武器威力の尺度 | 見た目 |
|---|---|---|
| 低（3） | 安い・古い | 鉄色、飾りなし、刃こぼれ・巻いた布・木の柄 |
| 中（6） | 標準 | 鋼色、国の色の柄・簡単な縁取り |
| 高（10） | 上等 | 国の意匠（オルクス: ツノ・翼の鍔、アルストロ: 金の縁と円）、大きな宝石1つ |

- 種類ごとの形の基本（シルエットで分ける）:

| 種類 | 形 |
|---|---|
| 剣 | まっすぐな刃・十字の鍔。片手剣と大きい剣（両手）の2つの大きさ |
| 槍 | 長い柄・葉の形の穂先。オルクスはとがった返し付き |
| 斧 | 片刃の大きな刃。柄は槍より短い |
| 弓 | 弓と腰の矢筒。オルクスは黒い反った弓、アルストロは白い木の弓 |
| 杖（魔法武器） | 先に大きな宝石か飾り。オルクスは三つまた、アルストロは青い宝石の金の杖（今のモブと同じ） |
| 魔核 | 体の器官なので**武器の絵はない**（魔法を使うときは手を前に出す。光はゲームで重ねる） |

- 今のモブの兵（SDの発注書 §4.6）はもう武器を持った姿で頼んである。汎用武器のデザイン画は、**店で買う武器のアイコンや、名前のあるキャラが汎用武器に持ち替えるとき**に使う。急がない。
