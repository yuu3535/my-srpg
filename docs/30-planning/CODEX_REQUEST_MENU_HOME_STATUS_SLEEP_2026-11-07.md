## 1. なぜ変えるか（原作者の考え）

- メニューは作中の**携帯端末（スマホ）**。アルシェとカリマが現代っ子でタイムスリップしていることの表現であり、現実のプレイヤーとキャラクターをつなぐ接点。だから「ゲームのボタンの板」ではなく「本物のスマホ」に見せたい。
- スマホに**戻るボタンはない**が、**スリープボタンはある**。閉じる操作はスリープボタンにする（四角い「戻る」や、下の細い横線＝ホームバーは使わない。OSのジェスチャーとぶつかる・分かりにくい・世界観に合わないため）。
- **所持金・名声をアプリにする意味は薄い**。「開いて使う物」ではなく「ちらっと見る数字」なので、スマホでいえば通知のバーやウィジェットに出る情報。上の段の状態表示へ移す。
- あいたアプリの列の右端（右下）にスリープを置く。右下は、探索でメニューを開く「端末」ボタンと同じ場所で、横持ちの右手の親指が届く所。「同じ所で開いて、同じ所で閉じる」になる。

## 2. お願いしたいこと（`アイコン素材/携帯端末メニュー画面素材/メニューホーム_独立アプリ01/`）

### 2-1. 所持金・名声を、アプリの列から上の段へ

- アプリの列から「所持金」（`data-home-app="wallet"`）と「名声」（`renown`）を外す。残るアプリは **設定・運命予報・？？？** の3つ。
- 上の段（`#home-status-row`：持ち主の点・章・場所・右端に時間帯の飾り）に、**所持金と名声を小さな数字の表示**として入れる。場所の名前と時間帯の飾り（844×390基準で x712〜）のあいだのすき間に収める。
  - 見た目の例: 小さな絵（今のアプリの絵を小さくしたもの、またはコードで描く印）＋数字。「残金 —」「名声 —」の今の数字表示をそのまま使ってよい。
  - 目立たせすぎない。章・場所の文字より一段控えめ。時間帯の飾りとぶつけない。
  - 押したときに今の詳細（ダイアログ）が開く作りなら、それは残す（数字を押すと同じ詳細が開く）。押せる範囲は実寸44px四方以上。
- 場所の名前が長い場合（例: 「オルクス城・回廊」より長い名前）でも重ならないよう、場所の名前を省略（…）するか、数字の表示を詰めるかを決めてほしい。

### 2-2. 右下にスリープボタン（月）

- アプリの列の右端（右下）に**スリープボタン**を置く。アプリとは役割が違うので、アプリの絵の並びとは少し離し、細い区切りの線などで分ける（アプリの1つに見えないように）。
- 見た目: **細い金の線の三日月＋小さな星**。黒・アンティークゴールド・淡いアイボリー（アルシェ）、カリマは今のカリマの配色（白地・青灰／銀）に合わせる。強い発光・点滅はしない。
  - 演出担当の試作 `メニュー開閉演出_比較01/sunfan.html` の「戻るボタン：D スリープ（月）」に同じ月の絵がある（SVG。`sunfan.html` の `.style-d`）。そのまま使ってよい。上の段の時間帯の飾り（太陽）と「太陽と月」の対になる。
  - 文字（「スリープ」）を添えるかは任せる。添えるなら11px以上。
- 押せる範囲: 実寸で44px四方以上。スマホの safe-area（右・下）にかからない。今の戻るキーの大きさの計算（`home-model.js` の `returnLayout`：縮尺と safe-area から実寸44pxを確保）が使える。
- 押したとき: 少し縮んで戻る（0.94倍）、金の縁が一度だけ柔らかく光る。粒子や強い光はなし。
- 押したら、**親（開閉演出のページ）へ `{type:'menu-transition-sleep'}` を送る**（埋め込み `embed=transition` のときだけ）。画面が暗くなってしまう演出は親が行う。ホームの中では演出しなくてよい。
  - 詳細のダイアログが開いているときは、今の戻るキーと同じく「一段戻る」（ダイアログを閉じる）だけにして、親へは送らない。
  - 連打で二重に送らない（一度送ったら、親から次の設定が届くまで押せなくする、など）。
- 単体のホームのページ（埋め込みでないとき）では、押しても何もしない／表示だけでよい。

### 2-3. 今の「戻るキー」

- 右下の戻るキー（`#home-return`、`returnKey` の設定）は、スリープボタンに置きかわる。⑤（`sunfan.html`）はもう使っていない（`returnKey.enabled:false` を送っている）。
- ④の比較ページ（`index.html`・`transition.js`）は今も `returnKey.enabled:true, visible:false`（空き枠だけ使う）を送っている。スリープボタンの場所と重ならなければ、そのままでよい。不要になったら演出担当が④側を直すので、消すかどうかは知らせてほしい。

## 3. 変えないでほしいこと

- 左の太陽盤（素材・位置・大きさ・回し方）、コマンドの並びと選ぶときの見た目。
- 運命予報の帯、場所の絵（今日のタスク）、背景、アプリの絵（設定・運命予報・？？？）。
- 開閉演出との通信（`menu-transition-config` / `menu-transition-motion` / `menu-transition-escape` / `menu-transition-settings` / `menu-transition-ready`）の形。特に:
  - `menu-transition-motion` の `items` は**13個のまま**受け付けてほしい（親が13個を送っている）。並びは 0〜4 太陽盤、5 上の段、6 運命予報の帯、7 場所の絵、8〜12 アプリの列。アプリが3つになったら、8〜10 を左から3つのアプリに、12 をスリープボタンに当て、11 は使わない（無視）。上の段に入れた所持金・名声は 5（上の段）と一緒に出す。
  - 親は送り元のウィンドウと origin を確かめている。`menu-transition-sleep` も同じ送り方でよい。
- ゲーム本編（`index.html`・`game.js`・`style.css`）と `unity-prototype/`。元の画像。

## 4. 終わったら知らせてほしいこと

- 変えたファイル、上の段の所持金・名声の位置と大きさ（844×390基準）、スリープボタンの位置と押せる範囲。
- `menu-transition-sleep` を送るようにしたこと。
- 確かめた範囲（Node の検証、ブラウザで見たか、スマホの実機か）。

受け取ったら、演出担当が `sunfan.html` 側でスリープの合図を受けて「画面が暗くなる→しまう→探索へ戻る」（0.3秒）につなぎ、今は親の側に重ねて置いている仮の月のボタンを外す。
