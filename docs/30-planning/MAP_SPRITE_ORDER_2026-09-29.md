# 盤面のキャラの絵（モーション用の元の絵）発注書（ChatGPT向け）

作成: 2026-09-29 / 総合担当（Claude Code）
状態: 発注用（原作者が ChatGPT に渡す）。方針: `docs/10-design/map/MAP_SPRITE_ART_DIRECTION_2026-09-29.md`
最初の4人（原作者 2026-09-29）: **リングホルム（大人・女性）・アルバス（大人・男性）・ギュンター（大人・男性）・ベル（子ども・男性。幼いギュンター）**。4人とも原作者が描いた絵があるので、画風をそろえやすい。アルシェは百年戦争編の原作者の絵がないため、あとで（原作者が自分で描く）。

## 1. 何を作るか

- AutoSprite に渡す**元の絵**を、1キャラ1枚。SD（大人3頭身・子ども2.5頭身）の全身、斜め前・右向きで、武器を持って立つ絵。
- ChatGPT には**動きは作らせない**（動きは AutoSprite で作る）。
- 4人を**同じ画風・同じ頭身・同じ大きさ**にそろえるのが一番大事。1人目ができたら、2人目からは1人目の絵も「画風の見本」として添える。

## 2. 渡すもの

| B SDの画風の見本（2人目から） | 頭身・線の太さ・塗り・大きさ | 1人目にできたSDの絵 |

| キャラ | 原作者の絵 |
|---|---|
| リングホルム | `リングホルム(通常衣装).png` |
| アルバス | `アルバス(通常).png` |
| ギュンター | `ギュンター.png` |
| ベル | `ベル立ち絵.png` |

- **原作者の絵のポーズは、市販のゲームのキャラのポーズをなぞって描いたもの**（原作者 2026-09-28）。見本からポーズを写させない（依頼文でポーズを指定する）。

## 3. 依頼文（共通の部分）

キャラごとの部分（§4）を〈キャラごと〉に貼って、そのまま渡す。

```
ゲームのマップ（盤面）に立たせるキャラクター〈名前〉の、SD（デフォルメ）の全身の絵を1枚描いてください。
この絵をもとに、別のツールで歩く・攻撃するなどのアニメーションを作ります。
添付の絵は、服装・髪型・髪と目の色・飾り・顔の特徴を合わせるための見本です。ポーズは写さないでください。
〈2人目から: 2枚目は、同じゲームの別のキャラのSDの絵です。頭身・線の太さ・塗り方・キャラの大きさを、この絵とそろえてください。〉

【形】
- 〈大人: 3頭身 ／ 子ども: 2.5頭身〉のSD。頭を大きく、顔がはっきり分かるように。
- 頭のてっぺんから足先まで全身。体は斜め前（3/4）で、画面の右を向く。
- 1024×1024 の正方形。キャラは真ん中に置き、足先は下から約8%の所、頭のてっぺんから足先までがキャンバスの高さの約80%。
- 背景は透明（できなければ真っ白）。地面の影は描かない。

【ポーズ】
- 戦いの前の、構えた立ち姿（待機のポーズ）。両足を少し開いて、しっかり立つ。
- 腕と脚を体から少し離し、手足が重ならないようにする（あとで動かしやすいように）。
- 〈キャラごと: 武器と持ち方〉

【絵柄】
- 太めの濃い紫〜紺の輪郭線（黒ではない）。内側の線は細め。
- はっきりしたアニメ塗り。影は2〜3段で、ぼかしは少なめ。
- 色は見本と同じ。ただし小さく表示しても地面から浮くように、服の色は少しだけ強めに。
- 目は切れ長で、瞳に小さな光。

【描かないもの】
- 魔法の光・炎・オーラ・刃の軌跡などのエフェクト。
- 文字・枠・背景の模様・地面の影。

【キャラクター】
〈キャラごと〉
```

## 4. キャラごとの部分

### リングホルム（大人・女性。1人目におすすめ）

```
- 名前: リングホルム（大人の女性。小柄）
- 髪: 長い黒髪（腰まで）。頭のてっぺんに1本はねた毛。前髪は目にかかる。
- 目: 赤い瞳。表情は余裕のある小さな笑み。
- 服: 赤い胸だけの短いトップス（肩を出す。裾に金の縁）、赤い長い手袋（ひじの上まで）、黒い首輪（チョーカー）、白い長いスカート（片側に深い切れ込み、裾は少し破れている）、茶色の太いベルトを腰に斜めにかける、黒いヒールのブーツ。
- 武器と持ち方: 片手剣を右手に持ち、刃先を斜め下に向けて構える。
```

### アルバス（大人・男性）

```
- 名前: アルバス（大人の男性。細身で背が高い。魔族）
- 髪: 肩にかかる長さの金髪。前髪を横に流し、片目に少しかかる。
- 目・顔: 切れ長で、上まぶたの線が太く、目尻が少し跳ね上がる。瞳は明るい紫で小さな白い光。伏し目がちで落ち着いた表情。耳の先が少しとがる（エルフほど長くない）。
- 服: 茶色のジャケット（前を開ける）、黒いベスト、白いシャツ、紫の宝石の付いた黒い紐のネクタイ、茶色のベルト、白いズボン（太ももに茶色のベルトが片脚に2本・もう片脚に1本）、こげ茶の革靴。
- 武器と持ち方: 魔法で戦う。剣は持たない。右手は体の前で軽く開き（魔法を放つ手）、腰に小さな短剣を下げる。
```

### ギュンター（大人・男性）

```
- 名前: ギュンター（大人の男性。魔族。騎士）
- 髪: 短い紫の髪。頭の上に、黒い羽根のような細い飾り（触角）が2本。
- 目・顔: 右目に黒い眼帯。見えている左目は琥珀色（オレンジがかった黄）。耳の先がとがる。まじめで少し不機嫌そうな表情。
- 服: 紫の長いコート（ひざ下まで。高い襟、銀の縁取り、胸に銀の留め具）、白いひだの襟飾り（クラバット）に紫の宝石、黒いベスト、黒いベルト、白いズボン、黒い革靴。
- 武器と持ち方: 片手剣を右手に持ち、刃先を下に向けて落ち着いて構える。
```

### ベル（子ども・男性。幼いギュンター）

```
- 名前: ベル（幼いころのギュンター。小さな男の子。魔族）
- 髪: 短い紫の髪。頭の上に、黒いくるりと巻いた触角が2本。
- 目・顔: 大きめの琥珀色（オレンジがかった黄）の瞳。まじめで、少しむっとした表情。眼帯はない。
- 服: 紫の半袖の上着（詰め襟、胸にポケット2つ、袖口に黒い太い折り返し）、下に白い長袖、黒いベルト、黒い半ズボン、黒い靴下、こげ茶のブーツ。
- 武器と持ち方: 体に対して大きい片刃の剣（新米の剣。紫の柄、黒い鍔）を右手で持ち、刃先を斜め下に向ける。
- 子どもなので2.5頭身。大人のキャラより背が低い。
```

## 5. できた絵を確かめること

- [ ] 頭身（大人3・子ども2.5）と、1人目の絵との大きさ・線の太さがそろっている
- [ ] 頭から足先まで入っていて、足先は下から約8%、真ん中にいる
- [ ] 斜め前・右向き。手足が体から離れている
- [ ] 見本と同じ服・髪・目の色・飾り（ギュンターの眼帯は右目、アルバスの耳の先）
- [ ] エフェクト・影・背景の模様・文字がない
- [ ] 小さく縮めても（70px くらい）誰か分かる

直すときは「〈直したい所〉だけ直して、ほかは変えないでください」と頼む。顔の小さな所（目）が直りにくいときは、会話の立ち絵のときと同じく、顔を切り出して頼み、直した所だけ貼り合わせる（`tools/tachie_face_patch.py`）。

## 6. AutoSprite で動きを作る

1. https://www.autosprite.io/app に、できた元の絵を入れる。
2. 動きを選ぶ: まず **待機（Idle）・歩き（Walk）・攻撃（Attack）・被弾（Hurt／Hit）**。攻撃は、剣のキャラは剣を振る、アルバスは手を前に出して魔法を放つ（カスタムの動きで文で指示する）。
3. 再生して確かめる: 顔・服が崩れていないか、足元の高さがそろっているか、待機がなめらかにつながるか。
4. 書き出す: PNGのスプライトシート＋コマごとのPNG（Unity 向けの形があればそれ）。
5. 置き場所: `キャラモーション/<キャラ名>/`（元の絵も一緒に）。置いたら総合担当に伝える（盤面に組み込んで、見え方を確かめる）。

- 最初はリングホルム1人で最後まで通して、盤面に置いて見え方を確かめてから、ほかの3人に進むのがおすすめ。
- 斜め後ろの絵・魔法・倒れる・勝利の動きは、4つの動きが盤面で使えると分かってから頼む。
