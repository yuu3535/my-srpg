## 0. しくみ

- ゲームは、盤面のマス目を「菱形（横2：縦1）」に変形して、その下にマップ絵を1枚敷く。
- 絵のマス目とゲームのマス目がずれると、キャラが石畳からはみ出して見える。そのため、**下絵（マス目の線と番号）の上に描いてもらう**。
- 下絵: `assets/maps/iso_trial_12x8_guide.png`（1472×880。横12マス×縦8マス、1マスは横128px・縦64pxの菱形）
- 今は仮の絵（`assets/maps/iso_trial_12x8.png`、石畳の台地）で動かしている。清書が届いたら同じ名前で置き換える。

## 1. 依頼文（下絵を添えて貼る）

```
添付の下絵（灰色の菱形のマス目、横12マス×縦8マス）の上に、
ダークファンタジーのシミュレーションRPGの戦闘マップを描いてください。

【いちばん大事な条件】
- 画像の大きさは下絵と同じ 1472×880 ピクセルのまま。
- 菱形のマス目の位置・大きさ・形を一切変えない。1マスの菱形が、そのままゲームの1マスになります。
- 赤い線で囲まれた菱形の範囲が戦闘する盤面。盤面の外（周りの余白）は透明にする（盤面の手前の厚みは描く）。
- 真上から見て斜め45度に回した、ドット絵寄りのアイソメトリック（斜め見下ろし）の見た目。

【描いてほしいもの】
- 森の中の古い石畳の台地。ところどころに苔や草。
- 盤面の手前の2辺には、台地の厚み（崖・石垣）が見えるように。
- 盤面の外は描かない（透明）。遠景は別の画像で用意する（原作者 2026-09-26）。

【描かないでほしいもの】
- キャラクター、敵、旗、文字、UI、マス目の番号
- 盤面の中に高い壁・木・柱（キャラが隠れてしまうため。低い草や小石程度まで）
- マス目の線（ゲーム側で薄く描きます。石畳の目地が菱形に沿っているのはよい）

【色】
- 全体は暗めで落ち着いた色。盤面の石畳は、キャラが見やすいよう周りより少し明るく。
```

## 2. 届いたあと

1. `assets/maps/iso_trial_12x8.png` に置く（下絵と同じ大きさなら、設定はそのまま）。
2. 大きさや位置がずれていたら、Claude Code が `isoView` の値（`tileW`・`originX`・`originY`）を合わせ直す。
3. 盤面の中に高い物（壁・柱）を置く場合は、そのマスを通れないマスにする設定（`tiles` の `wall`）も必要。

## 3. 今回の試作でわかったこと（2026-09-26）

- 盤面の変形・キャラの配置・クリックは、仮の絵で問題なく動いた（真上からの表示へは「2D」ボタンで切り替え）。
- 斜め見下ろしでは、キャラの絵が奥のマスにかぶるため、キャラの絵ではなく**立っているマスを押して**選ぶ形にした。
- 高さ（段差）はまだ絵だけで、ルール（命中・移動）には効かない。高さをルールに使うなら、タイルを組み立てる方式（案B）かUnityが要る。
