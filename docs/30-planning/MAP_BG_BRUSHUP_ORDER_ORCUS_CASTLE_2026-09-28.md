## 2. 共通の方針（3枚すべて）

- **オルクスらしさ**: 黒い石（灰色や茶色の石にしない。黒〜紫がかった黒の石）、濃い紫の布、暗い金の金具。灯りは、暖かい炎（橙）と、冷たい**紫の魔灯**（魔鉱石の光）を混ぜる。
- **多種族の国**: 扉・通路・階段を人間用より少し大きく。
- **紋章**: 旗・壁掛けの紋章は、すべて §4 の紋章に替える。百合の紋・獅子・十字は描かない。
- **窓・空の向こう**: ここは魔王城の中。**遠くの丘に別の城を描かない**。
- 画風・塗り・色の雰囲気は今の絵のまま（原作者の好み）。

## 3. 窓の外の景色（マップ担当の決定 2026-09-28）

城下町の背景（`背景/オルクス城下町.png`）では、魔王城は丘の上にそびえている。そこで、城の中からの景色を次のようにそろえる。

- **回廊**（城の翼の2階）: アーチの向こうに、城の内側の中庭（噴水はそのまま）。その先の城壁の外は、**丘の下に広がる城下町の屋根と灯り**、さらに遠くに山並み。右奥に、**同じ魔王城の本丸の黒い塔**が近くに見えてよい。
- **鍛錬場**（城の中庭）: 城壁に囲まれた中庭。片側に**魔王城の本丸（黒い石の塔・紫の魔灯の窓）がすぐ近くにそびえる**。城壁の向こうは空と遠くの山だけ（城下町は丘の下なので、屋根の先がわずかに見える程度）。
- **玉座の間**: 奥の大窓の月はそのまま（外の景色は描かない）。

## 4. 依頼文

### 4.1 オルクスの紋章

```
ダークファンタジーのシミュレーションRPGに登場する、魔物の国「オルクス」の王家の紋章をデザインしてください。

【入れるもの】
- 中央上に、魔物の王の冠。
- 冠の下に、1匹の蛇。蛇の頭には魔物の2本のツノ（後ろへ反り返る角）。蛇は体をS字に曲げて縦に伸びる。
- 背後に、6枚の翼（左右に3枚ずつ。上がいちばん大きく、下へ行くほど小さい）。翼は鳥の羽ではなく、魔物らしい骨ばった翼。
- 全体は左右対称。縦長の盾の中に収めてもよいし、盾なしでもよい。

【形と色】
- 金（#d6a740）の線と面だけで描く。背景は透明。1024×1024px。
- 旗に大きく描いても、画面の隅に小さく（32px くらいに）出しても形が分かるように、シルエットをはっきり。細かすぎる模様は入れない。
- 光沢・光のにじみ・影・文字は付けない。

【避けるもの】
- 百合の紋、獅子、十字、鷲など、現実の王家の紋章に似た形。
- 可愛らしい形、漫画的な形。上品で、少し不穏な印象に。
```

2〜3案出してもらい、原作者が1つ選ぶ。選んだら `アイコン素材/紋章/オルクス紋章.png` に置く。

### 4.2 鍛錬場（訓練場・屋外・晴れた朝）

添付: 今の `背景/オルクス魔王城鍛錬場.png`、採用した紋章

```
添付の背景の絵を、次のとおりに直してください。構図・画風・塗りの細かさは今の絵のままにします。

場所: 魔物の国オルクスの魔王城の中庭にある、兵の鍛錬場。屋外。
時間: 晴れた朝（日が昇ってまもない、やわらかい光。空は澄んだ薄い青に、淡い金色の雲）。今の夕焼けを朝の空にする。

【直すところ】
- 建物と城壁の石を、黒〜紫がかった黒の石にする（灰色・茶色の石にしない）。
- 旗・天幕の紋章を、添付の紋章に替える（百合の紋・獅子・十字は描かない）。旗の布は濃い紫。
- 遠くの丘の上の城を消す。ここはその城の中。代わりに、画面の片側に、この魔王城の本丸（黒い石の高い塔。窓に紫の魔灯）がすぐ近くにそびえるようにする。
- 城壁の向こうは、朝の空と遠くの山並み。城下町は丘の下なので、屋根の先がわずかに見える程度。
- 灯りは、暖かい炎のランタンに加えて、紫の魔灯の灯籠を2〜3か所。
- 扉と階段を、人間用より少し大きく（多くの種族が暮らす城なので）。

【そのまま残すもの】
- 砂の稽古場、木の訓練用の人形、木の柵、一段高い木の演台、武器立て、樽、木箱、手前の石の通路と階段、天幕。

【描かないもの】
- 人物、文字、UI。
```
