# 2Dの探索の「調べる・話す・出口」の札 — メニュー画面UIデザインのチャットへの依頼（2026-11-14）

状態: **依頼（たたき台づくり）**。できた案の正式採用は原作者が決める。
書いた人: 総合担当（Claude Code）。
渡す先: claude.ai のプロジェクト「自作trpgをsrpg化計画」のチャット「メニュー画面UIデザイン」。Hub2・支援会話の相手選び・タイトル画面を作ったチャット。

## なぜ頼むか

- 原作者（2026-11-13）「探索できるものの選択。今のところ灰色のボタンを押す形式だけど、画面とあまり調和していない。演出を考える余地あり」。
- 今の札は、動きを確かめるための仮の物。灰色の四角に白い字（「調べる（収納箱）」）を、画面の下の真ん中に出している。
  - 実装: `Corridor2DView`（`exitButton`・`ShowAction`）、`Explore2DController`（いちばん近い物を選ぶ）。
- ほかの画面（会話の枠 H案・Hub2・タイトル）は、銀の線や金の差し色でそろってきたので、浮いて見える。

## 今の動き（変えない所）

- アルシェが近づくと、いちばん近い1つの札が出る。離れると消える。
  - 話す: 人から 一定の距離の内側。「話す（キャリー）」
  - 調べる: 調べられる物の近く。「調べる（収納箱）」
  - 出口: 扉・階段など。「回廊へ」のような行き先
- 札をタップ（Enter・スペース）で実行する。
- 会話の間・拠点メニューを開いている間は出さない。
- 画面の基準は 844×390 の2倍（1688×780）。今の札は 1688×780 で 440×68、下から 28 の所。

## 下の「貼る文」の使い方

- 原作者は、下の枠の中をそのチャットに貼る。
- 今の画面の画像（`調べる（収納箱）` の札が出ている所）を一緒に貼ると伝わりやすい。
