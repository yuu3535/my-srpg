# TRPGの魔法の仕分け（戦闘で使うか・魔核にできるか）

作成: 2026-10-02 / Claude Code（総合担当）
状態: **検討中**（仕分けは総合担当のたたき台。原作者が決める）
目的: 魔核の最初の装備を決める前に、TRPGの魔法を「戦闘で使う／使わない」に分け、戦闘で使うものを「魔核にする／魔法戦技にする／ほか」に分ける。

出典:

- 今の戦技の表: `Regarding character growth rates, skills, and combat arts/各キャラ兵種表 - 因果スキル_戦技.csv`
- 魔核の決まり: `採用版md/DAMAGE_WEAPON_ENEMY_RULES.md` §4.1・§4.2

## 0. 前提（採用済み）

- 魔核＝本人の体の器官。**1つの魔核に1種類の基本魔法**。壊れない。最初の枠はヒト・竜人2、魔物・エルフ3、最大8。一族は1枠が一族の魔核。
- 魔法戦技は戦技4枠に入れる。**使うには、その系統の魔核が要る**（例: 炎の魔法戦技には火の魔核）。
- 魔核の手に入れ方の一つが「その人の中で新しい魔核に**目覚める**」。
- TRPGの秘伝は「1回の戦闘につき一度だけ」使える。物理戦技の「1戦闘○回」と同じ形なので、魔法戦技に移しやすい。

## 1. 仕分けの物差し（案）

| 行き先 | どんな魔法が向くか |
| --- | --- |
| **魔核**（基本魔法） | 何度も使う基本の行動（攻撃・回復・守り）。多くのキャラが持ちうる。効果が単純。魔法戦技の「系統」の元になる |
| **魔法戦技** | 強い、または盤面を大きく動かす（再行動・行動不能・範囲・転移）。キャラの個性。どれかの魔核の系統の上に乗る |
| **スキル** | 使う行動ではなく、いつも効いている効果 |
| **敵・物語専用** | 戦闘で使えるが、味方が持つと壊れる・仕組みが重い。ボスやイベントで使う |
| **探索・物語用** | 戦闘では意味がない（調べる・聞く・記憶・見た目など）。消さずに、探索や会話で使う魔法として残す |

## 3. 魔核の候補のまとめ

| 段 | 魔核 | 理由 |
| --- | --- | --- |
| 確定寄り | 火・水・土・風・治癒 | TRPGの基礎魔法5つ |
| 一族の魔核 | 氷（白）・星（星飼い）・ガゼラ（ガゼラ使い） | 一族の初期値4の魔法。天空（空飼い）は天候の仕組み待ち |
| 新しく魔核にする案 | **破壊・結界** | 原作者 2026-10-02「わざわざ戦技にしなくてもよかったかも」。多くのキャラが戦技で持っていて、基本の攻撃・守りに当たる |
| さらに検討 | 補助・虚像・解除 | 軽い補助・妨害。魔核にすると「補助役」を作りやすい。戦技に残してもよい |

数: 確定寄り5＋一族3＋案2で10種。補助系まで入れると13種。

## 4. 決めてほしいこと

1. **§1 の物差し**でよいか。
2. **破壊・結界を魔核にする**場合、CSVの「破壊(戦技)」「結界(戦技)」の因果Lvは「その魔核に目覚める」に置き換えてよいか。置き換えると、そのキャラの戦技枠が1つ空く。
   - 破壊の魔核の効果: TRPGでは「装甲を壊して本体に通す」だが、この作品の戦闘の「装甲」は結界くらいしかない。「ふつうの魔法攻撃＋結界・守りの効果を壊す」、または「相手の守り（魔防）を少し無視する」などに読み替える必要がある。
3. **落雷・万雷の系統**: 魔法戦技は系統の魔核が要る決まりなので、どの魔核の上に乗るかを決める必要がある。案: 雷の魔核を新しく作る／風の系統にする／破壊の系統にする。
4. **系統のはっきりしない魔法戦技**（加速・転移・封印・誘惑・悪夢・カウンター・浮遊）: どの魔核が要るか。案:
   - A: 系統なし。どの魔核を持っていても使える。
   - B: 「空間」（加速・転移・浮遊）、「幻」（虚像・誘惑・悪夢）、「封」（封印・カウンター）のような魔核を新しく作る。
5. **勇気・発狂を戦闘に入れるか**（悪夢・誘惑・明鏡・祈りに関わる）。
6. **探索・物語用に分けた魔法**（眼識・聴音・心象・変身など）は、探索で使える魔法として後で拾うか。
7. 回復の魔法（採用版 §4.1 の検討中の項目）: この仕分けの案では「治癒＝魔核、回復(戦技)＝治癒の魔核の上に乗る魔法戦技」。これでよいか。

## 5. 原作者の決定（2026-10-03）

> 「基礎4つ＋破壊・治癒の6種だけにすると、レパートリーが少ない」ため、TRPGで誰でも覚えられる特殊魔法を汎用の魔核にする。§2・§3 の案はこの節で置き換える。

### 5.1 仕分けの結果

| 行き先 | 魔法 |
| --- | --- |
| **汎用の魔核**（15） | 火・水・土・風・治癒・破壊・結界・加速・解除・虚像・誘惑・浮遊・カウンター・悪夢・付与 |
