## 1. 役割

- 会話用の立ち絵を、ChatGPT に頼む**依頼文を作り**、届いた絵を**確かめ**、必要なら**顔だけ直して貼り合わせ**、**透過**して、ゲームで使える形にそろえる。
- 絵を生成するのは ChatGPT（原作者が依頼文と見本の絵を渡す）。決めるのは原作者。
- ゲームのコード（`game.js`・`scenario.js`・Unity）は変えない。会話の画面に組み込むのは総合担当。組み込みたい絵ができたら、総合担当に知らせる（下の §7）。

## 5. 作り方（アルバスで確立した手順）

1. **基本の絵**: 発注書 §3 の依頼文（〈 〉を埋める）と見本の絵を、原作者が ChatGPT に渡す。依頼文に**そのキャラの顔の特徴**（発注書 §2 の表）を必ず入れる。
2. **確かめる**（原作者から絵を受け取ったら）:
   - 向き（見ている人から見て右を向いた3/4）・絵柄（つやが強くないか）・服と飾り・顔の特徴（目・耳など）。
   - 前の絵と同じ絵が届いていないか（原作者が取り違えることがある。ピクセルで比べると分かる）。
   - 拡大して目を見る（ChatGPT は目の特徴を落としやすい。アルバスは瞳が灰色がかって光がなかった）。
3. **顔だけ直す**（目などが違ったとき）: 全身の絵のまま頼んでも小さな所は変わりにくい。顔を切り出して頼む。
   ```powershell
   py -3.12 tools/tachie_face_patch.py crop <全身の絵> <x> <y> <一辺> 立ち絵AI生成/会話用/<キャラ名>
   ```
   切り出した顔と、原作者の絵の顔のアップ（同じくらいの大きさに切り出す）を ChatGPT に渡し、「1枚目の目だけを、2枚目の目に合わせて描き直す」と頼む。
4. **直した所だけ貼る**: ChatGPT は切り出しの全体を少しずつ描き直すので、直した所（目と眉など）だけを貼る。
   ```powershell
   py -3.12 tools/tachie_face_patch.py paste <全身の絵> <直した顔> <x> <y> <一辺> <左> <上> <右> <下> <出力>
   ```
   貼ったあと、拡大して境目が見えないか確かめ、前と後を並べて原作者に見せる。
5. **表情の差分**: 決まった基本の絵を渡して、1つずつ頼む（§6）。届いたら基本の絵と重ねて、体の位置がずれていないか・目が元に戻っていないかを確かめる。目が崩れたら 3・4 で直す。
6. **透過**: `py -3.12 tools/tachie_studio.py`（1枚ずつ）か `tools/prepare_tachie_batch.py`（まとめて）。白い服・細い髪・とがった耳の先を重点的に目で確かめる。確かめたものだけ `立ち絵透過済み/会話用/<キャラ名>/` へ。

- 作業用の確認画像（比べる絵・拡大など）はリポジトリに置かず、チャットのスクラッチパッドに置く。
- Python は `py -3.12`。PowerShell で日本語のファイルを読むときは `-Encoding UTF8`（Read ツールを使う方が確実）。

```
この立ち絵と、ポーズ・服・髪・耳・向き・体の大きさと位置・絵柄をまったく同じにして、顔の表情だけを「〈表情〉」に変えた絵を描いてください。
```
