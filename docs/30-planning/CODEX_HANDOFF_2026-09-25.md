## 1. UI設計担当へ

### 今回行ったこと

**戦闘画面を参考UIの配置へ寄せた**（`style.css` 末尾の `[layout-ref]` 節。Codex作の既存CSSは書き換えず上書き）

| 場所 | 内容 |
| --- | --- |
| 左端 | 味方一覧 `#landscapeRoster`（`renderLandscapeRoster`）。行動済みは暗く「済」、押すと選択 |
| 左上 | フェーズ名の横に勝利条件（`getVictoryConditionText`） |
| 右 | ユニット情報欄（従来は左） |
| 下 | 横一列のコマンド（従来の扇形の針型を置き換え）と全幅の説明帯 |
| 戦闘予測 | 上部中央の小さな枠（`renderLandscapeBattlePreview` の中身を置き換え）。攻撃対象が盤面の上半分なら枠を下に出す。反撃がある場合だけ「反撃」行を追加（参考UIにない行。不要なら削る） |
| 盤面 | マップの大きさを盤面領域の実寸から計算（`sizeLandscapeBattleCanvas`） |

**コマンド**: 攻撃・魔法・戦技・持ち物・待機・詳細。特技は「戦技」（自己強化の戦技だけ）に。試験用ユニットの攻撃は「通常攻撃」とセット中の物理の戦技。

**ステータス画面（試験用ユニット）**: 個人スキル枠（控えめな「個人スキル」表記）、兵種4＋兵種固有1、因果3、戦技4。追撃欄・被追撃・MAGIC欄を削除し、LOADOUTを右列の上下に通した。

**出撃準備（ブリーフィング）画面** `briefingUi.js`、CSSは `style.css` 末尾の `[briefing]` 節

- 原作者が示した参考画像（円形メニュー）の構成を、本作の意匠で描き直した。左上「ブリーフィング」の帯、中央の円（選択中の扇形が光る）、中心「戦闘開始」、下の説明帯。マウスと矢印キー・Enterで操作。
- 項目: ユニット選択・身支度・セーブ・システム・戻る・ショップ・支援・マップ・配置。セーブ・システム・ショップ・支援は「準備中」。
- 身支度: 個人スキル（外せない）、通常兵種4、兵種固有1、因果3、戦技4の付け外し。

### 分かったこと

- 画面の文字は小さいもの（6〜8px、拡大表示前の値）が多い。原作者の実機での読みやすさは未確認。

### 提案・次にできること

## 2. 戦闘システム担当へ

### 今回行ったこと

**データを兵種表CSVから作るようにした**

- `abilityData.js`（自動生成）: 12兵種の兵種スキル、10人の兵種適性、11人の個人スキルと因果Lv5〜50の能力。条件のない能力値上昇（「技・魅力+10」など）は効果文から読み取る。
- `trialStatSystem.js` の手書きの転記をやめ、`abilityData.js` から作る。

**`SKILL_LOADOUT_RULES.md` v1.0 に合わせた点**

- 因果Lv50スキルは、専用兵種が現在兵種のときだけ兵種固有枠へ（試験は最初の兵種なので置かない）。
- 戦技型の兵種能力（威光・魔光・突撃・ブレス・投擲）は通常兵種スキル4枠に入れない。
- セット内容（selection）と付け外しの純粋処理 `trialToggleLoadoutSelection`（テストあり）。

**テスト戦闘で効果を実装したもの**（`game.js` の `[trial]` と、`trialStatSystem.js` の純粋な判定）

| 区分 | 能力 | 効果 |
| --- | --- | --- |
| 個人 | 野望 | 自分から攻撃したとき魅力×2%で反撃封じ（予測の反撃発生率にも反映）・命中+10・必殺+10。相手の反撃の命中−10 |
| 因果 | 黒・白・黄・翠の一族 | 対応属性の魔法で命中+20・1.5倍 |
| 因果 | 死神・王威 | 周囲4マスの命中・回避（王威は必殺耐性も）。死神の速さ−5は未実装 |
| 因果 | カウンター・祈り・詠唱破棄・魔法射程+1 | 各効果（確率は CSV の式） |
| 因果・兵種 | 能力値上昇 | 能力値に加算 |
| 物理の戦技 | 両断・大振り・破天・奇襲・復讐 | 1.5倍／2倍・命中−30／命中+10／相手の回避−50・追撃なし／減ったHPを威力に加算（最終ダメージに加算） |
| 魔法の戦技 | 破壊・落雷・封印・結界・虚像・加速・転移・回復・悪夢・召喚「ヒトダマ」 | 既存の同名の魔法で代用（回復→治癒）。戦技独自の数値は未実装 |

- 戦技は1撃目だけに乗り、追撃は通常攻撃。予測も「22+6」のように表示し、実際の結果と一致することを確認。
- 魔法の反撃は、セット中の魔法戦技と魔導書の魔法だけから選ぶ。

### 見つけて直した不具合

- 予測の「×2」（追撃）が魔法攻撃にも出ていた。実際は魔法攻撃に追撃がないため、物理だけに限定。
- 魔法攻撃の予測に反撃が出ていた。実際は魔法攻撃は反撃を受けない（`executeMagic` に反撃処理がない）ため、予測を物理だけに。**魔法攻撃が反撃を受けないのが意図どおりかは未確認**（原作者への確認事項）。

### 他担当・原作者へ確認したいこと

1. 魔法戦技の「単独発動型」と「上乗せ型（魔導書が必要）」の分け方（`MAGIC_ARTS_AND_GRIMOIRE_DRAFT_2026-09-25.md`）。
2. 封印の「魔防÷2の射程」、転移の「範囲は魔力÷2」は字どおりだと20マス超。
3. 魔導書を誰に持たせるか（今は仮: リングホルム・アルシェ＝火、カリマ＝治癒、アルバス＝なし）。
4. `SKILL_LOADOUT_RULES.md` への反映: 個人スキル（外せない固定枠）、Lv50スキルの扱いの実装方針、魔法の扱い（魔法戦技＋魔導書）。

### 次にできること

1. 前回の指示書の残り（`physicalPowerBonus` の位置、BattlePlan への移行）。今回の `[trial]` フックもBattlePlanへ移す対象。
2. 魔法戦技の独自効果と数値、魔導書（武器・魔導書の装備欄）のデータ。
3. 未実装の能力: 円舞・月詠・生命吸収・万雷・召喚・デュアル関連・兵種経験値・戦闘指揮・応援・剣の舞・魔神の器、兵種スキル全般（兵種Lvが未実装）。
4. 敵データの作り方（成長率・レベル）。

### 注意点

- テスト戦闘の味方4人は、スキル・戦技の習得だけ因果Lv45相当（`TRIAL_PROFILES` の `abilityLevel`）。能力値は因果Lv25〜30のまま。身支度で入れ替えを試すための原作者依頼。
- 本編（シナリオ）の戦闘は採用版ステータスに切り替わっていない。スキル効果はテスト戦闘だけ。

## 3. 総合相談担当へ

### 今回行ったこと（要約）

- 上の1・2の作業と、原作者の決定の記録（0章の表）。
- 身支度の内容をパーティ状態（`partyState.js` の `loadoutSelection`）に持たせ、セーブ・ロードで残るようにした（テストあり）。
- 本編の戦闘でも、シナリオから戦闘に入るときにブリーフィングを開く（`startBattleSession`）。プロローグのチュートリアル戦闘で「ブリーフィング → 戦闘開始 → 勝利 → プロローグ終了」まで従来どおり進むことを確認。本編では「戻る」と出撃の選択を制限し、身支度は採用版切り替え前のため使えない旨を表示。

### 正式決定が必要な項目（原作者）

1. 本編のキャラを採用版ステータスへ切り替える時期（切り替えれば本編でも身支度が使える）。
2. 本編で出撃メンバーを選べるようにするか。
3. ブリーフィングの「セーブ」を使えるようにするか（戦闘直前から再開する形になる）。
4. `ui/battle-reference-layout` と `trial/adopted-stats` を main へ統合する時期と順番。
5. 魔法攻撃が反撃を受けないのは意図どおりか。

### 注意点

- シナリオと戦闘の接続（`startChapter`・`playBattleScene`・`setBattleMode`・`resumeScenarioAfterBattle`）は変えていない。`startBattleSession` の最後でブリーフィングを開くだけ。ブリーフィング中は盤面の操作を止めている（`onUnitClick`・`onCellClick`）。
