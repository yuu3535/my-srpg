## 0. この版で変わった前提（2026-09-26 の決定）

素材の大きさ・作り方に関わる決定。ChatGPTへの依頼文にはすでに反映してある。

1. **画面は3段の重ね**（`docs/10-design/ui/UI_DIRECTION_AND_ASSET_LIST_2026-09-25.md` §6）
   - 奥: **背景**（画面の端から端まで。ゲーム画面は横2.16：縦1）
   - 中: **マップ**（盤面とキャラ。画面いっぱいに出し、動かして見る）
   - 手前: **UI**（中央の**16:9の枠**＝ゲーム画面844×390のうち約693×390の中だけに置く）
   - そのため、背景の絵が新しく要る。UIは枠の大きさが決まっているので、**伸ばさない1枚の絵**で作れる素材が増えた。
2. **戦闘予測は画面の下の帯**（原作者の見本の構成）。左右の端に顔のアップ、真ん中に交差した剣、下に「キャンセル／攻撃する／戦闘詳細」。
3. **UIの枠は上下同じ太さ**（上辺だけ太い枠は不採用）。
4. 光（にじみ・発光）は**盤面の印と演出だけ**。UIの枠・ボタンには付けない。
5. ~~駒の台座は味方＝白・敵＝黒~~ → 3Dの盤面では台座なし。足元の影と陣営の枠（D4・D5）（原作者 2026-09-27）。
6. **マップは3Dの盤面＋2Dのキャラ**（原作者 2026-09-27）。斜めの1枚絵は作らない。盤面は、真上から見た正方形の**模様**を貼ったブロックで組む。木・壁・門などの高い物は総合担当が3Dの模型で作り、模様だけ頼む。制作仕様: `docs/10-design/map/UNITY_3D_BOARD_MAP_PRODUCTION_GUIDE_2026-09-27.md`
7. **寄りの画面が基本**（原作者 2026-09-27。理想の画面の見本に合わせた）。盤面全体を1画面に収めず、キャラに寄って見る。盤面の外も透明にせず、まわりに景色（森・崖・道の続き）を置く。そのため、**模様は細かく**（M5 を 64×64点に）、**小さい物（M3）と景色の模様を増やす**。

## 3. 依頼文

### 3.0 毎回はじめに貼る文

UI（F・R・A5）のとき:

```
ダークファンタジーのシミュレーションRPG（百年戦争・スマホの横画面で遊ぶ）のUI素材を作ってください。
添付のゲーム画面（黒紫の地に細い金の罫線・明朝体）と見本の画像の雰囲気に合わせてください。

【雰囲気】
- 上品で落ち着いた、古書のような意匠。派手さより品のよさを優先。
- 地の色は黒に近い深い紫〜紺（#0e0b1a〜#04060e くらい）。
- 線は金（#c8922a〜#d6a740）。飾りは最小限。

【やってほしくないこと】
- 光沢、つや、金属の立体感、ベベル（面取りの立体表現）
- 光のにじみ、発光、ネオン、グロー、レンズフレア
- 太い縁取り、重たい装飾、宝石
- 素材の外側に落ちる影
- 文字

【書き出し】
- PNG、背景は透明。1回に1つの素材。
- 指定の大きさで作る。ちょうどの大きさで作れない場合も、縦横の比率は必ず守る。
```

マップ・盤面の印・キャラ（M・P・K）のとき:

```
ダークファンタジーのシミュレーションRPG（百年戦争・スマホの横画面で遊ぶ）の素材を作ってください。
マップは3Dの盤面（正方形のマスのブロック）を斜め上から見下ろす形で、キャラは板に貼ったドット絵です。

【共通の約束】
- 1回に1つの素材だけ作る。文字は入れない。
- 色の役割: 青＝味方、赤＝敵・危険、緑＝回復・補助、金＝線・大事なもの、黒紫＝地。
  青・赤・緑をただの飾りに使わない。
- 画風: 暗く落ち着いたダークファンタジー。キャラと盤面は見やすく、はっきりした輪郭で。
```

見本として、今のゲーム画面のスクリーンショットと、原作者の見本の画像（戦闘予測の構成）を添える。

### K1 カリマの盤面の絵

```
斜め見下ろしのマップに立たせるキャラクター「カリマ」の全身の絵を作ってください。
添付の、今の白い背景のカリマの絵と同じ見た目（白い髪・左右で色の違う目・白いシャツに黒いベスト・紫のネクタイ）で、
背景だけを透明にした絵がほしいです。

- 画像の大きさ: 1024×1024px、背景は透明（白い背景にしない。髪の間や腕の内側も透明に）。
- 足の裏が画像の下から4%くらいの位置、横の中央に来るように立たせる。頭の上は少し余白を残す。
- 体はやや右向き（斜め前）。魔法の光は体のまわりに収め、画像の端で切れないように。
- 画風は添付の他のキャラの盤面の絵に合わせる（等身の低いドット絵風）。
```

添付: `立ち絵AI生成/幼少期カリマドット.png`（今の白い背景の絵）と、ほかのキャラの盤面の絵（例: `立ち絵AI生成/アルバスドット.png`）。

### F1 戦闘予測の帯の枠

ゲームでは **681×132px** で出す（16:9の枠の幅いっぱい）。大きさが決まっているので、伸ばさない1枚の絵でよい。

```
戦闘の予測を出す、画面の下の横長の帯の「枠」を作ってください。

- 大きさ: 2724×528px（横5.16：縦1）。背景は透明。
- 地: 黒に近い深い紫（#0e0b1a）、不透明度90%くらい。ムラの少ない、ごく薄い質感。
- 縁: 細い金の線を2本（外側と、その少し内側）。上下左右とも同じ太さ。
- 四隅: 金の細い唐草のような飾り。角から120pxの中に収める。
- 上の辺と下の辺の真ん中に、小さな金の飾り（菱形くらい）を1つずつ。
- 帯の中（顔の絵・文字・数字が入るところ）には何も描かない。
- 光沢・光のにじみ・影は付けない。
```

見本の画像の、下の帯の枠の雰囲気（細い金の線と四隅の唐草）に合わせる。

### M1 戦闘の背景（奥の層）

マップ（盤面）の**後ろ**に敷く絵。盤面はこの上の真ん中に乗る。画面の端から端まで見える。

盤面は90°ずつ回して見るので、**どの向きから見ても違和感のない、向きのない絵**にする（特定の建物や地平線の向きに頼らない）。

```
シミュレーションRPGの戦闘画面の、いちばん奥に敷く背景の絵を作ってください。
この上に、3Dの戦闘マップ（石畳の台地）を重ねます。マップは90°ずつ回して見るので、向きのない絵にしてください。

- 大きさ: 3376×1560px（横2.16：縦1）。ちょうどが無理なら、横2.16：縦1の比率で作れる大きさで。
- 舞台: 暗い森の奥。木々の幹と葉が画面のまわりを囲み、奥は霧に溶ける。かすかな月明かり。特定の建物・道・地平線は描かない。
- 真ん中（横の中央60%・縦の中央70%くらい）には、盤面が乗るので、細かい物や明るい物を置かない。暗く、模様の少ない所にする。
- 画面の左右の端と上の端は、さらに暗く沈める（UIの文字が読めるように）。
- キャラクター、建物の中、文字、UI、マス目は描かない。
- 色: 黒紫と深い緑が中心。青・赤・緑の強い光を飾りに使わない。
```

- ChatGPTで横2.16：縦1が作れないときは、横に長い大きさで作ってもらい、Claude Codeが上下を切る（大事な物は真ん中に置いてもらう）。
- M1は、マップ担当が決めた舞台（今の推奨は「百年戦争跡の国境監視路」）に合わせる。舞台の説明をマップ担当の文書から差し替えてよい。

### M3 小さい物の板の絵

3Dの盤面の上に、キャラと同じく板に貼って立てる小さい物（草むら・花・旗・道標など）。高い物（木・壁・門）は3Dの模型で作るので頼まない。

```
3Dの戦闘マップの上に立てる「{草むら／花／旗／道標 など}」を1つ描いてください。板に貼って、いつもこちらを向く形で使います。

- 大きさ: 256×256px、背景は透明。
- 物の足元（地面に接する所）を、画像の下端の中央に置く。横から見た形（正面の姿）で描く。
- 画風: 暗く落ち着いたダークファンタジーのドット絵。キャラの盤面の絵に合わせる。
- 地面に落ちる影は描かない。
```

### M5 盤面の模様（天面8種・側面2種＋景色の3種）

3Dの盤面のマス（ブロック）の面に貼る模様。**1マスに1枚**を、ぼかさずに拡大して貼る。今は仮の模様（ツールで描いたもの）で動いているので、同じ名前・同じ大きさで差し替える。
ゲームでの大きさは **64×64点**（2026-09-27 に32×32から変更。寄りの画面では1マスが大きく見えるので、原作者の理想の画面のように石・草を細かく描く）。ChatGPTには、512×512で「8×8の点を1つの点として」描いてもらい、Claude Codeが64×64に縮める。
