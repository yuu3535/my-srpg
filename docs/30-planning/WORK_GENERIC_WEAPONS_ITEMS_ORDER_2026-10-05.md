## 1. 汎用武器（店で買う武器・持ち替える武器の絵）

### 1.1 描き方（全部に共通）

| 項目 | 決まり |
|---|---|
| 大きさ | 正方形 1024×1024。背景は透明（できなければ真っ白） |
| 置き方 | **斜め45°**: 柄（持つ所）が左下、刃先・穂先が右上。1枚に武器1つ。画面の8割くらいの大きさで、真ん中に |
| 形 | **黒く塗りつぶした形（シルエット）だけで何の武器か分かる**。鍔・刃先・柄頭などの特徴を大きめに |
| 輪郭 | 太めの濃い紫〜紺の線（真っ黒にしない）。内側の線は細め |
| 塗り | 2〜3段のアニメ塗り。刃の光は白い線1本くらい |
| 入れない物 | 光・炎・オーラ・刃の軌跡・魔法の輝き、文字・数字、持つ手、台・背景・影 |
| 細かさ | 彫り・宝石・模様は大きく少なく（宝石なら1つ大きく）。小さく縮めても形が崩れないように |

### 1.2 種類（形で分ける）

| 記号 | 種類 | 形 |
|---|---|---|
| sword | 片手剣 | まっすぐな刃・十字の鍔 |
| greatsword | 大剣（両手） | 片手剣より長く幅の広い刃・長い柄 |
| dagger | 短刀 | 短い刃・小さな鍔 |
| spear | 槍 | 長い柄・葉の形の穂先 |
| axe | 斧 | 片刃の大きな刃・槍より短い柄 |
| bow | 弓 | 弓だけ（矢筒は描かない） |
| staff | 杖（魔法の武器） | 先に大きな宝石か飾り |

### 1.3 国と品質（見た目で分ける。武器の種類で強さは変わらない）

| 国 | 金属・色 | 飾り | 使わない物 |
|---|---|---|---|
| plain（どこでもない・旅人・傭兵） | 鉄・鋼・革・木 | 飾りなし。使い込んだ傷・巻いた布 | 国の紋章 |
| orcus（オルクス・魔物の国） | 黒〜黒紫の金属、暗い金、深い紫 | 魔物のツノ・蛇・冠・6枚の翼、とがった形。槍はとがった返し付き、弓は黒い反った弓、杖は三つまた | 百合・獅子・十字・鷲 |
| alstro（アルストロ） | 白い鋼・銀、金の縁、青 | すっきりした直線と円。弓は白い木の弓、杖は青い宝石の金の杖 | オルクスの紋章 |

| 品質 | 見た目 |
|---|---|
| low（低） | 安い・古い。鉄色、飾りなし、刃こぼれ・巻いた布・木の柄 |
| mid（中） | 標準。鋼色、国の色の柄・簡単な縁取り |
| high（高） | 上等。国の意匠をはっきり、大きな宝石1つ |

- `plain` は low と mid だけ（high は作らない）。

### 1.4 作る順

1. **最初の1枚**: `common_weapon_sword_plain_low` を作って止める（原作者が色・細かさ・線の太さを決める）。
2. plain の low・mid（7種類×2 = 14枚）
3. orcus の mid・high（7種類×2 = 14枚）
4. alstro の mid・high（7種類×2 = 14枚）
5. （あとで）orcus・alstro の low

- ファイル名: `common_weapon_<種類>_<国>_<品質>.png`（例 `common_weapon_spear_orcus_high.png`）。同じ物の別案は末尾に `_b`。
- 置き場所: `立ち絵AI生成/武器/汎用/`

## 2. 汎用アイテム（消耗品・持ち物のアイコン）

### 2.1 描き方

| 項目 | 決まり |
|---|---|
| 大きさ | 正方形 512×512。背景は透明（できなければ真っ白） |
| 置き方 | 少し上から見た正面（斜め上から15°くらい）。1枚に1つ。画面の7割くらいの大きさで、真ん中に |
| 形・塗り・輪郭 | 汎用武器と同じ（§1.1）。小さく縮めて（64px）も何か分かる形 |
| 入れない物 | 光・オーラ・きらめき、文字・数字・ラベルの字、手、台・背景・影 |
| 色 | 種類ごとに1つ目立つ色。薬は瓶の中身の色で分ける（下の表） |

- アイコンを出す画面（携帯端末のメニュー）は別の担当（Codex）が作っている。枠や背景は付けず、物の絵だけを作る（枠はメニューの側で付ける）。

### 2.2 作る物（案。名前と効き目はゲームの側で決める。絵だけ先に作る）

| 記号 | 物 | 見た目 |
|---|---|---|
| potion_small | 回復薬（小） | 小さな丸い瓶・赤い薬・コルクの栓 |
| potion_mid | 回復薬（中） | 中くらいの瓶・赤い薬・紐を巻いた栓 |
| potion_large | 回復薬（大） | 大きめの瓶・赤い薬・金の栓 |
| ether | 魔力の回復薬 | 細長い瓶・青い薬 |
| antidote | 毒消し | 小瓶・緑の薬 |
| remedy | 万能薬 | 金の飾りの小瓶・白く光らない乳白色の薬 |
| herb | 薬草 | 束ねた緑の葉 |
| bread | 携帯食 | 布に包んだパン |
| bandage | 包帯 | 巻いた白い布 |
| key | 鍵 | 古い鉄の鍵（汎用。オルクスの紋章なし） |
| pouch | 金貨袋 | 革の袋・口から金貨が少し見える |
| scroll | 巻物 | 紐で結んだ巻物（字は描かない） |
| gem | 宝石（素材） | カットした宝石1つ（紫） |
| ore | 鉱石（素材） | ごつごつした鉄の鉱石 |
| bone | 魔物の骨（素材） | 白い骨1本 |
| horn | 魔物のツノ（素材） | 曲がったツノ1本 |

### 2.3 作る順

1. **最初の1枚**: `common_item_potion_small` を作って止める。
2. 回復薬・薬（potion_mid 〜 remedy）
3. 持ち物（herb 〜 scroll）
4. 素材（gem 〜 horn）

- ファイル名: `common_item_<記号>.png`（例 `common_item_antidote.png`）。別案は末尾に `_b`。
- 置き場所: `アイコン素材/アイテム/汎用/`
