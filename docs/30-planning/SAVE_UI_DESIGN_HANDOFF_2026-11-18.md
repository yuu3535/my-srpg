## 今のセーブに入っていること（画面に出せる情報）

| 項目 | 中身 |
|---|---|
| 保存した日時 | 端末の時刻（yyyy-MM-dd HH:mm） |
| 遊んだ時間 | 秒 |
| 場所の名前 | 例: オルクス城・回廊 |
| 章の名前 | 空ならプロローグ |
| 進み具合 | 0 クリア前／1 サタン撃破後／2 終幕後（タイトル画面の空・星・文が変わる） |
| 仲間 | 一人ずつの因果Lv・経験値・能力 |
| 読めない枠 | 壊れた枠・新しい版のゲームで作った枠は「読めない」と出す |

- 保存先: PC は端末の中、ブラウザ版はブラウザの保存（ページを閉じても残る）。
- 上書きは確かめてから（今もそう）。
