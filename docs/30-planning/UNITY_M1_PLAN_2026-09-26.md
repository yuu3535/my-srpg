## 2. M1の目標: 「斜め見下ろしの1マップで、1ターン遊べる」

チェックリスト§27「縦切り完成の判定」を、今のブラウザ版の決定に合わせて絞ったもの。

- 斜め見下ろしのマップ（テスト戦闘と同じ12×8）が表示される
- 味方4人（リングホルム・アルシェ・アルバス・カリマ）と敵が並ぶ
- ユニットを選ぶと移動範囲が出て、移動できる
- 右のコマンド一覧（攻撃・戦技・魔法・待機）から攻撃・魔法を選び、相手を選べる
- 戦闘予測（両者のHP・ダメージ・命中・必殺、反撃）が出て、実行するとHPが減る
- アルバスの魔法でアニメが再生される
- 敵フェーズで、敵が行動予告どおりに動いて攻撃する
- 見た目はステータス一覧の意匠（黒紫・細い金の罫線・明朝体）

**M1でやらないこと**: シナリオ・ホーム・セーブ・出撃準備・全戦技・高低差のルール・スマホ対応。

### 原作者が試す手順（3Dの盤面）

1. Unity でプロジェクトを開き、`Assets/Scenes/Battle3D` をダブルクリック。
2. Game 欄を横長にして ▶。
3. 味方のマスを押すと選べて青い移動範囲が出る。青いマス（または自分のマス）を押すと動き、左下で「攻撃」「待機」を選ぶ。「攻撃」なら赤い範囲の敵を押すと戦闘予測が出て、「実行」で攻撃する。全員が動くと敵の番になる（左下の「ターン終了」でも）。
4. 右下のボタン（または Q・E、横にスワイプ）で90°回す。「真上から見る」で真上に切り替え。
5. 試し終わったら、Claude Code が作業する前に Unity を閉じる。

### M1-b・M1-c（基本）: 戦闘をUnityへ移した（2026-09-27）

- 原作者の選択: 3Dの盤面で戦闘システムを試す場所は Unity（ブラウザ版に3Dを載せるのではなく）。
- **M1-b 戦闘の計算**: ブラウザ版の `battlePlan.js` と、使っている式（`trialStatSystem.js` の命中・ダメージ・必殺・追撃・反撃・死神・王威・野望・一族・祈り・カウンター・詠唱破棄）を C# に移した（`Assets/Scripts/Battle/Plan/`）。
  - 答え合わせ: `tools/export_unity_battle_plan.mjs` がブラウザ版を画面なしの Edge で動かし、キャラの戦闘の状態と、272通りの結果（全ての味方×敵、距離1・2、戦闘予測と乱数を決めた交戦3通り、物理の戦技）を書き出す。Unity のテスト `BattlePlanParityTests` で、全部同じ結果になることを確かめた。
  - 丸めは JavaScript と同じ（`Math.round` は .5 を上へ）。
- **M1-c（基本）**: 3Dの戦闘（`Battle3D`）で1ターン遊べる。
  - 味方: 選ぶ → 動く（自分のマスならその場）→「攻撃／待機／移動を取り消す」→ 攻撃なら赤い範囲の敵を押す → 戦闘予測 →「実行／戻る」。全員が動くと敵の番（「ターン終了」でも）。
  - 敵: 動ける先×届く相手を戦闘予測で評価し（ブラウザ版と同じ `ScoreAttack`）、いちばん良い攻撃をする。攻撃できなければ近づく。
  - ダメージの数字・ログ・倒れたキャラを消す・行動済みを暗くする・勝利／敗北。
- まだないもの（次にやる）: 戦技・魔法・持ち物のコマンド（今は装備している武器・魔導書の攻撃だけ）、敵の行動予告と狙われた赤い丸、正式なUI（今は仮の操作の欄）、攻撃の動き（演出）、地形の戦闘補正、戦闘データへの地形の書き出し。
- 作り直す手順: 静的サーバーを動かした状態で `node tools/export_unity_battle_plan.mjs` → `Srpg.EditorAgent.Battle3DBuilder.BuildAll` → テスト。
