# 会話用の立ち絵 発注書（ChatGPT向け）

作成: 2026-09-28 / 総合担当（Claude Code）
状態: 発注用（原作者が ChatGPT に渡す）。見せ方の方針: `docs/10-design/ui/DIALOGUE_STAGING_DIRECTION_2026-09-28.md`
最初の試し: **幼少期のアルシェ・カリマ**（画風と向きを決めるため。うまくいったら他のキャラへ広げる）

## 1. 何を作るか

会話の場面で、画面の左右の端に立てる**会話用の立ち絵**。1キャラにつき
1. 基本の絵（通常の表情）1枚
2. 表情の差分（同じポーズ・同じ服で顔だけ変えたもの）

## 2. 渡すもの

- 今の仮の立ち絵（見た目の見本。服・髪・目の色を合わせるため）
  - アルシェ: `立ち絵透過済み/アルシェ幼少期表情/元気_transparent.png`
  - カリマ: `立ち絵透過済み/幼少期カリマ1_transparent.png`
- キャラの設定（原作者が必要な所だけ書き添える。設定は `CharaStatus/` の各キャラのファイル）

## 3. 依頼文（基本の絵。コピーして〈 〉を埋めて渡す）

```
添付の絵のキャラクター〈名前〉の、ゲームの会話場面で使う「立ち絵」を1枚描いてください。
服装・髪型・髪と目の色・体つきは、添付の絵と同じにしてください。

【ポーズと向き】
- 全身。まっすぐ立った、落ち着いた自然なポーズ（会話している最中の立ち姿）。
- 体と顔は、見ている人から見て「右」の方へやや向ける（斜め45°くらい。3/4の向き）。目線も右の方へ。
- 手は体の近くに（腕を大きく広げない・前に突き出さない。絵の左右の幅を狭く保つ）。
- 武器は持たない（腰に下げている程度はよい）。

【描かないもの】
- 魔法の光・炎・オーラ・飛び散るエフェクト。
- 背景・床・影。背景は真っ白の単色にする。
- 文字・枠・サイン。

【絵の形】
- 縦長（横2：縦3くらい）。頭の上と足の下に少し余白を残す。
- 〈画風: 添付の絵と同じ、アニメ調の手描き。落ち着いた色。〉

【キャラの性格・雰囲気】
〈例: 13歳の少年。明るく負けず嫌い。〉
```

## 4. 依頼文（表情の差分。基本の絵ができたあと、同じ会話の中で1つずつ頼む）

```
今描いてもらった立ち絵と、ポーズ・服・向き・大きさ・位置をまったく同じにして、顔の表情だけを「〈表情〉」に変えた絵を描いてください。
背景は真っ白、エフェクトは描かないでください。
```

- 表情の候補（キャラごとに原作者が選ぶ）: 通常・笑顔・怒り・驚き・悲しみ・困り・呆れ・照れ・真剣。
- アルシェ・カリマの幼少期は、今の表情フォルダ（元気・呆れ・怒る・明るい・涙・生意気・笑顔・やる気・ギャグ）を目安にする。

## 5. 左右で違う所があるキャラ

ゲームは、右に置くキャラを左右反転して使う。眼帯・髪の分け目・片側だけの飾り・紋章などがあるキャラは、反転すると設定と食い違うので、**左向きの絵も**頼む（§3 の「右」を「左」にして、同じ依頼文で）。
- 例: ギュンター（眼帯）。ほかのキャラは原作者が判断する。

## 6. 届いたら

1. 原作者: 届いた絵を `立ち絵AI生成/会話用/〈キャラ名〉/` に置く（ファイル名は `〈キャラ名〉_〈表情〉.png`）。
2. 透過: `tools/tachie_studio.py`（1枚ずつ）か `tools/prepare_tachie_batch.py`（まとめて）。目視で確かめたものだけ `立ち絵透過済み/会話用/〈キャラ名〉/` へ。
3. 総合担当: 差分の位置が基本の絵とずれていないか重ねて確かめる（ずれていたら位置を合わせる）。会話の画面の試作に入れて画像で報告する。

## 7. 確かめること（試しの2人で）

- 右向きの3/4がそろうか（キャラによって向きがばらつかないか）。
- 表情の差分で、ポーズ・服・位置が保たれるか（ChatGPT は差分でポーズが変わりやすい。変わるなら、顔だけを描き直してもらう頼み方に変える）。
- 画風: 今の仮の立ち絵に合わせるか、変えるか（原作者が決める）。
