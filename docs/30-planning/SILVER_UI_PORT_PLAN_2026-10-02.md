## 1. 見本と今の Unity 版の対応

Unity 版の戦闘の画面は `unity-prototype/Assets/Scripts/Battle/UI/Battle3DHud.cs`（uGUI をコードで組み立て）。今は 844×390 の枠を画面の真ん中に置き、その上の座標で並べている。

| 見本の部品 | 今の Unity 版 | 移すときにすること |
| --- | --- | --- |
| 左上: Chapter・戦場名・勝利条件 | `BuildTopStrip`（「ALLY PHASE／味方フェーズ」・勝利条件・TURN） | 常に出ているフェーズ名をやめ、Chapter・戦場名・勝利条件（と敗北条件）にする。TURN は左の一覧の上へ移す |
| 左: TURN と山形の開閉、下へ伸びる顔の一覧 | `BuildRoster`＋`BuildRosterToggle`（2026-10-02 に付けた「◀／▶ 味方」） | つまみを TURN＋山形に置き換える。閉じたら TURN と山形だけ（「味／方」の縦の札はやめる）。開け閉めを覚える仕組みは残す |
| 右上: 地形 | `BuildTerrainPanel`（もうある） | 見た目を移すだけ |
| 右: 人物の欄（顔・名前・Lv・兵種・HP/MP・移動・射程・能力・武器・スキル） | `BuildUnitCard`（左下）＋`BuildWeaponCard`（下）の2枚 | 2枚を1つの欄にまとめて右へ。能力値は `PlanUnit`（atk・def・mag・res・tec・spd・cha）、スキルは `abilityNames` から出せる |

## 2. 画面の大きさと端末の安全領域

- 見本は 1254×627（2:1）を基準に、左右の余裕も使う。今の Unity 版の「844×390 の枠を真ん中に置く」やり方はやめる（旧引き継ぎの中央16:9限定には戻さない）。
- 移し方: 基準の画面を 1254×627 にし、**高さに合わせて拡大縮小**（`CanvasScaler` の高さ基準。会話の画面 `DialogueView` と同じ）。左の部品は画面の左端から、右の部品は右端から位置を決める。横に長いスマホでは左右が端へ広がり、真ん中の盤面が広くなる。
- スマホの切り欠き・丸い角: `Screen.safeArea` の内側に左右の部品を置く。
- 盤面の操作との分け方: 今の `IsOverHud`（UIの上を押したときは盤面のマスを押さない）を新しい部品にも使う。

## 3. 反映する順序（案）

各段で、組み立ての画面の撮影（通常・選択・予測・一覧を閉じたとき）、EditMode・PlayMode のテスト、訓練の戦闘の自動の通しを確かめてから次へ進む。

1. **土台**: 基準の画面を 1254×627 に変え、左右の端から位置を決める形にする。色は一か所（パレット）にまとめる。全画面の最終の色は未決なので、あとで差し替えやすくするため。見た目はまだ変えない。
2. **左側**: 左上の Chapter・戦場名・勝利条件、TURN＋山形＋顔の一覧（今の「◀／▶ 味方」を置き換え）。常に出ているフェーズ名をやめ、ブラウザ版のフェーズ切替の演出を移す。Chapter・戦場名を書き出しのデータに足す。
3. **右側**: 人物の欄（ユニットのカードと武器のカードをまとめる）、地形。コマンドの置き場所（§4 の1）もここで決める。
4. **戦闘予測**: 下の帯、はみ出す肖像、中央の印、ボタン、カメラの寄せ、予測のあいだの一覧の短縮。
5. **素材**: 銀の枠（9分割で伸ばす）とボタンの画像を Unity に入れる。手引きの帯・下の説明・戦況の見た目をそろえる。

ブラウザ版の本編（GitHub Pages）に移すかどうかは §4 の2。

## 4. 原作者に決めてほしいこと

1. **コマンド（攻撃・魔法・待機・アイテムなど）の置き場所**。見本にはない。右に人物の欄が来るので、今の右のコマンドとは重なる。案: 選んだキャラの近く（盤面の上）に出す／人物欄の下に出す／人物欄と切り替える。
2. **ブラウザ版の本編にも移すか**。ブラウザ版は戦闘の計算の正本で、公開版でもある。案: Unity だけに移し、ブラウザ版の見た目は今のままにする。
3. **Chapter 名・戦場名・敗北条件**。今のデータには勝利条件しかない。各戦闘の Chapter 名と戦場名、敗北条件（例: アルシェが倒れる）を決める。
4. **銀の枠とボタンの画像を、正式な素材ができるまで仮で使ってよいか**。見本の背景・肖像は使わない（肖像は今の正式な絵を使う）。
5. **前の引き継ぎの「UIの窓をドラッグで動かせる」**（`CODEX_UI_POLISH_HANDOFF_2026-10-02.md` §3 の7）は、この方向でもまだ要るか。
6. **人物欄に出すスキル**の範囲（セット中のスキルを全部・個人スキルと因果スキルだけ、など）。
