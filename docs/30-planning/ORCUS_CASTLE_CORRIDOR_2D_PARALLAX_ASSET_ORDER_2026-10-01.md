# オルクス魔王城・回廊 2D横スクロール探索背景 発注仕様書

作成: 2026-10-01 / Codex
状態: **画像制作依頼用・検討中**
用途: Unity等で使う、SDキャラクター向け2D横スクロール探索マップ
注意: 現在の3D盤面用マップ仕様とは別系統の素材案。採用・実装は原作者確認後。

---

## 1. 制作目的

魔物の国オルクスの魔王城にある、2階の開放回廊を横スクロールで探索するための背景素材を制作する。

1枚の完成背景ではなく、Unity上で奥から順に重ね、カメラ移動量に差を付ける**パララックス背景**として納品する。

重ねる層は次の5系統。

1. 空
2. 遠景の城下町と山
3. 中庭・庭園
4. 回廊本体
5. 小物

すべての層を同じ大きさ・同じループ仕様にはしない。自然物、遠景、建築、小物で制作単位を分ける。

---

## 2. 画面と書き出しの基準

| 項目 | 基準 |
|---|---|
| ゲームの基準画面 | 844×390px、横画面専用、約19.5:9 |
| 素材の基本制作倍率 | 3倍 |
| 画面1枚分の制作寸法 | 2532×1170px |
| 色 | sRGB、RGBA 32bit |
| ファイル形式 | PNG。透明不要の空のみPNGまたは可逆圧縮画像でも可 |
| 輪郭 | 外側は濃い紫〜紺。内側線は外周より細くする |
| 塗り | アニメ塗り。影は2〜3段階。ぼかしと写真風の質感は控えめ |
| 見え方 | SDキャラクターに合わせ、形と色面を読みやすく簡略化する |
| 余白 | 切り抜き素材は外周に8〜24px程度の透明余白を残す |

### 解像度について

- Unityへ入れる最終寸法を上表の3倍基準とする。
- 画像生成時に指定寸法を直接出せない場合は、指定された**縦横比と構図を優先**し、生成後に拡大・切り出して最終寸法へ合わせる。
- 超横長素材の横幅はUnityで扱いやすいよう、原則8192px以下に収める。
- 同一種類の素材は、Unity側で同じ `Pixels Per Unit` を使う。基準値は100を推奨するが、キャラクターとの縮尺確認後に一括調整してよい。

## 3. 共通の美術方針

### 3.1 オルクス魔王城の意匠

- 主な石材は、灰色や茶色ではなく**黒〜紫がかった黒い石**。
- 布は深い紫。金具と縁飾りは、光りすぎない暗い金。
- 王家の紋章は、**魔物のツノ・蛇・冠・6枚の翼**。百合、獅子、十字、鷲は使わない。
- 灯りは、橙色の炎と冷たい紫色の魔灯を併用する。
- 通路、扉、手すりは、多種族が使う城として人間用より少し大きめ。
- 見た目は中世ダークファンタジー。電線、液晶、現代的な照明器具は描かない。

### 3.2 回廊から見える景色

- 回廊は魔王城の2階。アーチの外側に城内の庭がある。
- 庭の先には、丘の下へ広がる城下町の屋根、そのさらに奥に山並みが見える。
- 遠い丘の上に「別の魔王城」は描かない。
- 同じ魔王城の本丸の黒い塔は、必要なら遠景の片側へ近く見せてよい。ただしループ部分には入れない。

### 3.3 描かないもの

- キャラクター、敵、通行人
- 文字、看板の文章、UI、操作アイコン
- マス目、当たり判定の線、ガイド線
- 強い被写界深度、写真風のボケ、過度な発光
- すべてのレイヤーをまたぐ固定の強い影

### 3.4 時間帯への対応

- 回廊本体と小物は、朝・昼・夕方・夜へ色調変更しやすい**中立的な基礎色**にする。
- 硬い朝日の筋や長い柱影は、回廊本体へ描き込まない。Unityのライト、半透明オーバーレイ、別の影レイヤーで表現する。
- 空は時間帯ごとの差し替え素材にする。最初は「晴れた朝」を制作する。

## 4. レイヤー別の制作仕様

## 4.1 空

| 項目 | 指定 |
|---|---|
| 役割 | 最奥。晴れた朝の空と雲 |
| 推奨最終寸法 | **7596×1170px**（画面約3枚分）。必要なら左右各128pxの余白を加え、8192px以内に収める |
| 生成時の比率 | 約6.5:1の超横長。難しい場合は3:1前後で生成し、横へ拡張する |
| 透過 | 不要。全面を描く |
| ループ | **不可**。雲の並びに始点と終点を持たせる |
| Pivot / アンカー | 中央 `(0.5, 0.5)` |
| 推奨パララックス係数 | カメラ移動の **0.02〜0.05** |
| Unityでの配置 | 最奥の `BG_Sky`。カメラを覆う大きさに拡大し、カメラ移動にごく小さく追従 |
| 優先順位 | **1** |

制作内容:

- 澄んだ淡い青から、地平線付近の淡い金へ移る朝空。
- 雲はアニメ塗りで、影を2段階程度。輪郭は遠景なので回廊より細く、弱くする。
- 左右へ同じ雲を繰り返さない。
- 魔法世界らしさは、非常に薄い紫の高層雲や細かな光で控えめに出す。大きな魔法陣は描かない。

## 4.2 遠景の城下町と山

| 項目 | 指定 |
|---|---|
| 役割 | 空の手前。丘の下の城下町、城壁、山並み |
| 推奨最終寸法 | **7596×780px**。上側は透明余白を含んでよい |
| 透過 | **あり**。空を別レイヤーで見せる |
| ループ | 基本 **不可** |
| Pivot / アンカー | 左下 `(0, 0)`。地平線の高さを全素材で統一 |
| 推奨パララックス係数 | **0.10〜0.18** |
| Unityでの配置 | `BG_Distant`。画面下から一定の高さへ固定し、空より少し大きく移動 |
| 優先順位 | **2** |

制作内容:

- 最奥に紺〜青紫の山並み、中間に霞んだ城壁、手前に丘の下へ続く城下町の屋根。
- 城下町は黒石と暗い屋根を基調にしつつ、朝の窓灯りを点在させる。
- SD背景として、家を細密に描き込みすぎず、大きな屋根の塊と塔のシルエットで読む。
- 同じ魔王城の本丸を入れる場合は、左右端のどちらか一方だけに配置する。中央や反復部には置かない。
- 遠景なので外周線は細く、彩度とコントラストを回廊本体より一段落とす。

## 4.3 中庭・庭園

| 項目 | 指定 |
|---|---|
| 役割 | アーチ越しに見える中景。植え込み、噴水、石道、庭の区画 |
| 推奨最終寸法 | **1区画2532×720px**。まず2区画制作 |
| 透過 | **あり** |
| ループ | 区画単位では不可。複数区画を並べ替えて使用可能 |
| Pivot / アンカー | 左下 `(0, 0)`。庭の地面基準線を共通化 |
| 継ぎ目 | 左右それぞれ96〜144pxを重ねられるよう、端に大きな固有物を置かない |
| 推奨パララックス係数 | **0.35〜0.50** |
| Unityでの配置 | `BG_Garden_A`、`BG_Garden_B` のように区画ごとに並べ、端を少し重ねる |
| 優先順位 | **3** |

推奨区画:

- `garden_a_fountain`: 噴水と低い植え込みを中心とする区画。
- `garden_b_path`: 石道、花壇、低木を中心とする区画。
- 将来用 `garden_c_event`: 像、東屋、階段などを含む固有区画。

制作内容:

- 回廊の柱越しに見たとき、人物より目立たない明度と彩度にする。
- 青緑の植栽を基調にし、味方表示の青や回復表示の緑と競合する鮮烈な色を避ける。
- 噴水や像など大きな固有物は区画中央へ置き、継ぎ目をまたがせない。
- 回廊の手すりや柱は庭レイヤーへ描かない。

## 4.4 回廊本体

回廊は、1枚の長大背景ではなく**横へ接続できる建築モジュール**として制作する。

### 共通仕様

| 項目 | 指定 |
|---|---|
| 推奨モジュール寸法 | **1266×1170px**（画面の半分幅） |
| 特殊区画の寸法 | **2532×1170px**まで |
| 透過 | **あり**。アーチの開口部は完全透明 |
| Pivot / アンカー | 左下 `(0, 0)` |
| 地面基準線 | 全モジュール共通。キャラクターの足元が立つ高さをずらさない |
| ループ | 通常アーチだけ可。端、扉、壁、特殊区画は不可 |
| 推奨パララックス係数 | **1.0**。キャラクターと同じ移動量 |
| Unityでの配置 | `MAP_Corridor` 配下へ横並び。Transformの拡大率を統一し、幅単位でスナップ |
| 優先順位 | **1** |

### 必要なモジュール

| ID | 素材 | ループ | 内容 | 優先順位 |
|---|---|---:|---|---:|
| `arch_repeat_a` | 通常アーチ | 可 | 柱1組、アーチ、床、天井梁、手すり。左右が完全接続 | 1 |
| `arch_repeat_b` | 通常アーチ差分 | 可 | 同じ接続規格。石の欠け、布、植木の影など軽い差分 | 2 |
| `end_left` | 左端 | 不可 | 回廊の始点。壁、角柱、奥へ続く入口など | 1 |
| `end_right` | 右端 | 不可 | 回廊の終点。左右反転だけで済ませず、必要なら別構図 | 1 |
| `door_single` | 扉区画 | 不可 | 大型扉、扉枠、壁、床。多種族向けにやや大きい | 1 |
| `wall_solid` | 壁区画 | 不可 | アーチのない黒石壁。窓や壁掛けを置ける余白 | 2 |
| `corner_or_stairs` | 特殊区画 | 不可 | 曲がり角、階段、渡り廊下への接続など | 3 |
| `event_balcony` | 特殊区画 | 不可 | 会話やイベント用の少し広い張り出し | 3 |

### 通常アーチの接続条件

- 左右端の柱、床、天井梁、手すりの高さと太さを完全に一致させる。
- 左右端から64px以内へ、旗、扉、大きなひび、光源などの目印を置かない。
- 継ぎ目をまたぐ固定影を描かない。
- 石の模様は端で途切れて見えないよう、左右の色と明るさを近づける。
- 反復が目立たないよう、通常アーチは最終的にA・Bの2種を交互に置ける形が望ましい。

### 回廊の画面構成

- 手前下部: キャラクターが歩く黒石の床。足元と影が読めるよう、中間程度の明るさ。
- 中央: 柱、手すり、アーチ開口部。
- 上部: アーチと天井梁。画面を覆いすぎない。
- 右側壁が必要な区間は、通常アーチへ常時描かず、壁区画として分ける。
- 旗、鉢植え、ベンチ、魔灯などは回廊本体へ焼き込まず、原則として個別小物にする。

## 4.5 小物

| 項目 | 指定 |
|---|---|
| 透過 | **あり**。1ファイルに1種類・1個 |
| ループ | 対象外 |
| Pivot / アンカー | 原則、足元中央 `(0.5, 0)`。壁掛けのみ上中央または中央 |
| 推奨パララックス係数 | 床置きは **1.0**。手前演出用のみ1.05〜1.10 |
| Unityでの配置 | Prefab化し、回廊の床または壁へ個別配置。Sorting Layerを用途別に分ける |
| 優先順位 | **2** |

| 小物 | 推奨最終寸法 | アンカー | 備考 |
|---|---:|---|---|
| 吊り旗・縦旗 | 512×1024px | 上中央 `(0.5, 1)` | 紋章入り。布部分は必要なら軽く揺らせるよう別パーツ化 |
| 壁掛け紋章 | 512×768px | 中央 `(0.5, 0.5)` | 壁配置用。背景透明 |
| 鉢植え・植木鉢 | 512×512px | 足元中央 | 葉がSDキャラの顔を隠しすぎない高さ |
| ベンチ | 1024×512px | 足元中央 | 正面寄り。座面と脚が読みやすい形 |
| 紫の魔灯・床置き | 512×768px | 足元中央 | 本体と発光を別PNGにできるとよい |
| 紫の魔灯・壁付け | 512×512px | 壁への取付点 | 壁面用。発光は別PNG推奨 |
| 炎の燭台 | 512×768px | 足元中央 | 本体、炎、発光を分けられるとアニメ化しやすい |
| 小卓・荷物 | 768×512px | 足元中央 | 探索の生活感用 |
| 木箱・樽 | 各512×512px | 足元中央 | 過度に戦場風へしない |

小物の線は回廊本体より少し強くし、SDキャラクターと同じ距離にある物として読めるようにする。

## 5. 命名規則

英小文字とアンダースコアを使い、次の形式に統一する。

```text
orcus_corridor_<layer>_<content>_<variant>_<time>.png
```

### layer

- `sky`: 空
- `distant`: 遠景
- `garden`: 庭
- `structure`: 回廊本体
- `prop`: 小物
- `fx`: 光、炎、霧などの演出

### time

- `morning`: 朝
- `day`: 昼
- `dusk`: 夕方
- `night`: 夜
- `neutral`: 時間帯に依存しない素材

### 例

```text
orcus_corridor_sky_clear_a_morning.png
orcus_corridor_distant_town_mountain_a_morning.png
orcus_corridor_garden_fountain_a_neutral.png
orcus_corridor_structure_arch_repeat_a_neutral.png
orcus_corridor_structure_door_single_a_neutral.png
orcus_corridor_prop_banner_royal_a_neutral.png
orcus_corridor_prop_magic_lamp_floor_a_neutral.png
orcus_corridor_fx_magic_lamp_glow_a_neutral.png
```

左右専用素材は末尾のvariantへ `left` / `right` を入れる。

## 6. Unityでの組み立て方

### 6.1 推奨Hierarchy

```text
OrcusCorridor_2D
├─ BG_Sky
├─ BG_Distant
├─ BG_Garden
│  ├─ Garden_A
│  └─ Garden_B
├─ MAP_Corridor
│  ├─ End_Left
│  ├─ Arch_01
│  ├─ Arch_02
│  ├─ Door_01
│  └─ End_Right
├─ Props_Back
├─ Characters
├─ Props_Front
└─ FX_Light
```

### 6.2 Sorting Layerの推奨順

1. `BG_Sky`
2. `BG_Distant`
3. `BG_Garden`
4. `Map_BackStructure`
5. `Props_Back`
6. `Characters`
7. `Props_Front`
8. `FX_Light`
9. `UI`

### 6.3 Import Settingsの目安

- Texture Type: `Sprite (2D and UI)`
- Sprite Mode: 1枚素材は `Single`
- Mesh Type: 継ぎ目と透明部分の安定を優先し、まず `Full Rect`
- Filter Mode: `Bilinear`
- Compression: 高品質。輪郭に色にじみが出る場合は圧縮なしで比較
- Generate Mip Maps: 基本OFF。強い縮小表示を行う遠景だけONを比較
- Wrap Mode: 通常は `Clamp`。通常アーチをTiled Spriteで使う場合だけRepeatを検討
- Max Size: 空と遠景は8192、ほかは2048〜4096を目安

### 6.4 配置上の注意

- 空と遠景は、カメラのX座標へ係数を掛けて緩やかに追従させる。
- 庭は区画を横へ並べ、透明な端を96〜144px重ねて継ぎ目を隠す。
- 回廊本体は左下Pivotで幅単位にスナップし、拡大率を途中で変えない。
- 通常アーチは、まずSpriteRendererを複数並べる。素材が完全に接続できることを確認してから、必要ならTiled Spriteへ置き換える。
- 小物はPrefab化し、背景へ焼き込まない。旗の揺れ、炎、魔灯の明滅、調べられる物への反応を個別に付けられるようにする。
- 魔灯の本体と発光、燭台の本体と炎は分離する。発光PNGは加算または半透明合成で重ねる。
- キャラクターの足元基準線を最初に決め、すべての回廊モジュールで変えない。

## 7. 制作優先順位

| 優先度 | 制作物 | 目的 |
|---:|---|---|
| 1 | 通常アーチA、左右端、扉区画 | 横スクロールできる通路を成立させる |
| 1 | 朝の空 | 最奥の色と時間帯を決める |
| 1 | 遠景の城下町と山 | オルクス城からの眺めを成立させる |
| 2 | 庭A（噴水）、庭B（石道） | パララックスと場所の奥行きを確認する |
| 2 | 旗、鉢植え、ベンチ、魔灯 | 回廊らしさと生活感を出す |
| 2 | 通常アーチB、壁区画 | 反復感を弱める |
| 3 | 階段、曲がり角、イベント用バルコニー | 探索経路とイベント区画を増やす |
| 3 | 昼・夕方・夜の空と光差分 | 時間帯変化へ対応する |
| 3 | 追加小物、破損・式典などの状態差分 | 章や場面の変化へ対応する |

## 8. 最初に作る最低限の素材セット

まずUnity上で1〜2画面分の探索を確認するため、次の**11点**を制作する。

1. 朝の空 ×1
2. 遠景の城下町と山 ×1
3. 庭・噴水区画 ×1
4. 庭・石道区画 ×1
5. 通常アーチA ×1
6. 左端 ×1
7. 右端 ×1
8. 扉区画 ×1
9. 王家の旗 ×1
10. 鉢植え ×1
11. 紫の床置き魔灯 ×1（可能なら本体と発光を分離）

組み立て例:

```text
左端 → 通常アーチA → 通常アーチA → 扉 → 通常アーチA → 右端
```

この段階で確認すること:

- SDキャラクターと柱・扉・手すりの縮尺が合うか
- 足元の高さが全モジュールで揃っているか
- アーチの反復部分に継ぎ目が出ないか
- 空、遠景、庭、回廊の移動差で奥行きが出るか
- 庭や遠景がキャラクターより目立っていないか
- 844×390相当まで縮小しても、通路と小物の形が読めるか

確認後、通常アーチB、壁区画、ベンチ、壁付け魔灯、特殊区画を追加する。

## 9. 納品時の確認項目

- [ ] 各PNGの背景透過が指定どおりか
- [ ] 透明部分に白や黒の縁が残っていないか
- [ ] 通常アーチの左右端が完全につながるか
- [ ] 全回廊モジュールの床・天井梁・手すりの高さが一致するか
- [ ] 足元基準のある素材は、最下部中央に正しく置かれているか
- [ ] 紋章がツノ・蛇・冠・6枚の翼になっているか
- [ ] 別の城、現代設備、人物、文字、UIが描かれていないか
