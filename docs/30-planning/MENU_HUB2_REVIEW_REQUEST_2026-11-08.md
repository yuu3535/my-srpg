| 項目 | 正本 | 試作（原作者の決定） |
|---|---|---|
| 開閉 | 帯スイープ 1.75秒（左上から） | **切り裂き**: 押した星（右上）が弾けて流星になり、左下の角へ金の切れ目を引いて、右上の側から裂けて開く。閉じる 1.43秒・開く 1.93秒。帯は比較用に残した |
| 運命予報のティッカー | 新着のとき流れる | **流さない**（止まった1行。はみ出しは「…」） |
| 太陽盤 | 既存実装を使う | 既存の `太陽盤_コマンド試作01/layout.html?embed=menu&profile=independent-home` を iframe で埋め込み（ホームと同じ物） |
| NEW の札 | 支援会話の右上 (500,616) | 太陽盤が回ると札が動くので、支援会話の札を毎コマ追いかけ、回っている間は消す |
| 仲間カードの名前 | 左9%・下13%、キャリーだけ (18,188) | 3人とも左12px・下36px |
| 仲間カードの立ち絵 | 上揃え・幅100% | 3人の目の高さ（上から80px）・顔の大きさをそろえた（全身の絵から切り出した仮の絵なので、胸上の立ち絵が来たら合わせ直す） |
| ページ送りの菱形 | 今のページだけティール | **色が巡る**: 水色→藤色→赤→金を20秒で1周（隣は1色ずつずらす）。今のページは光で見分ける。9秒に1回、左から右へ波のように小さく跳ねる |
| メインイベントの角の菱形 | 左上・右下 | **右下だけ**（左は回るレティクルがあるので） |
| 線の端の菱形 | 無し | 無し（付けない） |

- 詳しい数値と経緯: `docs/10-design/ui/MENU_OPEN_MOTION_SPEC_2026-11-06.md` の「Hub2 の開閉（正）」。
- 動く飾りは「支援の菱形（巡る＋跳ねる）」「レティクル（正本どおり18秒で1回転）」「時間帯アイコン」だけに絞った（メインイベントの菱形を回す案は「視界の端でうっとうしい」で取りやめ）。
- 演出「なし」・OS の動きを減らす設定では、開閉は0.15秒のフェード、菱形などの動きは止まる。

## 提案

- Unity に組むときは、`hub2-sweep-model.js` の時刻表（切り裂きの各段の長さ、`tearGeometry`／`tearLens` の形）をそのまま写すと、試作と同じ動きになる。裂け目は「画面＝裂け目の外」をマスクで切る形。
- 太陽盤は試作では iframe だが、Unity では既存の太陽盤の実装をそのまま置く。

## 正式決定が必要な項目

- 「端末の演出：短い／なし」の時間（試作の案: 短い＝約半分、なし＝0.15秒のフェード）。
- CLOSE／MENU の星の素材（素材 C が見つからず、試作ではコードで描いた星）。
- ギュンター・ウロボロスの素材をどれにするか（`MENU_HUB2_ASSET_MAP_2026-11-08.md`）。
