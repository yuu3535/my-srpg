## 0. 考え方

- 部屋は屋内なので、**奥の壁（モジュール）**と、**家具（1つずつの絵）**に分けて頼む。家具を別の絵にすると、置く位置を調整ページで動かせ、ChatGPT への依頼も簡単になる。
- 窓の外（空・遠景・中景）は回廊の絵を使い回す（同じ城の2階。窓が小さいので見え方の違いは目立たない）。
- 床は使いまわしの床の発注（`FLOOR_AND_BATTLE_GROUND_ORDER_2026-10-04.md` A の「木の床」）を使う。
- 部屋は回廊より短い（画面の約1.5枚分）。左の端が廊下への扉、右へ向かって 剣立て → アルシェの机 → アルシェのベッド → 窓 → カリマのベッド → 衣装棚 → 本棚 → カリマの机（並びは調整ページで動かせる）。

## 2. 奥の壁（モジュール）— 4枚

共通の条件（依頼文の最後に付ける）:

```text
・添付の回廊の絵と同じ描き方・同じ石の色・同じ細かさ。真横から見た、部屋の奥の壁だけ。
・大きさは添付と同じ比率（横 1305×縦 1205 くらい）。床は描かない（壁の下の端まで）。
・家具・人・文字は描かない。明るさはふつう（朝や夜の光の筋は描かない）。
・黒い石の城の中の、子ども2人の部屋。壁は暗い石に、暖かい色の布（深い紫のタペストリー）を少し。
```

| # | 絵 | 依頼文（上の共通の条件を後ろに付ける） |
|---|---|---|
| 1 | 左の端（扉） | `部屋の左の端の壁を描いてください。左側に廊下へ出る木の扉（両開きでなく片開き、背の高い扉）。` |
| 2 | 壁（くり返す） | `部屋の奥の壁を描いてください。左右の端に大きな物を置かず、模様は全体に同じくらい。壁の燭台を1つ。` |
| 3 | 窓のある壁 | `部屋の奥の壁を描いてください。真ん中に大きな縦長の窓。窓ガラスの部分は透明にして、外は描かない。` |
| 4 | 右の端 | `部屋の右の端の壁（角）を描いてください。右側に壁の角が見える。扉や窓はなし。` |

- 2はくり返して使う。左右の端がつながらなくても、総合担当が `make_seamless.py` で直す。
- 3の窓の外は、回廊の空・遠景・中景が見える。

## 3. 家具 — 1つずつ（透過）

共通の条件:

```text
・添付の回廊の絵と同じ描き方・同じ細かさ。真横（少し上から）見た家具を1つだけ。背景は透明（白でもよい）。
・床に置いた形で、足元までちゃんと描く。影・光の筋・人・文字は描かない。明るさはふつう。
・オルクス（魔物の国）の城の家具。黒っぽい木と暗い金の金具、深い紫の布。現代的な物（電灯など）は描かない。
```

| # | 家具 | 依頼文（共通の条件を後ろに付ける） | 調べる |
|---|---|---|---|
| 1 | アルシェのベッド | `少年のベッド。布団がぐしゃぐしゃに乱れていて、枕が落ちかけている。ベッドの下に漫画の本が数冊。` | 寄り道（b04） |
| 2 | カリマのベッド | `少女のベッド。布団がきちんと整えられている。枕元に魔物のツノの形の頭飾り。` | 寄り道（b03） |
| 3 | 剣立て | `剣立てに、2本の剣（黒陽の双剣：黒い刀身に、暗い金の太陽の飾り）が立ててある。` | **必須**（b02_r09: 剣を見つける） |
| 4 | アルシェの机 | `少年の机と椅子。紙・おもちゃ・本が散らかっている。机の上に小さなランプ。` | |
| 5 | カリマの机 | `少女の机と椅子。本がきちんと積んである。机の上に小さなランプ。` | |
| 6 | 本棚 | `背の高い本棚。古い本がたくさん（勇者の物語の本など）。` | |
| 7 | 衣装棚 | `背の高い衣装棚（扉付き）。上にツノの頭飾りの箱。` | |
| 8 | 小物（任意） | `オルクスの紋章（魔物のツノ・蛇・冠・6枚の翼）の小さな旗。` | |

- 黒陽の双剣の見た目に原作の絵・設定があれば、それを添える（今の説明は仮）。
- ベッドの散らかり方と整い方の対比が、2人の違いを見せる大事な所（配置表 §1）。
