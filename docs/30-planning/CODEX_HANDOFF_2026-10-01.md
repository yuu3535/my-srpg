## 1. 決まったこと（原作者 2026-10-01）

### 1.1 ダメージ式・武器威力（`採用版md/DAMAGE_WEAPON_ENEMY_RULES.md` §2・§3、採用値・調整可能）

```text
物理ダメージ = max(1, round(武器威力 + (力 − 防御) / 2 + 行動・スキル補正))
魔法ダメージ = max(1, round(武器威力 + (魔攻 − 魔防) / 2 + 行動・スキル補正))
武器威力の尺度 = 低3 / 中6（標準）/ 高10
```

- 補正の置き場所は、以前の Codex 回答（`SYNC_AGENDA.md`）のまま。能力そのものを変える補正は括弧の中、最終の威力を増やす補正は括弧の外。
- HP は案②（TRPG Lv1 HP × 1）。採用版 v1.7、2026-09-29。
- 旧案（使わない）は次の3つ。`docs/99-archive/10-design/battle/trpg_to_srpg_damage_design.md` にある。
  - HP×2
  - 引き算式（力 + 武器威力 − 防御）
  - 武器威力 6/8/10/12

### 1.2 武器種（同 §4）

**剣・槍・斧・弓・魔核・杖** の6種類。種類ごとの違い（威力・命中・必殺・射程・重さ・耐久・相性）は未決。

### 1.3 魔核と魔法武器（同 §4.1）

この世界の魔法は書物ではなく、みんなが生まれつき持っている。

| | 魔核 | 魔法武器（杖など） |
| --- | --- | --- |
| 何か | 本人が生まれつき持つ、魔法を扱う体の器官（生体パーツ） | 魔法を扱うための武器（試験の「魔導書」の代わり） |
| 表すもの | 本人の素の魔法の素養 | 武器の恩恵（命中・威力の補正） |
| 耐久 | なし。壊れない（倒れる・MPが尽きる以外で使えなくならない） | あり。種類ごとに耐久・付いた戦技のコスト・火力の補正 |
| 補正 | 一族の得意に付けてよい（黒の一族のリングホルム＝炎の命中など） | 武器ごと |

- 素養が高すぎるキャラ（アルバス）が、魔法武器の耐久を超える魔法を撃つと、武器が壊れるおそれがある。だから強い術者は、素の魔核で撃つ方がかえってよい場面がある。
- 初期装備で魔核を持つユニットや、魔核付きの杖もあってよい。
- CSV の「武器種『魔法』装備時」は、魔核・魔法武器（杖）のどちらで魔法を使うときも含む、と読む。
- **コードとのずれ**: `trialStatSystem.js` の「火の魔核」「治癒の魔核」などは、旧・魔導書の名前を変えただけ（`kind: "grimoire"` の装備品）。いずれ魔核（本人の器官）と魔法武器（杖）に分け直す。

### 1.4 モブ（名のない敵）の能力値（同 §5、数値は `採用版md/MOB_TEMPLATES.md`）

- 型は**汎用兵種の系統ごと**の4つ（戦列・術・騎兵・隠密）と、民間人。
  - 盗賊・野生の戦士などは、見た目と呼び名を変えて増やす。原作者の提案。
  - 上級の兵種（傭兵・ガーディアン・アークメイジ・シューターなど）は、同じ系統の型に上級の兵種補正を足すだけ。
- 計算: `因果Lv1基礎値（＋種族の補正）+ (L − 1) × 実効成長率`。実効成長率は次の4つの合計。
  - 型の成長率（合計325%。民間人は200%）
  - 汎用兵種の補正（`採用版md/GENERIC_CLASS_GROWTH_RATES.md`）
  - 種族の成長率補正（モブだけ）
  - 幸運・勇気補正
- 種族:
  - 因果Lv1基礎値に、採用版 §4.4 のダイスの差を足す。
  - 成長率は、魔物が7能力 −5%、竜人はさらに HP・防御 −5%、エルフは補正なし。
  - 種族の差は、因果Lv50ごろにほぼ消える。
- 手応え（同じ因果Lv・武器威力6）: 主人公はモブを2〜5発で倒し、モブは主人公を3〜9発で倒す。
- **文書は `tools/build_mob_templates.py` が書き出す。数値を変えるときは道具の値を直して実行する（`採用版md/MOB_TEMPLATES.md` を手で直さない）。** Googleドライブ用の CSV は `output/モブの型.csv`（Git の外）。
- ネームドの敵（オルクス・アルストロの名のある人物・サタン）は、型ではなく `SRPG_CHARACTER_STAT_GROWTH_STANDARD.md` の本人の値を使う。ディラン・ヘレルはテスト戦闘の仮想敵で、シナリオには出ない。
