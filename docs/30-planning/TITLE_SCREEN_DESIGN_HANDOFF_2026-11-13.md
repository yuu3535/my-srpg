渡す先: claude.ai のプロジェクト「自作trpgをsrpg化計画」のチャット「メニュー画面UIデザイン」。Hub2 と支援会話の相手選びを作ったチャット。

## なぜ頼むか

- 今の入口は仮の画面で、3Dの探索の場面の上に出している。ボタンを並べただけになっている。
- 2Dの探索に統一したので、入口を整理する（原作者 2026-11-13）。
  - 「はじめから」は2Dの探索から始まる。
  - 「戦闘テスト」は開発中だけ出す。
- 見た目は、Hub2 と同じやり方でたたき台を頼む（原作者 2026-11-13「そうしよう」）。

## 下の「貼る文」の使い方

- 原作者は、下の枠の中をそのチャットに貼る。

---

```text
次は、ゲームのはじめの画面（タイトル画面）のたたき台をお願いしたいです。
Hub2 と支援会話の画面と同じ見た目の決まり（色・線・字・余白・光り方）でそろえたいです。

■ 画面
- 横画面専用。キャンバスは 1688×780（Hub2 と同じ）。

■ 置くもの
1. ゲームの題名
   - 正式な名前はまだ無いので仮の文字で。あとで差し替えられるように。
2. 続きから
   - セーブした所から。
   - 最後に遊んだ場所・日時などを小さく添えるかは、提案してください。
3. はじめから
   - プロローグ（アルシェが自室で起きる所）から。
4. 設定
5. 戦闘テスト
   - 開発中だけ出す入口。目立たない所に小さく。
   - 最後は消す前提。
6. 保管庫（あとで入れる）
   - 見た支援会話の見返しなどをここから行う予定（支援会話の仕様書 §14）。
   - 今は入口の場所だけ考えておいてもらえると助かります。

■ 背景と雰囲気
- 背景は何がいいか、2〜3案を提案してください。オルクス城の景色、太陽盤を大きく見せる、など。
- 黒紫と金はオルクスの色です。UI 全体の固定色ではありません。
- 景色に色をかけるときは、背景の色相の隣の色か反対の色にします（例: 青空に紫はかけない）。

■ 動き
- 開いたときの出方、ボタンを押したときの動きがあれば、それも案に入れてください。
- 「はじめから」を押したら、暗転して会話へ入る、など。

■ 欲しいもの
- たたき台を2〜3案。
- 原作者が選んだら、これまでと同じく Claude Code 向けの仕様書にまとめてほしい。
  - 中身: 座標・寸法・色・線・字、要素ごとの決まり、素材の一覧。
  - 見本画像を 1688×780 の実寸で付ける。位置を書き込んだ図も付ける。
```

## 総合担当の側のメモ

- 今の入口: `unity-prototype/Assets/Scripts/Battle/Scenario/StartMenu.cs`。
  - Explore3D の場面を開いたときに、上に重ねて出している。
  - ボタンは「続きから」「はじめから」「戦闘テスト（`StartMenu.ShowBattleTest`、開発中だけ）」と右上の「設定」。
- 3Dの盤:
  - 訓練場（戦闘の場所）だけで使う。2Dの探索で訓練場に入ると 3D の盤に移り、会話と戦闘のあと 2D に戻る。
  - オルクス城の回廊・自室を 3D で歩く探索は、入口から行かなくなった（場面は残している）。
- たたき台が来たら:
  - はじめの画面を、専用の場面にするか、今の重ね方のままにするかを決める。
  - 専用にするなら、場面の一覧（WebGLBuilder）も変える。
