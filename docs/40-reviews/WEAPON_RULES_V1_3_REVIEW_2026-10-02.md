# 武器・魔核・魔法武器のルール（採用版 v1.3）の点検

作成: 2026-10-02 / 総合担当（Claude Code）
対象: `採用版md/DAMAGE_WEAPON_ENEMY_RULES.md` v1.3、`採用版md/SKILL_LOADOUT_RULES.md` v1.1、Codex の試算 `docs/40-reviews/MAGIC_CORE_WEAPON_TRIAL_CALC_2026-10-02.md`
状態: **点検の結果と案** → **原作者が案Bに決定（2026-10-02）**。採用版 v1.4 に入れた（物理武器にも命中補正・魔法の射程の有利さを強さの計算に入れる・回復の魔法は検討中）

## 1. よいと思う所

- 剣・槍・斧に基礎性能差・三すくみを作らない。物理武器に耐久を作らない。物理戦技は戦闘ごとの使用回数制。数字と管理が減り、武器の差は固有効果や付属戦技で出せる。
- 弓は射程と飛行特効で役割がはっきりする。
- 魔核は壊れず渡せない体の器官、魔法武器は耐久とMPを同じだけ払う補助の装備、という分け方は分かりやすい。突然壊れる・装備できない、という不意打ちのルールを取りやめたのもよい。

## 2. 気になる所: 魔核だけの魔法が、物理よりかなり弱い

v1.3 では、魔核だけで使う魔法に固定の威力を足さない（`(魔攻 − 魔防) / 2` だけ）。いっぽう物理攻撃は、耐久もコストもない武器の威力（標準6）がいつも足される。

採用版の因果Lv1のネームド10人（幼アルシェ・リングホルム・アルバス・幼カリマ・幼ギュンター・ラディン・キャリー・ヘンリー・フィロ・アン）の総当たり90組で、相手を倒すまでの平均の回数を比べた（命中は入れない）:

| 攻撃 | 平均の回数 | 1ダメージしか出ない組 |
| --- | ---: | ---: |
| 物理（標準の武器6） | 3.0回 | — |
| 魔法・魔核だけ | **10.5回** | **48組／90組** |
| 魔法・標準の魔法武器（6） | 4.1回 | 6組 |

- 魔核だけの魔法は、半分以上の組で1ダメージになる。しかも魔法はMPを使い、物理はコストなし。強い術者でも魔核だけで戦う理由がほぼ無くなり、「強い術者は魔核だけでも強い」という狙いとずれる（アルバスが強く出るのは、魔防の低いモブ相手だけ）。
- **プロローグの訓練（チュートリアル）が壊れる**: 幼アルシェの「火」はギュンター（魔防16）へ、今の試験（威力6）では7ダメージ、v1.3 の魔核だけなら **1ダメージ**。訓練の「物理・魔法・戦技を一通り使って倒す」が成り立たない。
- 高い因果Lvでは魔防が伸びるので、魔核だけの魔法はさらに通りにくくなる（2026-09-24 に見つかった「魔法が通らない」問題がまた出る）。

## 3. 直し方の案

採用版の本文には「魔核だけの魔法は、本人の魔攻と相手の魔防、および**魔法・戦技固有の補正**で決める」とある。Codex の試算はこの固有の補正を0として計算している。**基本魔法そのものに固有の威力を持たせる**と、魔核に装備品の威力を持たせないまま、魔法を使える強さにできる。

総当たり90組での比べ（魔法の固有の威力＋魔法武器の威力）:

| 魔法の固有の威力 | 魔法武器 | 平均の回数 | 1ダメージの組 |
| ---: | ---: | ---: | ---: |
| 0 | なし | 10.5 | 48 |
| 3 | なし | 7.1 | 23 |
| 4 | なし | 5.9 | 16 |
| 0 | 標準6 | 4.1 | 6 |
| 3 | 低3 | 4.1 | 6 |
| 4 | 低3 | 3.1 | 2 |
| 3 | 標準6 | 2.3 | 0 |
| 4 | 標準6 | 2.1 | 0 |

- **案A（今のまま）**: 魔核だけ＝弱い補助。術者は魔法武器がほぼ必須。訓練は子どもに杖を持たせて直す。
- **案B（基本魔法に固有の威力3）**: 魔核だけで物理の半分強の手応え（7.1回）。標準の魔法武器を足すと物理より強い（2.3回）が、MPと耐久を払う代わりの強さとして筋が通る。
- **案C（固有の威力4・魔法武器は低め）**: 魔核＋低い魔法武器で物理とほぼ同じ（3.1回）。

総合担当のおすすめは **案B**。「魔核だけでも戦える（強い術者ほど）」「魔法武器は払う代わりに強い」の両方が立つ。高い因果Lvで魔法が通らない問題も和らぐ。

## 4. ほかに決めたいこと

- 物理武器の命中補正: 魔法武器に命中補正（+5か+10）を付けるなら、物理武器はどうするか（付けないなら、魔法武器の命中補正は弱めの+5がつり合う）。
- 魔法の射程（1〜2）は、物理（1）より有利。反撃を受けにくい分も、魔法の強さの計算に入れる。
- 回復の魔法（治癒）の量も、同じく固有の威力＋魔攻で決めるか。

## 5. コードへの影響（決まったあとに直す所）

- `game.js calculateMagicDamage`（試験）は、今はどの魔法も威力6（`TRIAL_WEAPON_POWER.mid`）。魔核だけ／魔法武器ありで分ける。
- `trialStatSystem.js` の「火の魔核」などの装備品（`kind: "grimoire"`）を、魔法武器（杖・耐久あり）に作り直す。魔核は装備品にしない。
- 物理戦技のコスト（`combatArts.js` の `cost.durability`）を、戦闘ごとの使用回数に変える。
- 訓練の戦闘（`battle_prologue_training`）の数値と、Unity版に書き出した値。
