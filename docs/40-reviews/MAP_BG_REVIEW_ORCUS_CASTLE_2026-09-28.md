## 1. 3枚に共通すること

### 良い所

- 画風・塗りの細かさがそろっていて、3枚で1つの城に見える。原作者が好む「整理された大きな形・光のドラマ」（`背景/SRPG_MAP_ART_DIRECTION_2026-09-27.md`）に合っている。
- 暖かい灯り（ランタン・炎）と、紫〜藍の影の対比がある。色の方針（`MAP_COLOR_MOOD_DIRECTION_2026-09-27.md`）と一致。

### 気になる所

1. **オルクスらしさが弱い（回廊・鍛錬場）**。旗の紋章が**フルール・ド・リス（百合の紋）と冠の獅子**で、どちらも現実のヨーロッパの王家の紋章。建物も人間の中世の城と街。
   - 世界観の基準では、オルクスは「黒い石材・濃紫の布・冷たい魔鉱石の光・暗い金属装飾・多種族が暮らせる道幅や扉」、白と青の整然とした城はアルストロ寄り。
   - 今のままだと、プレイヤーが「ここはアルストロの城？」と誤解しやすい。和平後の城なので人間的な要素があってよいが、**紋章はオルクス独自のもの**にしたい。
2. **窓の外に「別の城」が見える（回廊・鍛錬場）**。どちらも遠くの丘の上に大きな城が描かれている。ここが魔王城の中なら、見えている城は何か、が説明できない（城下町と、魔王城の別の塔、などなら成り立つ）。
3. **大きさが人間向け**。オルクスは多種族の国なので、扉・通路・段差を少し大きめにすると、らしさが出る（世界観の基準 §2）。

## 2. 1枚ずつ

### 回廊

| | |
|---|---|
| 物語との一致 | ゲーム本文にも原作にも「回廊」の場面の記述は見当たらない（探索用の場所として使える） |
| 良い所 | 左のアーチの柱列と中庭、右の窓と燭台、奥の扉。**探索マップの形（細長い通路・片側が開けている）がそのまま読み取れる** |
| 直したい所 | 紋章（百合・獅子）、遠くの別の城。床の強い映り込みは3Dの盤面では描かない（床の1枚絵の決まり「強い光・影は描かない」） |
| 盤面にすると | 細長い盤面（例: 横5×縦20前後）。左の辺＝柱 `P` が2マスおき＋低い手すり（外は中庭で下の階＝入れない）。右の辺＝壁 `W`（窓・旗・燭台は壁の模様と小物）。奥＝扉 `D`。ベンチ・鉢植えは小物（通行に影響しない） |
| 戦闘に使うなら | 幅が3マスを切ると戦いにならない。戦う範囲は幅5マス以上の所に置く |

### 玉座の間

| | |
|---|---|
| 物語との一致 | **3枚でいちばんオルクスらしい**（紫の魔灯・角と翼の意匠・黒い石・ゴシック）。ゲーム本文の「紫の魔灯」とも合う |
| 時代の違い | 原作の決戦（サタンの時代）の玉座の間は「薄暗く、腐臭漂う…**漆黒の骸のような1つの玉座**」「黒い霧」。この絵の玉座は赤い布張りの豪華な椅子で、**和平後（フォースの時代）の玉座の間**として読むのが自然。サタンの時代の場面にも使うなら、骸の玉座と霧の差分が要る |
| 直したい所 | 大きな問題はない。赤い絨毯は、盤面では**敵の攻撃範囲（赤）と重なって読みにくくなる**おそれがあるので、今の赤紫〜ワインの色より赤に寄せない |
| 盤面にすると | 左右対称の広間（例: 横11×縦14前後）。中央の絨毯 `r`、左右の柱の列 `P`、燭台の列（マスを占めるなら遮蔽物、端に置くなら小物）、奥に玉座の台 `+`（階段は1〜2段に抑える。高さの戦闘補正が未決定のため） |
| 戦闘に使うなら | 「儀礼と緊張」の形。中央の絨毯が最短路、柱の陰が遮蔽。玉座へ登る階段は狭い一本道になりやすいので、左右にも回り道を作る |

### 鍛錬場

| | |
|---|---|
| 物語との一致 | **ゲーム本文と食い違っている（要判断）**。プロローグ本文は「**黒い石造り**の鍛錬場…**高い天井**の奥では**紫の魔灯**が揺れ」＝**屋内**。この絵は**屋外**（夕焼けの空・城壁・街）で、魔灯もない |
| 良い所 | 砂の稽古場・木の人形・柵・演台・武器立て・樽と木箱・上の段の石の通路と階段。**チュートリアルの戦闘に必要な物が全部そろっている** |
| 直したい所 | 屋内か屋外かを決めてから直す（§4）。紋章、遠くの別の城 |
| 盤面にすると | 砂の稽古場 `a` が中心（例: 横12×縦10前後）。木の柵＝低い物（遮蔽物・飛行は止まれる）、木の人形＝マスを占める物、演台＝一段高い台 `+`、手前の石の通路＝一段高い段（階段でつなぐ） |
| 戦闘に使うなら | チュートリアルなので形は単純に。柵で「遮蔽物」を1回教え、演台で「高い所」を見せる程度にする |

## 3. 3Dの盤面へ落とし込むときの約束（提案）

- 会話の背景の絵と戦闘・探索の盤面が**同じ場所**なので、配置（柱の側・扉の位置・玉座の向き）を背景の絵に合わせる。盤面を作ってから背景と食い違わないよう、**背景のブラッシュアップで配置を先に確定する**。
- 背景の絵は「会話の場面の絵」、盤面は `MAP_ART_PIPELINE_v1` の①床・②壁の模様・③小物で作る。背景から、②③の**部品の一覧**（柱・燭台・旗・ベンチ・鉢植え・人形・柵・武器立て・樽・木箱）を拾う。
- 紋章は、ブラッシュアップの前に1つ決めて、旗・壁・絨毯のすべてで同じものを使う。

## 4. 原作者に決めてほしいこと

1. **鍛錬場は屋内か屋外か**。
   - A 本文どおり屋内（黒い石の広間・高い天井・紫の魔灯）に絵を描き直す。盤面は屋内の方式（`MAP_ART_PIPELINE_v1` §8 では「屋外寄り」としているので、そちらも直す）。
   - B 絵どおり屋外（城の中庭の稽古場）にして、本文の「高い天井」「紫の魔灯」を直す。
   - マップ担当の推奨: **B**。屋外は盤面の見通しがよく、最初のマップとして作りやすい（屋内の壁の隠れ問題がない）。魔灯は中庭の灯り（紫の炎の灯籠）として残せる。
2. **オルクスの紋章**。百合・獅子に代わるオルクス独自の紋章を決める（例: 角のある竜・翼・魔鉱石の結晶・月）。玉座の間の角と翼の意匠が手がかりになる。
3. **玉座の間はどの時代の場面に使うか**。和平後（フォース）だけなら今の絵でよい。サタンの時代の決戦にも使うなら、骸の玉座と黒い霧の差分を作る。
4. **窓の外に見える城**は何か（城下町と魔王城の別の塔、にするか、描かないか）。
