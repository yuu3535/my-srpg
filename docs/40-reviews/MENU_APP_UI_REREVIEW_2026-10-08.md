## 結論の先出し

前回の大きな問題（スマホで 7〜8px の文字）は、**フレームなしなら解決**した（844×390 で 12〜16px、667×375 でも 9.5〜12.6px）。構図も、太陽盤の黒と金・アプリの金の板・細い銀の枠がそろい、ひとまとまりに見える。残る大きな点は「フレームを付けると、また小さくなる」「白い出撃／探索の札」「最初の読み込みが約17MB」の3つ。

## 2. 構図と調和（画像で確認）

- 太陽盤の黒と金、アプリの黒い正方形と右・下の金の板、マップの細い銀の線と金の小さな接点がそろっている。前回より一枚の画面としてまとまった。
- **白い「出撃／探索」の札が、画面でいちばん目立つ**（白はここだけ）。左の太陽盤にも「出撃」「探索」があるので、同じ入口が2つあり、しかも札の方が強い。案（原作者判断）: (a) 黒地＋金の細い縁の札にして色をそろえる、(b) 札をやめてマップの窓全体を押せる所にし、右下に金の小さな矢印だけ置く、(c) 札の文を「マップを開く」にして、太陽盤の出撃・探索と役割を分ける。
- 金の板・β版のシール・マップの枠の角は、**どれも切れていない**（`crops_corner_beta.png`）。
- 背景の四隅の星飾りが、右上の時間帯のアイコンと、右下の「？？？」の金の板に近い（重なってはいない。10px ほど）。右側の要素が詰まって見えるので、星飾りを少し外へ逃がすか小さくすると余裕が出る（背景の素材側で直せる）。

## 3. テロップ（実測・静的確認）

- 止まるか（実測）: ふだん running → **フォーカス中 paused、詳細を開いている間 paused、閉じると running、「予報を流す」OFF で paused**。マウスを乗せたときは CSS で止まる（静的確認）。画面が隠れたとき（`visibilitychange`）と「動きを減らす」設定（CSS で animation を消し、複製も隠す）も止まる作り（静的確認。OS の設定を入れての実測はしていない）。
- 継ぎ目（静的確認＋実測の値）: 本文の複製を 48px あけて並べ、本文の幅（短ければ帯の幅）＋48px だけ動かして繰り返すので、継ぎ目で飛ばない。速さは 28px/秒、一周 13〜15 秒（種類ごとの実測値）。
- **短い文も流れる**（実測: セール・飯屋・遭遇戦は帯に収まる長さだが流れる）。読み終わる前に動き出すので、収まるときは止めたままにし、はみ出すときだけ流す案がある（原作者判断: テロップらしさを優先するなら今のまま）。
- 種類を切り替えると、右の種類の文字の長さで帯の幅が 304〜340px と変わる（実測）。気にならない程度。
- 全文: 帯を押すと詳細が開き、全文が読める（実測）。読み上げは帯の `aria-label` に全文が1回入り、流れる2つの文は `aria-hidden`（静的確認）。重ならない。
- フォントの読み込み・画面の大きさが変わったとき: 幅を測り直す処理がある（`ResizeObserver`・`document.fonts`。静的確認）。

## 4. 操作と失敗のとき（静的確認・一部実測）

- アプリ・予報の帯・マップ・詳細の種類の切り替え・閉じる・Escape は、ふつうの `<dialog>` と `<button>` で、フォーカスも戻る作り。前回の実測（Escape で閉じると押したアプリへ戻る）と同じ部品。
- 素材が読めないとき: アイコン（「素材未読込」と下地）、β シール（隠す）、場所の画像（場所の名前の文）、マップの枠（細い銀の線に戻す）、壁紙（炭色の無地）、端末フレーム（枠なしへ）、太陽盤（警告）。すべてに代わりの表示がある。
- 飾り（壁紙・マップの枠・端末フレーム）は `pointer-events: none` で、押すのを遮らない。
- 謎のアプリを隠すと、説明の欄からも消える。

## 7. 背景制作へ進んでよいか

**進んでよい。** 今の構図（左に太陽盤、右に帯・マップの窓・アプリ）で、背景はほとんどが文字やアプリの後ろに隠れず見える場所はわずかで、無地＋四隅の飾りという方向が合っている。作るときの注意:

- 寸法は前回どおり 1688×780（844×390 の2倍）。フレームの判断（1）がまだなので、端の約5%には大事な物を置かない。
- 四隅の飾りは、右上の時間帯のアイコン・右下のアプリと 20px 以上離す（今の素材は約10px）。
- 本番では、無地の部分は色で塗り、飾りだけを小さな画像にすると軽い（3）。
- 持ち主ごとの壁紙（アルシェ／カリマ）を作るなら、同じ寸法・同じ「真ん中は暗く静か」の決まりで。

## 8. 原作者の答え（2026-10-09）

1. **端末フレーム**: あると面白い。ふだんの画面には描かず、**演出の小道具**にする（例: スマホを構える動き、スマホを見るために少し寄る動き）。
   - 総合担当の読み: メニューを開くとき、フレームつきの端末が下から上がってきて（構える）、画面いっぱいまで寄ったら、フレームの外が消えて今のホーム（枠なし）になる。閉じるときは逆。操作するときはいつも枠なしなので、字の大きさ（§1 の枠なしの値）は保たれる。動きを減らす設定・早く閉じたいときは、すぐ切り替える。→ 状態: **アイデア**（動きの細かい所はメニュー担当と原作者で詰める）
2. **出撃／探索の札**: **案(b)**。札をなくして、マップの窓全体を押せる所にし、右下に金の小さな矢印だけ置く。→ **正式採用**
3. **テロップ**: 帯に**収まる文は止めて、読める間をとる**。はみ出す文も、流す前と流し終わりに**読める間**をとる。そのあと**次のお知らせへ**移り、お知らせを順に繰り返す（ループ）。→ **正式採用**（間の秒数は試作で決める）
4. **背景**: 背景はもうある（今の炭色＋四隅の飾りの素材が背景）。新しく作る必要はない。§7 の「背景制作」は、今の素材の四隅の飾りの位置（右上・右下の要素から少し離す）と、軽くする工夫（無地は色、飾りだけ画像）だけが残り。
