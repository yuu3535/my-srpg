# 魔核のみ／魔法武器ありの試算

作成: 2026-10-02 / Codex
状態: **比較用の試算**。ダメージ式とキャラクター能力値は採用版を使用。命中式・魔法武器の命中補正・個々の武器性能は未採用の仮値。

## 1. 目的

次の採用方針が、実際の数値でどのような手応えになるかを確認する。

- 魔核だけの魔法には固定の武器威力・武器命中補正を付けない。
- 魔法武器は、本人の魔攻・命中能力へ威力と命中を加算する。
- 強い術者は魔核だけでも強く、苦手な術者にとって魔法武器は最終手段になる。

## 2. 試算条件

採用済みの魔法ダメージ式:

```text
魔法ダメージ = max(1, round(魔法武器の威力 + (魔攻 − 魔防) / 2 + 行動・スキル補正))
```

- 魔核のみ: 魔法武器の威力0、武器命中補正0。
- 低威力の魔法武器（仮）: 威力3、命中+5。
- 標準の魔法武器（仮）: 威力6、命中+10。
- 高威力の魔法武器（仮）: 威力10、命中+15。
- 行動・スキル補正は0。

命中は、まだ採用されていない試験式を比較用に使う。

```text
命中率 = clamp(round(60 + (攻撃側の技 − 防御側の速さ) × 2.5
                         − 防御側のサイズ回避補正 + 攻撃補正 − 防御補正), 5, 100)
サイズ回避補正 = clamp(11 − SIZ, −10, +5)
```

したがって、以下の命中値と「命中+5／+10／+15」は正式値ではない。

## 3. アルバス対アルバス（因果Lv1）

採用版能力値:

- HP18、魔攻24、魔防22、技12、速さ9、SIZ15。

### ダメージ

| 使用方法 | 計算 | ダメージ |
|---|---|---:|
| 魔核のみ | `(24 − 22) / 2` | 1 |
| 低威力の魔法武器 | `3 + (24 − 22) / 2` | 4 |
| 標準の魔法武器 | `6 + (24 − 22) / 2` | 7 |
| 高威力の魔法武器 | `10 + (24 − 22) / 2` | 11 |

### 命中（仮）

アルバスのSIZ15による回避補正は−4。魔核のみでは約72%。

| 使用方法 | 命中率 |
|---|---:|
| 魔核のみ | 72% |
| 低威力の魔法武器（命中+5） | 77% |
| 標準の魔法武器（命中+10） | 82% |
| 高威力の魔法武器（命中+15） | 87% |

アルバスは攻撃側として魔攻が高い一方、防御側としても魔防が非常に高い。アルバス同士は通常の敵味方より魔法ダメージが小さくなる極端な組み合わせであり、シナリオ上の標準戦闘を表す例ではない。

参考として、魔防10の相手なら、アルバスの魔核のみは7、標準魔法武器ありは13ダメージになる。

## 6. 読み取り

- アルバスは魔核だけでも戦列モブへ8ダメージ。標準魔法武器を持つと一撃圏に入り、武器の恩恵が明確に出る。
- 幼少アルシェは、魔核のみの3回撃破から標準魔法武器の2回撃破になり、武器を装備する意味が分かりやすい。
- アンは魔核のみでは最低保証の1ダメージ。標準魔法武器で戦列モブへ6ダメージまで上がるが、術兵モブには4ダメージに留まる。「苦手な人物が魔法を使うときの最終手段」という狙いに近い。
- 魔法武器の威力6は効果が大きい。さらに命中+10を同時に与えると恩恵が強すぎる可能性がある。最初の比較候補は、**威力6・命中+5**と**威力6・命中+10**。

## 7. まだ決めていないこと

- 正式な命中・回避式。
- 魔法武器の命中補正を+5と+10のどちらへ寄せるか。
- 低・標準・高の個別武器名、最大耐久、魔法のコスト。
- 耐久が残りコスト未満のとき、最後の1回を使えるか。
- 戦列下級・術下級モブの正式なSIZ。
