## 2. 直しの依頼文

§3.1 の共通の文（`docs/30-planning/ART_PRODUCTION_BRIEF_2026-09-26.md`）と、UI発注書の「1. 共通の指定」を先に貼ってから使う。

### A5 顔枠（ChatGPT）

```
味方一覧に並べる顔アイコンの枠を、3種類作り直してください（通常・選択中・行動済み）。
ゲームでは 36×36px ほどに縮めて使うので、縮めても形が分かる、飾りの少ない枠にしてください。

- 大きさ: 各144×144px、背景は透明、枠の中（顔が入る部分）も透明。
- 枠の線: 金の細い線を1本（太さは画像の幅の3%くらい）。飾りは四隅の小さな菱形だけ。
- 通常: 落ち着いた金。
- 選択中: 通常より明るい金（光・にじみは付けない。色の明るさだけで区別する）。
- 行動済み: 暗い金（灰色がかった金）。
- 発光・グロー・光沢・影は付けない。
```

### B1・B2 ボタン（ChatGPT）

```
ボタンの枠を作り直してください。主ボタン（実行）と副ボタン（戻る）を、それぞれ3つの状態で。

- 大きさ: 各440×80px（横5.5：縦1）、背景は透明。文字は入れない。
- 飾りは左右の端から24pxの中だけに置く。上下の辺の中央には飾りを置かない
  （ゲーム側で真ん中を横に伸ばすため、辺の真ん中は単純な線にしてください）。
- 主ボタン（実行）: 落ち着いた金〜赤銅の帯に、細い金の縁。紫は使わない。
- 副ボタン（戻る）: 地はほぼ透明な黒紫、細い金の線の枠だけ。
- 状態: (1)通常 (2)押した時: 少し暗く (3)使えない時: 彩度を落とす。
- 発光・グロー・光沢・影は付けない。
```

### D4 選択枠（Codex）

```
選択枠（味方）を、線を太くして作り直してください。ゲームでは1マス約36pxに縮めて使います。

- 大きさ: 256×256px、背景・中央は透明。
- 青の線の太さ: 画像の幅の6%（約16px）。線の外側の端が、画像の端から2%（約5px）の位置。
- 四隅の小さな金の飾りは、青の線の内側に収める（線の外にはみ出さない）。
- 光・にじみは線の太さの中に収め、外に広げない。
- あわせて、敵用（赤）の選択枠と、移動先の印（控えめな青の枠）も同じ作りで。
```
