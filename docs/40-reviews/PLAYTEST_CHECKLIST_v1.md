# 遊びやすさの点検表 v1（戦闘）

作成: 2026-09-28 / 総合担当（Claude Code）
使う人: ゲームレビュー担当（`docs/30-planning/GAME_REVIEW_CHAT_HANDOFF_2026-09-28.md`）
対象: Unity版の3Dの戦闘（`Battle3D`・国境監視路）。ブラウザ版は計算の確かめ用なので、見た目の点検はしない

各項目は **○（問題なし）／△（気になる）／×（遊びにくい）／－（見ていない）** で付け、△と×には「どの画像・どの操作で」「何が困るか」「こうなっているとよい」を書く。
「確かめ方」の画像は `unity-prototype/Assets/Previews/` にある（組み立て直すと撮り直される）。

## A. 盤面が読めるか

| # | 見ること | 確かめ方 |
|---|---|---|
| A1 | 通れるマスと通れないマス（水堀・壁・茂み・瓦礫）が、絵を見ただけで分かる | `Battle3D_ui_select`・`Battle3D_close_top` |
| A2 | マス目が戦う範囲だけに見え、景色との境目が分かる | `Board3D_T8_painted_*` |
| A3 | 味方と敵がひと目で見分けられる（足元の枠・向き・色） | `Battle3D_close`・`Battle3D_ui_turn2` |
| A4 | 移動範囲（青）・攻撃範囲（赤）・補助の範囲（緑）が、どの地面の上でも読める | `Battle3D_ui_select`・`Battle3D_attack_range`・`Battle3D_ui_support` |
| A5 | 木・壁・門がキャラを隠したとき、隠れたキャラが分かる（半透明） | `Board3D_T6_occlusion_*` |
| A6 | 高さ（壁・石の基礎）が見て分かる。高さで戦闘が変わると誤解しない | `Battle3D_front` |
| A7 | 斜め・正面・真上のどれでも、キャラの位置とマスが食い違わない | `Battle3D_ring_tilt`・`Battle3D_ring_top` |
| A8 | 味方に付く印（狙われている赤い丸など）の色が、敵の色と混ざらない（2026-09-28 追加） | `Battle3D_ui_idle` |
| A9 | 寄り・全体・回したあとのどれでも、景色の外（黒や面の端）が見えない（2026-09-28 追加） | `Battle3D_ui_*`・`Battle3D_turn180` |
| A10 | 同じ絵のキャラ（同じ兵種の敵・鏡の戦い）を、足元の枠と色で見分けられる（2026-09-28 追加） | `Battle3D_ui_forecast`・`Battle3D_close` |

## B. 選ぶ・押す

| # | 見ること | 確かめ方 |
|---|---|---|
| B1 | 押したいマスが、UI（左の一覧・下のカード・右のコマンド・上の帯）に隠れていない。隠れても盤面をずらせる | 各画像のUIと盤面の重なり |
| B2 | キャラの体を押しても、そのキャラのマスが選ばれる（後ろのマスにならない） | PlayMode テスト「押す判定」 |
| B3 | 今どのキャラを選んでいるか（青の▼・枠・カード）が迷わない | `Battle3D_ui_select` |
| B4 | 取り消し・戻るがどの段階でもできる（移動のあと、相手を選ぶ間、予測の間） | `Battle3D_ui_acting`・`Battle3D_ui_forecast` |

## 撮影の決まり（2026-09-28 追加）

- `Battle3D_ui_forecast_next` は、攻撃の選択肢が2つ以上ある味方（アルシェ）で撮る。
- `Battle3D_ui_acting` は、動いた直後のコマンドの一覧（別のキャラの一覧を開いたままにしない）。
