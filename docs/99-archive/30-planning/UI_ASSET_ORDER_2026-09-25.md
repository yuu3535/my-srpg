## 0. この発注書の使い方

1. 下の「1. 共通の指定」を毎回いっしょに貼る。
2. 「3. 素材ごとの指定」から1つずつ依頼する（1回の依頼で1素材。まとめて頼むと大きさや線の太さがばらつく）。

## 1. 共通の指定（毎回貼る）

```
ダークファンタジーのシミュレーションRPGのUI素材を作ってください。
添付のゲーム画面（黒紫の地に細い金の罫線）の雰囲気に合わせてください。

【雰囲気】
- 上品で落ち着いた、資料や古書のような意匠。派手さより品のよさを優先。
- 地の色は黒に近い深い紫〜紺（#0e0b1a〜#04060e くらい）。
- 線は細い金（#c8922a〜#d6a740）。線の太さは素材の幅に対して細く、髪の毛1〜2本分。
- 飾りは最小限。角や中央に小さな菱形を置く程度。

【やってほしくないこと】
- 光沢、つや、金属の立体感、ベベル（面取りの立体表現）
- 光のにじみ、発光、ネオン、グロー、レンズフレア
- 太い縁取り、重たい装飾、宝石、ドクロなどのモチーフ
- 素材の外側に落ちる影（影はゲーム側で付けます）

【書き出し】
- PNG、背景は透明。
- 1枚に1素材。文字は入れない。
- 指定の大きさで、絵を画像の端まで使う（周りに余白を残さない）。
```

## 2. 伸ばして使う素材の作り方（9分割）

パネルやボタンは、ゲーム側で「四隅はそのまま、辺と中央を伸ばす」使い方をする。そのため:

- 四隅の飾りは、角から指定の幅（例: 48px）の中に収める。
- 辺（上下左右の真ん中の部分）は、どこで切っても同じ見た目になる単純な線にする。
- 中央の地は、ムラの少ない色か、ごく薄い質感にする（伸ばしても不自然にならない）。

発注時に「四隅の飾りは角から◯pxの中に収め、辺はどこで切っても同じ見た目の線にしてください」と書き添える。

## 4. 作らなくてよいもの（ゲーム側で描く）

- HP・MP・EXPのゲージ（細い線で描くほうが意匠に合う）
- 画面の上の帯・下のログの帯（グラデーションで描く）
- 文字、数字
