## 追記: スキル・戦技セット枠の採用を受けた UI 引き継ぎの補足（同日・Claude Code）

ゲーム設計担当（Codex）が原作者と相談し、`採用版md/SKILL_LOADOUT_RULES.md` v1.0 を採用した（`44f04c0`）。本メモの上の部分はこの採用より前に書いたため、UI担当は以下を優先すること。

### セット枠と、現在の試験版ステータス画面との差

| 採用された枠 | 現在の試験版の表示 | 必要な対応 |
| --- | --- | --- |
| 通常兵種スキル 4枠 ＋ 兵種固有 1枠 | CLASS欄に「兵種Lv5・10・15・マスター」の習得一覧 | セット中の4枠＋兵種固有1枠の表示へ変える。習得済み一覧は育成画面側へ |
| 因果スキル 3枠 | なし（PASSIVE欄に既存パッシブ） | 3枠の表示を追加 |
| 戦技 4枠 | ARTS欄に既存の戦技 | 4枠の表示へ変える。戦技型マスター能力（突撃・ブレス）は兵種固有枠側に出る |
| 個人スキル（未決） | なし | 枠を用意するかは未決 |

- 兵種固有枠は、転職すると外れる（マスタースキル・専用兵種のLv50スキルとも）。空き枠や「対応兵種ではないため外れている」状態の見せ方をUIで決める必要がある。
- 専用兵種の4人（アルシェ・リングホルム・アルバス・カリマ）は、Lv50スキル（奈落の王・勇者の器・破滅の王・神炎の器）を兵種固有枠に置く。
- `trialStatSystem.js` の `TRIAL_CLASS_SKILLS` / `TRIAL_UNIT_CLASS` と `renderTrialStatusSheet` のCLASS欄は、セット枠ができる前の暫定表示である。

## 追記: 個人スキルの扱い（同日・原作者の方針、Claude Code 記録）

原作者の方針（2026-09-25）。`採用版md/SKILL_LOADOUT_RULES.md` §2・§9 で未決とされている「個人スキル」の扱い。採用版への反映はゲーム設計担当（Codex）に依頼する。

- 個人スキルは、キャラクターが最初から持っている能力。
- 兵種スキル・因果スキルと違い、**セットの付け外し（カスタム）ができず、絶対に外せない**。
- 効果は原作者が作成した（2026-09-25 修正版 `Regarding character growth rates, skills, and combat arts/各キャラ兵種表 - 因果スキル_戦技.csv` の「個人スキル」列）。当初「効果は未定・名前だけ仮置き」としていたが、同日に効果付きの修正版が出た。

| キャラクター | 個人スキル | 効果 |
| --- | --- | --- |
| アルシェ・カリマ | 双蛇の逆針 | 味方が倒されたり攻撃を外したりしたとき、一手単位で行動を巻き戻せる。1回の戦闘で最初は3回まで、章が進むごとに1回ずつ増える |
| リングホルム | 殺気 | 自分から攻撃したとき命中+10・相手の回避−10・必殺+10 |
| アルバス | 野望 | 相手から攻撃された際、魅力×2で反撃封じ。相手の命中−10・相手の回避−10・必殺+10 |
| アン | 頑張り屋 | 味方が3マス以内にいると命中+5 |
| フィロ | エリート | 力・魔防・速さ・魅力+3 |
| ギュンター | 忠誠心 | オルクスの味方が盤面にいるとき全ステ+1、アルバスがいる時は全基礎ステ+2 |

同じ修正版で、サタンの因果Lv35「闇の霧」（相手から受ける専用スキル・戦技を無効化）の名前と、アンの因果Lv45「祈り」の効果文が補われた。

### 原作者の回答（同日）

1. **双蛇の逆針はゲームシステム級の機能**として扱う（原作者確認）。一手単位の巻き戻しのため、行動履歴の保存・巻き戻し操作・回数管理・画面の巻き戻しボタンが必要になる。アルシェとカリマは同じ個人スキルを持つ。SYNC_AGENDA §6 の回答にある「宣言制と巻き戻しの関係」の検証とも関係する。
2. **野望の「自分の回避−10」は書き間違いで、正しくは「相手の回避−10」**（原作者確認）。CSVも修正済み。
3. **忠誠心は新しい効果で実装し直す前提**（原作者確認）。現行ゲームの実装（`passiveSkills.js`: 2マス以内に味方がいれば派生戦闘値+3）は旧効果。殺気は現行実装と一致している。
