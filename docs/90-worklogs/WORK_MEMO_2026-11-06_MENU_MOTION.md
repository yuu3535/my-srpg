## 判断と理由

- 4番は、ホームの中の戻るキーを直す代わりに、親の「端末」ボタンを「戻る」に変える形にした。理由: 「まったく同じ位置・見た目」にするには、同じ一つのボタンにするのがいちばん確実で、ホーム（Codex）を触らずに済むため。ホームには、すでにある「空き枠だけ作る」設定（`visible:false`）を使ってもらう。
- 項目の順番は、出撃 → 太陽盤の残り → 下のアプリ → 場所の絵 → 上の情報。押す見込みの高い順の案。原作者に見てもらって変えてよい。

## 追加：⑤ 日輪の扇の提案

原作者の依頼（「太陽盤を活かしたかっこよくてスタイリッシュな演出を、今までのやり方は置いて考えて」）で、新しい案を別ページ `sunfan.html` に作った。状態はアイデア／試作対象。④の採用は変えていない。

- 流れ: 太陽盤が左端から回りながら昇る → 光の針が「出撃」を指す → 針が上下に割れて光の扇が開き、照らされた所からメニューが出る → 日輪の波紋。閉じると扇をたたみ、針を太陽へ戻し、太陽が回って沈む。
- 項目の順番は、太陽の中心から見た角度で自然に決まる（出撃が0度なので必ず最初）。
- 作り方の判断: 太陽盤の色はSVGのフィルターで付いているため、絵を複製せず、ホームの画面そのものを太陽の中心で回して切り抜いた。ホームのファイルは変えていない。
- 試作中に見つけて直したこと: 扇が0度のとき細いくさびが出る、扇が開く前に「出撃」が見えてしまう、扇が速すぎて読めない（曲線をゆるめた）、閉じるときに針が暗幕の戻りと少し重なる。
- 確かめた範囲: `verify-sunfan.cjs` 成功、ブラウザのコマ送り（アルシェ／カリマ）。実時間のなめらかさ・スマホ実機は未確認。

## 追加：⑤の磨き

原作者の感想:「太陽盤がぐるっと回って来て波紋が出るのおしゃれ。ステンドグラス風とも合っている。もうちょい綺麗に出来そう（演出担当のセンスに任せる）」。素材フォルダ（`アイコン素材/携帯端末メニュー画面素材/`）も教えてもらった。太陽盤は「盤」と「針・中心軸」の2層、色はSVGフィルター（`太陽盤_色違い方針_2026-10-04.md`）。

ステンドグラスの「光が通る」感じを軸に5つ足した（素材の画像は増やしていない、すべて光の層）:

1. 重みのある着地: 太陽が6度だけ回りすぎて戻る。最初は12度・320msで戻していたが、ホーム全体が回るので扇の中のメニューが傾いて見えた → 200msまでに戻し切るよう前へ寄せた。
2. ガラスを走る光: 着地のとき、太陽の上を斜めの光の帯が一度横切る。最初は太陽の画面外の左半分を通る時間が長く見えにくかった → 見えている右半分を通るように道筋を変え、芯を明るくした。
3. ステンドグラス越しの光: 扇の中に太陽から温かい光（カリマは青い光）が差しこみ、項目が出そろう頃に引く。最初は強すぎてメニューが濁って見えた → 0.34 → 0.26 に弱め、太陽の近くに寄せた。
4. 扇のふちに内側へにじむ光の帯（切り口ではなく光の筋に見せる）。
5. 二つめの柔らかい波紋。

開くのは 0.47 → 0.56秒（項目が出そろう時刻は0.35秒で変わらない。のびたのは光の名残だけ）。`verify-sunfan.cjs` に磨きの検査を足して成功。ブラウザのコマ送りでアルシェ／カリマを確認。実時間のなめらかさ・スマホ実機は未確認。

## 追加：⑤ 太陽が出てくる瞬間の途切れを直した

原作者の指摘:「太陽盤が出てくる瞬間途切れてるの違和感」（135msのスクリーンショット付き）。

- 原因: 太陽を「広がる円の窓」で見せていた。窓が太陽より小さいあいだ、光条の先が円のふちで切れ、窓の中のホームの暗い地が黒い円盤に見えていた。
- 直し方: 円をやめ、太陽盤の絵の形で切り抜く（扇の形と合わせたマスク）。太陽は不透明度で浮かび上がらせる。
- 途中で分かったこと: ホームの中の針（光条）は、選んでいるコマンドの方へ回っている（今は約90度、選び直すと変わる）。決まった絵の形だと合わずに黒いとげが出た → 開く・閉じる瞬間に針の角度を読み、その角度で形を描いて使うようにした（同じ角度なら作り直さない）。針を60度に回して試し、形が追いつくのを確かめた。
- file:// で開いたときは形を読めないので、ふちをぼかした円に戻る。
- `verify-sunfan.cjs` 成功。ブラウザのコマ送りで135ms・195msを確認。

## 追加：⑤ 太陽を元の素材で描くように変えた

原作者:「`太陽盤_試作03` に元の円盤の素材あるけど、これつかっちゃダメなの？それとも必要ないの？なんかすごい汚く見える」（カリマの135msのスクリーンショット）。

- 汚く見えた原因: ホームごと回していたので画面の端で太陽が斜めに切れた／太陽の形を半分の解像度で作っていたのでふちがぼやけた／ガラスの奥にメニューの地が透けて濁った。
- 答え: 使ってよい、むしろ使うべきだった。最初に使わなかったのは色（金・銀）の付け方が分からなかったため。調べると `太陽盤_試作03` の `material-engine.js`・`character-colors.js` で付けていたので、それを読み込んで同じ色にした（素材・スクリプトは変えていない）。
- 作り: 動いているあいだは元の素材の太陽を別の層で回す。ホームは回さない。開き終わり（380〜480ms）にホーム自身の太陽へ入れ替える。入れ替えまでは、ホームを「扇 − 太陽の絵の形」で見せる（円の穴だと太陽のまわりに暗い円が出たので、太陽の形の穴にした）。
- `verify-sunfan.cjs` に入れ替え・ホームを回さないことの検査を足して成功。ブラウザのコマ送りで、カリマ／アルシェの135ms、カリマの300ms・375ms・560msを見た。動かした太陽とホームの太陽が同じ姿になることを確かめた。
