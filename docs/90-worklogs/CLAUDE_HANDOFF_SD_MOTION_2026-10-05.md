# Claude Codeへの共有 — SD戦闘モーション・共通身体の試作

2026-10-05。状態: **試作対象 / 未採用**。この文書が今回の引き継ぎ入口。

## 最初に押さえること

原作者の狙いは「兵種ごとの汎用戦闘モーションをキャラ間で共有し、武器も交換できるようにして制作量を減らす」こと。いまは **共通の首から下の身体＋キャラごとの頭** を試している。完成モーション方式の正式決定ではない。

腕を肩・肘・手に分ける旧v2は、原作者から動きが不自然との指摘があった。全身を細分化して全キャラ・全兵種を調整する方向には進めていない。旧試作は比較・再現のため残しただけで、テスト成功を作画品質の承認と取り違えないこと。

AutoSprite、AI生成のポーズ連番、兵種衣装の共通化を比較した後、まず共通身体の静止フィッティングから検証することになった。AutoSpriteの採用済み方針の撤回ではない。本編・Unityへ接続せず、正式素材・キャラクター設定・採用済み頭身を変更していない。

## 現在できること

場所: `prototypes/sd-battle-motion/shared-body/`。

- 初期表示は原作者提供の「子供素体」。以前に生成した幼め・標準の身体も切替可能。
- 同じ身体にアルシェ・カリマ・ギュンターの頭を合成。頭サイズと首位置を身体×キャラごとに調整。
- 左に合成＋半透明の元SD、右に元SDそのままを並べる。透かしのON/OFF、不透明度、単色シルエット、元SDの倍率・位置を調整できる。
- 頭を調整しても、比較する元SDの基準全高は追従しない。比較位置・倍率も身体×キャラごとに保持。
- 反転、濃色背景、接合ガイド、3人比較、約70pxの縮小表示。
- JSON書出しと本文コピー欄。再読込で調整が消える。JSONの再取込・永続保存は未実装。再読込前に必要な調整を保存すること。

提供子供素体は腕を下げた姿勢なので **武器合成を無効化** している。旧身体の剣は静止合成の確認用で、武器交換・攻撃モーションの実証ではない。

## 未作成・未検証

共通身体方式の攻撃連番・APNGは **まだ作っていない**。旧 `generated/` と `generated/v2/` のAPNGは旧方式の比較出力であり、共通身体の成果ではない。

頭・身体・武器を独立したAPNGとして別々に再生する方式は未採用。試すなら、身体連番の各姿勢に頭の接合位置・角度、武器の握り位置・角度・前後順を同じタイムラインで付け、同期を確認してから合成・書出しを行う案。

2つの体格系統だけで全キャラに対応できるとは判断していない。肩幅・脚の長さ・極端な身長差、ロングヘア、背面・横向き、眼帯・利き手など左右非対称、盾・両手武器、専用兵種・個人衣装は未検証。武器1枚の差替えで全姿勢が成立するかも未検証。

## 次に相談したいこと

1. 原作者に提供子供素体と頭のバランス・首の接合を元SDと比較してもらう。
2. バランス確認後、身体1系統・片手剣攻撃1種類を少数のキー姿勢で試す。同じ身体モーションに3人の頭を載せて自然さと調整量を比較する。
