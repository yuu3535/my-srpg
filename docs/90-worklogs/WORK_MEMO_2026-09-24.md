### レベルと育成

- TRPGレベルはSRPGの因果Lvへ変換しない。
- 因果LvはSRPG内の本人レベルとして扱う。
- 兵種Lvは兵種スキル、兵種戦技、マスタースキルの習得段階として扱う。
- 因果Lv上昇時に基本8ステータスを成長させる。
- 実効成長率は次の式で求める。

```text
実効成長率 = キャラクター個人成長率 + 現在兵種の兵種成長率補正
```

### HP換算の再検討（検討中）

- HP×2は、TRPG Lv5の完成済みステータスを前提に決めた値だった（`docs/10-design/battle/trpg_to_srpg_damage_design.md`）。
- 原作者から、因果Lv1のHPはTRPG Lv1のHPそのまま（×1）の方がよいのでは、という案が出た。
- 成長は+1ずつの加算なので、×2でも因果Lv50で膨れ上がることはない（×2と×1の差は最初の12〜18のまま）。×1の方が成長の実感は強い（アルシェのHPはLv50で約3.6倍、×2では約2.3倍）。
- ×1にする場合、HP上限の式の「x 2」も見直す必要がある。上限も×1にすると、アルバスがLv54でHP上限に達し、「上限はやりこみ用」という方針とずれる。

### 武器威力の仮定

- 低威力3、中威力6、高威力10で仮定する。
- HP×1との組み合わせでは、得意な物理攻撃が因果Lv1〜40を通じて中威力2〜4発で安定する。

### 幸運・勇気を成長率へ加える案（D案を原作者が支持・検討中）

```text
実効成長率 = 個人成長率 + 兵種成長率補正 + floor((幸運 + 勇気) / 40)%
```

- 全8能力へ同じ値を加える。メイン3人は、アルシェ・カリマ+4%、リングホルム・アルバス+3%。
- 1因果Lvあたりの期待上昇は、アルシェ・カリマ+0.32ピン、リングホルム・アルバス+0.24ピン。主人公枠が伸びやすく、壊れ枠は個人成長率の高さで強さを保つ。
- 比較して見送った案:
  - A: 幸運÷20のみ。リングホルム（幸運35）が+1%にとどまる。
  - B: 下振れ救済。効果がほぼない。
  - C: 追加判定。強すぎる。
  - E: 勇気と幸運で担当能力を分ける。
- 勇気は戦闘中に減る値でもあるため、成長率には戦闘で変動しない最大勇気（基礎値）を使う。

### 新たに見つかった論点

- 因果Lvが上がるほど魔法ダメージが通らなくなる。魔防の成長率が魔攻より高いキャラが多く、Lv20以降はアルバスに誰の魔法も通らない。魔法ダメージ式、または魔防の換算・成長率の見直しが必要。
- 因果Lv1のアルバスの魔法は、武器威力にかかわらずリングホルム（HP×1で12）を1発で倒す。
- 検討資料 `TRPG_TO_SRPG_STAT_CONVERSION.md` §4.1 には、Lv5シートから換算する旧案が残っている。採用版で置き換え済みである旨の注記が必要。

## 12. 追記: 試験ブランチで使う基準ダメージ式（同日・原作者承認）

正式採用ではなく、採用版を試す試験ブランチでの基準として原作者が承認した。

### 基準の式

Codexの最新提案（`outputs/01a0c793-.../character_stat_conversion.xlsx` の「計算ルール」、2026-09-23）を基準にする。互角時の値を武器威力に置き換える。

```text
物理ダメージ = max(1, round(武器威力 + (力 - 防御) / 2 + 行動・スキル補正))
魔法ダメージ = max(1, round(武器威力 + (魔攻 - 魔防) / 2 + 行動・スキル補正))
武器威力（仮定）= 低3 / 中6 / 高10
```

## 15. 追記: 必殺率の式と倍率の重複ルール（同日・原作者承認、試験ブランチの基準）

正式採用ではなく、§12のダメージ式と同じく試験ブランチで使う基準として原作者が承認した。7月の必殺式（`COMBAT_ARTS_DESIGN.md` §12「必殺: 勇気・レベル・魅力式」）と「2倍奥義と必殺は重複しない」は、本節で置き換える。

### 必殺率

```text
必殺率 = 技 + floor(現在の勇気 / 5) - 相手の魅力 + 補正
最低0%
```

- 「魅力が1上がるごとに、相手の必殺率が1%下がる」という分かりやすさを優先する。攻める側も技をそのまま使い、尺度をそろえる。
- レベルの項は入れない。技と魅力が同じペースで伸びるため、平均必殺率は因果Lv1〜50を通じて約10%で安定する。
- 高Lvほど、育ち方の違いが必殺率の差として表れる（Lv50で0%の組20組、20%以上の組18組）。魅力を育てれば必殺を受けにくくなるという育成の手応えとする。
- 補正は兵種スキル（戦列攻撃上級の「必殺+10」など）・武器・固有スキル。
- 必殺ダメージは最終ダメージの3倍。

### 勇気

- 勇気はキャラクターが生来持つメンタルの強さ・気の強さを表す。TRPGの値が最大値で、それ以上には成長しない。
- 戦闘中は悪夢などで減る。必殺率には現在の勇気を使うため、勇気を削る攻撃は反撃率と必殺率の両方を下げる。
- 成長率の幸運・勇気補正には、変動しない最大勇気を使う（採用版§6.1のとおり）。

### 倍率の重複ルール（A: 掛け算）

```text
・2倍スキル（武道・魔導・急所など）は、1回の攻撃で1つだけ発動する（発動率 技÷2%）
・必殺（3倍）は別に判定し、2倍スキルと重なったら掛け算（2 × 3 = 6倍）
・倍率は、守備を引いた後の最終ダメージへ掛ける
・敵にも同じルールを適用する
```

- 原作者は「直感的な分かりやすさ」を理由にAを選んだ。比較した加算（C: 最大4倍）と防御半減（D）は不採用。
- 安全装置は、必殺耐性（相手の魅力）と命中・回避とする。ボスなどへの追加の保護は現時点では設けない。
- 平均ダメージは3案でほぼ同じだった（両方が重なる確率は1攻撃あたり約1〜4%）。差は、まれな大当たりで一撃撃破が起きるかどうかだけ。

### Lv40の代表例（中威力6、Codex案のダメージ式）

| 攻撃 | 必殺率 | 2倍スキル | ×6の確率 | 通常 / ×2 / ×3 / ×6 |
| --- | ---: | ---: | ---: | --- |
| リングホルム → アルバス（物理） | 10% | 18% | 1.8% | 12 / 24 / 36 / 72 |
| アルバス → リングホルム（魔法） | 16% | 22% | 3.5% | 14 / 28 / 42 / 84 |
| リングホルム → ラディン（物理） | 23% | 18% | 4.1% | 6 / 12 / 18 / 36 |

### 未決

- 必殺率の上限（FEでは100%）。
- 戦闘予測に最大ダメージ（×6）を表示するか。最終必殺率とスキル発動率の表示は既定方針どおり行う。
- 敵の攻撃を多数受けると×6が累積的に起きやすくなる。許容度は、戦闘不能時の扱い（ロストの有無）と合わせて決める。
- 2倍スキルの発動率「技÷2%」は兵種スキルCSVの記載どおり。個別スキルの効果量と合わせて見直す可能性あり。
