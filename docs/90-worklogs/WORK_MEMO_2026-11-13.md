  - 火の粉6つ（1.61秒のくり返し）。

## 何もない所を押すと、太陽盤の札を外す（試作と同じ）

- 原作者「太陽盤って関係ないとこ押したらコマンドに針は置かないようにならなかったっけ？」（試作 2026-10-04 の動画）。
  - BACK の星は目立たせなくてよい（原作者）。何もない所を押せば戻れ、2Dの探索では星が目に入るため。
  - 原作者の考え: メニューは情報が多い。多くのゲームでは2回押す・関係ない所を押すと戻れるので、このゲームではどうかと試したくなる。
- 試作 `wheel.js` の `clear()` と同じにした（`SunDialView.Clear`）。
  - 札を外し、針は菱形と菱形の間へ戻り、炎は消える。
  - 外した状態で ↑↓ を押すと、針の先にいちばん近い札から動く。Enter では何もしない。
- 拠点メニュー: 何もない所、または太陽盤の札でない所を押すと、札を外す。
- 支援会話の相手選び: 同じく札を外す。「支援会話」から離れたので、拠点メニューへ戻る（戻った太陽盤は札を外した状態）。
- テスト: EditMode 68件・PlayMode 23件すべて成功。

- 原作者「素早く２回タップでスッ…と戻る方が良い。１回タップだと誤タップしたときに、折角眺めてた画面が急にどこか行くのはストレス」。
  - 総合担当は1回で戻る案を勧めたが、原作者の判断で2回にした。
- 何もない所、または太陽盤の札でない所を 0.35秒以内に2回押すと、札を外して拠点メニューへ戻る。

- 拠点メニューのホームで何もない所を押したときは、今までどおり1回で太陽盤の札を外す（画面は変わらないので）。
- ほかのコマンドの画面も、つながったら同じ決まりにする。

## Hub2担当のレビュー（原作者が動画を見せて聞いた・6件）

原作者の指摘で直す前の動画を見てもらった。6件とも、その前の直しとは別の物だった。

1. タイトルのメニューで、選んでいる項目の下線が出ない。
   - 原因: 1px の線は、ブラウザの画面が基準（1688×780）より小さいと1点より細くなって消える。
   - 直し: 線の太さを、いつも画面の1点以上にした。
2. 題名の影が、右下にずれた硬い影になっていた。
   - 直し: ぼかした影にした（`SoftTextShadow`。字の形の影を 8方向×3段 ずらして薄く重ねる）。
   - Unity の Shadow をいくつも重ねると、前の影まで写して形が増え続けるので、1回で写す部品を作った。
3. メニューの間の印が、丸い点に見えた。
   - 原因: 小さな四角を回して描いていて、仕様より小さかった。
   - 直し: 7×7 の正方形を45度回した大きさの、ふちのなめらかな菱形の絵（`Hub2Textures.Diamond`）にした。
4. 会話中・拠点メニューを開いている間、マップの上の文字が透けて見えた。
   - 直し: その間は隠すようにした（`Corridor2DView.HideText`）。名前の札・調べる印・出口の札・「〇〇を手に入れた」・左右の矢印。
5. 右下の「最初へ」は、開発用。
   - 直し: 「DEV 最初へ」にして、開発中だけ出す（`StartMenu.ShowBackToStart`）。
   - 公開の形にするときは false にする。そのときは、タイトルへ戻る道を拠点メニューに用意する。
6. 話していない人の立ち絵の明るさ 0.72。
   - 実装は 0.72 になっていた。前に撮った確認の画像と見本を比べ、立ち絵の所の明るさがほぼ同じ（比 0.96〜1.0）だった。直していない。
