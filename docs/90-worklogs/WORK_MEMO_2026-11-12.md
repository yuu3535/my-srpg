## 支援会話：相手選びを Unity に組み込み（1回目）

- 原作者から仕様書のまとまり（`support_select_spec_pack`）を受け取った。正本は `docs/10-design/ui/support_select/` に置いた。
- 作る前に、食い違いと決める所を11個に分けて報告した。答えは「基本はおすすめで」。違う指定は2つ:
  - 字の太さ 700 は、16px 以下を 600（SemiBold）、19px 以上を 800（ExtraBold）にする。
  - 解放の前でも開けるのは、開発中だけの切り替えにする（あとで戻せるように）。
- 決めたことの一覧: `docs/10-design/ui/support_select/README.md`。
- 記録: `docs/20-implementation/SUPPORT_SELECT_UNITY_2026-11-12.md`。
- 見本 ref_01〜05 を Unity で重ねて、線と文字が合うまで直した。確認の画像は `docs/40-reviews/support_select_unity_2026-11-12/`。エディターでは F8 で見本を重ねられる。
- 立ち絵:
  - 仕様書の数値は、デザイン側の別の絵の物だった。
  - アルシェ・アルバスは、見本のカードに総当たりで重ねて大きさと位置を決めた（`tools/build_support_portraits.py`）。
- つまずき:
  - 行の左上に大きさ 0 で置いた鍵の絵が描かれなかった。RectMask2D が「枠の外」と見なして消すため。入れ物を置いて直した。
  - 確認の画像を撮る RenderTexture は sRGB にする。そうしないと黒に近い色が粗くなる。
