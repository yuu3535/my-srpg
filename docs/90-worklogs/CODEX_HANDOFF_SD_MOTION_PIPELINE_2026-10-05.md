# Codex への引き継ぎ — SD戦闘モーションの作り方（方針の整理）

2026-10-05 / 総合担当（Claude Code）→ SDモーション試作担当（Codex）
前の共有: `docs/90-worklogs/CLAUDE_HANDOFF_SD_MOTION_2026-10-05.md`（Codex → Claude Code）への返事。
状態: **方針は原作者が確認（2026-10-05「あってます」）**。中身の数値・コマ数・作り方の細部は **試作対象**。本編・Unity への接続はまだ決めていない。

## 0. いちばん大事な条件

**武器をキャラに焼き込まず、あとから自由に差し替えられること**（原作者 2026-10-05）。剣・槍・斧・短剣・固有武器・武器の更新で、見た目が変わる。

## 1. 原作者と決めた流れ（3つ）

1. **兵種の衣装つきの身体**
   子供・大人の素体から、兵種ごとの衣装を着た身体を作る（ChatGPT Work か Codex のスキル）。頭は付けない。
   - 色違いは、衣装の色を変える所だけを塗った下絵（**マスク**）を1枚つけ、塗り替えで作る（色相の自動判定は、肌・革・金具まで変わる失敗が出やすいので使わない）。塗り替えをゲームの中でするか、前もって画像で作るかは、試作で決める。
2. **モーション**
   APNG の**モーション見本**を、兵種の衣装でなぞる（トレス）。
   - 見本は兵種ごとではなく、**体型（子供・大人）× 武器の種類（剣・槍・斧・短剣・弓・杖…）ごと**に作る。同じ体型・同じ武器の種類なら、兵種が違っても同じ見本をなぞる。
   - 鉄の剣・銀の剣・固有の剣は、同じ「剣の見本」から作った動きに差し替えるだけ。動きは「武器の種類」ごと、絵は「武器1本」ごと。
3. **最後に合わせる**
   **頭 ＋ 兵種の身体 ＋ 武器** を重ねる。頭と武器の位置・角度は、見本の印から決める。

## 2. モーション見本の作り方（提案。試作で確かめる）

- **印を入れる**: 見本の各コマに、決まった色の点を打つ。
  - 首のつなぎ目（頭を置く所）: 赤
  - 武器の握り: 青
  - 武器の先: 緑
  - （必要なら）頭の傾き用にもう1点
  印の色と大きさは Codex が決めて、文書に書く。プログラムが点を読み、コマごとの位置・角度を自動で出す。人は、ずれた所だけ直す。
- **見本の武器は棒でよい**: 握りと先の印が付いた棒。本物の武器の絵は、その棒の位置・角度に合わせて重ねる。
- **握っている手は別の小さな絵**: 剣を握る手を身体と一緒に描くと、剣が手の上に乗って見える。握る手だけを別の絵にして「身体 → 武器 → 握る手」の順に重ねる（コマごとに手1つ）。武器が身体の後ろに回るコマは、前後の順を見本に書いておく。
- **見本の作り方の候補**: クリスタの3Dデッサン人形を子供素体の体型に近づけてポーズを付ける（コマの姿勢がぶれにくい）。原作者が作るか、ほかの作り方にするかは原作者と相談。
- **コマ数は少なめ**: 盤面のキャラは約70px。目安は 待機 2〜4・歩行 4・攻撃 4〜5・被弾 2。向きは斜め前の1方向（左右反転で両側）から。

## 3. データの持ち方（提案）

| 物 | 持つもの |
|---|---|
| 武器（1本ごと） | 絵、握りの点、先の点（2点から角度と長さ）、種類、片手・両手 |
| 見本（体型 × 武器の種類 × 動き） | コマの並び、コマごとの首・握り・先の位置と角度、武器と握る手の前後、コマの時間 |
| 兵種の身体（兵種 × 体型 × 武器の種類 × 動き） | 見本をなぞったコマの絵、握る手の絵、色を変える所のマスク |
| キャラ | 頭の絵（首の点つき）、兵種、色、今の武器 |

- 武器の絵は、ChatGPT Work に頼んだ汎用武器（`docs/30-planning/WORK_GENERIC_WEAPONS_ITEMS_ORDER_2026-10-05.md`。斜め45°・1枚1本）も、握りと先の2点を記録すればそのまま使える。
- 頭と身体のバランス（頭の大きさ・首の位置）は、今の共通身体の試作（`prototypes/sd-battle-motion/shared-body/`）の調整値を引き継ぐ。

## 4. 担当の分け方（提案）

| 工程 | 誰が |
|---|---|
| 兵種の衣装・頭・武器の絵 | 原作者と画像生成（ChatGPT Work など） |
| モーション見本（印つき） | 原作者（クリスタなど）。作り方は相談 |
| 見本をなぞる | 画像生成か原作者。試作で、どちらが安定するか比べる |
| 印の読み取り、重ねた確認（APNG）、大きさと足元のそろえ、ファイル名、色違い | Codex（プログラム） |
| Unity への取り込み（盤面のキャラを、頭・身体・武器を重ねる形にする） | 総合担当（Claude Code）。方式が決まってから |

- AutoSprite は、武器を持ち替えないもの（魔物・訓練人形・ボスなど）や、攻撃の動きの参考に向く。武器を差し替える人のキャラの本番の動きは任せない（条件と合わない）。課金の前に、書き出せる形を1体で確かめる。

## 5. 最初の試作（1兵種を最後まで通す）

原作者の提案どおり、1兵種で流れを最後まで通してから量産する。確かめたいこと:

- 子供素体 → 戦列下級の衣装の身体
- 頭2人（アルシェ・カリマ）が同じ身体に合うか（今の試作の続き）
- 色違い2色で、肌・金具が変わらないか
- 武器は **2種類・3本**（例: 鉄の剣・銀の剣・槍）。「同じ種類で差し替え」と「種類が変わって動きも替わる」の両方
- 待機・歩行・攻撃・被弾
- 約70px に縮めて、武器の形が読めるか
- 1キャラ・1武器を足すのに何がどれだけかかるか（記録する）

通ったら、もう1兵種（重装など）で同じ手順が通るかを見てから量産へ。Unity への接続は、方式が決まってから総合担当がする。
