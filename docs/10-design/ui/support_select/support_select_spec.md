# 支援会話：相手選び画面 実装仕様書 — Unity（uGUI）向け

> **見本画像と、この仕様書の数値の両方を使って組んでください。**
> 元デザインは Claude Design キャンバスの「支援会話：相手をえらぶ 2案（太陽盤を残して右側だけ切り替え）」です。1案（全体を暗くぼかした版）は不採用なので、参考にしないでください。
> 色・線・字の決まりは、拠点メニュー（Hub2）の仕様書と同じです。

## 0. 前提

| 項目 | 内容 |
|---|---|
| 基準解像度 | **1688 × 780**（スマホ横 844×390 の2倍）。数値はすべてこの基準の px |
| Canvas | uGUI、Canvas Scaler = Scale With Screen Size、Reference 1688×780、Match = 1（高さ基準）。Hub2と同じ |
| 座標 | 左上原点・下向きが＋Y。uGUI では anchor/pivot を左上 (0,1) にして `anchoredPosition = (x, -y)` |

| 出方 | 右上の星（BACK）→ 拠点メニューに戻る。支援会話（会話画面）の CLOSE → この画面に戻る |
| 対象 | 今操作している側の軍の、**加入済みの仲間だけ**。最大8人 |

## 11. 立ち絵の切り抜き

顔の位置と大きさをそろえて切り抜く。キャラごとに「元画像での顔の中心 (fx, fy)」と「頭の幅 hw」を持たせ、

```
scale = 表示したい頭の幅 / hw
画像の左上 = (表示枠の中の顔の位置x − fx × scale,  表示枠の中の顔の位置y − fy × scale)
画像の大きさ = 元画像の大きさ × scale
```

| 使う場所 | 表示枠 | 顔の位置 | 頭の幅 |
|---|---|---|---|
| 仲間カード | 92×212 | (48, 58) | 40 |
| 詳細の顔 | 42×42 | (21, 19) | 22 |
| 簡易の顔 | 40×42 | (20, 19) | 21 |

今ある立ち絵の値（元画像の px）：
| キャラ | 元画像 | fx | fy | hw |
|---|---|---|---|---|
| アルシェ（13歳） | 284×950 | 150 | 98 | 106 |
| カリマ（13歳） | 233×950 | 125 | 100 | 104 |
| キャリー | 491×1060 | 242 | 86 | 86 |
| アルバス | 286×1000 | 140 | 66 | 80 |
| ヘンリー | 401×1000 | 173 | 82 | 90 |

> 顔の大きさでそろえるので、子ども2人はアップ気味、大人は引き気味に見える。立ち絵が増えたら同じ表に足す。

## 12. データの持ち方

```
SupportPair {
  charA, charB        // キャラID（順不同で1組）
  rank                // 見終わったランク数 0〜3（0=未、1=C済、2=B済、3=A済）
  state               // Ready（次の会話が話せる）/ Gauge（支援値をためている）/ Locked（条件待ち）
  points              // 支援値 0〜100（Gauge のとき）
  unlockChapter       // Locked のときの「第〇章から」
}
```
- 組み合わせは**限定式**。主人公（アルシェ／カリマ）は軍の全員と組がある。それ以外は、決めた組だけ（1人2〜3組、勧誘で増える仲間は主人公＋1人を目安）。**組がないペアは一覧に出さない**。
- 組み合わせ・加入順・確定枠／追加枠は**まだ決まっていない**。キャンバスのデータは仮。データは ScriptableObject などで外から差し替えられるようにする。
- 両軍は合流するまで支援会話をしない。アルバスは両軍に在籍するが、**この画面では特別な表示はしない**。
