## 作る前に決めたこと（原作者 2026-11-14）

1. アルシェは歩かせる（おすすめ）。
   - 見本では、アルシェとカリマは部屋の絵に描き込まれていて、動くのはカメラだけ。
   - ゲームでは、床を押すとそこまで歩く。物を押すと、歩いてから選ぶ。矢印の長押しで走る（1秒に 900px）。
2. 部屋の絵は、今の組み立て式のまま（おすすめ）。
   - 見本の部屋は `背景/双子の部屋/イメージ.png` を 2340×780 にした物。SDが描き込まれているので背景には使えない。
3. 部屋に何があるかは、シナリオの場面に合わせる（原作者の指定）。
   - 仕様書の6つの家具とカリマを全部置くのではない。その場面にある物だけ。
   - 見た目・種類（拾得物・チップス・話す）・当たり判定は仕様書どおり。
4. 「話す」は、物語の会話なら会話の画面（H案の全画面）のまま（おすすめ）。
   - 短い一言だけ、仕様書の吹き出しで見せる案。今は短い一言のデータが無いので、まだ作っていない。
5. ほかの場所（廊下など）も、今回の作りにする（原作者の指定）。
   - 途中の扉は、扉の絵を足さない。「EXIT 〇〇へ」の案内を出し、その範囲を押すと歩いて出入りする。
   - 原作者「組み立て式素材を作るだけでも大変だったので、追加で扉を画像生成するのも一苦労。exitがあるんだからそこから出入り口すればいい」
6. 文字の出る速さは、会話の画面と同じく設定の「文字の速さ」に従う（仕様書は1字 45ms。「ふつう」は 34ms）。
7. タップの波紋（銀の菱形）は全部の画面に入れた。支援会話の画面の金の光の輪は、これに置き換えた（仕様書「金は使わない」）。
