# 探索画面 実装仕様書 — Unity（uGUI）向け

> **見本画像と、この仕様書の数値の両方を使って組んでください。**
> 元デザインは Claude Design キャンバスの「探索の札 E」（ページ「探索の札（たたき台）」）です。
> 探索の札 A〜D は不採用です。参考にしないでください。
> 拠点メニュー（Hub2）・会話画面・タイトル画面の仕様書と同じ決まり（字・座標・色）を使います。テキスト枠は **会話枠 H と同じ見た目** です。

## 0. 前提

| 項目 | 内容 |
|---|---|
| 基準解像度 | **1688 × 780**（スマホ横 844×390 の2倍）。数値はすべてこの基準の px |
| Canvas | uGUI、Reference 1688×780。画面の広がり方（Canvas Scaler）は **Unity の Hub2 の今の設定に合わせる** |
| 座標 | 左上原点・下向き＋Y。uGUI では anchor/pivot を左上 (0,1) にして `anchoredPosition = (x, -y)` |

| フォント | 日本語 Shippori Mincho（600〜800）／英字ラベル Barlow Condensed（大文字） |
| 絶対ルール | ① **出口は「端まで歩けば出る」**。押して開く札・確認は出さない ② **テキストは勝手に消さない**。閉じるのはプレイヤーのタップだけ ③ 光るのは「拾得物（アイテムが手に入る所）」だけ。チップス（読み物）は選んだときだけ光る |

### 3.1 タップがどれに当たるか（優先順）

1. テキスト枠が出ている → 枠を進めるだけ（部屋には何も起きない）
2. **出口の範囲** → 廊下へ（ほかの判定より先。カリマのベッドと重なっていても出口が勝つ）
3. **今選んでいる物の当たり判定の中** → その物を実行（調べる／話す）
4. 当たり判定に入っている物のうち **面積がいちばん小さい物** を選ぶ（カリマは本棚より小さいので、重なりではカリマが勝つ）
5. どれにも入らないが、ある物の「指す点」の横位置から ±110px 以内 → その物を選ぶ
6. それ以外 → 床をタップしたことにして、そこまで歩く

## 4. 縁の光

### 4.1 しくみ
家具ごとに3枚のマスク画像（`rim_masks/`）を、部屋の座標 `rects.json` の位置に置き、マスクの形に色を塗る（色 #eef0f4）。

| 層 | ファイル | 役目 |
|---|---|---|
| glow | `*_glow.png` | ふわっとした光（にじみ） |
| rim | `*_rim.png` | 縁の細い線 |
| band | `*_band.png` | 縁に沿って **光が流れる** 帯。中心 (--cx, --cy) から回る扇形（conic-gradient）の明るい部分だけを見せる |

光の層には暗い縁取り（drop-shadow 1.5px rgba(10,6,14,.85)＋4px rgba(10,6,14,.45)）を付けて、白っぽい背景の上でも見えるようにする。

### 4.2 いつ光るか

| 状態 | glow | rim | band（流れる光） |
|---|---|---|---|
| 拾得物・まだ調べていない | なし | **常に** 不透明度 .34 | **ときどき1周**：11秒ごとに、最初の約2.6秒で1周（最大の明るさ .55） |
| 拾得物・選んでいる | 2.4秒周期で .15↔.32 | .32 | 光が2つ、3.6秒で1周し続ける（.6） |
| チップス・ふだん | なし | なし | なし（代わりに4.3の印） |
| チップス・選んでいる | 2.4秒周期で .15↔.32 | .32 | 光が2つ、3.6秒で1周し続ける（.6） |
| 拾得物を取ったあと | なし（チップスと同じ扱い） | | |

光の出し入れは 0.4秒でふわっと。家具の光は家具ごとに開始を 1.2秒ずつずらす（bedA 0／chestA 1.2／shelfA 2.4／bedK 3.6／chestK 4.8／shelfK 6.0秒）。

### 4.3 チップスの印
光らないチップスには、指す点に **小さな菱形の印** を出す（選んでいるときと、画面外のときは出さない）。
- 30×30 の正方形を45°回した菱形。枠 1px rgba(228,231,236,.7)、中 rgba(9,10,13,.86)、影 0 2px 8px rgba(0,0,0,.55)。
- 中に虫めがねのアイコン 16px（線 2px #e4e7ec）。
- 3秒周期で上下に 5px ふわふわ（不透明度 .75↔1）。

### 4.4 画面の外にある拾得物
拾得物が画面の外にあるとき、その側の画面端（x=20 または 1668、y＝指す点の y＋40 を 120〜700 に収める）に菱形の印を出し、11秒周期で光らせる。

## 5. 札（調べる・話す）

`xp_03`〜`xp_06`。**枠なし**（文字＋下線＋引き出し線＋指す点の菱形）。

| 部品 | 値 |
|---|---|
| 英字ラベル | アイコン 16px＋`CHECK`／`TALK`（Barlow 12px 600、字間 .36em） |
| 動詞 | 「調べる」「話す」 27px 800、字間 .12em、#f6f4ef |
| 物の名前 | 22px 800、字間 .08em、#dcd8cf。動詞との間 14px |
| 色 | 調べる #e4e7ec ／ 話す #4fa3a8 |
| 下線 | 札の幅 × 1px。指す点の側が濃い（.85）→反対側へ透明になるグラデーション |
| 引き出し線 | 1px rgba(228,231,236,.9)＋下に 3px rgba(6,6,10,.55)。札の下の角 → 18px 内側 → 指す点の 14px 上 |
| 指す点 | 10px の菱形（札の色）＋ 22px の菱形の輪が 2.2秒周期で広がって消える |
| 背景 | 札のまわりに楕円の暗がり（幅＋100 × 128、中心 .86 → 外 0）。ALSO 行があるときは高さ 172 |
| PC | 動詞のあとに `ENTER` の小さな枠（22px 高） |

**位置の計算**（画面の座標。`ax = 指す点のx + camX`、`ay = 指す点のy`）
- 幅 `w = max(動詞の字数×27.5 ＋ 名前の幅(1+24+字数×22.7) ＋ 8, 150)`（PC は +62）
- 指す点が画面の左半分（ax < 844）なら札は右へ、右半分なら左へ。はみ出すなら反対側へ。
- `left = 右へ ? ax+70 : ax−70−w` を 24〜(1664−w) に収める。`top = max(ay − 124, 16)`

**出方**：札 .24秒（下から10px＋縮小から）→ 引き出し線が .34秒で伸びる → 下線 .34秒（.14秒遅れ）→ 文字 .4秒（.2秒遅れ）→ 指す点の菱形がポンと出る。
**押したとき**：.24秒で少し縮んで明るくなって消える。

**重なり（ALSO）**：収納箱とベッドのように2つが重なる場所では、札の下に `ALSO  ベッド ›` の行（高さ 40px）を出し、押すとそちらに切り替える。

## 6. 移動

### 6.1 タップで移動
- 床をタップ → そこまで歩く。タップした位置の **床（y=752）** に印を出す：
  - 楕円の輪 128×30（線 1px rgba(238,240,244,.85)）が .9秒で広がって消える
  - 内側の輪 68×16
  - 上から 10px の菱形が落ちてくる
  - 全体は 1.6秒で消える
- 物をタップ → その物まで歩いて選ぶ（縁が光って札が出る）。
- **選んでいる物をもう一度タップ**（当たり判定のどこでも）または札を押す → 実行。
- カメラ：行き先の部屋の x が 1350 より右なら右端へ、1000 より左なら左端へ。その間なら今のまま。
- 歩いている途中で別の場所をタップしたら、行き先を変える。

### 6.2 左右の矢印（Hub2 の矢印の形・丸い下地なし）
| 項目 | 値 |
|---|---|
| 位置 | 右：(1588, 290) 100×200／左：(0, 290) 100×200（ここ全体が押せる範囲） |
| 出る条件 | その方向にまだ部屋が続くときだけ。**左端（最奥）では左矢印なし**。**右端では右矢印なし**（出口の案内が見えているため） |
| 形 | 細い線（透明→.8）→ 8px の菱形 → 太い「›」（線 3px #eef0f4）→ 手前に薄い「›」（1.6px, .5）。下地は丸ボタンではなく、画面端から内側へ薄くなる暗がり（.62→0） |
| ふだんの動き | 2秒周期で外向きに 3px 揺れる |
| タップ | その方向の端まで歩く |
| 長押し（0.18秒以上） | 押している間 **走る**（1秒に 900px）。矢印が明るく光り、揺れが 0.35秒周期に速くなる。離したところで止まる |
| 右端で右を長押し | 端に着いてからさらに 0.35秒押し続けたら廊下へ |
| PC | ←→／A・D キーでも同じ（押しっぱなしで走る） |

### 6.3 ヒント
部屋に初めて入ったときだけ、下中央（y=716）に `◆ 行きたい場所をタップ ◆`（18px 600、字間 .14em）を 3.4秒周期でゆっくり明滅。**最初のタップで消える**。2回目以降は出さない（数秒放置で再表示するかは任意）。

## 7. 出口（廊下へ）

**押して開く札にはしない。端まで歩けば出る。**

- **案内表示**：部屋の右端に `EXIT 廊下へ` を常に出す（`xp_02`）。押せない飾りの表示（タップは 3.1 の出口の範囲で受ける）。見た目は5章の札と同じ（枠なし・下線・引き出し線・指す点の菱形）。位置は部屋の座標で固定：
  - 札 (2064, 424) 幅 150 × 60、右揃え
  - 指す点 (2284, 548)
  - 背景の暗がり (2014, 390) 250×128
- **出る方法**：出口の範囲をタップ／右矢印を長押しして端に着いてから 0.35秒／右端で右矢印をタップ。
- **出方**：右端まで歩く（約 0.45秒）→ 暗転 2.3秒のうち、最初の 22% で黒 #050508 になる → 中央に `CORRIDOR ── 廊下へ`（Barlow 14px ＋ 線 30px ＋ 22px 700）が左から少し滑って出る → 廊下の画面を読み込んで明ける。
  - キャンバスでは明けたあと部屋に戻っていますが、**ゲームでは廊下の画面へ** 進めてください。

## 8. テキスト枠（会話枠 H と同じ見た目）

`xp_07`〜`xp_10`。会話画面（会話枠 H・Hub2寄り）の部品をそのまま使う。

| 種類 | いつ | 形 |
|---|---|---|
| 地の文 | 調べた結果（拾得物・チップス） | 上中央。名前札なし。文は中央揃え・色 #d6d2c9 |
| セリフ | 話す | 名前札（台形、22px 700）＋話している人へ向くしっぽ。文は左揃え・#f1efe9・枠の右側に点模様 |

**寸法**（会話枠 H と同じ式）
- 1字 31.8px、1行 50px、文字 30px 600、字間 .06em
- 幅 `w = max(540, 最長の行の字数×31.8 ＋ 110)`、高さ `h = 30 ＋ 行数×50 ＋ 34`
- 地の文：`x0 = 844 − w/2`、`y0 = 98`
- セリフ：話す人の頭の位置 `hx`（カリマ＝部屋の x 1497 ＋ camX）
  - 画面の右半分なら `x1 = min(1648, hx+70)`、左半分なら `x0 = max(40, hx−70)`
  - `y1 = 292`（はみ出すなら y0=98）
  - しっぽは下辺から人の方へ 34px・下へ 40px
- 枠：角を 14px 斜めに欠いた形、線 rgba(214,218,224,.72)、中 rgba(9,10,13,.92)×86%。内側 6px に細い線 rgba(214,218,224,.22)。左上・右下の角に 7px の菱形。
- 出方：.26秒で下から 6px 浮き上がる。名前札は .24秒で左から。

**文字の出し方と進め方（いちばん大事）**
- 1字 45ms で出す。出している間は右下に3つの点。出し終わったら3つの菱形が跳ねる（会話枠 H と同じ）。
- **自動では絶対に閉じない・自動で次へ進まない。**
- タップ（画面のどこでも）：
  - 文字を出している途中 → 全部出す
  - 全部出ている → 次のページ、最後のページなら閉じる
- **誤タップ対策**：
  - 枠が開いた直後・ページが変わった直後の 0.4秒はタップを無視
  - 全部出た直後の 0.35秒もタップを無視
- 枠が出ている間は、部屋のタップ・矢印・キー移動を受けない。
- 閉じたら選んでいた物の選択を外して探索に戻る。
