### 決まったことの要約

1. メインの吹き出しは **画面の真ん中に固定**。話す人が変わっても、位置も大きさも動かない。
2. 誰が話しているかは **尾** で示す。内側の人は下から、外側の人は横から。姿の見えない声は尾なし。
3. 立ち位置は **先に来た人が内側**。人数が増えても、先にいる人は動かない。
4. 台詞は **1行13字・1ページ3行**。超えたらページ送り。
5. 端の人のつぶやき（**ガヤ**）と、画面の外の声（**ひそひそ・ざわざわ**）を出せる。
6. 怒鳴る・叫ぶ台詞には **叫ぶ演出**（一気に出る＋画面が揺れる＋話す人が前へ＋周りが暗く）。箱の形は変えない。

> - 高さ: そのページの行数に合わせて 1〜3行（114・164・214）。
> - 幅: そのページのいちばん長い行が11字以下なら、本文（字数 × 31.8）＋ 左右の余白 67。ただし名前札（札の幅 ＋ 34 × 2）と「次へ」の印が入る 200 より狭くしない（いちばん広くて 417）。12字以上の行があるページは 480。

### キャラごとの補正（体格の差）

| キャラ | 横（＋で画面の外側へ） | 縦（＋で下へ） | 頭のてっぺんY（参考） |

| アルシェ | 0 | 0 | 297 |
| カリマ | 0 | 0 | 293 |
| キャリー | 0 | 0 | 273 |
| ギュンター | ＋16 | 0 | 230 |

## 3. 尾

### 決まり

| 話す人 | 尾 |
|---|---|
| 内側に立っている人 | 箱の **下の辺** から |
| 外側に立っている人 | 箱の **左右の辺** から（話す人の側） |
| 立ち絵のない人・画面の外の声 | **なし**（「尾がない＝姿の見えない声」） |
| 地の文・携帯端末 | なし |

1〜2人の場面は全員が内側に立つので、尾はいつも下から（4人のときの内側の人と同じ）。

### 形：細く鋭い三角

**外側の人（横の尾）**
- 付け根の高さ：by = y0 + 110（＝208）
- 付け根の幅：18（by の上下に 9 ずつ）
- 先：左の人は (x0 − 50, by + 31)、右の人は (x1 + 50, by + 31)
- **隣の頭をよける**：先の Y が「同じ側の内側の人の頭のてっぺん − 40」より下になるときは、付け根ごと上へずらす（上限は y0 + 24 まで）。
  - 例：右の内側がギュンター（頭 230）のとき、先は 190 まで上がり、付け根は約 159。

**内側の人（下の尾）**
- 付け根の中心 bx：頭の中心X ＋（左の人は ＋40／右の人は −40）。ただし [x0 + 64, x1 − 64] に収める。
- 付け根の幅：18
- 先：左の人は (bx − 37, y1 + 42)、右の人は (bx + 37, y1 + 42)

尾の線・地は箱と一体（同じ輪郭の一部として描く）。

## 4. ガヤ（立ち絵のある人のつぶやき）

### 出す条件

- **3人以上の場面で、外側に立っている人だけ。** 内側の人の頭はメインの箱のすぐ下なので置く場所がない。
- その人がメインで話している台詞のあいだは出さない。
- **地の文・携帯端末のあいだは出さない。** 立ち絵のない人の台詞（兵士の知らせなど）には、反応として出してよい。
- 台詞ごとにシナリオで指定する（誰が・何を・ふつう／強め）。

### 出方・消え方

- **出る**：メインの台詞と同時に、メインと同じ出方（下から 6px・0.26 秒）。
- **消える**：そのガヤの出番が終わったとき、0.45 秒で 5px 上へ浮きながらフェードアウト。
- **同じガヤが次の台詞にも続くときは、動き直さない**（ちらつかせない）。

### 見た目（ふつう）

| 項目 | 値 |
|---|---|
| 位置 | 頭の中心X に中央をそろえる（画面の端から 16px 以内に収める）。下の端 = 頭のてっぺん − 26 |
| 大きさ | 幅 = 字数 × 25.4 ＋ 48、高さ 50 |
| 字 | 24px・太さ 600・行送り 50・中央揃え・色 #d6d2c9 |
| 形 | メインと同じ作り：角の切り落とし 8、地 rgba(9,10,13,0.79)、線 `ln`、内側の線（5px 内側・角 5）、ドット柄 0.22 |
| 菱形 | **右下に1つだけ**（7px、中心 (右端 − 12, 下の端)） |
| 尾 | 下の辺から。付け根の中心 = 頭の中心X（[左端+22, 右端−22] に収める）、付け根の幅 14、先は 14px 下・左の人は ＋4／右の人は −4 |

### 見た目（強め：割り込み・驚き用）

| 項目 | 値 |
|---|---|
| 字 | 26px・太さ 800・行送り 54・色 #f6f4ef |
| 大きさ | 幅 = 字数 × 28 ＋ 54、高さ 54 |
| 形 | **とげC**（下の「とげC の作り方」）。内側の線もとげに沿う。右下の菱形は残す |
| 線・地 | ふつうと同じ。**光らせない**（メインより目立たせない） |
| 出方 | 小さい所から弾んで出る：scale 0.8 → 1、0.38 秒、cubic-bezier(.2,1.6,.4,1)。2回目以降は動かさない |

目立つ順は **メイン ＞ 強めのガヤ ＞ ふつうのガヤ ＞ 画面の外の声**。

#### とげC の作り方（角の斜めを外へ引き出す）

箱 (x0, y0)–(x1, y1)、角の切り落とし c、とげの長さ s、辺のへこみ k として、時計回りに：

```
(x0+c, y0) → (中央X, y0+k) → (x1−c, y0) → (x1+s, y0−s) → (x1, y0+c)
→ (x1−k, 中央Y) → (x1, y1−c) → (x1+s, y1+s) → (x1−c, y1)
→ [下の尾] → (x0+c, y1) → (x0−s, y1+s) → (x0, y1−c)
→ (x0+k, 中央Y) → (x0, y0+c) → (x0−s, y0−s) → 閉じる
```

- 外側：c = 10、s = 13、k = 4（尾付き）
- 内側の線：5px 内側の箱で c = 7、s = 5、k = 3（尾なし）

### 使いどころ

- **日常の場面・間の抜けたやり取り・ちょっとシュールな場面向け。** ガヤは少しコメディ寄りに見えるので、シリアスな場面・緊張した場面では使わない。
- 会話ログには **残す**。名前の横に「（ガヤ）」の印を付ける。

## 5. 画面の外の声（ひそひそ・ざわざわ）

| 項目 | 値 |
|---|---|
| 尾 | なし |
| 字 | 20px・太さ 600・行送り 40・中央揃え・色 #b8b5ae |
| 大きさ | 幅 = 字数 × 21.6 ＋ 36、高さ 40 |
| 形 | 角の切り落とし 6、地 rgba(9,10,13,0.58)、線 rgba(214,218,224,0.3)。飾りなし |
| 動き | 3.6 秒で1周をくり返す：0〜18% で 5px 下からフェードイン → 68% まで表示 → 100% で 5px 上へフェードアウト |
| 置き場所 | 画面の上の空いた所（y ≒ 108〜150）。ガヤ・メインの箱・名前札にかからないように |

| 種類 | 例 | キャンバスでの置き方 |
|---|---|---|
| ひそひそ | 「ねえ、聞いた…？」「ひそひそ…」 | 左上（左の端 46）と右上（右の端 1688−46）。2つ目は 1.8 秒遅らせて交互に |
| ざわざわ | 「ざわ…」「ざわざわ…」 | (70,118)・(372,150)・(1150,112)・(1430,108) に4つ。0・0.9・1.8・2.7 秒ずらす |

- 場の空気なので、**地の文のあいだも出してよい**。シリアスな場面（陰口・不穏なざわめき）にも使える。
- 置き場所は場面ごとにシナリオで変えられるようにする（キャンバスの位置は見本）。

## 6. 叫ぶ演出（メインの台詞）

怒鳴る・叫ぶ台詞だけに使う。**箱の形は変えない。**

| 要素 | 内容 |
|---|---|
| 文字 | 文字送りをせず、全文を一気に出す |
| 箱と文字 | scale 1.08・不透明度 0.2 → 1、0.2 秒、cubic-bezier(.2,.9,.3,1)。中心は箱の中心 |
| 画面の揺れ | 0.36 秒。画面全体を scale 1.015 にしたまま、(−6,3)→(6,−3)→(−4,2)→(3,−1)→(−1,0)→元へ（15/30/48/66/84/100%） |
| 話す人 | 立ち絵を 12px 上げて 1.04 倍（足元を基準）。0.35 秒で移る |
| 周り | 画面の端を暗くする：中心 (50%, 45%)、楕円 70%、30% まで透明 → 端で rgba(0,0,0,0.5)。0.25 秒でフェードイン |

- タップ1回で次の台詞へ（全文が出ているので「全文を出す」の段階はない）。
- 動きを減らす設定では、揺れ・弾みを止める。
- **たまに使うから効く。** 連続して使わない。

### 強さの段階（特殊演出との関係）

| 段階 | 演出 | 使いどころ |
|---|---|---|
| 1 | 字の指定（太さ・フォント） | 少し語気が強い |
| 2 | 叫ぶ（この章） | 怒鳴る・叫ぶ |
| 3 | ひび（慟哭） | 感情が爆発する |
| 4 | 崩れて赤へ | 表の言葉が割れて本音が出る |
| 別枠 | 染まる | 洗脳・侵食 |

- **3・4・別枠（特殊演出）は今回は作らない。** ひびの見た目を作り直す予定（ひびの絵は画像で用意し、動きはコードで付ける方針）。決まったら別の仕様書で渡す。
- 段階3のひびは、段階2の揺れのあとにひびが走る形にしてつなげる予定。

## 7. シナリオの書き方（テキスト担当へ）

- **改行は「段落の区切り」として書く。** 字数を数えて手で折り返さなくてよい。
- ゲームが **13字で自動で折り返す**。そのとき「、。！？」）…ー」と全角スペースは行頭に来ないようにする（禁則処理）。
- 1つの台詞は **3行（39字）くらいまで** を目安にする。長い台詞・説明・モブの会話は、2ページ目に送られる。8行を超える特別な台詞は特殊演出として扱う。
- シナリオ表に、次の列を足すと渡しやすい：

| 列 | 中身 |
|---|---|
| 箱の演出 | ふつう／叫ぶ |
| 字の指定 | 太さ・フォント（場面に合わせて） |
| ガヤ | 誰が・本文・ふつう／強め |
| 画面の外の声 | なし／ひそひそ／ざわざわ と本文 |

- **前の決まり（1行18字・2行）は使わない。**

## 9. Unity への持ち込み（総合担当へ）

- 依頼の `bubble_slots.json`（枠ごと：話す人の側の端・上の端・尾の先・1行の字数・1ページの行数）は、今回の決まりでは **箱が1つに固定** されるので、枠ごとの箱の値は要らない。代わりに次の値を持つ形がよさそう：
  - 箱：x0 604・y0 98・幅 480・高さ 214、1行 13字、1ページ 3行
  - 立ち位置：基準 内 300・外 600、キャラごとの補正（横・縦）
  - 尾：横の尾（付け根 y0+110、幅 18、長さ 50、下がり 31、よける余白 40、上限 y0+24）、下の尾（頭から ±40、幅 18、先 ±37・+42）
  - ガヤ・画面の外の声の大きさと出方
  - 叫ぶ演出の値
- 「全員が同じ真ん中の箱を使う」「人数で並び方が変わる」は、今の仕組みに足す必要がある。
- 組み方は元の仕様書と同じく、見本を 40% で重ねて合わせる。見本の画像はキャンバスのアートボードから書き出す（下の「見本の撮り方」）。

| 4人・右の外（横の尾・頭をよける） | 4人 | 右の外 | 3行の台詞（続きなし） | order：内＝ギュンター |
| 4人・ガヤふつう | 4人 | 左の内 | | gaya オン・gayaMode ふつう |
