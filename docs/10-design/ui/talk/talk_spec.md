# 会話画面（ノベルパート）実装仕様書 — Unity（uGUI）向け

> **見本画像と、この仕様書の数値の両方を使って組んでください。**
> 元デザインは Claude Design キャンバスの「会話枠 H」「会話ログ画面（H案の見た目）」「テキストボックスの特殊演出」です。
> A〜G案の会話枠は不採用です。参考にしないでください。
> 拠点メニュー（Hub2）の仕様書と同じ決まり（色・線・字）を使います。

---

## 0. 前提

| 項目 | 内容 |
|---|---|
| 基準解像度 | **1688 × 780**（スマホ横 844×390 の2倍）。数値はすべてこの基準の px |
| Canvas | uGUI、Reference 1688×780。**画面の広がり方（Canvas Scaler の設定）は、Unity の Hub2 の今の設定に合わせる**（iPhone で確かめ済みのもの） |
| 座標 | 左上原点・下向きが＋Y。uGUI では anchor/pivot を左上 (0,1) にして `anchoredPosition = (x, -y)` |
| 背景 | 2Dの探索マップ（シーン）がそのまま見える。会話用に背景を差し替えない |
| 絶対ルール | ① 吹き出し・名前札は **いつも立ち絵より手前**（立ち絵が UI の前に出ない） ② 名前札の色は **どんな演出でも変えない** ③ 1ページ **2行まで**。超えたらページ送り。**文字は小さくしない** |

## 1. 色・線・字

### 色（テーマ変数）
場所によって2種類を切り替える。既定は「汎用」。

| 変数 | 汎用 | オルクス城 | 用途 |
|---|---|---|---|
| `ln` | rgba(214,218,224,0.72) | rgba(201,205,210,0.75) | 主線（銀のヘアライン） |
| `ln2` | rgba(214,218,224,0.22) | rgba(201,205,210,0.25) | 副線 |
| `ac` | #e4e7ec | #e2b04a | アクセント（ひし形・強調） |
| `acg` | rgba(214,226,240,0.55) | rgba(242,196,96,0.55) | アクセントの光彩 |
| `pl` | rgba(9,10,13,0.92) | rgba(12,10,20,0.92) | 吹き出し・タブの地 |
| `tx` | #f1efe9 | #f1ead9 | 本文 |
| `nar` | #d6d2c9 | #d9d0bd | ナレーション本文 |

- 地の黒は **`pl` を不透明度 0.86 で重ねる**（吹き出し・上のタブ共通）。下に別の色の層を敷かない（敷くと透けて灰色になる）
- ティール #4fa3a8 は「次へ」のひし形でだけ使う
- 景色そのものに色はかけない

### 線
- 枠は1pxの銀ヘアライン（`ln`）＋内側6pxにもう1本（`ln2`）
- 角は14pxの斜め切り（内側の線は10px）
- 飾りの菱形は7px（正方形を45°回転）

### 字
| 用途 | フォント | サイズ |
|---|---|---|
| 台詞 | Shippori Mincho 600 | 30px／行送り50px／字間0.06em |
| 名前札 | Shippori Mincho 700 | 22px／字間0.14em |
| 英字ラベル | Barlow Condensed 600（大文字） | 14〜15px／字間0.3em前後 |
| ログの台詞 | Shippori Mincho 600 | 26px／行送り46px |

> **字の太さの置き換え**：Unity に入っている Shippori Mincho は 600 と 800 だけ。この仕様書で 700 と書いてある所は、**19px以上（名前札22px・ログの名前20px・タブの場所名20px など）は 800、16px以下（下のボタン16px など）は 600** にする。支援会話の相手選び画面と同じ決まり。

- 全員 **右向きで描かれている**ので、右側に置く人は左右反転する

## 4. 吹き出し（台詞の枠）

### 形
- 角を14px切った長方形。地＝`pl`×0.86、線＝`ln` 1px
- 内側6pxに `ln2` の線（角10px）
- 中にドット柄：16px格子・半径1.1px・rgba(241,234,217,0.5)、全体の不透明度0.3。左→右に濃くなるマスク（0%透明 → 45%で薄く → 100%不透明）
- 左上（x0+10, y0−4）と右下（x1−17, y1−4）に菱形7px

### 大きさ（台詞の長さで伸び縮み）
- `CW = 31.8`（30px＋字間の1文字幅）
- `txW = その台詞の全ページで一番長い行の文字数 × 31.8 + 10`
- `w = max(540, txW + 100)`（ページをめくっても幅は変わらない）
- `h = 30 + 行数 × 50 + 34`（1行=114、2行=164）
- 本文：左揃え、ブロックごと吹き出しの中央へ。`txX = 吹き出し中心X − txW/2`、`txY = y0 + 34`

### 置き方① 頭の上（通常モード）
- 横
  - 左の人：`x0 = max(40, 頭X − 70)`
  - 右の人：`x1 = min(1648, 頭X + 70)`
- 縦
  - `y1 = min(292, 話す人の立ち絵の上端 − 8)`
  - `y0 = max(98, y1 − h)`（上のタブとぶつからないための下限）
- 尾：下の辺から斜め下へ短く
  - `bx = 頭X±20 を [x0+70, x1−70] に収めた値`
  - 左の人：(bx+18, y1) → (bx−34, y1+40) → (bx−6, y1)
  - 右の人：(bx+6, y1) → (bx+34, y1+40) → (bx−18, y1)

### 置き方② 顔の横（支援会話モード・2人）
- 横（2人の間に出す）
  - 右の人：`x1 = max(w + 40, 頭X − 115)`
  - 左の人：`x0 = min(1648 − w, 頭X + 115)`
- 縦：`y1 = max(98 + h, 話す人の立ち絵の上端 + 70)`（下の端が目の高さあたり）
- 尾：下の辺の、話す人に近い角から斜め下へ（**真横には出さない**）
  - 右の人：`bx = x1 − 64`、先端 (bx+36, y1+38)
  - 左の人：`bx = x0 + 64`、先端 (bx−36, y1+38)

### 特別な話し方
| 種類 | 名前札 | 尾 | 本文 | ほか |
|---|---|---|---|---|
| ナレーション | なし | なし | 中央揃え・`nar` 色 | 吹き出しの地は通常と同じ |
| 携帯端末 | 「携帯端末」＋四芒星 | なし | 通常 | ドット柄を不透明度0.55に強める |
| 立ち絵の無い人 | あり | 右の辺から画面外へ（(x1,中央−12)→(x1+46,中央−22)→(x1,中央+12)） | 通常 | 立ち絵は全員話していない扱い |

- ナレーション・携帯端末：吹き出しは画面中央（中心X 844）
- 立ち絵の無い人：吹き出しは中心X 904

## 6. 「次へ」の印

- 位置：吹き出しの右下の内側（右端 x1−30、上 y1−32）。右揃え
- 文字送り中：灰色の丸点（5px）3つ。間隔12px。1.4秒周期で順にゆっくり明滅
- 送り終わり
  - 点が1つずつ（0.12秒ずつずらして0.55秒で）9pxの菱形に変わる
  - その後の跳ね：3.6秒に1回、6pxだけ。左から0.22秒ずつずらす
  - その後の色：ティール #4fa3a8 → 金 #e2b04a → 銀 #c9cdd2 が、9秒で1周しながら隣へ移っていく
  - 間隔10px
- ページ送りがある台詞では、菱形の左に「1 / 2」（Barlow Condensed 14px、#b8b5ae）
- 動きを減らす設定では、跳ねと色の変化を止めて、ティール・金・銀を並べた状態で表示する

### 操作
- 文字送り：1文字ずつ、34ms間隔
- 画面タップ（ボタン以外）
  1. 文字送り中なら、その場で全文を出す
  2. 次のページがあれば、そのページへ
  3. どちらでもなければ、次の台詞へ
- 台詞が変わるとき：吹き出しを下から6pxずらしつつ、0.26秒でフェードイン

## 12. 特殊演出（後で作る。今は決まりだけ）

普段の吹き出しと同じ形・線を使い、「普段との差」で見せる。名前札は変えない。

| 演出 | 使いどころ | 流れ |
|---|---|---|
| ひび（慟哭） | 感情が爆発する台詞 | 吹き出しが0.42秒揺れる → 衝撃点から白いひびが走る（0.5秒）→ 文字が一瞬ぶれる |
| 崩れて赤へ | 表の言葉が割れて本音が出る | 揺れとひび → 黒い吹き出しが表の台詞ごと6片に割れて落ちる（0.85秒〜、約1秒）→ 下から**同じ黒い吹き出し**が現れる。太い亀裂（暗い溝＋奥に細い赤線）が残り、**文字だけ深紅（#e23a44、赤いにじみ）** |
| 染まる（洗脳・侵食） | 何かに書き換えられる | **上から下へ**、にじんだ縁で吹き出しが**透けるくすんだ白**に染まっていく（約3.4秒）。染まった所は、文字が**黒・手書き風フォント（Zen Kurenaido）**に変わる |

- Unity では、マスク（ステンシル／スプライトマスク）と、割れ片のメッシュ（またはスプライト）が必要
- 実際に使う台詞と場面が決まってから詰める
