## 2. なぜかっこいいのか（目を引く・ドラマがある）

かっこよさは「何を見せないか」と「どこに力をためるか」で決まる。10月4日の版は次の6つがそろっていた。

1. **主役が一つ**
   画面にあるのは太陽盤と5枚の札だけ。目が迷わず、一点に集まる。要素が増えるほど一つ一つは弱くなる。
2. **大きさの差が極端**
   太陽盤は画面の高さを超えるほど大きく、札は小さい。大と小の差が大きいほど画面に緊張が生まれる。中くらいの物ばかりだと平板になる。
3. **画面の外へはみ出している**
   太陽盤は左の端で半分切れている。見えない半分を想像させるので、実物より大きく、画面の外にも世界が続いて見える。全部を枠の中に収めると、とたんに「部品」になる。
4. **世界と地続き**
   メニューの後ろに回廊・空・城・キャラクターがそのまま見える。メニューが世界を「隠す」のではなく、世界に「重なる」。奥行きと空気がある。
5. **色の対立がはっきり**
   アルシェの金・橙の太陽と、青い空は反対の色どうし（色の調和の決まり「隣か反対」の「反対」）。互いを引き立てて、太陽が光って見える。カリマの白・青は空と隣の色どうしで、静かでまとまる。どちらも決まりに沿っているから気持ちよい。
6. **動きに理由と重さがある**
   札は円弧に沿って回り、選ぶと真ん中へ来て大きくなり、炎が灯る。「回る→止まる→灯る」に順番と結果があるので、ただ動くのではなく「操作した手応え」になる。原作者の言う「用がなくても押したくなる」の正体はここ。

ダークファンタジーとして効いている点: 暗い中に光が一点だけある（明暗の差）。光を配りすぎると、暗さも光もどちらも弱くなる。

## 3. なぜ美しいのか・秀逸なのか（整っている・品がある）

美しさは「そろえること」と「一点だけ崩すこと」の釣り合いで決まる。

1. **色を絞っている**
   アルシェは黒・金・橙、カリマは白・銀・青。持ち主ごとに3色前後。色が少ないほど、一色ごとの意味が強くなる（金＝アルシェ、青＝カリマ）。
2. **線の言葉がそろっている**
   太陽盤の縁、札の縁、針、アプリ枠の張り出しが、どれも「細い金の線」でできている。線の太さと質感がそろうと、別々の部品が一つの物に見える。戻るボタンA（細い線が時間帯の飾りへつながる）が自然に見えたのもこのため。
3. **形の言葉がそろっている**
   太陽＝円と放射、札＝矢羽根（太陽の中心を指す）、針＝中心から外へ。どの形も「太陽の中心」を向いている。中心が一つある画面は落ち着く。
4. **並びが有機的**
   札が四角い格子ではなく円弧に沿って並ぶ。格子は機能的だが硬い。円弧は太陽盤と一体に見え、品がある。
5. **余白が大きい**
   10月4日の版は右半分以上が景色。何も置かない場所があるから、置いた物が美しく見える。
6. **静かに動き続ける物は、控えめ**
   ステンドグラスのような太陽盤、ガラスの輪の薄さ、BOOTHの線の素材。「置いておくだけでおしゃれ」は、主役の邪魔をしない薄さと遅さで成り立っている。強い光や点滅は、何度も見るとうるさくなる（⑤の「きらっ」を初回だけにした理由と同じ）。

## 4. なぜ機能的なのか（迷わない・疲れない・何度でも気持ちいい）

1. **よく使う物ほど近く・大きく・先に**
   「出撃」が太陽盤の真ん中で、選ぶと大きくなる。⑤では開くとき「出撃」が最初に出る。右下は横持ちの右手の親指が届く所で、「端末」で開き「スリープ」で閉じる案もここに集めた。
2. **知っている操作を借りる**
   スマホの作法（スリープで閉じる、アプリの中では左上の「＜」で一段戻る）を使えば、説明がいらない。スマホに無い物（四角い「戻る」、独自のスワイプ）は、迷いと「おもちゃっぽさ」を生む。
3. **一つの物に一つの意味**
   開くのは「端末」、閉じるのは「スリープ（月）」。数字（所持金・名声）は見る物、アプリは開く物。役割が混ざると、押して何が起きるか分からなくなる（所持金をアプリにすると「開くと何があるのか」と迷う）。
4. **今の状態が一目で分かる**
   選んでいる札は大きく・炎が灯る。時間帯は絵で分かる。状態が文字を読まなくても分かると、疲れない。
5. **速い・止めない**
   開くのは0.6秒以内、開き始めから押せる、途中で反対の操作をすればその場から戻る。メニューは何十回も開くので、待たされる時間は積み重なる。
6. **読める**
   文字は11px以上、押せる所は実寸44px以上。文字の後ろは十分に暗く（または明るく）する。景色を透かすときも、文字の多い側ほど暗くする。
7. **100回目も気持ちいい**
   初めてのときに嬉しい演出と、毎回見る演出を分ける。毎回の物は短く静かに、特別な物は初回や物語の節目だけ。

## 5. 今の画面に当てはめると（演出担当の見立て）

Codex がブラッシュアップ中なので、指示ではなく見立てとして書く。

**良い所（守りたい）**
- 太陽盤と札の手触り（回る・真ん中へ・大きく・炎）。§2-6 そのもの。
- 持ち主ごとに絞った色（黒金／白銀青）と、細い金の線でそろった縁取り。
- アプリの絵の金の張り出しなど、部品の仕上げの丁寧さ。

**弱いかもしれない所（考える価値がある）**
- **主役が分散**: 上の段・運命予報の帯・場所の絵・アプリ5つが、どれも同じくらいの強さで並ぶ。太陽盤が「主役の一人」に下がって見える（§2-1）。→ 何を一番に見せ、何を一段下げるか、強弱をつける。
- **後ろが無地の板**: 世界と切れて、10月4日の版の奥行きが消えている（§2-4）。→ 「背景が世界」の見比べ（`sunfan.html` の「ホームの背景」）。
- **所持金・名声がアプリ**: 見る物が開く物の形をしている（§4-3）。→ Codex へ依頼済み（上の段へ移す）。
- **余白が少ない**: 右側がほぼ埋まっている（§3-5）。情報は減らさずに、まとめ方で余白を作れないか。
- **静かに動く物が少ない**: 開いたあと、画面がほとんど止まって見える（§3-6）。BOOTHの線のような、薄く遅い飾りが一つ二つあると「部屋」になる（TRPGの部屋の名残を雰囲気で残す、にもつながる）。

## 6. 迷ったときの問い（上から順に当てる）

0. **ホームの目的「一目で状況を把握し、考える時間をつくること」（原作者 2026-11-07）に役立っているか。** 状況が一目で入るか。考えるのを急かす物（点滅・強い光・せわしない動き）はないか。
1. 主役は一つか。一番に見せたい物はどれか、言えるか。
2. 大きさの差は十分か。中くらいの物ばかりになっていないか。
3. 画面の外へはみ出す物があるか（全部を枠に収めていないか）。
4. 後ろに世界を感じるか。メニューが世界を隠しすぎていないか。
5. 色は持ち主ごとに3色前後に収まっているか。景色に重ねる色は、背景の色の隣か反対か。
6. 線の太さ・形の言葉はそろっているか。そろえた上で、崩しているのは一点だけか。
7. 余白はあるか。
8. スマホに無い物を置いていないか。スマホの作法で済むなら、そうしているか。
9. 一つの物に一つの意味か（見る物と押す物が混ざっていないか）。
10. よく使う物ほど近く・大きく・先にあるか。右手の親指で届くか。
11. 0.6秒以内に開き、開き始めから押せるか。途中で戻せるか。
12. 文字は11px以上、押せる所は44px以上、文字の後ろは十分に暗いか。
13. 100回目も気持ちいいか。チカチカ・待たされる所はないか。
14. ダークファンタジーとして、暗さの中に光が一点か。光を配りすぎていないか。
15. TRPGの部屋らしさ（四隅の飾り・静かに動く物・幕の開く窓）が、主役の邪魔をしない薄さで残っているか。

## 7. 次に試す価値がある物

- **背景が世界**（試作あり。`sunfan.html` の「ホームの背景：世界が透ける」）。開いた瞬間の景色をぼかして暗く沈め、左は明るく右ほど暗く。
- **置いておくだけの飾り**（未試作）: 細い金の線をゆっくり光が渡る／太陽盤のまわりに小さな光の粒が漂う／四隅の飾りがかすかに呼吸する。条件は「薄く・遅く・点滅しない」。どれか一つから。
- **強弱の整理**（Codex の受け持ち）: 太陽盤を一番、次に運命予報と今日のタスク、数字は一段下げる、など。§6 の 1〜3 を当てて見比べる。
- **資料の見方**: interfaceingame.com を「Menu」＋動画で絞り、①開いてから操作できるまでの速さ ②背景の扱い ③置いておくだけの飾り、の3点だけ見る。真似はせず、理由だけ持ち帰る。
