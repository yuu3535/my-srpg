## 物語の核

百年戦争編の中心は、「英雄譚として語られる歴史」と「英雄譚を成立させるために誰かが背負った犠牲」の二重構造。

表の物語:

- オルクスとアルストロの百年戦争
- 魔王サタンの討伐
- 勇者リングホルムの伝承
- 戦争終結と両国同盟
- 世界平和へ向かう歴史

裏の物語:

- 勇者を作る計画
- 戦争後も残る国民感情の溝
- 「トドメを刺す」か「止める」かの倫理
- 友好度や説得で運命を変える余地
- 正史ではリングホルムが死ぬ
- 勇者が本当には救われていない

SRPG化では、単に敵を倒すゲームにしないことが重要。
この作品では「勝つこと」よりも、「どう勝つか」「誰を殺さずに済ませるか」「誰の視点で歴史を見るか」が重い。

## 二人の主人公視点

主人公枠は、アルシェとカリマの二視点を軸にすると世界観と相性が良い。

### アルシェ視点

役割:

- 王族としての理想
- 伝承や正史を信じたい側
- 戦争を「物語」として受け取る側
- 表の歴史、和平、王族の責務に近い視点

UI/演出の方向:

- 比較的明るい金、王族感、儀礼感
- 「記録」「正史」「宣誓」「戦況」など、公式文書寄りの言葉が合う
- 画面は整然、左右対称、王城・軍議・式典感が出るとよい

### カリマ視点

役割:

- 同じ王族でも、影・現場・臣下の視点に近い
- ギュンターやオルクス側の現実感に触れやすい
- 戦争の後始末、魔物の国の痛み、ヒトに見える王子たちの歪さを見る側
- 表の英雄譚に隠れた犠牲へ近づく視点

UI/演出の方向:

- 黒、紫、鈍い金、暗いアンバー
- 情報の見せ方は少し冷静、観察的、密偵的でもよい
- 「兆候」「異常」「密命」「観測」「裏報告」などの語感が合う

## 国ごとのUIテーマ

今後、所属・視点・マップによってUIテーマを切り替える案はかなり有効。
これは単なる色替えではなく、「どちら側の歴史を見ているか」をプレイヤーに伝える演出になる。

### オルクス側

世界観:

- 魔物の国
- 黒、紫、魔鉱石
- 魔性、退廃、重厚、華やかさ
- 王族や貴族は紫を好む
- 現魔王フォースは平和的だが、サタン時代の影が残る
- 国民側にはヒトへの憎しみや過激思想も残っている

UI色:

- 背景: 黒、墨色、濃紺寄りの黒
- 主色: ヴァイオレット、深紫
- 強調: 鈍い金、アンバー
- 危険色: 深い赤、黒赤
- 光: 魔鉱石のような冷たい紫光、暗い金の反射

UI形状:

- 重厚な細枠
- 黒い石材、魔鉱石、王城の金属装飾
- 直線的だが、少し異形感のある切り欠きや偏り
- パネルは暗く、情報は金で浮かせる

使う場面:

- オルクス魔王城
- オルクス王族視点
- アルシェ/カリマが自国側として動く場面
- 魔鉱石、魔法、密命、臣下、ギュンター周り

### アルストロ側

世界観:

- ヒトの国
- 白と青、神聖、秩序
- 重厚な白い石材
- 青は神聖な色
- 王族に聖なる蝶の召喚獣の伝統がある
- 百年戦争の伝承や勇者物語が強く残る
- 魔物への冷ややかさ、純血主義も一部に残る

UI色:

- 背景: 白石、青灰、淡い紺
- 主色: 聖青、銀
- 強調: 淡い金、白金
- 危険色: 冷たい赤、血色を抑えた赤
- 光: 聖堂の窓光、冷たい朝の光

UI形状:

- 整然とした枠
- 白い石壁、聖堂、騎士団、公式記録の雰囲気
- 直線と左右対称を多めにする
- 装飾はオルクスより清潔で硬い

使う場面:

- アルストロ城
- 終戦記念パーティ
- ギルド、騎士、公式軍議
- 勇者伝承、正史、表向きの歴史

## テーマ切り替え案

実装する場合は、CSS変数を使って安全に切り替える。
大規模にクラスを書き換えるより、`#gameScreen` に属性を付ける方式がよい。

例:

```html
<div id="gameScreen" data-theme="orcus">
```

想定テーマ:

- `data-theme="orcus"`: オルクス側
- `data-theme="alstro"`: アルストロ側
- `data-theme="mixed"`: 両国が同時に関わる戦場、終戦記念、外交場面
- `data-theme="abyss"`: サタン、黒い霧、悪意の伝染、異常存在寄り

CSS方針:

```css
#gameScreen[data-theme="orcus"] {
    --panel-bg: rgba(6, 8, 14, 0.92);
    --text-main: #deb96a;
    --gold: #c8922a;
    --teal: #3ecfb8;
}

#gameScreen[data-theme="alstro"] {
    --panel-bg: rgba(12, 18, 28, 0.92);
    --text-main: #d8e7ff;
    --gold: #b8a45a;
    --teal: #7db8ff;
}
```

注意:

- 最初から全UIを一気にテーマ対応しない。
- まずは上パネル、VS予測、フェーズ表示、ボタン、ログ周りから小さく対応する。
- 色だけで情報を伝えず、ラベルや配置でも陣営が分かるようにする。
- 既存のヴァイオレット×ゴールド×アンバーはオルクス標準テーマとして残す。

## SRPG戦闘UIへの落とし込み

百年戦争編では、戦闘UIに以下の情報があると作品性に合う。

- 勝利条件だけでなく、非殺傷条件や撤退条件
- 「トドメ」選択の重み
- 友好度、説得、妨害RPに相当するSRPG上の介入
- 反撃や命中だけでなく、相手を殺す危険性
- 戦闘後の評価が「撃破数」だけにならないこと

今後の候補:

- 戦闘終了時に「撃破」「撤退」「説得」「生存」などを記録する
- 予測UIに「撃破見込み」「非殺傷不可」などの警告を出す
- 特定戦闘で「トドメを刺す / 見逃す / 説得する」を出す
- 章ごとに「正史」「異聞」「救済」のような分岐タグを持たせる

## 言葉遣い

オルクス側:

- 命令、密命、魔鉱、王命、影、兆候、異常、観測、臣下、魔王、血統、誇り

アルストロ側:

- 宣誓、正史、聖堂、騎士、軍議、王命、記録、伝承、栄誉、討伐、秩序

共通して避けたいこと:

- 軽すぎるソシャゲ風コピー
- 世界観にない現代的すぎるUI語
- ただの「かっこいい英語」だけで意味が薄い演出

英語表記を使う場合は、短く補助的にする。
例: `ORCUS SIDE`, `ALSTRO SIDE`, `BATTLE FORECAST`, `OATH`, `RECORD`

## 実装時の優先順位

1. 既存のオルクス標準UIを壊さず安定させる
2. `#gameScreen[data-theme]` でテーマ切り替えの土台を作る
3. VS予測、フェーズ表示、ログ、上部タブなど影響範囲の小さい場所から対応する
4. シナリオ側に `theme: "orcus"` / `theme: "alstro"` のような指定を持たせる
5. 戦闘定義 `battleId` 側にもテーマを持たせる
6. 章全体の視点演出、アルシェ/カリマ視点切り替えへ広げる

## Claude Code / Codex への注意

- このメモはデザイン判断の基準であり、必ずしも即実装の仕様ではない。
- 大きなUIテーマ切り替えを入れる前に、まずCSS変数で小さく試す。
- 既存のブラウザ直接実行構成を守り、フレームワークやビルドツールは入れない。
- 世界観演出を理由に、戦闘ロジックを勝手に変えない。
- 仕様上の「トドメ」「説得」「友好度」などは、実装前にユーザーと確認する。
- アルシェ/カリマの二視点は、今後の章構成・UIテーマ・会話演出の重要軸として扱う。
