# 拠点メニュー（携帯端末）実装仕様書 — Unity向け

> この仕様書が **正** です。Codexで作りかけたUI設計案（ファイル・メモ）がプロジェクト内に残っていても、それは旧案なので使わないでください。
> 元デザイン：Claude Design キャンバス「Hub2」（HTML製のモック）。見た目はこの仕様書の数値で再現してください。

---

## 0. 前提

| 項目 | 内容 |
|---|---|
| エンジン | Unity（既存プロジェクトに組み込む） |
| 対象 | ブラウザ（WebGL）＋スマホ、横画面 |
| 基準解像度 | **1688 × 780**（スマホ横 844×390 の2倍）。この仕様書の数値はすべてこの基準のpx |
| 推奨 | uGUI ＋ TextMeshPro。Canvas Scaler = *Scale With Screen Size*、Reference 1688×780、Match = 1（高さ基準） |
| 座標の読み方 | 左上原点・下向きが＋Y。uGUIでは anchor/pivot を左上 (0,1) にして `anchoredPosition = (x, -y)` |
| 世界観 | メニューは「アルシェが持つ携帯端末」。探索マップの上に重なって開き、**背景の探索画面は透けて見える** |
| 絶対条件 | 主人公アルシェは常に画面中央に立つ。**画面の中央下は大きく塞がない** |

UI方式（uGUI か UI Toolkit か）は実装側の判断でよいです。迷ったら uGUI。

### 色
| 用途 | 値 |

| ティール | `#4fa3a8` — **ページ送りのアクティブ菱形1個だけ**に使う。他では使わない |

### 線と飾り
- 枠線は **1px の銀ヘアライン**。太くしない（拡大縮小しても1pxのまま）
- 角の飾りは **金の小さな菱形**（7〜8pxの正方形を45°回転）
- タイル背景は半透明の暗色（`rgba(16,14,24,0.72)`）＋右下を14px斜めに切り欠き

### フォント

### 3-6. 時間帯アイコン
- (1206, 236, 160, 64)（メインイベント枠の右上の中に重なる）。**文字ラベルは付けない**
- 朝／昼／夕方／夜 の4種類。素材はアトラス1枚（後述の素材表 #T）
  - 朝：太陽が1.5sで昇る＋光線が出る、地平線にきらめきが走る（4sループ）
  - 昼：太陽＋光線が3.8sでゆっくり明滅・揺れ、両脇の星がまたたく
  - 夕方：太陽が1.6sで沈む、地平線のきらめき
  - 夜：月＋両脇の星がまたたく（4.4〜4.9s）
- 演出の意図：夜戦・昼戦の伏線になる雰囲気づけ。主張しすぎない
- 既存の時間帯アニメ実装がプロジェクトにあれば、それを流用してよい

### 3-14. 開閉トランジション（帯スイープ）
- 画面より大きい暗い帯（`#08070c`）が **155.2°傾いた向き** で画面を横切る。全体 1.75s
  - 0〜46%：画面外から中央へ（ease-in-out）
  - 46〜54%：画面を完全に覆って一瞬止まる
  - 54〜100%：反対側の画面外へ抜ける
- 帯の両端に金の発光ライン（3px `#f2cd78`、光彩 8/26/60px）
- 帯の先頭に星が乗って、長さ420pxの光の尾を引きながら1回転する
- **閉じる**：帯が覆いきった瞬間（0.875s）にメニューを消す → 探索画面に戻り、右上に「MENU」の星ボタンが出る
- **開く**：MENUボタンで逆向きに流し、同じタイミングでメニューを出す。終わったらCLOSEの星が着地（1.7倍・-90°から0.5sで弾むように戻る）
- 演出中は入力を受け付けない

| NEWバッジ | 未読の支援会話があるか |

## 6. モックの読み方の注意

- モックHTMLの末尾にある、位置指定のない `BOND` という英字と2つ目の `支援の深い仲間` は、編集中の残りです。**無視してください**
- モックのスクリプト内にある `bonds` 配列（SDキャラの画像）は旧案です。カードの絵は素材表の L/M/N（立ち絵）が正しいです
- タイル（ステータス・名声報酬・設定・ログ）の半透明の暗い背景は、意図したデザインです。不透明にしないでください
