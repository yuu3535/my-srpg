# タイトル画面 実装仕様書 — Unity（uGUI）向け

> **見本画像と、この仕様書の数値の両方を使って組んでください。**
> 元デザインは Claude Design キャンバスの「タイトル C3」です（C改をもとに、終幕後だけ作り直したもの）。
> タイトル A・B・C・C改は不採用です。参考にしないでください。
> 拠点メニュー（Hub2）・会話画面の仕様書と同じ決まり（字・座標）を使います。

---

## 0. 前提

| 項目 | 内容 |
|---|---|
| 基準解像度 | **1688 × 780**（スマホ横 844×390 の2倍）。数値はすべてこの基準の px |
| Canvas | uGUI、Reference 1688×780。**画面の広がり方（Canvas Scaler の設定）は、Unity の Hub2 の今の設定に合わせる** |
| 座標 | 左上原点・下向きが＋Y。uGUI では anchor/pivot を左上 (0,1) にして `anchoredPosition = (x, -y)` |
| 横の中心 | x = 844。題名・運命予報・メニュー・説明の行はすべて中央揃え |
| 絶対ルール | ① **画面は3つの状態**（クリア前／サタン撃破後／終幕後）で、配置は3つとも同じ。変わるのは **空・色・文** だけ ② 星のまわりの輪と運命予報は **謎文字フォント（Neko_no_Mezame）** で出す ③ 終幕後は **色を黒と赤と灰だけ** にする |

同梱の画像は、すべて **1688×780 の実寸** です。キャンバスと同じフォント・空の絵で描いています。動き（回転・明滅など）は止めた状態です。

**組み方の手順**
1. 画面いっぱいに `title_02` を **不透明度 40% の Image** として最前面に置く（エディターで動かしたときだけ読み込む。公開版には入れない）。
2. その下に UI を組み、**見本と線・文字がぴったり重なるまで** 位置を合わせる。
3. 数値は `map_*` と、この仕様書の表を使う。**見た目（雰囲気・余白）は見本画像が正**、**数値は仕様書が正**。食い違ったら、勝手に決めずに報告すること。
4. 状態を切り替えて、`title_01`〜`title_06` でも同じように確かめる。

> `TitleC3.dc.html` には、デザイン検討用の切り替え（endSky・endTitle・sky など）が残っています。**ゲームに入れるのは、この仕様書に書いた組み合わせだけ** です（終幕後＝褪せた朝焼け＋黒い題名、クリア前＝宵空）。

## 1. 3つの状態

**「続きから」で再開するセーブ（いちばん最近遊んだセーブ）の進み具合** で、タイトル画面の状態が変わる。フラグ名は Claude Code が決めてよい。

| 状態 | いつ | 空 | 星 | 星のまわりの輪の文 | 題名の下 |
|---|---|---|---|---|---|
| **クリア前** | 最初から、サタンを倒すまで | 宵空 | 青白い宵の明星 | `ONLY I WAS THE CREATOR OF THIS WORLD` | 運命予報（章ごとに変わる） |
| **サタン撃破後** | サタンを倒してから、終幕まで | 朝焼け | 金色の明けの明星 | `THIS WORLD IS DEDICATED TO YOU` | `NEW DAWN` ／ `soshite, atarashii yoake e` |

- 輪の文は Old World の書（シャヘルの言葉）から。3つとも英文のまま謎文字で出す
- 終幕後：本編をすべてクリアしたあとのタイトル画面
- **2周目を始めたら、クリア前（宵空）に戻る**（新しいセーブの進み具合に合わせる）
- 決め方：いちばん最近遊んだセーブの進み具合を見る。セーブが1つもなければクリア前

> **字の太さの置き換え**：Unity に入っている Shippori Mincho は 600 と 800 だけ。700 と書いてある所は、**19px以上は 800、16px以下は 600** にする（戦闘テストのボタン 12px → 600、続きからの演出の場所名 32px → 800）。ほかの画面と同じ決まり。
>
> **字間の「text-indent」**：キャンバスでは、字間をあけた文字列の中心がずれないよう、左にも同じだけ字間を入れている。TextMeshPro で中央揃えにするとき、最後の字の後ろの字間ぶん左にずれるので、**字間の半分だけ右へずらす** か、最後の字の字間を消すこと。

### 文字の輪の作り方
1. 輪の文（例：`ONLY I WAS THE CREATOR OF THIS WORLD  ·  `、最後に空白2つ・中黒・空白2つ）を、**70文字以上になるまで繰り返してつなぐ**
2. 文字数を N として、i 番目の文字を **角度 i×360/N°**（真上が0°、時計回り）に置く
3. 1文字ずつ、中心で角度ぶん回してから、中心から上へ100px動かす（文字の下が星のほうを向く）
4. 1文字の枠は 24×24、文字は枠の中央

## 8. タップ待ちとメニュー

### タップ待ち（起動して最初の画面）
- `TAP TO START` と「画面をタップ」を縦に並べ、間8px。**上 y600**、中央
- 2.4秒周期で 不透明度 0.35↔1 の明滅

- タップしたらメニューに切り替える

### メニュー
- 並び：続きから／CONTINUE ・ はじめから／NEW GAME ・ 保管庫／ARCHIVE ・ 設定／CONFIG
- **上 y584**、中央揃え、横に並べる。項目の間 28px。項目と項目の間に **7×7 の菱形**（差し色・不透明度0.7）

- 選んでいる項目：字の色が変わり、下に **1px の下線**（字と同じ色、項目の下 8px）が中央から0.3秒で伸びる
- 最初に選ばれている項目：セーブがあれば「続きから」、なければ「はじめから」
- 文字の影：0 1px 10px rgba(0,0,0,0.8)（終幕後はなし）

### 説明の行
- **上 y688**、高さ20、中央。選んでいる項目に合わせて変わる

| 設定 | `音量・文字の速さ・画面の設定など。` |

### 押したとき
| 項目 | 動作 |
|---|---|
| 続きから | 演出（9章）→ セーブの場面へ。セーブがないときは押せない（字を押せない色にして、押しても何も起きない） |
| はじめから | 保存先のスロットを決める（下の「はじめからとセーブスロット」）→ 演出（9章）→ プロローグへ |
| 保管庫 | **今は押せない**（字を押せない色に）。あとで、見た支援会話などを見返す画面を作る |
| 設定 | 拠点メニューと同じ設定画面を開く |

### はじめからとセーブスロット
- セーブスロットは複数ある。「はじめから」を押したとき
  - **空いているスロットがあれば**、そこに新しいデータを作る（確認は出さない）
  - **空きがなければ**、上書きするスロットを選ぶ画面を出す（普通のゲームと同じ方式）。選んだら上書きの確認を出してから始める
- スロットを選ぶ画面の見た目は、まだデザインしていない。今は拠点メニューの見た目に合わせた仮のものでよい

- `DEV`（Barlow 11px）＋「戦闘テスト」（12px）
- 公開版では出さない

## 9. 演出（押したあと）

### はじめから（約5.2秒）
