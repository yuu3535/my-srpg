# 絵を描くときの画面の大きさ

作成: 2026-09-29 / 総合担当（Claude Code）
状態: **正式採用**（画面の基準の大きさ・3倍で描くこと。原作者 2026-09-29「その方針で行きましょう」）／携帯端末の枠の寸法は**目安**（見せ方が決まったら直す）

## 1. 画面の基準

- ゲームの画面の基準は **横 844 × 縦 390**（比率 約2.16：1＝19.5：9。iPhoneを横にしたときと同じ）。横画面専用。
- Unity版の画面の部品（戦闘のUI・会話・探索の表示）はすべてこの大きさを基準に置き、実際の画面に合わせて拡大する（`CanvasScaler` の referenceResolution＝844×390）。公開版の WebGL は 1266×586（同じ比率）。ブラウザ版も同じ基準（`style.css` の --design-w／--design-h）。
- **絵は基準の3倍で描く**（スマホでも粗くならない）。画面全体なら **2532 × 1170**。

## 2. 携帯端末（メニュー）の飾り枠の目安

画面の中に、横向きの携帯端末を置く形のとき:

| | 基準（844×390の上） | 3倍で描く大きさ |
|---|---|---|
| 端末の外側 | 約 720 × 350（画面の約85%） | **2160 × 1050** |
| 中の画面（メニューを出す所） | 約 630 × 291（19.5：9） | **1890 × 873** |

- 中の画面も19.5：9にすると、ゲームの中にゲーム画面があるようで収まりがよい。
- 中の画面の部分は**透明**にする（メニューの文字・項目はゲームの側で描く）。
- 飾りは**四すみに集め、辺はくり返せる模様**にする（大きさを変えても形が崩れない。9分割で伸ばせる）。
- 「画面いっぱいに出す」か「手に持った絵にする」かで数字が変わる。見せ方が決まったら、この表を直す。
