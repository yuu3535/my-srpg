## 2. 気になる点

1. **C（星）が素材フォルダにない**。Hub2 の CLOSE の星は、細い光が斜めに伸びる金の四方の星。近い物の `メニューホーム_独立アプリ01/home-corner-star-mask-v01.png` は白い星に弧が付いた別物。時間帯のアトラスの星は小さく形も違う。Claude Design にだけ上げた画像の可能性がある。→ 原作者に元の画像を素材フォルダへ置いてもらう。
2. **M（ギュンター）が2つ**。カードは胸から上しか見えないので、スクリーンショットの大きさでは見分けられない。→ 原作者に確認。
3. **J（ウロボロス）が3種類**。→ 原作者に確認。
4. **B は アルシェ版だけ**。実装は既存の太陽盤（カリマの色も出せる）を使うので、モックの見本としては問題ない。
5. **A の周り**: 2026-11-08 時点の作業ツリーで `背景/オルクス城回廊.png` などが削除された状態になっている（誰の作業かは未確認）。A に使う `背景/ブラッシュアップ版/オルクス回廊.png` は残っている。
