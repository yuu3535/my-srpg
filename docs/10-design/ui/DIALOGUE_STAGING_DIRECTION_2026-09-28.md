# 会話劇の見せ方（立ち絵の置き方）方針

作成: 2026-09-28 / 総合担当（Claude Code）
状態: **方針の骨子は原作者の案（2026-09-28）**。「会話するキャラが左右に寄り、やや斜めを向いて向かい合う会話劇にしたい」。細かい値は試作して決める。テキストボックスの位置は後で決める（原作者）
関連: `docs/10-design/map/MAP_ART_PIPELINE_v1_2026-09-28.md`（探索も3Dの盤面で行う）、`AGENTS.md`「立ち絵の背景透過ワークフロー」

## 1. 形

- 会話は、**探索の盤面（3Dの盤面）を映したまま**、その上に立ち絵を重ねて行う。暗転して別の会話の画面にしない（その場で起きている感じを残す）。
- 立ち絵は**画面の左右の端に寄せ**、体をやや斜めにして**内側（相手の方）を向く**。真ん中はマップ（話している場所・キャラの小さな姿）が見える。
- 立ち絵の大きさは、膝上〜太ももで画面の下に切れるくらい（顔が読める大きさ。横画面 844×390 で顔が約60〜80px）。

## 2. 決まり（案。試作で確かめる）

| 項目 | 案 |
|---|---|
| 左右 | 左＝主人公の側（アルシェたち）、右＝相手の側。場面の途中で入れ替えない |
| 片側の人数 | 2人まで。3人目は入れ替えで出す |
| 話している人 | 明るく、少し手前（内側）へ出る |
| 黙っている人 | 少し暗く（明るさ約70%）、少し奥へ下がる |
| 出る・引っ込む | 画面の外から横に滑って入る／出る（短く。0.2〜0.3秒） |
| 立ち絵の縁 | 縁取りなし、または細い金の縁。足元の方は暗く溶かす（見本の白い縁取りは明るい絵柄向けで、この作品の黒紫×金の意匠には合わせない。試して決める） |
| ナレーション | 立ち絵を暗くし、地の文の欄だけ出す |
| 戦闘中の会話 | 同じ形（戦闘の盤面の上）。戦闘のUIは会話の間は隠す |

## 3. 立ち絵の素材の決まり（発注書: `docs/30-planning/TACHIE_DIALOGUE_ORDER_2026-09-28.md`）

- **会話用の立ち絵を全員分作り直す**（今の立ち絵はAIで作った仮。原作者 2026-09-28）。
- 体をやや斜め（3/4）にした、落ち着いた立ちポーズ。**全員同じ向き（画面の右を向く）** で描く。左に置くときはそのまま、右に置くときはゲームで左右を反転する。
  - 眼帯・髪の分け目・紋章・利き手の武器など、左右で違う所があるキャラは、反転すると設定と食い違う。そのキャラだけ**左向きも**頼む。
- **立ち絵は膝上でよい（全身は描かなくてよい）**（原作者 2026-09-29。全身は作画の手間が大きいため）。膝の少し下まで描くと、切る位置に余裕ができる。腰までだと、太ももの所で絵が足りなくなる（大きく出すと顔だけ他のキャラより大きくなる）。
  - 以前の決まり（全身で描いてもらい、ゲームで膝上に切る）は、切る位置をあとで変えられるようにするためだった。会話・戦闘予測の顔・カード・ステータスは胸から上しか使わないので、全身がなくても困らない。
  - 探索で、盤面の絵がない人に立ち絵を縮めて立てているのは仮（盤面のキャラの絵 `docs/10-design/map/MAP_SPRITE_ART_DIRECTION_2026-09-29.md` ができたら置き換える）。
- 表情の差分は、体の絵を1枚にして顔だけ描き分ける（位置を動かさない）。キャンバスは全員同じ大きさ（今は 1024×1536）。
- 魔法の光・炎・武器を振るなどの演出は描かない（戦闘の立ち絵・戦技の演出は別に作る）。
- 表情の差分: 同じポーズ・同じ服で、顔だけ変える（通常・笑顔・怒り・驚き・悲しみ・困り、キャラによって足す）。アルシェ・カリマの幼少期の表情フォルダの作り方に合わせる。
- 背景は白で生成し、`tools/tachie_studio.py` で透過する（今までどおり）。

## 4. 今の実装（ブラウザ版）との違い

- ブラウザ版の会話は `scenario.js` の `setCharacters`（キャラの並び）と、キャラごとの切り取り（`bgSize`・`bgPos`）で立ち絵を出している。左右の決まり・話している人の明るさは、この方針で作り直す。
- Unity版には会話の画面がまだない。探索（3Dの盤面）を作るときに、この方針で作る。
