### 雰囲気

1. **暗い中に、はっきりした光がある**。まわりは暗く沈んでいるが、ランプ・ろうそく・窓・ステンドグラス・魔法の光が強く光り、そこだけ明るい。全体を均一に暗くしているのではない。
2. **暖かい光と冷たい影の組み合わせ**。光は琥珀〜橙〜クリーム、影や遠くは青緑〜藍。この2色の対比が多くの絵の軸になっている。
3. **空気の厚み**。霧・もや・光の筋・舞う粒子で、奥が青くかすむ。
4. **色は鮮やかすぎず、くすみすぎず**。石や木は落ち着いた色だが、光・花・水・魔法の差し色ははっきり鮮やか。

## 2. 今の試作との違い

- 今の C は**全体を均一に暗くしただけ**で、光の当たる場所がない。素材より明るさがかなり低い（0.22 と 0.40）。
- 光も影も同じような色（紫寄りの暗さ）で、**暖かい光と冷たい影の対比**がない。
- 仮の模様の石が**ほぼ灰色**（彩度0.1）。素材の石は、暖かい灰色・赤茶がかっている。

## 3. 方針（案）

### 3.1 明るさ

- 盤面の平均の明るさは素材と同じくらい（0.35〜0.45）にする。今より明るくする。
- ただし**均一に明るくしない**。光の当たる所（明かりのそば・目的地点・選んだキャラのまわり）を明るく、盤面の端と奥を暗く沈める。

### 3.2 光と影の色

| | 色 | 3Dの盤面での作り方 |
|---|---|---|
| 主な光 | 琥珀〜クリーム（`#e9dcbb`〜`#ab8d70` 寄り） | 太陽・月の光（向きのある光）を少し暖かく |
| 影・まわりの明るさ | 青緑〜藍（`#37454b`・`#355b60` 寄り） | まわりの明るさ（環境光）を紫寄りから**青緑寄り**に変える |
| 霧・遠く | 深い藍〜紺（`#102533`・`#0f131d`） | 霧の色を、UIの黒紫から少し青緑寄りの藍へ |
| 差し色の光 | 橙のたいまつ・ランプ、青白い魔法 | 盤面に置く明かり（点の光）と、光のにじみ（後処理のブルーム） |

- UIの黒紫・金はそのまま。盤面だけ、青緑と琥珀の対比を足す。UIの黒紫は影の色（`#23161b`・`#0a0916`）とも近いので、並べても浮かない。

### 3.3 彩度

- 地面（石・土・木）: 0.2〜0.45。石は灰色一色にせず、暖かい灰色〜赤茶を混ぜる。
- 草・苔: 0.3〜0.5（青みのある深い緑）。
- 水: 0.5〜0.7（深い藍〜青緑。光を受けた所だけ明るい水色）。
- 明かり・魔法・花などの差し色: 0.6〜0.8。ただし面積は小さく。
- 味方＝青・敵＝赤の意味の色（陣営の枠・範囲マス）と、魔法の青が混ざらないよう、魔法の青は青緑寄り・白寄りにする。

### 3.4 空気

- 霧は「全部を黒く沈める」から「奥が青くかすむ」へ。霧を弱め、色を青緑寄りにする。
- 光の筋・舞う粒子（ほこり・蛍・火の粉）は、マップごとの演出として後で足す。

### 3.5 模様（ChatGPTに頼むときの指定に入れる）

- 明るさは中くらい（0.3〜0.5）。暗すぎる模様にしない（暗さは光と霧で作る）。
- 石は暖かい灰色〜赤茶を混ぜる。苔は青みのある深い緑。水は深い藍〜青緑。
- ドット絵の粗さ（1マス32点）。色は20色くらいまで。

## 4. 次にやること（原作者の確認後）

1. 試作 C を作り直す: 環境光を青緑寄り、主な光を暖かく、霧を弱く藍寄り、明るさを上げる。盤面に仮の明かり（たいまつ2つ・目的地点の門の光）と光のにじみを足す。
2. 仮の模様の色を、上の方針に寄せて描き直す（`tools/make_board_textures.py`）。
3. 作り直した C と、今の C を並べた画像で確認してもらう。
4. 良ければ、ChatGPTへの模様の依頼文を作る（第3版の発注書に足す）。
