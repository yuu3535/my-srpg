# 2Dマップの見え方（プリセット）と効果

作成: 2026-10-04 / 総合担当（Claude Code）
状態: **仕組みは正式採用**（原作者 2026-10-04「その形で進めてください」）。Unity への組み込みはこれから（下の §4）。数値は場面ごとに合わせる。
関係: 2Dマップの作り方 `SIDE_SCROLL_2D_MAP_PIPELINE_2026-10-03.md`、色の決まり `docs/10-design/ui/COLOR_HARMONY_DIRECTION_2026-10-02.md`

## 1. 考え方

- 2Dマップの「場所」（層の並び・モジュール・床。`Assets/Data/Corridors/<場所>.json`）と、「見え方」（空・効果）を分ける。同じ回廊を、朝・夕方・戦争中の空などで見せ分ける。
- 見え方は**プリセット**として保存する: `unity-prototype/Assets/Data/Looks/<プリセット>.json`。
- シナリオのシーンにプリセットの名前を書くと、そのシーンで切り替わる（例 `look: "orcus_castle_morning"`）。書かなければ、その場所のふだんの見え方。
- 調整は、ブラウザの調整ページ（`debug/corridor_layers.html` の「効果（画面全体）」）と、ゲームの中の調整画面（これから）でする。

## 2. 効果の種類

| 効果 | 値 | 中身 |
|---|---|---|
| 空気遠近 | `haze`・`hazeColor` | 奥の層ほど霞の色に寄せる。いちばん奥の層（空）にはかけない |
| 被写界深度 | `dof` | 奥の層ほどぼかす（px） |
| 層ごと | `layers[].haze`・`layers[].blur` | その層だけの霞・ぼかし（なければ上の2つ×奥行き） |
| ヴィネット | `vignette`・`vignetteSize`・`vignetteColor` | 四隅を暗くする |
| 色調 | `bright`・`contrast`・`saturate`・`temp` | 画面全体の明るさ・コントラスト・彩度・色温度（−寒色 ＋暖色） |
| 光の筋 | `shafts`・`shaftColor`・`shaftAngle`・`shaftY`・`shaftX`・`shaftWidth` | アーチの間から斜めに差す光と、床に落ちる光 |

奥行きは層の「流れる速さ」で決める（遅いほど奥）。

## 3. プリセットのファイル

```json
{
 "look": "orcus_castle_morning",
 "place": "orcus_castle",
 "title": "オルクス城の回廊・朝",
 "sky": "背景/空/朝焼け.png",
 "effects": { "haze": 0.26, "hazeColor": "#e7e9aa", "dof": 1.3, "...": "..." },
 "layers": [ { "name": "空", "haze": 0.02, "blur": 0.9 }, "..." ]
}
```

- `layers` は場所のデータの層の名前で合わせる（名前が見つからなければ同じ順番の層）。
- 今あるプリセット: `orcus_castle_morning`（原作者が調整ページで合わせた朝の回廊。2026-10-04）。

## 4. Unity への組み込み（順番）

1. **効果を出す**: 霞（層の色を霞の色へ寄せる）・ぼかし（絵を前もってぼかした版を使い、動かすときの負担をなくす）・ヴィネット（画面にかぶせる絵）・色調（画面全体）・光の筋（半透明の絵を重ねる）。スマホで重さを確かめる。
2. **プリセットを読む・シーンで切り替える**: 空の絵を `背景/空/` から Unity へ写す（WebGL の圧縮設定つき）。シーンのデータに `look` を足す。
3. **ゲームの中の調整画面**: 隠しの操作で開き、つまみで合わせて「コピー」の文を総合担当に貼る（立ち絵の調整と同じ流れ）。
4. **AI が合わせる決まり（§5）で、最初のプリセットを何種類か作る**。

## 5. AI がシーンに合わせて見え方を決めるときの決まり（案）

原作者の作業を減らすため、AI（総合担当など）がシーンの内容から先に見え方を選ぶ・作る。原作者は見て気になったところだけ直す。

- **空**: 時間帯と天気で選ぶ（朝＝朝焼け、昼＝昼空、夕方＝夕方・薄暮、夜＝宵空・夜空、曇り＝曇り空）。**百年戦争中で治安が最悪な頃のオルクス**は、オルクスの空（赤黒空・紫黒空・淡い蛍光桃）を使う。
- **霞の色**: 空の色相の**隣**の色（朝は淡い黄〜青、夕方は淡い橙、夜は紺）。景色に空の反対の色をかける場合は、原作者に何案か見せて選んでもらう。青空に紫はかけない。
- **空気感**:
  - 平和・日常: 彩度はふつう、ヴィネット弱め、光の筋あり（晴れの日）。
  - 不穏・緊張: 彩度を下げる、コントラストを少し上げる、ヴィネットを強める、光の筋は弱めるか消す。
  - 戦いの前・危機: 寒色寄り、ヴィネット強め。
  - 回想: 少し明るく、彩度を下げ、ぼかしを強める（どう見せるかは原作者に確認）。
- **会話のあいだ**: 台詞が読みやすいように、背景のぼかし・ヴィネットを少し強める（会話のUIの採用方針 `採用版md/SILVER_DIALOGUE_UI_DIRECTION.md` を優先）。
- 新しいプリセットを作ったら、ここの §3 の一覧に足す。
