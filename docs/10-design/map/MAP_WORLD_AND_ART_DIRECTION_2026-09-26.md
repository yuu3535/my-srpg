# 百年戦争編 マップ世界観・美術設計

更新: 2026-09-26

## 状態

- 原作TRPGと既存設計から、マップ制作に必要な要素を整理した**現行の設計基盤**。
- 国家、歴史、登場人物の解釈を勝手に確定する文書ではない。
- シナリオ未完成のため、章ごとの正式マップ配置はまだ決めない。
- 画像生成時はこの文書を世界観基準として使い、個別マップの構図と地形は複数案を比較する。

## 1. 作品の核をマップへ翻訳する

この作品のマップは、戦いやすい床に装飾を置くだけの背景ではありません。次の三層を同時に持たせます。

1. **現在そこにある生活**: 道、住居、祈り、物流、水、食料、仕事。
2. **百年戦争の傷**: 壊れた橋、埋め直した石、墓、封鎖、空き家、異なる国の補修跡。
3. **プレイヤーの選択**: 倒す、守る、逃がす、説得する、迂回する、危険を引き受ける場所。

表向きには勇者が魔王を倒して平和をもたらした英雄譚があります。しかし原作の中心には、勇者を作る計画、戦争後も残る差別、誰を殺すか、誰を救えなかったかという裏側があります。

したがって、明るく整った場所にも不穏な痕跡を残し、暗い場所にも人が暮らしてきた温度を残します。善の国と悪の国を、白と黒だけで単純化しません。

## 2. 世界観の視覚言語

### アルストロ

- ヒトの国。白と青、神聖、秩序、公式の歴史。
- 重い白石、青い屋根、聖堂、騎士団、整然とした水路や庭園。
- 青は神聖な色であり、王族には聖なる蝶の召喚獣の伝統がある。
- 王都は左右対称、直線、広い階段、公開された広場が似合う。
- 百年戦争の勇者伝承が強く、魔物への警戒や純血主義も残る。

マップでは、整然とした美しさの裏に、閉ざされた門、監視、立入禁止、鎖で固定された書物、異種族を遠ざける境界を置けます。

### オルクス

- 魔物の国。黒、紫、魔鉱石、重厚さ、退廃と華やかさ。
- 黒い石材、濃紫の布、冷たい魔鉱石光、暗い金属装飾。
- 多種族が暮らし、ヒト中心ではない身体寸法や生活設備が存在しうる。
- 現魔王フォースは平和を望むが、サタン時代の暴力と対ヒト感情が残る。

マップでは、異形を恐怖演出だけにせず、様々な種族が暮らせる道幅、扉、段差、空間を考えます。暗さの中にも市場、温室、鍛錬、臣下の生活を置きます。

### 国境・戦争跡

- 両国の石材、旗、補修法が混ざる。
- 壊れた橋、封鎖された物流路、放棄された砦、仮設墓地、兵站の跡。
- どちらの国にも属しきれない人々や孤児、避難民の生活が見える。
- 戦場だった場所が、現在は道、村、祭典会場として使い直されている。

国境マップは、作品の二重構造を最も表現しやすい場所です。美しい遺構と、そこで失われた生活を同じ画面に置きます。

### 異常・悪意

- 黒い霧、規則的に並んだ骨、未完成の魔法陣、時間や視界の歪み。
- 派手な紫の発光を全面に使わず、自然物や建築の秩序が少しずつ壊れている状態で不安を作る。
- 異常地形でも、移動可能マスと危険マスは読み取れるようにする。
- 悪意を単なる毒沼にせず、人の判断や関係を壊すものとして扱う。

## 4. 場所ごとの感情

マップを発注するときは、国名や地形だけでなく、プレイヤーに感じてほしい感情を1つ主軸にします。

| 感情 | 地形と構図の例 |
|---|---|
| 儀礼と緊張 | 広い中央、左右対称、周囲に警備線、逃げにくい群衆 |
| 貧困と諦め | 継ぎ足しの道、空き家、生活物が通路を圧迫、唯一の物流路 |
| 神秘と侵入への罪悪感 | 美しい水面、狭い足場、巣や卵、敵を倒さず退く経路 |
| 公開された英雄譚 | 観客席、門、中央舞台、勝利を見せる構図 |
| 閉塞と悪意 | 霧、一本橋、墓標、徐々に狭まる進路、中心の異常 |
| 選択の重さ | 二者の間に立つ位置、退路、説得可能距離、倒さず隔離できる地形 |

## 5. 戦術へ落とす原則

- 地形は、最短路、迂回路、危険だが有利な路の少なくとも2種類を作る。
- 一本道は、橋の封鎖、撤退、護衛、追跡など、物語上の意味がある場合に限る。
- 高台は見た目だけで有利にしない。ルールが決まるまでは進入可否と視認性だけを定義する。
- 民間人、倒したくない相手、守る物を配置できる余白を残す。
- 説得や非殺傷を扱う可能性がある戦場では、接近して会話できる安全地帯、分断、足止めの場所を作る。
- 増援は画面外から突然出すのではなく、門、森の道、階段、船着場など物語上の入口を見せる。
- 宝箱や報酬は、世界に存在する理由を持たせる。戦場の中央へ無関係に置かない。

## 6. 美術上の共通基準

- ダークファンタジーだが、盤面全体を暗く潰さない。
- 通行可能床は周囲より一段明るくし、ユニットの輪郭と台座を読めるようにする。
- 青は味方・アルストロの神聖色、赤は敵・危険、緑は回復・支援と競合するため、地面装飾へ大量に使わない。
- 金は鈍く細く使う。全面を光らせない。
- 外向きの強い発光は魔法・異常・選択表示へ限定する。
- 同じ石畳を全面へ均一に貼らず、生活、補修、戦争被害による変化を付ける。
- AI生成の細密さより、マス境界、通行可否、遮蔽物の占有範囲を優先する。

## 7. 既存たたき台の評価

### アルストロ王都コンセプト

白石、青屋根、水路、金の紋章、植栽はアルストロの基準として有効です。一方で、全体が明るく豊かで傷が少ないため、百年戦争の影や排他性を表す場合は、閉鎖門、警備、補修跡、古い弾痕などを追加します。

### 戦闘UIコンセプト群

盤面とキャラクターの密度、滝や城壁を使った高低差の印象は参考になります。ただし、完成画像のように壁、樹木、火鉢を盤面へ描き込むとユニットを隠します。地面構図の参考に留め、高い物は別素材にします。

### 雰囲気1〜3

黒、鈍い金、宗教画、ステンドグラス、手、輪、剣は、運命、祈り、犠牲、正史を象徴する画面演出に向いています。戦闘マップの床柄として全面使用すると視認性を損なうため、魔法陣、礼拝堂の壁画、章間演出などへ限定します。

## 8. 画像生成の制作単位

一度に完成マップと全地形部品を作りません。

1. 論理盤面の白地図
2. 地面だけのマップ画像
3. 低い装飾
4. 高い地形部品
5. 遠景
6. 霧、水、炎などの演出
7. Unity上で重ねた確認画像

各段階で縮小表示を確認し、採用後に次へ進みます。生成画像は受取用フォルダへ置き、承認前に既存のUnity素材へ上書きしません。

## 9. 最初の試作候補

シナリオとチュートリアルが未確定のため、最初は物語へ固定しない検証マップが適します。

### A アルストロ王都外郭の訓練庭

- 白石、水路、低い植栽。
- 視認性は高いが、世界の暗さと戦争跡は弱い。

### B 百年戦争跡の国境監視路 推奨

- 森、古い石畳、補修された橋または水路、両国の石材が混ざった小砦。
- 世界観、ルート分岐、遮蔽、橋の戦術を一度に確認できる。
- 特定章の正史を確定せず、後からナザレ近郊や別の国境地帯へ転用できる。

### C オルクス城外郭の鍛錬台地

- 黒石、紫の魔鉱石、暗い金属、異種族向けの広い通路。
- オルクスらしさは強いが、床が暗くなりすぎない調整が必要。

最初の画像生成では、この3案を同時に混ぜません。原作者へ構図案を並べたうえで、1案ずつ下絵に沿って作ります。
