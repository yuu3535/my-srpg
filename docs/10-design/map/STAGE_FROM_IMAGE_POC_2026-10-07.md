# 2Dの背景の絵を舞台にして、3Dのキャラを歩かせる（試作）

作成: 2026-10-07 / 総合担当（Claude Code）
状態: **試作対象**（技術の検証。本編・Web版にはつないでいない）
きっかけ（原作者 2026-10-07）: Xで見た「VRM と背景の絵を渡して、絵の中を歩かせる」デモ。目的は VRM を使うことではなく、**完成した2Dの背景の絵を AI が3Dの舞台として読み取り、その中をキャラが自然に歩く**方式を、この SRPG に使えるか確かめること。
進め方（原作者 了承）: まず舞台の仕組みを仮のキャラ（VRoid の仮のアルシェ）で試す → 良ければ本番のキャラの作り方（VRoid の土台＋AI の部品＋Blender のスクリプト）へ。

## 1. 仕組み

| やること | 作り方 | 場所 |
|---|---|---|
| 奥行き | Depth Anything V2 small（室内・メートルの版。ONNX。手元のPCだけで動く。`~/.cache/depth-anything/`） | `tools/stage_from_image.py` |
| カメラ | 絵の床の線が集まる点（消失点）をカメラの中心にする。柱が縦にまっすぐな絵は、水平のカメラで写す範囲をずらした撮り方なので、カメラは下を向けない。射影は Unity で同じ数を使う | 同上・`StageFromImage.FitViewport` |
| 床・世界の向き | 奥行きを3Dの点にして、床の面を探す（RANSAC）。床が水平になる向きを世界の上、床までの距離をカメラの高さに | 同上 |
| 歩ける所 | 上を向いた面の高さの表（0.1 m のマス）。床から、一歩（0.28 m）で上がれる高さでつながっている所だけ（床・階段・玉座の前の台） | 同上 → `stage.json` の grid |
| 前後関係 | 背景を画面いっぱいに描くとき、奥行きも書く。歩ける面（床）は奥へ押しやり、柱・燭台など**だけ**がキャラを隠す（足元が床に埋まらない） | `Shaders/StageBackground.shader`・`occlusion.png` |
| 歩く | 押した所まで、歩ける所のマスをたどる道（8方向）。床の高さに沿って上り下り | `Scripts/Stage/StageFromImage.cs` |
| 光を拾う | 絵の明るく色のある所（燭台・窓の灯り）を奥行きで3Dの点にする。床への映り込み（高さ 0.3 m 未満）と、歩ける所から遠い物（3 m より外・5 m より上）は外す | `stage_from_image.py` の `find_lights` → `stage.json` の lights |
| 光をなじませる | どの背景でも同じ仕組み（原作者 2026-10-07）。キャラの胸の高さで、拾った光を距離で弱めて足し合わせ、主な光の向き・色・強さにする（燭台の近くを通るとその色で照らされる）。キャラより奥の光は縁の光に。影の色は足元のまわりの背景の色。2段のアニメ塗り。足元に丸い影 | `StageFromImage.UpdateSceneLight`・`Shaders/StageToon.shader`・`StageBlob.shader` |
| キャラ | VRM（UniVRM 0.131.3）。URP では MToon が使えず、読み込むと UniUnlit になるので、その Shader を StageToon に差し替える | 同上 |

- 組み立てと確認の画像: `-executeMethod Srpg.EditorAgent.StageBuilder.Build`（場面 `Assets/Scenes/StageTest.unity`。本編のビルドには入れない）。キャラは遊ぶときに読む（場面には入れない）。
- 画面の左上: 舞台の切り替え（謁見の間・回廊・城下町）、キャラの背の高さ（仮 1.4 m）、光の強さ、影の明るさ。
- 舞台を足すとき: `py -3.12 tools/stage_from_image.py <背景の絵> <名前> [確認の画像の置き場] [--floor=0.72]`（`--floor` は床を探す範囲。絵の下から何割の所より下を床の候補にするか）→ `StageBuilder.Stages` に名前を足す。
- 手元で遊ぶ版（Windows。公開しない）: `-executeMethod Srpg.EditorAgent.StageBuilder.BuildLocal` → `unity-prototype/Builds/StageTest/`（Git に入らない）。VRM は書き出した版の `StageTest_Data/StreamingAssets/` にだけ写す。開くのはリポジトリの一番上の `舞台の試しを開く.bat`。床を押すとそこまで歩く。

## 3. 分かっていること・残り

- **画角は奥行きだけでは決まらない**（どの画角でも床は平らに出る）。仮に 60°。キャラの大きさは画面で合わせる。決め方の案: 階段の一段の高さ・扉の高さなど、大きさの分かる物から割り出す。
- 歩き方は仮（手足を振るだけ）。次は Quaternius の Universal Animation Library（CC0。原作者 2026-10-07 に A 案を選択。落とす前に確認する）の人型の動きに替える。
- 光は、拾った光を足し合わせて1つの主な光にする形（光ごとに別の光は当てない）。キャラの床への映り込みはまだ。昼の外（城下町など）は拾える光が少なく、影の色（背景の色）が主になる。
- 奥行きの推定は細い物（燭台の細い部分など）の縁があまい。
- VRM は再配布禁止の設定なので `Assets/LocalOnly/`（Git に入らない）。Web版に載せる前に原作者に確認する。
- 横スクロールの重ね絵（回廊など）には、そのままでは向かない（1枚のパースのある絵向け）。
