# 盤面のキャラの絵（モーション）の方針

作成: 2026-09-29 / 総合担当（Claude Code）
状態: **正式採用**（原作者 2026-09-29「その方針で行きましょう」）
発注書: `docs/30-planning/MAP_SPRITE_ORDER_2026-09-29.md`

## 1. なぜ作り直すか

- 今の盤面の絵（`assets/`・`立ち絵AI生成/` のドット絵。Unity版は `Assets/Art/Tokens`）は、刃の渦・魔法の炎などのエフェクトが絵に描き込まれていて、描いた地面（砂・石畳）に溶けて見えにくい。
- 1キャラ1枚で、向きもアニメもない。
- 作り方: **ChatGPT に、画風をそろえた「元の絵」を1キャラ1枚描いてもらう → AutoSprite（https://www.autosprite.io/ ）で動き（スプライトシート）を作る → Unity版に組み込む**。
  - AutoSprite: 1枚のキャラの絵から待機・歩き・攻撃などのコマの一覧を作る。Unity 向けの書き出しあり。商用のゲームに使ってよい（サイトのよくある質問、2026-09-29 時点）。

## 2. 絵の決まり

| 項目 | 決まり | 理由 |
|---|---|---|
| 頭身 | **大人3頭身・子ども2.5頭身**（SD） | 盤面のキャラは寄りの画面で約70pxしかない。顔と誰かが読めるように頭を大きく |
| 向き | **斜め前・右向き**が基本。左はゲームで反転。あとで**斜め後ろ・右向き**も | 盤面を回せるので、斜め前と斜め後ろがあれば4方向に見える |
| 輪郭 | **太めの濃い紫の線**（真っ黒にしない。濃い紫〜紺）。内側の線は細め | 明るい砂・石畳の地面から浮かせる |
| 塗り | **影は2〜3段のはっきりしたアニメ塗り**。ぼかしは少なめ。服の色はそのキャラの色を少し強めに | 地面に溶けないように。原作者の絵より彩度をやや上げる |
| エフェクト | **絵に入れない**（刃の渦・魔法の炎・オーラ・光）。必要ならゲームで別の絵を重ねる | 今の素材が見えにくい一番の原因 |
| 影・背景 | **入れない**（背景は透明、または真っ白） | 足元の影はゲームで付ける |
| 立ち方 | **頭から足先まで全身**・武器を持つ。腕と脚を体から少し離す（動きを作りやすい） | AutoSprite が手足を動かしやすい |
| キャンバス | **1024×1024 の正方形**。キャラは真ん中、足先は下から約8%、頭のてっぺんから足先までキャンバスの高さの約80% | 全員の足元と大きさをそろえる。背の違いはゲームで大きさを変えて出す |
| 絵柄 | 原作者の絵柄（細い線・落ち着いた色・切れ長の目）に寄せる。見本は原作者の絵 | 会話の立ち絵と同じ世界に見えるように |

- 背の違い（ゲームで大きさを変える目安。TRPGの体格 SIZ から）: リングホルム SIZ10（小柄な女性）・アルバス SIZ15・ギュンター SIZ15・ベル SIZ4（小さな子ども）。
- 左右の反転で設定と食い違う所（ギュンターの眼帯など）は、盤面の大きさでは目立ちにくいので、まずは反転で使う。気になったら左向きも作る。

## 3. 動き（モーション）

| 順 | 動き | ループ | メモ |
|---|---|---|---|
| 1 | 待機（息をする） | する | いちばん長く見る。ゆっくり小さく |
| 1 | 歩き | する | 探索・移動 |
| 1 | 攻撃 | しない | 武器を振る。魔法のキャラ（アルバス）は手を前に出して魔法を放つ |
| 1 | 被弾 | しない | 後ろへのけぞる |
| 2 | 魔法 | しない | 剣のキャラも魔法を使う（アルシェ・リングホルムなど） |
| 2 | 倒れる | しない | |
| 2 | 勝利 | する | |

- 書き出し: PNGのスプライトシート＋コマごとのPNG。コマの大きさは 256×256 を目安（盤面で約70pxなので十分）。
- 置き場所: `キャラモーション/<キャラ名>/`（元の絵・書き出したシート・コマ）。組み込みは総合担当。

## 4. Unity版への組み込み（総合担当・これから）

- 今の盤面は、キャラ1人につき板の絵1枚（`Board3DView` の billboard）。向きもアニメもない。
- コマの絵を切り替える仕組み（`SpriteFlipbook`）はあるので、これを使ってキャラを動かす: 待機のループ／歩くとき歩き／攻撃・被弾・倒れるときにその動き。
- 向き: 動く方向・相手の方向で左右を反転する。盤面を回したとき、カメラから見て背中側なら斜め後ろの絵（できたら）。
