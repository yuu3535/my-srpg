## 1. 流れと場所

```
アルシェの自室 ──→ 城の廊下（探索のチュートリアル）──→ 訓練場（合流 → 戦闘のチュートリアル）
                        │
                        └─→ 謁見の間（寄り道・任意）
```

| 場所 | シナリオの背景名 | 今ある背景の絵 | 盤面 | 役割 |
|---|---|---|---|---|
| アルシェの自室 | アルシェ自室 | **なし** | 未作成 | 起床・携帯端末のチュートリアル・任意の調査（1〜2か所） |
| 城の廊下 | オルクス城廊下 | `背景/オルクス城回廊.png`（夕方） | 未作成 | 探索移動のチュートリアル。従者の環境会話・キャリー・ヘンリー |
| 謁見の間 | オルクス城謁見の間 | `背景/オルクス魔王城玉座の間.png` | 未作成 | 寄り道。**のちに終戦記念式典とラスボス戦で同じマップを使う** |
| 訓練場 | オルクス城訓練場 | `背景/オルクス魔王城鍛錬場.png` | 配置表あり（`layouts/orcus_training_yard`） | 合流の会話 → 戦闘のチュートリアル → 会話 |

- **廊下が中心（ハブ）**。自室・謁見の間・訓練場の3つの扉がつながる。探索のチュートリアルとして「分かれ道があって、寄り道できる」形にする。
- 時間はすべて**朝**。アルシェの台詞「今日もいい天気だな」から、**晴れた朝**（カリマのメッセージは朝6時ごろ。アルシェは寝坊して少し遅れて出る）。
- シナリオでは「訓練場」。ファイル名・既存の文は「鍛錬場」だが、表示名は新しいシナリオに合わせて「訓練場」にする（ファイル名はそのまま）。

## 2. 場所ごとに要るもの

### 2.1 アルシェの自室

- アルシェとカリマの**2人部屋**（シナリオに「カリマのベッド周り」「アルシェのベッド周り」があり、プロローグの最後も「アルシェとカリマの部屋」）。
- 整理されたカリマのベッド（下に色々なツノの頭飾り）と、散らかったアルシェのベッド（下に折れた漫画）が**対比**になるように置く。
- 「黒陽の双剣」を見つける場所（剣立て・机の上など）。
- 扉1つ（廊下へ）。
- 小さい部屋（例: 8×7マス前後）。探索だけで、戦闘はしない。

### 2.2 城の廊下

| 出来事 | 盤面に要るもの |
|---|---|
| 探索移動のチュートリアル（目的地は訓練場） | 自室の扉 → 廊下 → 訓練場の扉。**寄り道が見える分かれ道**（謁見の間の扉） |
| 従者たちの井戸端会議（環境会話） | 従者2人の立ち位置と、**近づくと会話が流れる範囲**（話しかけなくてよい）。アルシェが剣を見せに割り込める距離 |
| キャリーとの会話（「ツノ」をもらう） | キャリーの立ち位置。**接近で会話が始まる範囲** |
| ヘンリーとの会話（運命予報のチュートリアル） | ヘンリーの立ち位置。接近で会話 |
| 終戦記念の準備で忙しい城 | 荷物を運ぶ従者、飾りつけ途中の花や布などの小物 |

- 背景の絵は「2階のアーチの回廊（夕方）」。プロローグでは**朝**に使うので、ブラッシュアップは朝にする（`MAP_BG_BRUSHUP_ORDER_ORCUS_CASTLE_2026-09-28.md` §4.3 を直した）。
- 盤面は細長い通路＋分かれ道。探索専用（戦闘はしない）。

### 2.3 謁見の間

- 「父上のいる場所」「家の中心」という安心感を優先する（構成メモ No.16）。戦闘マップになることは、まだ見せない。
- 同じマップを**3つの状態**で使う:

| 状態 | 使う場面 | 変わるもの |
|---|---|---|
| 準備中 | プロローグ1-1（寄り道） | 飾りつけ途中の花・布・運び込まれた椅子、準備する従者。いつもより少し華やか |
| 式典 | 終戦記念式典 | 来賓の席・人・飾りの完成形 |
| 決戦 | ラスボス戦 | 差分の背景（原作者 2026-09-28「和平後のものをベースにラスボスマップ背景の差分」）。壊れた柱・霧など |

- 盤面の地形（床・柱・玉座の台）は3つで**共通**にし、状態ごとに**小物と高い物だけ**を差し替える。背景の絵は「和平後の基本」＋「決戦の差分」の2枚。
- 謁見の間は、ラスボス戦の盤面として作り込む必要があるので、ほかの場所より先に配置の方針（広さ・柱・台）を決めておく。

### 2.4 訓練場

- 探索の終わり: **訓練場へ入ると探索パート終了**（構成メモ No.20）→ 合流の会話。
- 会話の時点で、カリマとギュンターはすでに訓練場にいる。アルシェは**廊下からの扉**で入ってくる。
- 戦闘中の会話で、カリマとの**アイテム交換のチュートリアル**（「ツノ」を渡し、ポーションをもらう）がある。今の `battle_tutorial` はマップ上にポーション小を置いているので、戦闘設計担当と扱いを決める（マップ担当としては、落ちているポーションを消してよい）。

プロローグ1-1 の探索には、今の配置表の項目（`MAP_ART_PIPELINE_v1` §4）に、次が要る。

| 項目 | 中身 | 例 |

| 会話の範囲 | 近づくと会話が始まる／環境会話が流れるマスの範囲 | 従者の井戸端会議: 半径2マス |
