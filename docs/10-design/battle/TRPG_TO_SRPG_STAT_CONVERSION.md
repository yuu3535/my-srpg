# TRPGからSRPGへの能力換算表

設計案 v0.3 / 2026-09-23

この文書は、TRPGのキャラクター資料をSRPG用の能力へ翻訳するための基準を整理したものです。現時点では設計・比較用であり、ゲームコードへ適用する確定仕様ではありません。

## 1. この換算表の目的

- キャラクターが増えても、同じ根拠で初期能力を作れるようにする。
- TRPGでの人物像と強弱関係を残す。
- TRPGの数値を、用途を確認せずSRPGへ直接流用しない。
- TRPGのレベルとSRPGの育成レベルを同一視しない。
- 初期能力の換算と、SRPG開始後の因果Lv成長を分ける。
- 基本能力、派生能力、戦闘資源を混同しない。

この文書が扱うのは、主に加入時の初期能力です。加えて、換算した技・速さ・SIZを実戦闘へ接続するため、採用方針となった命中・回避式と、命中率に関係するDualの初期案を記録します。因果Lvの成長率、兵種成長補正、必殺・追撃・ダメージの戦闘式は別工程で決めます。

## 2. 調査で確認した過去の換算

### 2.1 TRPG原資料

`rurubu4/ルルブ4.xlsx` と `CharaStatus` の資料では、次の関係が確認できます。

| TRPG項目 | 原資料上の意味・式 |
| --- | --- |
| HP | 作成時は `(CON + SIZ) / 2`。その後の成長結果はキャラクターシートに記録される |
| MP | POWの現在値 |
| DB | STRとSIZを参照する物理ボーナス |
| MB | POWとDEXを参照する魔法ボーナス |
| APP | 容姿・魅力・好感に関係する能力 |
| 勇気 | 0から100の独立値。反撃判定などに使用 |
| 幸運 | 0から100の独立値 |

TRPGのHP、STR、CON、DEX、POW等はレベルアップ時の成長結果を含みます。リングホルムとアルバスのLv5値は、幼少期の初期値ではなく、TRPGで成長した完成能力です。

### 2.2 Git履歴で確認した最初のSRPG換算案

コミット `cbd72e2` では、TRPG値を小さく圧縮する案が記録されていました。

| SRPG項目 | 当時の式 |
| --- | --- |
| 力 | `floor(STR / 3)` |
| 魔力 | `floor(POW / 3)` |
| 技 | `floor(DEX / 3)` |
| 守備 | `floor(CON / 8) + 装備` |
| 魔防 | `floor((POW + INT) / 16) + 装備` |
| 勇気ゲージ | `floor(courage / 10)` |

この案は後のコミットで置き換えられており、現在のゲームでは使われていません。

### 2.3 現在のゲームで使われている換算

コミット `f0bef4c` 以降、`statConversion.js` はTRPG生値をほぼそのまま戦闘値へ使っています。

| 現行項目 | 現行式 |
| --- | --- |
| 力 | `STR` |
| 魔力 | `POW` |
| 技量 | `DEX` |
| 物防 | `floor((STR + SIZ) / 2)` |
| 魔防 | `floor((POW + CON) / 2)` |
| 最大MP | `POW` |
| 反撃率 | `勇気` |
| 運トークン | `floor(幸運 / 10)` |
| 注目度 | `APP` |

現在の必殺基礎は勇気とレベル、必殺回避はAPPを参照します。これは現行挙動の記録であり、新しい8基本ステ設計へそのまま採用する決定ではありません。

### 2.4 Git履歴で確認した戦闘式の変化

- 最初の命中試作は `DEX × 2 + 使用技能 × 5` だった。
- 後に `50 + DEX + 使用技能 × 5` へ変更された。
- 回避は当初 `DEX - SIZ + 回避技能 × 3` だった。
- 後にSTR、DEX、SIZ、回避技能の乗算補正を使う式へ変更された。
- 勇気は一度、10段階のゲージとして使う案が存在した。
- その後、現在の `勇気％で反撃` へ変更された。

この履歴から、現行式も複数回の試作を経た暫定結果だと分かります。新換算では、現行式を証拠として残しつつ、人物像に合わない部分を分離して検討します。

## 4. 初期能力の換算案 v0.3

### 4.1 使用する能力の時点

キャラクター全員をTRPGのLv1へ巻き戻さず、SRPG加入時の人物像に対応するシートを使います。ただし、ここで参照するTRPGレベルは資料の時点を識別するための情報であり、SRPGの育成レベルではありません。

| キャラクター | 換算に使う時点 | 理由 |
| --- | --- | --- |
| 幼アルシェ | TRPG Lv1 | 序盤の未熟な主人公として加入するため |
| リングホルム | TRPG Lv5 | 表ルートを少人数で戦う完成済みの強者だから |
| アルバス | TRPG Lv5 | 中盤加入の完成済み魔法ユニットだから |

この違いは不公平な換算ではなく、加入時点の物語上の強さを反映するものです。

### 4.2 TRPGレベルとSRPGレベルの分離

TRPGレベルは、どの時点のキャラクターシートを初期換算の資料にしたかを示す**参照情報**としてだけ保持します。TRPGレベルをSRPGのレベルへ変換したり、そのまま引き継いだりはしません。

| 項目 | 役割 | 取り扱い |
| --- | --- | --- |
| TRPG資料Lv | 元のキャラクター資料がどの成長段階かを示す | 換算根拠と出典の記録にだけ使う |
| SRPG加入時Lv | SRPGへ加入した時点のゲーム内育成段階 | 加入時期、章の難易度、想定役割から別途設定する |
| 因果Lv | キャラクター固有の成長、固有スキル・戦技の習得に使う | SRPG開始後の成長として管理する |
| 兵種Lv | 現在の兵種に由来する成長、兵種スキル・戦技の習得に使う | 因果Lvとは別系統で管理する |

運用上は、表や資料の「Lv5」を必ず「TRPG資料Lv5」のように表記します。SRPG側のレベルを記録するときは「SRPG加入時Lv」など、別の列と名称を使います。

TRPGのレベル差からSRPGの成長回数や成長率を逆算しません。TRPG能力値は人物の素質・完成像を初期能力へ翻訳する材料とし、SRPG開始後の成長は因果Lv、兵種Lv、個人成長率、兵種成長補正で新しく設計します。

### 4.3 竜人のSIZ増加状態

竜人キャラクターは、TRPGシートに記録されたSIZ増加後の状態で戦闘することが多いため、**SIZ増加後の値をSRPG戦闘時の標準換算値として使用します。**

| キャラクター | 通常記載 | 標準換算に使う戦闘状態 |
| --- | --- | --- |
| バルド | HP28、SIZ14 | HP32、SIZ23 |
| ディラン | HP26、SIZ15 | HP31、SIZ25 |

通常時のHP・SIZも原資料として保持します。変身解除、弱体化、シナリオ上の非戦闘状態などで必要になった場合だけ、通常時の値を参照します。STR、CON等にSIZ増加時の別値が明記されていない場合は、シートの現在値を維持します。

### 4.4 比較用の作業式

| SRPG項目 | v0.3作業式 | 根拠 | 確定度 |
| --- | --- | --- | --- |
| HP | TRPGシートの現在HP | TRPGで得た成長結果を含む生命力を残す | 有力 |
| 力 | `STR` | 物理的な力と直接対応する | 有力。ただしアルバスの物理運用を実戦検証する |
| 防御 | `floor((STR + SIZ) / 2)` | 現行式と既存テストを比較基準として維持する | 仮。CONを含める案と比較が必要 |
| 魔攻 | `POW` | 魔法出力と直接対応する | 有力 |
| 魔防 | `floor((POW + CON) / 2)` | 魔力抵抗と生命力の両方を使う現行式 | 有力候補 |
| 技 | `floor(DEX / 2)` | DEXの精密さを残しつつ、DEX生値が命中・必殺を支配しすぎないよう圧縮する | 仮 |
| 速さ | `floor(DEX / 4) + 回避適性` | DEXの反応・機敏さを圧縮し、TRPGで実際に回避行動を身につけていたかを加える | 採用方針 |
| 魅力 | `APP` | APPが魅力の直接的な根拠で、現在値も15前後と扱いやすい | 有力 |

`回避適性`は、TRPGシートに記録された回避技能値を初期換算に一度だけ使うものです。SRPG開始後に修練度として成長させません。原資料に回避値がない場合は、人物資料から個別に設定し、その根拠を記録します。

SIZは基本ステータスの速さから直接引きません。大柄であることによる「攻撃を避けにくい」という影響は、速さそのものではなく、戦闘時に計算する派生回避へ反映します。これにより、竜人のSIZ増加が追撃能力まで一律に大きく下げることを防ぎます。

### 4.5 速さをDEXだけ、またはSIZだけで決めない理由

アルバスはDEX36ですが、これは魔法の精密さを強く表します。DEXをそのまま速さにすると、高精度の魔法砲台でありながら、高回避・高追撃の高速ユニットにもなります。

一方、リングホルムはDEX22ですが、回避適性9を持ち、実際の戦闘では素早く安定して立ち回る人物です。速さの作業式では、この差を次のように表します。

| キャラクター | 計算 | 速さ案 |
| --- | --- | ---: |
| 幼アルシェ | `floor(18 / 4) + 6` | 10 |
| リングホルム | `floor(22 / 4) + 9` | 14 |
| アルバス | `floor(36 / 4) + 0` | 9 |

幼アルシェの回避6は現在の `characters.js` にある暫定値です。`CharaStatus/幼アルシェ.txt` には特技一覧がないため、正式根拠は未確定です。

### 4.6 SIZと派生回避の分離

基本ステータスの速さは、追撃、行動の機敏さ、回避計算の土台として使います。SIZは速さを作る式には入れず、派生回避を計算するときだけ体格補正として参照します。

```text
初期速さ = floor(DEX / 4) + 回避適性
派生回避 = 速さを中心とした回避基礎値 + SIZによる体格補正 + 装備・地形・スキル補正
```

派生回避の係数と上下限は、後述する命中・回避式で定めます。地形、スキル、状態等の具体的な補正値は戦闘システム側で決めます。SIZは基本速さや追撃判定を直接下げず、命中・回避の対抗判定だけで体格補正として参照します。

## 7. 命中・回避のSRPG用対抗式

### 7.1 TRPG対抗表から残す考え方

TRPGでは、能動能力と受動能力が同値なら成功率50％、能力差1段階につき5ポイント増減する対抗表を使用していました。

```text
TRPG成功率 = 50 + (能動能力 - 受動能力) × 5
```

この「同じ尺度の能力を比較し、差1段階を5ポイントとして扱う」考え方をSRPGでも残します。ただし、通常攻撃を毎ターン繰り返すSRPGで互角50％にすると、攻撃失敗によって進行が停滞しやすいため、互角時の基準を60％へ上げます。

また、新SRPGの技・速さはTRPGの特技段階よりおおむね倍の尺度を使います。そのため、SRPG能力値2点差をTRPGの1段階差に対応させ、SRPG能力差1点につき2.5ポイント増減させます。

### 7.2 採用する命中式

```text
体格回避補正 = clamp(11 - 防御者SIZ, -10, +5)

最終命中率 = clamp(
  round(
    60
    + (攻撃者の技 - 防御者の速さ) × 2.5
    - 防御者の体格回避補正
    + 攻撃側補正
    - 防御側補正
  ),
  5,
  100
)
```

| 構成要素 | 役割 |
| --- | --- |
| 60 | 同程度の命中能力と回避能力が戦う場合のSRPG用基準命中率 |
| 攻撃者の技 | 攻撃精度の人物側基礎値 |
| 防御者の速さ | 回避能力の人物側基礎値 |
| 2.5 | SRPG能力値2点差を、TRPG対抗表の1段階差5％へ対応させる係数 |
| 体格回避補正 | 小柄なら避けやすく、巨大なら狙われやすくするSIZ由来の補正 |
| 攻撃側補正 | スキル、戦技、状態、支援効果等。明記された効果だけを加算する |
| 防御側補正 | 地形、スキル、状態、支援効果等。明記された効果だけを加算する |

武器固有の命中値は、現段階では採用しません。命中精度はあくまでキャラクター本人の技を中心にし、武器は威力、射程、属性等を担当します。特定の武器や戦技へ命中特性を付ける場合も、例外的な明記補正として扱います。

最終命中率は5％から100％に収めます。不利な攻撃にも最低限の成功可能性を残しつつ、十分な有利を作った攻撃は100％へ到達できるため、戦術で確実性を作れます。

### 7.3 3人の比較

地形、スキル、状態、Dual等をすべて除外し、基本能力とSIZだけで比較します。

| 攻撃方向 | 計算 | 命中率 | 防御側の実回避率 |
| --- | --- | ---: | ---: |
| アルバス → リングホルム | `60 + (18 - 14) × 2.5 - 1` | 69％ | 31％ |
| リングホルム → アルバス | `60 + (11 - 9) × 2.5 - (-4)` | 69％ | 31％ |
| リングホルム → ディラン | `60 + (11 - 13) × 2.5 - (-10)` | 65％ | 35％ |
| ディラン → リングホルム | `60 + (13 - 14) × 2.5 - 1` | 57％ | 43％ |
| アルバス → ディラン | `60 + (18 - 13) × 2.5 - (-10)` | 83％ | 17％ |
| ディラン → アルバス | `60 + (13 - 9) × 2.5 - (-4)` | 74％ | 26％ |

この関係では、リングホルムはアルバスを平地でも約3回に1回避け、回避地形を利用すればさらに五分へ近づきます。アルバスとディランは回避戦よりも、高精度・高火力を正面からぶつける関係になります。

### 7.4 判定処理

1. 攻撃者と防御者の能力、SIZ、補正を戦闘開始時の状態から取得する。
2. 上記の共通計算器で最終命中率を計算する。
3. 戦闘予測では乱数を使わず、同じ計算結果を表示する。
4. 実戦闘では1から100の乱数を1回取得する。
5. 乱数が最終命中率以下なら命中とする。
6. 命中後に必殺、ダメージ、追加効果の処理へ進む。

表示確率と実際の判定を一致させるため、命中計算は戦闘予測、実戦闘、敵AIで同じ共通計算器を使用します。

### 7.5 Dual発生率の初期案

Dualは通常攻撃の低命中を補う常時保証ではなく、支援関係を育てた結果として追加の攻撃機会を得る仕組みにします。

| 支援レベル | 基本発生率 | 支援補正 | 最終発生率 |
| --- | ---: | ---: | ---: |
| 支援なし | 5％ | 0 | 5％ |
| 支援C | 5％ | +10 | 15％ |
| 支援B | 5％ | +20 | 25％ |
| 支援A | 5％ | +30 | 35％ |

Dual攻撃の初期処理案は次のとおりです。

1. 前衛の通常攻撃を通常どおり解決する。
2. Dual可能な後衛がいる場合、前衛の命中・失敗とは独立して、1戦闘につき1回だけDual発生判定を行う。
3. 発生した場合、後衛は自身の技と攻撃内容を使い、同じ命中式で別個に命中判定する。
4. 命中した場合、後衛自身の能力でダメージを計算する。
5. Dual攻撃から別のDual、追撃、再帰的な追加攻撃は発生させない。

この方式では前衛が外しても後衛が補えるため、2人で戦っている感覚が生まれます。一方、Dual自体にも後衛の命中判定があるため、支援Aでも無条件の追加ダメージにはなりません。勇気、兵種スキル、因果スキルによるDual補正は、各システムの設計後に追加検討します。

## 8. この段階で採用できる内容

- 8基本ステータスは、HP・力・防御・魔攻・魔防・技・速さ・魅力とする。
- 魅力はAPPを根拠にする。
- 勇気は魅力と無関係の独立値とする。
- 幸運は8基本ステへ入れず、原資料の値は失わない。
- 完成済みキャラクターは、TRPGの完成能力を加入時換算の材料にできる。
- TRPGレベルは資料時点の識別情報とし、SRPGのレベルへ変換・引継ぎしない。
- SRPG加入時Lvは、加入章、難易度、役割を基準に別途設定する。
- 竜人はSIZ増加後の戦闘状態を標準換算に使い、通常時の値は別に保持する。
- 技と速さをDEXだけで同時に決めない。
- 初期速さは `floor(DEX / 4) + 回避適性` とし、SIZを直接差し引かない。
- SIZによる避けやすさの差は、基本速さではなく派生回避へ反映する。
- 命中・回避は、互角60％、能力差1点につき2.5ポイントの対抗式を使う。
- 武器固有命中は設けず、命中精度はキャラクター本人の技を中心にする。
- 最終命中率は5％から100％に収め、予測と実戦闘で同じ計算器を使用する。
- Dual発生率は、支援なし5％、支援C15％、支援B25％、支援A35％を初期案とする。
- TRPG技能はSRPGの修練度として成長させず、初期状態を決める資料として使う。

## 9. 決定が必要な項目

### 換算表を確定する前に決めるもの

1. 防御を現行の`(STR + SIZ) / 2`で維持するか、CONを含む式へ変更するか。
2. 技の`DEX / 2`が、武器・魔法命中を加えた際に適切な尺度になるか。
3. 回避技能が記録されていないキャラクターへ、回避適性をどの基準で設定するか。
4. 魅力をAPP直結にした後、因果Lvでどの程度成長させるか。
5. 最大MPをPOW直結のままにするか、魔法システムに合わせて圧縮するか。
6. 勇気と幸運の値を0から100のまま表示・保存するか。

### 戦闘システム設計後に決めるもの

1. 地形、状態、スキル、支援による命中・回避補正の具体値。
2. 必殺率と必殺回避の係数と上下限。
3. 追撃に必要な速さ差と武器重量の扱い。
4. ダメージ式と最低ダメージ。
5. 勇気の増減、勇気0、反撃、Dual、Breakとの関係。
6. Dual可能な位置関係、後衛の選択方法、追加攻撃の威力補正。
7. 個人成長率と兵種成長補正。
8. 基本能力・派生能力・装備補正の上限。
9. SRPGのレベル上限、加入時Lvの基準、因果Lvと兵種Lvの上昇速度。
