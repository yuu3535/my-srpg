# シナリオの演出の指示（カメラ・暗転）

作成: 2026-10-05 / 総合担当（Claude Code）
状態: **正式採用**（原作者 2026-10-05: 指示があるところは自動で、なければふつうのカメラ）

## 1. 考え方

- シナリオの表のト書き（台詞の行の「備考」「ゲーム処理」と、その前の制作メモの行）に、**決まった言い方**で書くと、ゲームが読み取って演出する。
- 指示がない所は、ふつうのカメラのまま（その場面のカメラ ＋ 会話のときに話す2人へ少し寄る）。
- 演出は、その会話（ブロック）が終わると自動でもどる。次の会話はふつうのカメラから始まる。
- 今は **2Dの探索（横スクロールの場所）の会話**で動く。3Dの盤面の会話はまだ読まない。

## 2. 言い方の一覧

| 書き方 | 動き |
|---|---|
| `カメラ：空を見上げる`（`見上げる`・`上を見る` でも可） | 見る所を上へずらす（画面の 150 点） |
| `カメラ：下を見る`（`足元` でも可） | 見る所を下へずらす（80 点） |
| `カメラ：右を見る` | 見る所を右へずらす（280 点。画面の外の人へ目を向ける） |
| `カメラ：左を見る` | 見る所を左へずらす（280 点） |
| `カメラ：寄る` | 大きく映す（1.35 倍） |
| `カメラ：引く` | 広く映す（0.8 倍） |
| `カメラ：もどす`（`ふつう` でも可） | ふつうのカメラへ |
| `暗転` | 画面を暗くする |
| `明転`（`暗転明け` でも可） | 暗いのをもどす |

- 「カメラ」のあとの `：` は全角でも半角でもよい。
- ずらしは足していく（`カメラ：右を見る` を2回書くと、もっと右）。
- 指示は、その行の台詞が出るときに動く。台詞の前に動かしたいときは、その行の備考に書く。
- 動きはなめらか（0.6秒ほど）。暗転は動かさずに切り替える。

## 3. 書くときの注意

- 見上げたり引いたりすると、場所の絵の外（黒）が見えることがある。部屋は天井の絵がないので、見上げると上が黒くなる。屋外で空を見上げる場面は、その場所の空の層を上に長くしておく（`docs/10-design/map/SIDE_SCROLL_2D_MAP_PIPELINE_2026-10-03.md` §5「このシーンのカメラ」）。
- 決まった言い方以外（例「カメラがゆっくり回る」）は読まない。新しい動きが要るときは総合担当に頼む。
- 「暗転」という言葉は、2Dの探索の会話の中では本当に画面を暗くする。ただのメモとして書くときは「暗転」を使わない。

## 4. 実装

- 読む: `unity-prototype/Assets/Scripts/Battle/Scenario/StageDirection.cs`（テスト `Tests/EditMode/StageDirectionTests.cs`）
- 渡す: `DialogueView.OnDirection`（出す行ごとのト書き）・`DialogueView.Closed`
- 動かす: `Explore2DController.OnDirection` → `Corridor2DView.SetShot`（ずらしと大きさ）・`Darkness`
