## 1. 台詞の長さ（いちばん大事）

| 決まり | 中身 |
|---|---|
| 1行 | **13字まで** |
| 1ページ | **3行まで**。超えたら2ページ目へ送られる（画面を押すと続きが出る） |
| 1つの台詞の目安 | **3行（39字くらい）まで**。長い説明・モブの会話は2ページ目に送られてもよい |
| 改行 | **意味の切れ目で、13字以内ごとに改行を入れて書くのがいちばん読みやすい** |

- 改行を入れなくても、ゲームが13字で自動で折り返す。なるべく「、。！？」や助詞（は・が・を・に…）の後ろで切るが、言葉の途中で切れることがある（例:「ずっと早く大／きくなっちまう」）。読ませたい切れ目があるなら、自分で改行を入れる。
- 「、。！？」）…ー」は行の頭に来ない（ゲームが直す）。
- **前の決まり（1行18字・2行）は使わない。**
- 吹き出しの大きさは、ページごとに台詞に合わせて変わる（2026-11-18 原作者が決定）。台詞を無理に伸ばしたり、長さをそろえたりしなくてよい。
  - 高さ: そのページの行数（1〜3行）。
  - 幅: そのページのいちばん長い行が **11字以下** なら、字数に合わせて細くなる（話す人の側の端は動かない）。12字以上の行があれば、13字ぶんの広さ。

### よい例・悪い例

| | 書き方 | 画面 |
|---|---|---|
| よい | あらアルシェ様、⏎おはようございます。 | あらアルシェ様、／おはようございます。 |
| よい | 今日のやること⏎確認しておこう。 | 今日のやること／確認しておこう。 |
| 悪い | 今日のやること確認しておこう。（15字・改行なし） | 自動で切れる。たまたま読めるが、切れ目は選べない |
| 悪い | もう訓練場にいるから早く来て。⏎先日父上からいただいた双剣を持ってくるのを⏎… | 1段落が13字を大きく超えて、4行以上（2ページ）になる |

## 2. 話す人の種類と見え方

| 種類 | 表の書き方 | 画面 |
|---|---|---|
| 立ち絵のある人の台詞 | 話者に名前 | 真ん中の吹き出し・名前札あり。**尾**で話す人を指す |
| 立ち絵のない人（兵士・モブなど） | 話者に名前 | 真ん中の吹き出し・名前札は真ん中・**尾なし**（姿の見えない声） |
| 地の文（場面の説明） | 話者を空に | 名前札なし・中央揃え |
| 携帯端末 | 話者に「携帯端末」 | 名前札に星の印・ドット柄が濃い |

- 吹き出しは**いつも画面の真ん中に1つ**。話す人が変わっても動かない。

## 3. 立ち位置（誰がどこに立つか）

- 左＝主人公の側（アルシェ・カリマ）、右＝相手の側（それ以外）。片側2人まで、画面に4人まで。
- **先に出てきた人が内側**、あとから来た人が外側。人数が増えても、先にいる人は動かない。
- 1〜2人の場面は全員が内側。
- 立ち絵のある人は、最初に話す前から（会話の始めから）立っている。並べたい順に初登場させると、その順に内側から埋まる。

## 4. 演出の列（シナリオの表に足す列。空のままでよい）

| 列 | 書き方 | 使いどころ |
|---|---|---|
| 箱の演出 | 空（ふつう）か「**叫ぶ**」 | 怒鳴る・叫ぶ台詞だけ。全文が一気に出て、画面が揺れ、話す人が前へ出て、周りが暗くなる。**たまに使うから効く。続けて使わない** |
| ガヤ | 「**名前：本文**」。強めは終わりに「**（強め）**」。2人ぶんは**改行**で分ける | 端の人のつぶやき（例: カリマ：えっ、そうなの？）。**日常・間の抜けたやり取り・ちょっとシュールな場面向け**。シリアス・緊張した場面では使わない |
| 画面の外の声 | 「**ひそひそ**」か「**ざわざわ**」。本文を変えるなら「ひそひそ：ねえ、聞いた…？／ひそひそ…」（／で分ける） | 姿の見えない人たちの声・場の空気。陰口・不穏なざわめきなど、シリアスな場面にも使える。地の文の行にも付けられる |

### ガヤが出る条件（満たさないと出ない）

- **3人以上の場面で、外側に立っている人だけ**（内側の人の頭の上には置く場所がない）。
- その人がその行でメインに話しているときは出ない。
- 地の文・携帯端末の行では出ない（立ち絵のない人の台詞には、反応として付けてよい）。
- ガヤの本文は短く（10字くらいまで）。会話ログには「名前（ガヤ）」で残る。
- 同じガヤを次の行にも書くと、出たまま残る（消えずに続く）。

### 強さの段階（叫ぶ演出との関係）

| 段階 | 演出 | 今 |
|---|---|---|
| 1 | 字の指定（太さ・フォント） | まだ（列は未定） |
| 2 | 叫ぶ（この表の「箱の演出」） | 使える |
| 3〜4・別枠 | ひび（慟哭）・崩れて赤へ・染まる（洗脳） | まだ（別の仕様書で決める）。書きたいときは「演出・備考」に書いておく |

## 5. 支援会話（2人の会話の画面）

- 支援会話は顔の横に吹き出しが出る別の画面で、**今は1行26字・1ページ2行**（ふだんの会話とは違う。決まったらここを直す）。
- ガヤ・画面の外の声・叫ぶは、支援会話では出ない。

## 6. 表の列（全部）

`No・シーン・パート・話者・表情・本文・台詞・区分・演出・備考・ゲーム処理・背景` と、上の `箱の演出・ガヤ・画面の外の声`（無くてもよい）。

- 「「○○」を手に入れた」と本文か演出・備考に書くと、その行で物を手に入れる。
- 【チュートリアル開始】のように【】だけの行は画面に出ない目印。
- シナリオの正本は Googleドライブのスプレッドシート。直したら総合担当が `tools/import_scenario.py` で取り込む。
