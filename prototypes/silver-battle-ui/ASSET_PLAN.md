## レイヤーと寸法

| 素材 | 表示先・寸法（基準画面） | 方針 |
| --- | --- | --- |
| 城塞の清書背景 | 盤面 1254×627 | UI・キャラ・色タイルを除いた別の背景画像。カメラとUIを分離 |
| アルシェの肖像 | 通常 146×205 / 予測 280×245 | 透過、予測では髪先が枠より30px程度上へ出る |
| 森の番人の肖像 | 予測 270×240 | 透過、兜の上端が少し枠から出る |
| 銀の装飾枠 | 通常右 292×518、地形 206×74、予測 1240×198 | 透過の細枠を9-sliceで利用。装飾をCSS図形で代用しない |
| 地図ユニット | 70〜90px高 | 透過のSD絵。背景に焼き込まない |
| 青・赤の範囲 / 選択 | 各ダイヤ状タイル | 既存の採用版透過素材を使用 |
| 味方の顔・武器・スキル | 顔60×46 / アイコン32〜44px | 既存素材を参照。未制作の戦技アイコンは流用しない |

文字・HPバー・数値・選択状態・各操作はHTMLで実装する。
横長比率は維持する。小画面は触れるボタンの物理寸法を優先し、一部詳細を開閉する。
本編の戦闘計算・セーブ・フェーズ演出は読み込まない。
