## 開く

リポジトリのルートで、既存のPythonを使って静的サーバーを起動する。

```powershell
py -3.12 -m http.server 8931 --bind 127.0.0.1
```

`http://127.0.0.1:8931/prototypes/silver-battle-ui/index.html`

HTMLは直接ダブルクリックでも開けるが、確認時は静的サーバーを使用。ビルド・npm install不要。ローカルのみ、外部公開なし。

## 試せる操作

- TURNの山形: 味方一覧を開閉。長い一覧は中だけをスクロール。
- 顔／盤面の味方: 人物を選択し、右の情報を切り替え。
- 何も乗っていない青いマス: 選択人物の移動。
- 盤面の敵／赤い対象マス: 戦闘予測。右欄が閉じ、盤面を上へ寄せる。
- キャンセル: 通常画面へ戻る。移動後の位置を保持。
- 攻撃する: 短い見本の演出、HP更新、途中撃破した敵を非表示。
- 戦闘詳細: 固定例の内容と未接続範囲を表示。
- 上の見本用ツールバー: 通常／予測の切り替え、初期化、説明。
- 左右キー: 味方切り替え。F: 予測。R: 初期化。Esc: 閉じる。Enter/Space: ボタン。

## 意匠・レイヤー

- 1254×627（2:1）を基準に全体を等比縮小。縦の並べ替えはしない。
- 盤面とUIは別の層。通常は右の人物情報、予測は下の対戦帯と少しはみ出す肖像。
- タイトルは左上、地形は右上。移動中の盤面へ戦況／予測の常設ボタンは追加していない。
- 銀の枠・透過の人物・背景は画像素材。情報・数値・操作はHTML。画面全体を画像にしただけではない。
- Windowsの游明朝など、既存画面に近いローカル書体を利用。標準の操作アイコンはPhosphor Core 2.1.1の公式SVG（MIT、`assets/package/LICENSE`）。
- モーション低減設定を尊重。素材読込中・読込エラー・対象なし・攻撃中の二重操作防止を用意。

## 試作と正式仕様を区別する

- キャラ名・数値・スキル・配置は表示確認用。採用版ステータスとは一致を保証しない。
- 魔法使い（仮）は参考画像の人物を模した見本専用。正史への追加ではない。
- アルバスとリングホルムは既存肖像・SD素材を読み取り参照するだけ。
- スキルアイコン3枚は手元の既存画像を `assets/skill-icons/` へコピーして同梱。元画像を変更せず、未追跡フォルダがなくても表示できるようにした。
- 背景・肖像は参考画像をもとに再生成したため、元画像との完全なピクセル一致はない。
- 移動／攻撃範囲は配置見本。障害物、正式な座標系・射程、敵AI、乱数、MP、耐久、BattlePlanとは未接続。
- 魔法も反撃される固定例を用意しているが、正式な距離判定の検証ではない。
- 味方フェーズ／敵フェーズ演出の再設計はしていない。
- 本編やUnityへの反映は、適用範囲を原作者と確認する別作業。方向性の確認を、全仕様や素材の正式採用に読み替えない。
