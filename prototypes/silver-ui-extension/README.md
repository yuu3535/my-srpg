## 色・大きさの調整機能（2026-10-03）

原作者が標準の飾り量を「ちょうどいい」と確認。その見た目を初期値として保ち、調整する機能だけを追加した。

- 幅480〜796px、高さ100〜180px、角の丸み0〜24pxを調整。値は844×390の設計画面基準。左右位置は中央揃え、下端25pxを維持する。
- 下地・直線の縁・文字の色を別々に選べる。銀細工の画像自体は色替えしない。
- **透過率0%＝不透明、100%＝下地が透明**。文字・銀細工の不透明度は変えない。名前札の下地も連動する。
- PCでは見本の横の調整欄をスクロールすると、色・コピー・保存の操作が出る。小さいウィンドウでは調整欄が見本の下へ回るが、ゲーム領域は横長のまま。
- 変更は `localStorage` の `srpg.silver-dialogue.settings.v1` に自動保存。同じブラウザ・同じホスト／ポートで再読み込みすると復元。ゲームのセーブとは無関係。ブラウザの保存データを消すと失われる。
- 「設定をコピー」をClaude Codeへ貼るか、「設定JSONを保存」でファイルへ残す。コピー不可の場合は共有欄のJSONを手動コピーできる。
- 「共有用の設定／前の設定を読み込む」を開いてJSONを貼り「この設定を読み込む」で再現。不正なJSONはエラーを表示し、現在値を維持する。
- 「元の見本に戻す」は調整値を初期値へ戻す。原画像・背景・本編には触れない。
- `?capture=1` は撮影用。保存値を読み書きせず初期値を表示し、編集欄を隠す。
- テスト: `node prototypes/silver-ui-extension/dialogue-settings.test.js`。

公開元mainへ保存する。GitHub Pagesの更新後は `https://yuu3535.github.io/my-srpg/prototypes/silver-ui-extension/dialogue.html` でも開ける。ローカルと公開URLでは自動保存は共有されないので、設定JSONで移す。
