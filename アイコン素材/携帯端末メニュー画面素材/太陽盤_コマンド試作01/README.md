- 回転する四角い札、太い文字の縁取り、45度刻みの8重複配置を廃止。

- 先端からの水平余白は18px。12〜48pxで比較できる。
- 上下端の文字は画面内へ寄せ、接続線で対応する針を示す。

## 針先の計測

1254×1254のrays-frame.pngを読み取り、アルファ180以上・中心から500px以上・各尖った方向の±10度で最遠の画素を調べた。
背景の低アルファ画素は除外。画像ファイル自体は変更していない。

| コマンド | 元画像の尖端X | 尖端Y |
|---|---:|---:|
| マップ | 629 | 7 |
| アイテム | 1184 | 319 |
| 仲間 | 628 | 1220 |
| 支援 | 71 | 934 |

中心は(627,627)。描画サイズ439pxに合わせて座標を変換し、針の回転行列を同じ尖端へ適用する。
他の右下・左上の尖った2本と、曲がった炎の先は装飾として残す。項目は重複させない。
素材は正確な60度対称ではないため、スナップも計測された角度に合わせる。
初期状態はマップの針が右中央に向く回転角。キャラ別の固定角度ではない。

## 文字の非重複

針を覆う半径225pxの領域を基準に、水平なラベルの矩形全体がその外側になる位置を計算。
文字の左右だけでなく、上端・下端が針の領域へ入り込まないことを確認する。
文字は針と同じ回転から位置を計算しつつ逆回転を補正するので、常に正立。
上下端での文字の移動は意図的な追従配置で、実際の先端との関係は接続線で保持する。
