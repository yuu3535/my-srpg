## ホームと端末の構成

既存の独立ホームを `?view=screen&embed=transition` で埋め込む。HTML内部は常に844×390、文字の折り返し・配置を途中で変えない。既存の端末原本1799×874を使用し、内窓X202.2410256410／Y109／W1391.5179487179／H643を844:390へ対応させた。既存③＋寄りの初期倍率は約0.735、④はその0.94倍から浮上、終点は1.0。④の画面点灯だけは意図して縦に開き、完了後は縦横とも1.0倍に戻る。
