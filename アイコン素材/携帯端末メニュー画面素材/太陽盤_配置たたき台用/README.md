# 配置たたき台用・太陽盤のみ

2026-10-04 原作者の依頼で、コマンド配置の試作を止め、手描き配置案の下敷き用に書き出した素材。正式採用素材ではない。

- アルシェ／カリマの2種類。背景・文字・コマンド・接続線・説明欄・端末フレームなし。
- サイズは1688×780。横画面844×390の2倍で、右側の空白も完全透過のまま維持。
- 既存の試作03の4枚のPNG、material-engine.js、character-colors.jsを使用。新しい画像生成や元素材の修正はしていない。
- 共通設定はガラス盤：中心(-40,195)、サイズ406、不透明度50%。針：中心(0,195)、サイズ439、不透明度89%。両方0度。数値は844×390基準。
- 金属枠は不透明。ガラスの透け具合を維持。元の分離PNGに残る縁の微小な残りもそのまま含む。
- PNGの寸法、アルファ、右側の完全透過、実際の画像表示を確認済み。

再書き出し用スクリプトは隣の `太陽盤_コマンド試作01/export-dial.cjs`。既存のPNGを保護するため同名ファイルがある場合は停止する。
