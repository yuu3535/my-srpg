## 青い下地について

- 「テキストボックスと同じ風」は、枠に沿う独立した半透明の文字面として解釈。飾り・文字・星・外側のぼかしは含めない。
- 単純な文字面の形状は画像生成せず、編集しやすいSVGで作成した。
- 上端は柔らかい肩、側面はまっすぐ、下端は枠のカーブに沿う形。葉飾りやシールの周囲まで四角く塗らない。
- 単独SVGの生成時の色は `#10253b`、不透明度は78%。確認ページの初期値は後述の原作者設定へ変更（素材SVG自体は上書きしない）。正式な固定値ではない。
- SVGの `fill` と `fill-opacity` だけを変えると、文字・枠を薄くせず下地を調整できる。
- 既存のゲーム内会話ボックスの素材をそのまま転用したものではない。そちらと厳密に同一の意匠を意味する場合は改めて形状確認が必要。

## 使い方

`layers-preview.html` を開くと、各素材と文字の表示を切り替え、青い下地の色・不透明度と星の濃さを個別に調整できる。背景は市松・暗い無地・明るい無地。背景風景は生成していない。

### 2026-10-05：配置・文字の調整機能

- フレームと中央の星の位置・縮尺は現在の表示で固定。移動できるのはβ版シールのみ。
- シールをマウス／タッチでドラッグできる。フォーカス後の矢印キーは1%、Shift＋矢印は0.1%ずつ移動。「左から／上から」の数値入力でも調整できる。
- 数値は確認キャンバスに対する割合。位置は画面サイズに追従し、シール全体がキャンバス内に収まる範囲へ制限する。シールのリセットは色・透明度・フォントを変えない。
- PNGは再加工していない。元PNGの描画領域を余白付きの矩形（800, 20, 190, 140）で表示側だけ切り出し、透明な全キャンバスではなくシール付近のみを操作対象にした。元の描画位置・寸法は維持。
- 「文字面の濃さ」は0%で完全に透明、100%で不透明。透け感も併記。銀線・星・文字の濃さは変わらない。
- 見出し「運命予報」と、「蛇」＋縦書き本文のフォントを別々に選べる。外部フォントは読み込まない。
- シール位置・傾き、下地の色・濃さ、星の濃さ、フォント、確認背景をブラウザのlocalStorageへ保存。表示切替チェックは保存しない。file:の保存可否はブラウザに依存し、保存できない場合も調整操作はできるが、再表示時の保持は保証しない。
- 「初期状態に戻す」で全調整と表示切替を初期化。素材ファイル、本編、Unityは変更しない。

確認コマンド：`node アイコン素材/携帯端末メニュー画面素材/運命予報_分離素材01/verify-layers.cjs`。ドラッグ、縮尺追従、キャンセル、キー操作、数値制限、透明度の独立、フォント、保存・復元・保存不可の挙動を模擬DOMで検証。ブラウザでの見た目・実際のタッチ操作は未確認。

### 続き：設定のコピー・JSON書き出し、PC内フォント、シールの傾き

- 「設定をコピー」で現在値をクリップボードへ渡す。このチャットへそのまま貼り付けられる。コピーが拒否される場合は設定欄が選択されるので、Ctrl+C等で手動コピーする。
- 「JSONを書き出す」で `fortune-preview-settings.json` のダウンロードを開始する。ブラウザのダウンロード先に保存される（ブラウザ側の許可・保存設定に従う）。保存対象は合成画像やフォント本体ではなく、調整値のみ。ページ内へのJSONファイル読み込み機能は未実装。
- 出力スキーマは `fortune-separated-preview-settings-v01`。基準1024×1536、シール位置は未回転の操作領域の左上をキャンバスの%で記録。角度は元素材からの追加回転（度）。フォントIDとファミリー名、直接指定した名前も記録する。
- 元の5候補に、このPCのWindows `InstalledFontCollection` で確認した日本語向け39候補を追加。「02うつくし明朝体」「Noto Serif JP」「異世明」「源界明朝」「叛逆明朝」等。確認日2026-10-05。端末の全フォントを自動列挙し続ける仕組みではない。
- 「フォント名を直接指定…」から別のインストール済みフォントも試せる。CSSのfont-familyとして名前だけを指定し、フォントファイルはコピー・読み出し・アップロードしない。未インストールや未収録文字は代替表示。製品へ同梱する際は各フォントの利用条件を別途確認する。
- シールの「追加の傾き」は−180〜180°、プラスで時計回り、0°はPNGに描かれた元の傾き。スライダー・数値どちらでも調整できる。回転後の外接矩形が画面内に入るよう位置を補正するため、端では回転時に少し位置が動く。
- 「シールの位置・傾きを元に戻す」はシールだけ初期化。以前の保存データに角度がなくても0°として復元する。
- 模擬DOMでフォント候補・直接入力の引用、回転と位置制限、旧保存互換、コピー／ダウンロード成功・拒否、ダウンロードURL解放、出力JSONの値と復元互換を検証。ブラウザの描画・クリップボード権限・ダウンロード実操作は未確認。

### 原作者設定の保存とFortuneの独立書体

- 受領設定を確認ページの `previewDefaults` に保存。下地 `#0d0f11`／濃さ59%、星26%、シール位置x=62.89772727272727%、y=10.392992424242424%、追加角度6°。見出しは `ベストテン-CRT`、本文は `源界明朝`、確認背景は市松。試作の初期値であり本編の正式採用ではない。
- 「初期状態に戻す」とシールだけのリセットは、この受領設定を基準にする。ブラウザ内の保存済み調整は勝手に上書きせず、初回表示では保存値を優先。新しい初期値を試す場合は全体リセットを使う。
- 「Fortune」用に独立フォント選択・名前の直接指定を追加。Garamond／Book Antiqua／Bahnschrift／Segoe UI／Consolas等の欧文書体、PC内39候補から選べる。見出し・本文のフォントや位置には影響しない。追加時の初期値はGeorgiaだったが、続けて受領したJSONに従い `Neko_no_Mezame` を試作初期値に設定。その他の受領値は変更しない。
- 出力JSONへ `fortuneFont`、`fortuneCustomFont`、`fortuneFontFamily` を追加。ブラウザ保存にも含める。従来のスキーマと互換の任意追加項目とし、旧設定に項目がない場合はGeorgiaを使う。
- 模擬DOMで受領設定の数値一致、リセット、旧保存優先、Fortuneの独立反映・名前指定・保存復元・JSON出力を検証。実ブラウザの見た目は未確認。
