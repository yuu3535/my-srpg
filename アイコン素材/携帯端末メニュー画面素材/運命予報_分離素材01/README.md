## 青い下地について

- 「テキストボックスと同じ風」は、枠に沿う独立した半透明の文字面として解釈。飾り・文字・星・外側のぼかしは含めない。
- 単純な文字面の形状は画像生成せず、編集しやすいSVGで作成した。
- 上端は柔らかい肩、側面はまっすぐ、下端は枠のカーブに沿う形。葉飾りやシールの周囲まで四角く塗らない。
- 初期色は `#10253b`、不透明度は78%。正式な固定値ではない。
- SVGの `fill` と `fill-opacity` だけを変えると、文字・枠を薄くせず下地を調整できる。
- 既存のゲーム内会話ボックスの素材をそのまま転用したものではない。そちらと厳密に同一の意匠を意味する場合は改めて形状確認が必要。

## 使い方

`layers-preview.html` を開くと、各素材と文字の表示を切り替え、青い下地の色・不透明度と星の濃さを個別に調整できる。背景は市松・暗い無地・明るい無地。背景風景は生成していない。

重ねる順序は下から「青い文字面 → 中央の星 → 外枠 → 文字 → β版シール」。文字はHTML表示で、PNGには焼き込んでいない。

本文の縦書きは右から順に「失せモノに注意。」「笑う声が聞こえたら、」「振り返らないこと。」。タイトルとFortune→二点→蛇は横方向に中央配置。

星は元の見本と同程度に控えめに見えるよう、確認ページで濃さ13%、下方向9.4%、縮尺90%を仮指定。PNGの位置・濃さを焼き直さず、表示側で調整する。

## 生成・検証記録

- 元見本：`../運命予報_タロットデジタル比較01/fortune-tarot-silver-hairline-v03.png`。
- 枠・シール・星は組み込み画像生成によるそれぞれ独立した分離編集。プロンプト全文は `prompt-frame-v01.txt`、`prompt-beta-v01.txt`、`prompt-star-v01.txt`。
- 枠はシールに隠れていた右上部分を左右対称に補完。中央の星は文字に隠れていた部分を補完。
- AIによる分離編集なので、元見本のピクセルを厳密にそのまま切り抜いた素材ではない。細部や星の位置・縮尺は変わっている。
- 3PNGとも1024×1536 RGBA。角・遠い外側・不要領域のサンプル点でアルファ0を確認。枠とシールの中央もアルファ0。
- ツールの画像表示には透明ピクセル内のRGBが霧のように見える場合がある。実際の重ね合わせではアルファを使う。
- SVG構文、参照ファイル、確認ページのスクリプトを静的検査。ブラウザでの描画・タップ操作は未確認。
