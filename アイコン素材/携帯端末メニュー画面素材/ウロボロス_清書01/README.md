## 清書の方針

二匹の蛇、相互の口・尾の接続、菱形、暗い赤の目、時計盤、時計盤に沿う金色の丸いリング、赤く塗った縦長の瞳孔を維持。輪郭を閉じたパスへ整理し、塗りを均一な色へ置き換えた。時計の円は同心円、目盛りは30度間隔の十二本。針・数字・文字・発光・立体金属は追加しない。

鱗の黒く見える部分は透過の抜き模様。蛇の灰色部分は見本の肩・内縁の切り替えを残す。下半分は上半分の単純な180度コピーではなく、独立した輪郭とする。

蛇の胴・鱗・金の縁、頭と目、口と尾、時計、金の円、赤い瞳孔にIDを付けた。後から別々に調整できるが、今回は静止画。

## 再生成と検証

build-ouroboros.cjsが座標・色・繰り返し模様の編集元。修正後は同じフォルダで以下を実行する。

    node build-ouroboros.cjs
    node verify-ouroboros.cjs

PNGと比較画像の描画には任意のローカルSharpを使用。HTML／SVGの表示には不要。使用前に対象パッケージのpackage.jsonで名前を確認する。追加する場合はnpm install sharpだが、この作業ではインストールしていない。

    node render-proof.cjs "ローカルSharpパッケージの絶対パス"

検証：NodeによるSVG構造・生成元との一致・相対参照・背景／サイズ／エラー表示連動、XML解析、PNGの透過と中央の塗りを確認。静止画の比較は実施。確認HTMLのブラウザ描画・保存操作はアクセス制限により未検証。配布前に原作者の見た目確認とブラウザQAが必要。
