# メイン3人の技能・魔法・戦技 棚卸し
確認日：2026-09-22 / 対象：現在のローカル実装とTRPG原資料

## 1. まず押さえる現在地
**現在の3人は、TRPGの特技値・魔法リストを持つユニットに、少数のSRPG戦技・パッシブが追加された状態。定義ファイルに載っている能力が、すべて使用可能なわけではない。**
本書はコードの静的読解による記録。全能力を実機で再現検証した結果ではない。新しい仕様案や成長率案は混ぜていない。アルシェは別IDの幼年版とLv4版を併記する。

| 対象 | 現在の戦技・パッシブと注意点 |
| --- | --- |
| 幼アルシェ / young_arshe / Lv1 | 両断が使用対象。絶影も条件を満たすが、通常の特技メニューへの入口が出ない。初期パッシブなし。魔法5種。 |
| アルシェ / arshe / Lv4 | 両断が使用対象。絶影は幼年版と同じUI上の問題あり。初期パッシブなし。魔法6種。 |
| リングホルム / ringholm / Lv5 | 両断・絶影が使用対象。固有パッシブ「殺気」が接続済み。魔法5種のうちヒトダマはログのみ。 |
| アルバス / albas / Lv5 | 現在使える戦技・初期パッシブなし。魔導9でも魔光・威光・明星等は使えない。魔法10種のうち変身・召喚3種はログのみ。 |

### 本書での分類
| 表記 | 意味 |
| --- | --- |
| 接続済み | ゲーム処理が能力を参照して、ダメージ・状態・行動等を変える。完全な仕様完成を意味しない。 |
| 一部・不整合 | 効果処理はあるが、UI導線や持続時間などに不足・食い違いがある。 |
| ログのみ | コマンドとして選べても、文章表示以外の本来の効果がない。MPや行動を消費するものもある。 |
| 定義のみ | JSのデータや説明はあるが、現在の能力効果・習得処理につながっていない。 |
| 原資料・設計のみ | TRPGメモや設計書の記載。現在の実装済み能力とは扱わない。 |

**最も紛らわしい点：** ステータス画面の「修練度」は現状ほぼ固定の特技値。「戦技」表示は攻撃系に限られ、「秘伝」「発作」は名前表示が中心。表示されることと、効果が動くことは別である。

## 5. 共通の効果・コストと不整合
根拠：spells.js / SPELLS_DATA、game.js / executeMagic・executeTeleport・getMagicHitResult、statConversion.js。
魔法欄の数値は一律の「成功率×10」ではない。攻撃魔法は命中計算へ参照し、支援・回復魔法は通常100%成功。転移は専用の成功値×10%判定。

| 魔法 | 射程 / MP | 現在の処理 |
| --- | --- | --- |
| 火 | 2 / 1d6 | 魔攻+呪文威力3と魔防等でダメージ計算。結界吸収前の必殺込みダメージ10以上で火傷。持続1d6、対象側フェーズ開始時1d3ダメージ。 |
| 落雷 | 3 / 1d6 | 単体攻撃。呪文威力4。 |
| 破壊 | 2 / 1d6 | 単体攻撃。呪文威力3。結界が吸収した後に残りの結界も消去。デュアルを崩すブレイクではない。 |
| カウンター | 自身 / 1d6 | 2d3の反射状態。通常物理・投擲の命中時、結界適用前のダメージを双方へ。魔法への万能反射ではない。 |
| 封印 | 2 / 1d8 | スタン1d3+1。付与は実装。通常物理と魔法・投擲・移動等で行動制限が揃っていない。 |
| 結界 | 2 / 1d6 | 吸収値5。通常攻撃でも消耗する。原資料の「破壊でのみ減少」とは違う。 |
| 虚像 | 2 / 1d8 | 命中低下状態value=-2。命中計算では-10相当。 |
| 治癒・生命 | 2 / 1d6 | floor(POW/3)+3回復。初期アルバスは15、最大HPまで。両魔法の値9と5で回復量は変わらない。 |
| 加速 | 2 / 1d6 | 対象のmoved・actedをfalseへ。自分にかけても最後に術者の行動終了処理が走る。 |
| 転移 | 5 / 1d8 | 成功時は移動扱いで行動権を残す。失敗時は行動終了。ファイル冒頭の「未実装」コメントは専用処理と食い違う。 |
| 変身・召喚 | 各定義参照 | 選択・MP消費・ログ表示はある。本来の変身・召喚効果なし。 |

### 誤解しやすい実装上の注意
- **結界・虚像の持続：** durationFormulaの「1d3+MB」をrollDiceへ直接渡す。MBが置換されずエラー時0となり、次の対象側フェーズ開始時に消える。効果そのものが全くない、という意味ではない。
- **MP不足：** 通常の魔法使用に十分なMPを要求する制限がない。消費後は0未満にならないが、MP0でも使用できる経路がある。
- **回数制限：** 魔法は1戦○回制ではない。絶影のみ1戦3回の制限が接続済み。
- **通常の反撃：** 勇気を参照する別処理。カウンター魔法と混同しない。魔法から攻撃した際など、予測と実処理の不一致もある（全体監査MD参照）。

## 9. 何を確認する時に、どこを読むか
| ファイル / データ・関数 | 役割と注意 |
| --- | --- |
| characters.js / CHARACTERS_DATA | 現在の本人のskills・spells・秘伝・発作・初期パッシブ。4つのIDを区別する。 |
