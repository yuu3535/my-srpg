# 自作SRPG 基本ステータス設計

設計記録 v0.2 / 2026年9月22日

本書は、会話「FE作品比較評価」で合意した現時点の設計と、その理由を保存するための資料。完成した戦闘仕様書ではない。**ステータスの構成・役割と、数値計算の確定度を分けて読むこと。**

## 1. 確定事項：構成と設計思想

### 1.1 設計思想

- **選択肢は多いが、管理項目は少ない。** 戦い方の選択肢を持たせつつ、成長や調整のために管理する基本ステータスは増やしすぎない。
- **基本ステと派生ステを分離する。** 本人が成長する能力と、戦闘時などに能力・装備・補正から算出する値を区別する。移動も基本成長ステには含めず、兵種などから決まる派生ステとして扱う。
- **TRPG由来の数値を、そのまま輸入しない。** 人物の特徴は参考にするが、別のルールで成立していた値をSRPGの確率や補正へ直接置き換えない。
- **技と速さの役割を分ける。** 技は攻撃精度・技巧・必殺、速さは追撃・回避を担う。両者を同じ役割のステータスにしない。
- **魅力の役割を広げても、「神ステ」化を避ける。** 連携・支援・特殊効果に加えて必殺回避にも使う。ただし、魅力だけを伸ばせば多くの問題が解決する状態を避ける。寄与率や具体的な処理は未決。

- **因果Lvは「本人そのものの成長」、兵種Lvは「その戦い方の習熟」を表す。**
- **汎用兵種は「何を学んできたか」を表す。** 訓練・戦闘経験・戦い方の履歴であり、成長補正や兵種スキル／戦技を通じて本人の成長へ影響する。
- **因果兵種は「結局この人は何者なのか」を表す。** 汎用兵種の単純な上位職ではなく、人物の出自・人生・役割・固有能力・戦闘スタイルを統合した本人専用の完成形とする。
- **汎用兵種はビルドの過程、因果兵種はキャラクターの完成形として扱う。**
- **兵種で習得したスキル／戦技は原則として本人に残す。** 因果兵種になった後も、使用条件を満たせば持ち越して使える。ただし、飛行・騎乗など、現在の身体・装備・移動形態そのものを必要とする兵種特性や能力は、その条件を満たす場合だけ使用可能とする。

### 1.2 基本ステータス：8種

| ステータス | 主な役割 | 主な依存元 |
| --- | --- | --- |
| HP | 生命力・耐久 | 個人成長＋兵種成長 |
| 攻撃 | 物理攻撃力 | 個人成長＋兵種成長 |
| 防御 | 物理防御力 | 個人成長＋兵種成長 |
| 魔攻 | 魔法攻撃力 | 個人成長＋兵種成長 |
| 魔防 | 魔法防御力 | 個人成長＋兵種成長 |
| 技 | 攻撃精度・技巧・必殺 | 個人成長＋兵種成長 |
| 速さ | 追撃・回避 | 個人成長＋兵種成長 |
| 魅力 | 連携・支援・特殊効果・必殺回避 | 個人成長＋兵種成長 |

「個人成長＋兵種成長」は主な依存元を示す整理であり、成長率の具体値や、成長処理・合成方法まで確定したことを意味しない。

兵種による成長は一時的な現在値補正だけを意味せず、その兵種を経験した期間の成長を通じて本人の因果ステ形成へ影響する。**具体的な成長率の合成方法・職歴の反映方法は未決**であり、確定仕様として扱わない。

### 1.3 派生ステータス：5種

| ステータス | 主な役割 | 主な依存元 |
| --- | --- | --- |
| 命中 | 攻撃が当たる確率 | 技＋武器＋戦技＋補正 |
| 回避 | 攻撃を避ける能力 | 速さ＋装備＋補正 |
| 必殺 | クリティカル発生率 | 技＋武器＋戦技＋スキル |
| 必殺回避 | 敵の必殺を防ぐ | 魅力＋補正 |
| 移動 | 1行動で移動できるマス数 | 兵種＋特殊効果 |

ここでの「＋」は依存元の列挙。すべてを単純加算する計算式を確定したものではない。命中は技、回避は速さ、必殺回避は魅力を主な参照先とするが、最終的な確率や数値の算出方法は未決。

## 2. 有力な方針：幸運を戦闘基本ステから外す

現時点では、**幸運を9番目の基本戦闘ステータスとして追加しない方針**。現在の8種構成に幸運は含めない。ただし、将来にわたる全面的な廃止を決めたわけではない。

- 管理項目を増やさないという設計思想に合う。
- TRPGでのアルシェの幸運90%などを、SRPGの戦闘補正にそのまま用いると、過大な効果になりかねない。
- 必殺回避は幸運ではなく、魅力＋補正に役割を持たせる。

幸運を固定値として残す案や、イベント・因果スキルなどに使う案は、現時点では採用決定ではない。必要になった場合に改めて検討する。

## 3. 仮案：計算式のたたき台

**以下は会話で例示された仮案であり、採用済みの式ではない。** バランス検証前の検討材料として記録する。

| 計算対象 | 仮の式 |
| --- | --- |
| 命中基礎 | 技 × 2 |
| 回避基礎 | 速さ × 2 |
| 必殺基礎 | 技 ÷ 2 |
| 必殺回避 | 魅力 ÷ 2 |

技を命中・必殺、速さを回避、魅力を必殺回避につなぐ関係を示したもの。命中基礎・回避基礎・必殺基礎は、最終的な戦闘確率そのものではない。武器・戦技・装備・スキル等の寄与や、相手側の値との計算は、この式だけでは定義されていない。

魅力の係数を控えめにする方向は「神ステ」化を避ける意図に沿うが、**係数を1/2にすること自体は未確定**。

## 4. 未決事項：今後決めること

以下は、本書の元となる合意範囲では確定していない。記載がない部分を、既存FE作品やTRPGのルールで自動補完しないこと。

| 項目 | 未決の内容 |
| --- | --- |
| 成長・数値規模 | 初期値、成長率、上限、個人成長と兵種成長の具体的な処理 |
| 命中・回避 | 最終命中率の算出方法、係数、各補正の扱い |
| 必殺・必殺回避 | 最終必殺率の算出方法、係数、補正、必殺時の効果・倍率 |
| 端数・上下限 | 除算の丸め方、確率の上下限、補正の適用順序 |
| 追撃 | 速さを参照する具体的な条件・閾値 |
| 魅力の各用途 | 連携・支援・特殊効果への具体的な寄与と、必殺回避とのバランス |
| 移動 | 兵種ごとの値、特殊効果の内容と重複時の扱い |
| 幸運の残し方 | 戦闘基本ステ以外で扱うかどうか、扱う場合の用途・数値体系 |
| その他の戦闘計算 | 攻撃・防御・魔攻・魔防からダメージを求める具体式 |

未決事項の一覧は、これらの機能や数値ルールの採用を新たに決めるものではない。現時点で埋まっていない仕様を示している。

## 5. 将来参照するAI・制作者への読み方

- **現在の基本ステは8種。** HP・攻撃・防御・魔攻・魔防・技・速さ・魅力。現時点では、FEらしさだけを理由に幸運などの基本ステを追加しない。幸運を将来別用途で扱う可能性まで禁止したものではない。
- **役割の合意と、式の合意を区別する。** 技→命中・必殺、速さ→追撃・回避、魅力→必殺回避という役割は記録済み。具体的な係数・計算式は未確定。
- **有力な方針を、永久の禁止に読み替えない。** 幸運は現在の戦闘基本ステから外す方針であり、イベント等での利用まで否定したものではない。
- **仮案を実装仕様へ昇格させない。** 第3節の式を使う場合は「検証用の仮置き」と明示し、確定した式として説明しない。
- **新提案は新提案として分ける。** 未決部分の案を出すときは、既存の合意に混ぜない。変更を合意したら、変更点だけでなく理由もこの記録に残す。
