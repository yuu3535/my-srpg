# SRPGステータス換算と成長　採用プランまとめ

作成日: 2026-09-24　／　基準: `採用版md/SRPG_CHARACTER_STAT_GROWTH_STANDARD.md` v1.4、`採用版md/GENERIC_CLASS_GROWTH_RATES.md` v1.1

この資料は、TRPGのキャラクターをSRPGへ登場させるときの「能力値の置き換え方」と「成長の計算方法」を、原作者向けにまとめたものです。正式な内容は採用版mdが正本で、この資料はその読みやすい要約です。ゲームコードにはまだ反映していません。

| 表記 | 意味 |
| --- | --- |
| **採用** | 原作者が承認した、今後の設計・実装の基準 |
| **採用値・調整可能** | 基準として使うが、戦闘テストで数値だけ調整できる |
| **未決** | 実装前に別途決める |
| **試験用・未採用** | 試験ブランチで試すための仮定。採用版には入っていない（付録A） |

## 1. 全体の考え方

### 1.1 置き換えの流れ

```text
TRPGシート（Lv1時点の値）
   ↓ 最初に1回だけ換算
因果Lv1の基礎ステータス          ← SRPGでのスタート地点
   ↓ 因果Lvが上がるたびに成長判定（個人成長率＋兵種補正＋幸運・勇気補正）
本人の現在ステータス              ← セーブする値。転職しても失わない
   ↓ 現在の兵種・装備・スキル・一時効果を足す
戦闘時のステータス
   ↓ 共通の戦闘計算
命中・回避・必殺・ダメージ
```

### 1.2 大事な原則

- **換算に使うのはTRPGのLv1時点の値だけ。** シートの `26(16+3.3.2.2)` なら、カッコ内の最初の数（16）を使う。
- **TRPGでのレベルアップ分（+3.3.2.2の部分）はSRPGへ持ち込まない。** SRPGの成長は、SRPGの成長率で改めて行う。
- **TRPGのレベルはSRPGのレベルに変換しない。** TRPG Lv5 = 因果Lv5 ではない。
- TRPGのレベルは、SRPGでの**初期兵種**と**加入時の因果Lv**を決めるときの参考にする。
- 経験豊富なキャラの強さは、加入時の因果Lvを高くすることで表す。
- TRPGシートから持ち込むのは、**Lv1の値**と、**能力上限**（`/94` のような右側の数）の2つ。
- TRPG技能は、SRPGで育つ値にはしない。初期能力・適性・習得済み能力を決める資料として使う。

## 2. レベルの役割

| レベル | 役割 | 扱い |
| --- | --- | --- |
| TRPG資料Lv | 原資料がどの時点の人物かを示す | 出典情報。初期兵種・加入時因果Lvの参考 |
| 因果Lv | キャラクター本人の成長 | 基本8ステの成長、因果スキル・因果戦技の習得 |
| 兵種Lv | 兵種への習熟 | 兵種スキル・兵種戦技・マスタースキルの習得。能力値は上げない |

**因果Lvの上限（採用）**

- 因果Lvに上限は設けない。成長の打ち止めは、キャラクター別の能力上限だけで表す。
- 本編のラスボス戦に挑むレベル帯は、因果Lv40〜50程度を想定する。
- 本編中は能力上限に届かない。上限は、経験値を稼ぎ続けたい人向けのやりこみの到達点。

## 3. 基本8ステータス

| ステータス | 主な役割 |
| --- | --- |
| HP | 最大HP、生命力 |
| 力 | 物理攻撃の基礎 |
| 防御 | 物理ダメージへの耐久 |
| 魔攻 | 魔法攻撃・魔法効果の基礎 |
| 魔防 | 魔法ダメージへの耐久 |
| 技 | 命中、必殺、技巧系効果の基礎 |
| 速さ | 追撃、回避の基礎 |
| 魅力 | APPが根拠の存在感。必殺回避・支援などの候補 |

基本8ステータスに含めない値:

| 項目 | 扱い |
| --- | --- |
| 勇気 | 独立した値。反撃などの戦闘資源。最大勇気は成長率補正にも使う（6.3） |
| 幸運 | 独立した値。成長率補正に使う（6.3）。戦闘での用途は未決 |
| MP | 戦闘資源。魔法システム確定後に尺度を決める |
| SIZ | 換算と、回避の体格補正にだけ使う。速さからは引かない |

## 4. TRPG → 因果Lv1 の換算式

| SRPG | 換算式 | 考え方 | 状態 |
| --- | --- | --- | --- |
| HP | 案① TRPG HP × 2 ／ 案② TRPG HP × 1 | 2案を検討中（4.2） | 検討中 |
| 力 | STR | 物理的な力と直接対応 | 採用 |
| 防御 | floor((STR + SIZ) / 2) | 腕力と体格による頑丈さ | 採用値・調整可能 |
| 魔攻 | POW | 魔法の出力と直接対応 | 採用 |
| 魔防 | floor((POW + CON) / 2) | 魔力と生命力による抵抗 | 採用値・調整可能 |
| 技 | floor(DEX / 2) | 精密さを残しつつ、命中を支配しすぎないよう圧縮 | 採用値・調整可能 |
| 速さ | DEXを目安に人物ごとに決める | 目安式: floor(DEX / 4) + TRPG回避技能値 | 採用（個別決定） |
| 魅力 | APP | 見た目・存在感と直接対応 | 採用 |

**速さについて**

- DEXだけで決めない。DEXは反応・精密さの資料で、TRPGの回避技能を「実際に身のこなしを鍛えていたか」の証拠として加える。
- 目安式どおりにならない人物は、個別に調整して根拠を残す。例: アルバスは目安式だと6だが、「極端な鈍重にはしない」ため9。
- SIZは速さに入れない。大柄・小柄の影響は、回避を計算するときの体格補正だけで扱う。

### 4.2 HPの換算（検討中・2案）

HPの換算は2案を検討中。試験ブランチで実際に遊び、武器威力・ダメージ式と合わせて決める。この資料の表は、比較の基準として案①で表示する。

| 案 | 因果Lv1のHP | HP上限 | 特徴 |
| --- | --- | --- | --- |
| 案① | TRPG HP × 2 | 8章の式（× 2）のまま | 従来の比較基準。Lv1から余裕があり、1発で倒れにくい |
| 案② | TRPG HP × 1 | 8章の式（× 2）のまま据え置く | 成長の実感が強い（アルシェはLv50でLv1の約3.8倍） |

- 案①の経緯: TRPG Lv5の完成済みステータスで試算した際、HP×2にすると通常攻撃一発でほぼ即死する状況を減らせた。
- 案②の経緯: 基準をTRPG Lv1に変えた後、Lv1から20以上のHPは高すぎるのでは、と原作者が指摘した。
- 成長は+1ずつの加算なので、どちらでもLv50でHPが膨れ上がることはない。両案の差は最初の差（12〜18）がそのまま残るだけ。
- 案②でHP上限まで×1にする形は採らない。アルバスがLv51で上限（52）に達し、「上限はやりこみの到達点」とずれるため。

## 6. 成長の計算

### 6.1 実効成長率

因果Lvが1上がるたびに、基本8ステータスそれぞれについて次の確率で+1する。

```text
実効成長率 = 個人成長率 + 現在兵種の兵種成長率補正 + 幸運・勇気補正
幸運・勇気補正 = floor((幸運 + 最大勇気) / 40)%
```

- どの補正も倍率ではなく、%をそのまま足す（例: 75% + 10% + 3% = 88%）。
- 兵種補正や幸運・勇気補正で伸びた分も本人の成長として残り、転職しても失わない。
- 能力上限に届いた能力は、それ以上伸びない。
- 確率成長・固定成長・下振れ救済付き成長のどれにするかは未決。この資料の期待値は「成長率どおりに伸びた場合の平均」。

## 8. 能力上限

TRPGシートの `現在値/上限値` の上限値を、本人の潜在能力の上限として使う。初期値を作る換算式と、上限の対応は別に扱う。

| SRPG | 上限の参照元 |
| --- | --- |
| HP | ceil((CON上限 + SIZ) / 2) × 2 |
| 力 | STR上限 |
| 防御 | CON上限 |
| 魔攻 | POW上限 |
| 魔防 | EDU上限 |
| 技 | INT上限 |
| 速さ | DEX上限 |
| 魅力 | INT上限 + 現在のAPP |

| キャラクター | HP | 力 | 防御 | 魔攻 | 魔防 | 技 | 速さ | 魅力 | 全上限到達の目安 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 幼アルシェ | 122 | 90 | 108 | 104 | 106 | 87 | 71 | 102 | Lv170前後 |
| リングホルム | 104 | 94 | 94 | 110 | 106 | 96 | 91 | 112 | Lv170前後 |
| アルバス | 104 | 80 | 89 | 110 | 108 | 98 | 108 | 115 | Lv172前後 |

- 上限は、因果Lvで得た本人の能力にだけかかる。兵種・装備・スキル・一時効果による戦闘中の上乗せは、上限を超えてよい。
- 速さの上限はアルバスが最も高い。やりこみ帯（アルシェ超えはLv108前後、リングホルム超えはLv143前後）で、本編と速さの順位が逆転する。許容するかは未決。

## 9. まだ決めていないこと

- やりこみ帯での速さの逆転を許容するか
- 本編後の経験値曲線

## 付録A　試験ブランチ用の前提（未採用）

採用版を実際のゲームで試すための仮定。採用版mdには入っていない。試験ブランチで遊んで確かめてから、採否を決める。

| 項目 | 仮定 | 補足 |
| --- | --- | --- |
| HP | 案②（TRPG HP×1、上限は据え置き）で試す | 4.2の2案のうち、試験ブランチでは案②を試す |
| 武器威力 | 低3 ／ 中6 ／ 高10 | |
| ダメージ式 | 下の式 | Codex案の「互角時6」を武器威力に置き換えたもの |

```text
物理ダメージ = max(1, round(武器威力 + (力 − 防御) ÷ 2 + 補正))
魔法ダメージ = max(1, round(武器威力 + (魔攻 − 魔防) ÷ 2 + 補正))
```

- 攻撃値と守備値の差の半分が、武器威力に上乗せ（または差し引き）される。互角なら武器威力そのもののダメージ。
- 単純な引き算と違い、能力差が極端でもダメージが0に潰れにくい。最低でも1は入る。

**例: 同じ因果Lv40同士、中威力6（HP×1）**

| 攻撃 → 防御（防御側HP） | 物理（力 vs 防御 → ダメージ） | 魔法（魔攻 vs 魔防 → ダメージ） |
| --- | --- | --- |
