# 自作SRPG ゲームシステム方針

壁打ちの引き継ぎ・読み返し用 / 2026-09-21

> 本書は仕様確定書ではなく、会話時点の設計整理。ゲームのコードを変更する指示ではない。今後も、ユーザーが明示的に「実装して」と指示するまでは、調査とゲームデザインの検討だけを行う。

## 1. 現時点の要点

目指すのは「選択肢は多いが、管理項目は少ない」SRPG。TRPGの人物像を守りながら、戦闘の判断、レベルアップのピン、兵種経験によるビルドを楽しめる作品にする。

### 方針の読み方

- **明示された方針**：ユーザーが希望・採用方向を明確に述べた内容。細部の数値まで確定したという意味ではない。
- **有力な仮案**：会話で検討を進めている候補。
- **未決**：選択肢や数値が残る内容。提案を合意済みとして扱わない。
- **現在実装**：読み取り調査で確認した既存処理。理想の設計とは区別する。

### 最新の重要な整理

| 項目 | 現在の理解 |
| --- | --- |
| 因果Lv | 本人の永久成長を管理するレベル。上限99程度。本編ではなく相当なやり込みで到達する |
| 兵種Lv | 兵種ごとに保持する熟練度。主にスキル・戦技・特性を習得する |
| 永久能力 | 基本的に因果Lv上昇時に成長判定。現在の兵種が成長率を少し補正する |
| 転職 | 本人の基礎能力を大幅に落とさない。初めての兵種はLv1、再就職では練度を保持 |
| 初期因果Lv | 完成済みキャラだから高くする必要はない。アルバスを因果Lv1・原作の完成能力から始める案も成立する |
| 初期能力とレベル | 因果Lv1は、必ずしも弱者を意味しない。ゲーム内の追加成長の出発点として扱える |
| 成長量 | 初期能力の上に、後々＋30程度が積み上がる案も許容。全能力一律＋30という決定ではない |
| 基本能力 | HP・攻撃・防御・魔攻・魔防・速さ・命中・魅力の8項目を軸に検討 |

### 直前の会話を踏まえた注意

以前は「完成済みのアルバスとリングホルムは高い因果Lvで加入する」案を中心に話していた。最新の会話では、**強い初期能力と低い初期因果Lvは両立できる**と整理し直した。3人の初期因果Lvそのものは、まだ確定していない。

会話中に提示した成長率や速さ・命中の数値は、比較用の仮案であり採用値ではない。次の壁打ちでは、古い仮表を確定仕様として使わず、人物像と成長回数から再検討する。

## 2. 作品全体で大事にする体験

### 戦闘と育成の楽しさ

- 誰を動かすか、どこへ行くか、誰を攻撃するか、どの武器・技を使うか、誰と連携するかを考えたい。
- レベルアップの成長率と、能力が上がる「ピン」を楽しみたい。
- 完成済みの強キャラも歓迎する。後半加入者に、使い物になるまでの育て直しを要求しない。
- キャラごとに本人らしい複数の育成ルートを持たせたい。全員が完全に何にでもなれる形は優先しない。
- 自分で強くしたキャラによる多少の強引な突破は許す。システムを理解すれば、さらに楽に戦えるようにする。

### 情報と管理

- 習得予定の魔法・技・兵種条件・転職後の能力変化を事前に見せる。
- 「知らなかったから損をした」より「情報を見たうえで選ぶ」ゲームにする。
- 敵攻撃範囲、ダメージ、命中率、必殺、追撃・攻撃回数などを予測で確認できるようにしたい。
- 数手の巻き戻しを希望。具体的な回数や乱数の扱いは未決。
- 戦闘外は編成・装備・スキル選択・クラス変更・育成配分を中心にしたい。

### 武器・魔法・技・切り札

| 分野 | 希望する方向 |
| --- | --- |
| 武器 | 通常武器の耐久なしを有力候補とする。威力・命中・重量・射程・押し出しなど、その場で分かる違いで使い分けたい |
| 魔法 | 習得先を公開し、自分で選べるツリーや配分を検討。適性差はあってよい |
| 戦技 | 自分で選ぶアクティブ技を少数に整理。大量の技を毎回管理する形は避ける |
| 消費資源 | キャンペーンを通した温存より、マップ内での使いどころを考える回数制などを好む |
| 覚醒・奥義 | 数ターンだけ強化される固有の切り札を検討。再使用のために特定マスへ行く方式は望まない |

### マップと避けたいもの

正面突破・迂回・飛行・魔法・エース・陣形崩しなど、複数の攻略を許す。ギミックは使えば有利な選択肢にし、必須の正解ボタンにはしない。

地形による大幅な移動阻害、毎マップの厳しい時間制限、固定手順を当てるパズル化は避けたい。防衛・脱出・到達そのものは使用可能。

毎章の散策・食事・施設巡回・素材集め・資格試験・多数の技能経験値・大量SPの継承は基本的に増やさない。全員が騎士団を装備する計略システムも不要。範囲効果は個人の技として採用できる。

障壁を割り、複数のHPゲージを削る魔獣型ボスは通常戦で使いたくない。特別なイベントや最終戦のみ候補にできる。

## 3. 因果Lvと兵種Lvの分担

### 明示された成長の構造

- 因果Lv上昇時に、本人の永久ステータスの成長判定を行う。
- 個人成長率に現在の兵種による小さな補正を加える方向。特定職で育てなければ不利になるほど大きくしない。
- 兵種Lvは兵種ごとに記録する。未経験ならLv1、以前の職へ戻れば育てた練度を再利用する。
- 兵種Lvの中心的な報酬はスキル・戦技・特性。兵種Lvが上がるたび、別枠で永久ステータスを何度も増やす方式ではない。
- 他職で習得したスキルを持ち越し、ビルドへ利用する楽しさは残す。
- 中核スキルと持ち越しスキルの区分、装備枠数、兵種の総数は未決。

### 通常の能力と育成成果

**戦闘で使う能力＝本人の初期能力＋因果Lvで得た永久成長＋現在の兵種・装備などの補正**

例として、アルバスの魔攻が「初期36＋永久成長24＋現在の兵種補正6＝66」となる構成は可能。これは説明用であり、成長率・兵種補正の採用数値ではない。

転職で変わるのは主に現在の兵種補正。すでに得た永久成長まで失わない。兵種補正を一度受けるたび永久に加算する方式は、まだ採用していない。

### 因果Lvの終点と本編の目安

上限99は極限まで育てた到達点。到達後は本人の永久ステータスがそれ以上成長しない。全能力を同じ高さまで伸ばしたり、必ず全項目を上限へ到達させたりする必要はない。

本編終盤は、主要な初期加入者が因果Lv40～50台程度という仮の目安。章数や成長回数は未定。Lv20・30・40・50で能力推移を比較したい。

「全兵種を何周も育てるほど遊び込んでLv99」という話は、やり込み量のイメージ。兵種Lvの周回・リセット機能を決めたわけではない。

### 経験値の獲得

| 経験値 | 想定する獲得機会 |
| --- | --- |
| 因果経験値 | 章クリア、大きな戦果、敵撃破、有効な回復・救援、支援関係の進展など、本人に意味のある成果 |
| 兵種経験値 | 命中した攻撃、回復、護衛など、その職業としての行動。倒し切れなくても蓄積できる |

TRPGでは次Lvまで100経験値、実獲得量は「配布経験値÷現在Lv」。この原作ルールは把握済みだが、SRPGで因果・兵種経験値のどちらへどう採用するかは未決。

以前の「高因果Lvほど技能や戦技を習得しやすい」案も残るが、具体式や採用範囲は未決。

## 4. ステータス・成長率の設計候補

### 8項目を軸に検討する

| 項目 | 主な担当・検討内容 |
| --- | --- |
| HP | 耐久力 |
| 攻撃 | 物理攻撃の威力 |
| 防御 | 物理ダメージの軽減 |
| 魔攻 | 攻撃魔法の威力。回復への寄与は別途整理 |
| 魔防 | 魔法ダメージの軽減 |
| 速さ | 主に回避と通常追撃。命中・必殺まで集中させない |
| 命中 | 攻撃の精度。最終命中率と区別して表示する必要がある |
| 魅力 | 意味のある用途を持たせる。魅力だけのピンも嬉しいというユーザーの意向 |

回避・必殺率などは、基本能力・武器・技能・相手から算出する派生値として検討。最終命中率は相手や装備によるため、キャラ本人の固定数値とは区別する。

速さ差による通常追撃を採用したい。双剣は基本2ヒット、追撃時に最大4ヒットでもよい。一撃の威力・重量などで調整し、攻撃回数を予測へ明示する。追撃の必要差、命中・必殺の判定単位、他効果との重複は未決。

### 魅力と幸運

幸運は、低い人物を極端に不安定にしない。被必殺や状態異常耐性への小さな補助程度を想定。固定値か成長対象か、尺度と式は未決。

魅力の候補用途は、被必殺耐性、支援値の上がりやすさ、デュアルサポートの効果、防陣の維持力など。ユーザーはサポート発生への関与も再び候補に挙げているが、確率制を採用したわけではない。連携の根幹を完全な運任せにしたくないという方針も残る。

魅力に全部を担当させず、主な用途を絞る。魅力で支援が進み、支援で因果経験値も得る場合は、戦闘と育成の両面で強くなりすぎないか検討する。

### TRPGからの翻訳

初期値、現在値、成長履歴、技能の熟練、原作者の人物像を合わせてSRPG能力へ表現する。STRをそのまま攻撃へ、DEXをそのまま速さへ移すと、人物像を取りこぼす可能性がある。

特技は技術の熟練度。初期能力・習得済みの技・兵種適性・成長率補正のどこへ反映するか検討中。現在の熟練を全部「将来の伸びやすさ」へ移すと、完成済みキャラの強さが失われるので注意する。

### まだ決まっていない数値

3人のSRPG初期能力、加入因果Lv、個人成長率、兵種成長補正、能力上限、命中・回避・必殺の式は未確定。会話で示した各種パーセントや速さ・命中表は比較用であり採用済みではない。

原作メモの「/80」「/110」は成長率ではない。異常な存在へ変異した際の器の限界だった値で、今後は潜在傾向や、やり込みの最大能力キャップの参考にする。変異システムの実装要求ではない。

### 役割についてのユーザーのイメージ

- **アルシェ**：未熟な成長型主人公。最初はコツコツ育てる。
- **リングホルム**：バランスの取れたアタッカー。回避と命中が高く安定し、戦闘面では苦手が少ない。幸運は低め。

アルバスは中盤以降のプレイアブル加入を検討中。二人の強者を全能力が低い新人へ戻さず、本人の強さの上に追加育成を積む。

### 専用兵種

本人らしい専用兵種へ、それまでの因果成長と兵種育成の成果を反映したい。因果Lvや複数兵種の経験を解禁条件にする案があるが、具体的な条件は未決。「因果Lv30」は過去の例であり確定値ではない。

専用兵種を能力倍率で強めるか、得意な能力・技を同時に運用できるようにするかは未決。通常兵種でも本人の強さを保つ。

### ルート別のボス

アルバスとリングホルムは、ルートによってどちらかがラスボス枠、または両方がボス枠になる。終盤で戦う際は専用兵種で登場させたい。

味方版とボス版で人物を象徴する戦い方を共有し、数値や装備技は分けて調整する案が出ている。ボス構成を固定にするか、プレイヤーの育成履歴を反映するかは未決。

「敵になると知っているから育てない方が得」という事前知識の損得を生まないことが検討点。専用兵種があることは、HP多段階・障壁の採用を意味しない。

## 7. デュアル・ブレイクと検討上の注意

### 有力な仮案

敵味方が共通ルールで連携し、武器相性によるブレイクで陣形に隙を作る方向に興味がある。デュアルを常時組むことが最適解にならないようにしたい。

後衛露出は、別マスへの強制分離より、**同じマスにいるまま護衛が崩れ、後衛も直接攻撃できる**案を優先して検討。ユーザーは軽くて分かりやすい方を望む。

攻陣を別マスの隣接援護、防陣を同マスのペアにする案は提案段階。援護回数、ペアの行動数、合流・解除コスト、ブレイクの反撃停止と持続時間は未決。

### 魅力と防陣の候補

- 高魅力で通常の防陣効果が強くなる。
- ブレイク後も後衛への被害を一部抑える。
- 連携耐久を持たせ、崩れるまでの回数を可視化する。
- 確率で崩壊を防ぐ方式も比較対象にはなるが、確定的な計画との相性に注意する。

いずれも未採用。ゲージ・追加状態・抽選を増やしすぎず、ブレイクする意味を保つ。

### 成長と戦闘の抜け道として確認したいこと

| 検討点 | 注意する理由・候補対策 |
| --- | --- |
| 因果Lvアップ直前だけ転職 | 成長補正目当ての着替え作業になる。出撃時兵種を参照する案は提案段階 |
| 特定兵種の成長補正 | 職歴による差が大きいと事前の最適育成が有利になる。補正は小さくする方向 |
| 万能な持ち越しスキル | 再移動・再行動などを誰でも無条件に持てると必修職が生まれやすい |
| 安全な反復稼ぎ | 攻撃・回復・補助の無限反復が最善にならないよう、有効な成果を評価する |
| 新兵種Lv1の経験値優遇 | 本人の因果Lvまで低く扱う抜け道にしない |
| 二回攻撃＋追撃 | 各ヒットで援護・固定加算・覚醒獲得まで重なると強すぎる可能性 |
| 魅力と支援経験値 | 支援・因果経験値・連携性能を全部強化すると最重要能力になり得る |
| 重量と体格 | 大柄なアルバスが重量を無視し、高速砲台になるなら人物像との整合を確認 |

これらの対策は未確定。やり込みそのものは禁止したくない。自由な育成を残し、面倒な反復や事前知識が最適になる部分を見極める。

## 8. 現在実装との境界・次の壁打ち

### 現在実装として確認したこと
