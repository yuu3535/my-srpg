## このフォルダへまだ入れないもの

- 命中・回避・必殺の式
- 反撃、追撃、Dualを含む一交戦の処理順と数値
- 加入時因果Lv
- 因果兵種・専用兵種の成長率
- 能力成長を確率式、固定式、下振れ救済式のどれにするか
- 実装前の比較メモや旧案

未決事項を含む資料は、採用が明示されるまで既存の検討資料側に残す。

## 運用規則

- 採用済みの方針を変更した場合は、該当資料の版番号と更新日を上げる。
- 過去案と競合する場合、このフォルダ内の新しい版を優先する。
- ゲームコードへ反映したかどうかを各資料に明記する。
- 採用版へ未決の数値を混ぜる場合は、必ず「未決」と表示する。
