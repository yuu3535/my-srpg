# スキル・戦技セット枠 採用ルール

版: v1.0

採用日: 2026-09-25

実装状況: ゲームコード未反映

## 1. この文書の範囲

本書は、習得済みの兵種スキル・因果スキル・戦技を、戦闘へ持ち込む際のセット枠を定める。

個々のスキル効果、戦技コスト、倍率の重複、個人スキルの内容は別途決定する。

## 2. 採用するセット枠

| 区分 | 枠数 | 用途 |
| --- | ---: | --- |
| 通常兵種スキル枠 | 4 | 兵種Lvで習得し、転職後も持ち越せるパッシブスキル |
| 兵種固有枠 | 1 | 現在兵種に属するマスタースキルまたは専用兵種のLv50固有スキル |
| 因果スキル枠 | 3 | 因果Lvで習得するパッシブスキル |
| 戦技枠 | 4 | 兵種戦技と因果戦技の共通セット枠 |
| 個人スキル枠 | 未決 | 因果Lv・兵種Lvに関係なく本人が持つ能力。内容と枠は後で決める |

兵種スキルは、通常4枠と兵種固有1枠を合わせて、画面上では最大5枠相当とする。

## 3. 通常兵種スキル

- 兵種Lvの途中で習得する通常兵種スキルは、一度習得すれば転職後も失わない。
- 習得済みの通常兵種スキルは、現在兵種にかかわらず通常兵種スキル4枠へセットできる。
- 同一スキルを複数の兵種や習得経路から得ても、所持数は1つとして扱い、重複セット・重複発動はできない。

## 4. マスタースキルと兵種固有枠

マスタースキルは、対応する兵種Lvを最大まで育てたときに習得する、兵種限定の能力とする。

- マスタースキルの習得記録は転職後も残る。
- マスタースキルは、対応する兵種が現在兵種である間だけ兵種固有枠へセットできる。
- 別の兵種へ転職すると、対応しなくなったマスタースキルは兵種固有枠から外れ、発動しない。
- 再び対応兵種へ戻れば、再習得せずにセットできる。
- マスタースキルは通常兵種スキル4枠へ移すことはできない。

マスタースキルにはパッシブだけでなく、「突撃」「ブレス」のような戦技も存在する。そのため、5枠目はパッシブ専用の「スキル枠」ではなく、現在兵種限定の「兵種固有枠」とする。

- パッシブ型マスター能力は、セット中に常時・条件発動する。
- 戦技型マスター能力は、セット中に戦闘コマンドから使用できる。
- 戦技型マスター能力も兵種固有枠を使用し、通常の戦技4枠は消費しない。

## 5. 専用兵種と因果Lv50スキル

次のプレイアブル4人は専用兵種を持つ予定であり、因果Lv50で習得する最終スキルを、その専用兵種の兵種固有枠へセットする。

| キャラクター | 因果Lv50スキル |
| --- | --- |
| アルシェ | 奈落の王 |
| リングホルム | 勇者の器 |
| アルバス | 破滅の王 |
| カリマ | 神炎の器 |

`神炎の器` は、旧案の名称 `蒼炎の器` を改称したものである。

- 因果Lv50へ到達することで、対応する最終スキルを習得する。
- 対応する専用兵種が現在兵種である間だけ、兵種固有枠へセットして使用できる。
- 別兵種へ転職すると兵種固有枠から外れ、通常の因果スキル3枠へ移して使用することもできない。
- 専用兵種へ戻れば、再び兵種固有枠へセットできる。
- 専用兵種では、このLv50スキルを兵種固有枠の最終能力として扱い、別のマスタースキルを同時に置かない。

専用兵種Lvも最大であることを追加条件にするかは未決とする。

## 6. サタンの扱い

サタンはプレイアブル用のセット枠で調整する対象ではなく、2形態を持つ真ラスボスとして扱う。

- `悪意の邪蛇` は、サタンの対応形態に設定するボス専用能力の候補とする。
- サタンの形態別能力は、プレイヤー用の通常兵種スキル4枠・因果スキル3枠・戦技4枠へ制限しない。
- 命中、必殺、ダメージ、状態異常などの基礎戦闘ルールは、原則として敵味方共通とする。

## 7. 同名・別表示名の扱い

- 同じ名前かつ同じ効果の能力は、習得者や習得経路が異なっても共通能力として扱う。
- 同一能力を兵種と因果の両方から習得しても、二重セット・重複発動はできない。
- 表示名だけが異なる同一能力は、内部では同じ能力として扱える。
- 飛行上級の `殺戮` と `疾駆` は、キャラクター・兵種によって表示名が異なる同一スキルとする。
- 同じ名前で効果が異なる現行案・旧案は、正式データ化するときに効果を統一するか、旧仕様であることを明記する。

## 8. 現時点の集計

汎用兵種表には47件の習得枠がある。`殺戮／疾駆` を同一能力とし、重複する `技+10` を統合すると、兵種能力は46種類となる。

今回提示された因果Lv表では、個人スキルを除き、サタンを含む11人に合計104件の因果能力習得がある。重複を除くと、因果スキル41種類、因果戦技24種類の合計65種類である。Lv50専用スキルを兵種固有枠へ移す最終分類は、因果Lv表を正式文書化する際に反映する。

## 9. 未決事項

- 個人スキルの効果、枠数、自動装備の扱い
- `応援`、`戦闘指揮`など、行動を選択して使う能力をスキルと戦技のどちらへ分類するか
- 専用兵種のLv50スキルに、専用兵種Lv最大も要求するか
- 兵種ごとに以前のセット内容を記憶し、再転職時に復元するか
- スキル・戦技の倍率重複ルール
- 物理戦技の武器耐久・使用回数と、魔法戦技のMP消費
- 状態異常、割合ダメージ、射程の共通ルール
