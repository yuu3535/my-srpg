### 状態の読み方

`SRPG_CHARACTER_STAT_GROWTH_STANDARD.md` と同じ。

- **採用**: 今後の設計と実装の基準にする。
- **採用値・調整可能**: 基準として使うが、戦闘テストで数値だけを調整できる。
- **未決**: 実装前に別途決める。

## 1. どちらの戦闘の側で作るか（採用）

- 今後の武器・敵・戦闘は、すべて**採用版の側**で作る。基本8ステータス・因果Lv（`SRPG_CHARACTER_STAT_GROWTH_STANDARD.md`）と、本書のダメージ式を使う。コードでは `trialStatSystem.js` の形と、そこから値を書き出す Unity版。
- ブラウザ版の古い戦闘（戦闘ルールv2。`battle_tutorial`・`battle_ch1`。TRPGの原値・武器威力は一律3）は、採用版の側へ移すまで触らない。古い戦闘のための新しい数値は作らない。

## 2. ダメージ式（採用値・調整可能）

```text
物理ダメージ = max(1, round(武器威力 + (力 − 防御) / 2 + 行動・スキル補正))
魔法ダメージ = max(1, round(武器威力 + (魔攻 − 魔防) / 2 + 行動・スキル補正))
```

- 魔法の「武器威力」は、使う魔核（魔法の武器）・魔法の威力。
- 補正の置き場所: **能力そのものを変える補正は括弧の中**（能力値に足してから差をとる）、**最終の威力を増やす補正は括弧の外**（Codex 回答 2026-09-24、`docs/30-planning/SYNC_AGENDA.md`）。
- 確かめたこと（2026-09-24、HP 案②・中威力6）: 因果Lv1 の総当たりで1発撃破が0組、得意な物理攻撃は因果Lv1〜40を通じて2〜5発。経緯は `docs/90-worklogs/WORK_MEMO_2026-09-24.md` §11〜12。
- コード: `trialStatSystem.js` の `trialDamage`・`trialPhysicalDamage`（名前は「試験」のまま）。

## 3. 武器威力の尺度（採用値・調整可能）

| 区分 | 武器威力 |
| --- | ---: |
| 低 | 3 |
| 中（標準） | 6 |
| 高 | 10 |

- 個々の武器は、この尺度を基準に決める（例: 標準の剣・標準の魔核は6）。尺度の間の値（4・8など）を使うかは、武器の一覧を作るときに決める。
- コード: `TRIAL_WEAPON_POWER`（`{ low: 3, mid: 6, high: 10 }`）。

## 4. 武器種（採用）

**剣・槍・斧・弓・魔核・杖** の6種類。

| 武器種 | いま決まっていること |
| --- | --- |
| 剣 | 試験の剣（仮の剣・アルバスの剣・黒陽の双剣）は威力6・射程1 |
| 槍 | — |
| 斧 | — |
| 弓 | — |
| 魔核 | **本人が生まれつき持つ、魔法を扱うための体の器官**（生体パーツ）。本人の素の魔法の素養。耐久なし・壊れない（§4.1） |
| 杖 | **魔法武器**（試験の魔導書の代わり）。武器の恩恵で命中・威力を補正する。耐久あり（§4.1） |

### 4.1 魔核と魔法武器（採用・数値は未決。原作者 2026-10-01）

この世界の魔法は書物ではなく、みんなが生まれつき持っているもの。魔法を扱う手段は2つある。

| | 魔核 | 魔法武器（杖など） |
| --- | --- | --- |
| 何か | 本人が生まれつき持つ、魔法を扱うための体の器官（生体パーツ） | 魔法を扱うための武器 |
| 表すもの | 本人の素の魔法の素養 | 武器の恩恵（命中・威力の補正） |
| 耐久 | **なし。壊れない**（本人が倒れる・MPが尽きる以外に使えなくなることはない） | **あり**。種類ごとに耐久・付いた戦技のコスト・火力の補正が違う |
| 補正 | 一族・本人の得意な魔法に補正が付いてよい（例: 黒の一族のリングホルムは炎が得意なので、炎の命中に補正） | 武器ごとに命中・威力の補正 |
| 持ち方 | 初期装備として魔核を持つユニットがいてよい。杖などの魔法武器に、付属の魔核が付いている物もあってよい | 装備する |

- **壊れる危険（魔法武器だけ）**: 素の魔法の素養が高すぎるキャラ（アルバスなど）が、魔法武器の耐久を超える威力の魔法を撃つと、武器が壊れるおそれがある。素の魔法火力が高いキャラに、代償のない魔法武器を持たせて手が付けられなくなるのを防ぐ。
- そのため、強い術者は魔法武器より**素の状態（魔核）で魔法を使う方が、かえってよい**場面がある。魔法武器は、素養の低いキャラが命中・威力を補うための物、という役割になる。
- 兵種スキル・因果スキルの CSV にある「武器種『魔法』装備時」は、魔核・魔法武器（杖）のどちらで魔法を使っているときも含む、と読む（扱いを分けたくなったら直す）。
- 試験のコードの「火の魔核」「治癒の魔核」などは、旧・魔導書の名前だけを変えた物で、仕組みは「装備する魔法の道具」。この考え方に合わせるときは、魔核（本人の器官・壊れない）と魔法武器（杖・耐久あり）に分け直す。

未決（魔核・魔法武器）:

- 壊れる条件（例: 魔法の威力や「魔攻 + 武器威力」が武器の耐久の値を超えたら壊れる、使うたびに耐久が減る、など）。
- 魔核は人に渡せるか（体の器官なので渡せない、が自然）。魔法武器に付いた魔核は武器ごと渡せるか。
- 魔核と魔法武器を同時に使えるか（装備は1つか）。
- 魔核の補正の付け方（一族ごと・本人ごと）。

未決:

- 種類ごとの違い（威力・命中・必殺・射程・重さ・耐久・相性）。
- 射程（弓の最低射程・槍の射程2など）、耐久（物理戦技のコスト。最小版から、という Codex の推奨あり）。

## 5. 敵（モブ）の能力値の作り方（採用・数値は未決）

モブ（名のない一般兵）は、**兵種ごとの「型」**から計算して置く。

```text
型 = その兵種のモブの 因果Lv1基礎値（基本8ステータス）＋ 型の成長率
配置する因果Lv L での能力値（期待値）
   = 因果Lv1基礎値 + (L − 1) × 実効成長率
実効成長率 = 型の成長率 + 汎用兵種の兵種成長率補正（GENERIC_CLASS_GROWTH_RATES.md）
           + floor((幸運 + 最大勇気) / 40)%
```

- マップの難しさは、主に置く因果Lvで調える。隊長・将軍も同じ型で、因果Lvを上げて作る。
- 型の候補: SDの絵があるモブ（アルストロの槍兵・魔法兵・弓兵・将軍、オルクスの剣兵・弓兵・魔法兵・騎乗兵・将軍、貧しい町の人）。
- ネームドの敵（オルクス・アルストロの名のある人物・サタン）は、型ではなく `SRPG_CHARACTER_STAT_GROWTH_STANDARD.md` の本人の値を使う。

未決:

- 各型の因果Lv1基礎値・成長率・能力上限の数値。
- 期待値の端数の扱い（四捨五入か切り捨てか）。
- モブの兵種スキル・兵種戦技・持たせる武器。

## 6. 本書に入れていないもの（未決）

- 命中・回避・必殺の式（試験では `TRPG_TO_SRPG_STAT_CONVERSION.md` §7.2 の命中式を使っている）。
- 反撃・追撃・Dual を含む一交戦の処理順（試験では追撃に速さ差5）。
