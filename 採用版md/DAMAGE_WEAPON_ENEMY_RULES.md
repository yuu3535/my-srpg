## 1. どちらの戦闘の側で作るか（採用）

- 今後の武器・敵・戦闘は、すべて**採用版の側**で作る。基本8ステータス・因果Lv（`SRPG_CHARACTER_STAT_GROWTH_STANDARD.md`）と、本書のダメージ式を使う。コードでは `trialStatSystem.js` の形と、そこから値を書き出す Unity版。
- ブラウザ版の古い戦闘（戦闘ルールv2。`battle_tutorial`・`battle_ch1`。TRPGの原値・武器威力は一律3）は、採用版の側へ移すまで触らない。古い戦闘のための新しい数値は作らない。

## 2. ダメージ式（採用値・調整可能）

```text
物理ダメージ = max(1, round(武器威力 + (力 − 防御) / 2 + 行動・スキル補正))
魔法ダメージ = max(1, round(武器威力 + (魔攻 − 魔防) / 2 + 行動・スキル補正))
```

- 魔核だけで使う魔法には、装備品としての固定「武器威力」を足さない。本人の魔攻と相手の魔防、および**魔法・戦技固有の威力**で決める。
- **基本魔法の固有の威力は3**（採用値・調整可能。原作者 2026-10-02、案B）。魔法戦技は、それぞれ固有の威力を持つ（基本魔法より高くてよい）。
- 魔法武器を装備して使う場合だけ、その武器の威力を「武器威力」として、魔法の固有の威力に足す。

```text
魔法ダメージ = max(1, round(魔法の固有の威力 + 魔法武器の威力 + (魔攻 − 魔防) / 2 + 行動・スキル補正))
               魔核だけのときは 魔法武器の威力 = 0
```

- 手応え（因果Lv1のネームド10人の総当たり、命中なし）: 物理（標準の武器6）は倒すまで平均3.0回。魔核だけの基本魔法は7.1回、標準の魔法武器（6）を持つと2.3回。魔法はMP（と魔法武器の耐久）を払い、射程（基本1〜2）でも有利なので、払う代わりの強さとして釣り合いを見る。
- **強さの計算の決まり**: 魔法の射程（基本1〜2）は、物理（1）より反撃を受けにくい有利さとして、魔法・魔法武器の強さを決めるときに必ず入れて考える（原作者 2026-10-02）。
- 補正の置き場所: **能力そのものを変える補正は括弧の中**（能力値に足してから差をとる）、**最終の威力を増やす補正は括弧の外**（Codex 回答 2026-09-24、`docs/30-planning/SYNC_AGENDA.md`）。
- 確かめたこと（2026-09-24、HP 案②・中威力6）: 因果Lv1 の総当たりで1発撃破が0組、得意な物理攻撃は因果Lv1〜40を通じて2〜5発。経緯は `docs/90-worklogs/WORK_MEMO_2026-09-24.md` §11〜12。
- コード: `trialStatSystem.js` の `trialDamage`・`trialPhysicalDamage`（名前は「試験」のまま）。

## 3. 武器威力の尺度（採用値・調整可能）

| 区分 | 武器威力 |
| --- | ---: |
| 低 | 3 |
| 中（標準） | 6 |
| 高 | 10 |

- 個々の武器は、この尺度を基準に決める（例: 標準の剣・標準の魔法武器は6）。魔核そのものにはこの固定威力を持たせない。尺度の間の値（4・8など）を使うかは、武器の一覧を作るときに決める。
- コード: `TRIAL_WEAPON_POWER`（`{ low: 3, mid: 6, high: 10 }`）。

## 4. 武器種（採用）

**剣・槍・斧・弓・魔核・杖** の6種類。

| 武器種 | いま決まっていること |
| --- | --- |
| 剣 | 槍・斧との種類による基礎性能差や三すくみは設けない。個々の武器の品質・価格帯・固有効果で差を付けてよい |
| 槍 | 剣・斧との種類による基礎性能差や三すくみは設けない。同上 |
| 斧 | 剣・槍との種類による基礎性能差や三すくみは設けない。同上 |
| 弓 | 主に**射程**と**飛行特効**で近接物理武器と差別化する |
| 魔核 | **本人が生まれつき持つ、魔法を扱うための体の器官**（生体パーツ）。本人の素の魔法の素養。固定の武器威力・武器命中補正・耐久を持たない（§4.1） |
| 杖 | **魔法武器**の代表（試験の魔導書の代わり）。武器の恩恵で命中・威力を補正する。耐久あり（§4.1） |

- 剣・槍・斧を選ぶ意味は、基本性能の優劣や相性表ではなく、キャラクターの装備可能種、武器名・外見・価格帯、個別の固有効果や付属戦技で表す。
- **物理武器には耐久を設けない。** 通常攻撃で壊れず、物理戦技のコストにも使わない。
- **物理戦技は戦闘ごとの使用回数制**にする。回数は戦技ごとに決め、戦闘開始時に回復する。
- 武器の残り使用可能量は、UI・データとも名称を**耐久**に統一する。「耐圧」という別の値は設けない。

### 4.1 魔核と魔法武器（採用・数値は未決。原作者 2026-10-01〜02）

この世界の魔法は書物ではなく、みんなが生まれつき持っているもの。魔法を扱う手段は2つある。

| | 魔核 | 魔法武器（杖など） |
| --- | --- | --- |
| 何か | 本人が生まれつき持つ、魔法を扱うための体の器官（生体パーツ）。**1つの魔核に1種類の基本魔法**（火の魔核・治癒の魔核など）。1人が複数持てる（§4.2） | 魔法を扱うための武器 |
| 表すもの | 本人の素の魔法の素養。威力は本人の魔攻、命中は本人の命中能力を中心に決まる | 武器の恩恵（命中・威力の加算補正） |
| 耐久 | **なし。壊れない**（本人が倒れる・MPが尽きる以外に使えなくなることはない） | **あり**。種類ごとに耐久・付いた戦技のコスト・火力の補正が違う |
| 補正 | 装備品としての固定威力・命中補正は持たない。一族・本人の得意属性など、本人側の適性補正は付けてよい | 武器ごとに命中・威力の補正。武器に固有魔法が付く場合もある |
| 持ち方 | 体の一部なので人へ渡さない。武器の装備枠ではなく、本人の**魔核の枠**に入る（§4.2） | 装備し、ほかの人へ渡せる |

- **同時使用**: 魔法武器は魔核の代わりになる器官ではなく、本人の魔法を補助する装備。魔法武器を装備した状態でも、魔法の基礎は本人の魔核・魔攻・命中能力を使い、その上に武器の威力と命中補正を足す。
- **基本魔法のコスト**: 行動ごとに1つのコスト値を持つ。魔核だけで使う場合は、その値だけMPを減らす。魔法武器を装備して使う場合は、**MPと魔法武器の耐久を同じ値だけ減らす**。
- **魔法戦技のコスト**: 通常の基本魔法より大きいコストを設定する。魔法武器を装備していれば、MPと耐久の両方から同じコストを払う。
- **破損後**: 魔法武器の耐久が0になったら、その武器の威力・命中補正と武器固有魔法を失う。ただし、本人の魔核による基本魔法と、本人が習得済みの魔法戦技は引き続き使える（MPが残っている場合）。破損した武器は消滅させず、修理可能な装備として残す。
- **取りやめた案**: 「本人の素の魔法威力が武器より5以上高いと装備不可」「本人の魔法威力が武器の耐久を超えると破損」は採用しない。装備制限と突然の破損を増やさず、MPと耐久の同時消費だけで強い効果の代償を表す。
- 強い術者は魔核だけでも高い威力を出せる。魔法武器はさらに火力・命中を上げられるが、MPに加えて耐久も消費する。苦手な術者にとっては、魔法武器が低い素養を補う最終手段にもなる。
- 兵種スキル・因果スキルの CSV にある「武器種『魔法』装備時」は、魔核・魔法武器（杖）のどちらで魔法を使っているときも含む、と読む（扱いを分けたくなったら直す）。
- 試験のコードの「火の魔核」「治癒の魔核」などは、旧・魔導書の名前だけを変えた物で、仕組みは「装備する魔法の道具」。この考え方に合わせるときは、魔核（本人の器官・壊れない）と魔法武器（杖・耐久あり）に分け直す。

- **回復の魔法**（検討中・原作者 2026-10-02）: 魔核の「治癒」として本人の適性に結び付けるか、覚えられる魔法戦技にするか。回復量の決め方（固有の威力＋魔攻など）も一緒に決める。

### 4.2 魔核の枠（採用。原作者 2026-10-02）

- 魔核の枠に入るのは**基本魔法の種類だけ**（火・治癒など）。魔法戦技は今までどおり戦技4枠に入れる（`SKILL_LOADOUT_RULES.md`）。魔法戦技を使うには、その系統の魔核を持っている必要がある（例: 炎の魔法戦技には火の魔核）。
- **最初の魔核の枠の数**: ヒト・竜人は2、魔物・エルフは3。因果Lvが上がると増え、**最大8**。
- **一族の魔核**: 一族のキャラは、最初の枠のうち**1枠**が自動的に一族由来の魔核になる（外せない）。例: 黒の一族＝火、白の一族＝氷、黄の一族＝土、翠の一族＝風（試験のコードの `TRIAL_CLAN_ELEMENTS`）。残りの枠には汎用の魔核を入れられる。
- **汎用の魔核の手に入れ方**（3通り）:
  1. その人の中で、新しい魔核に**目覚める**。
  2. 魔法武器に魔核が**付属**していることがある。
  3. **魔核の結晶・欠片**がまれに手に入る（敵が落とすなど）。集めた欠片を武器屋で魔核にしてもらえる。
- 魔核は体の器官なので、一度宿したら人へ渡せない（結晶・欠片のうちは持ち物として渡せる）。

枠の増え方（案・調整可能。総合担当 2026-10-02。種族の差が因果Lv50ごろにそろうようにした）:

| 種族 | 最初 | 増える因果Lv | 最大 |
| --- | ---: | --- | ---: |
| ヒト・竜人 | 2 | 8・16・24・32・40・48 で＋1 | 8（Lv48） |
| 魔物・エルフ | 3 | 10・20・30・40・50 で＋1 | 8（Lv50） |

未決（魔核の枠）:

- 枠の増え方（上の表は案）。
- 汎用の魔核の種類の一覧（基本魔法の一覧）。
- 「目覚める」の条件（因果Lv・出来事・キャラごとの決まった順など）。
- 宿した魔核を枠から外せるか・入れ替えられるか（身支度で入れ替え、など）。
- 魔法武器に付属の魔核は、装備している間だけ使えて枠を使わないのか、枠に宿せるのか。
- 結晶・欠片の手に入れ方と、武器屋で魔核にする値段・数。

未決（魔核・魔法武器）:

- 魔法武器の最大耐久、基本魔法・各魔法戦技のコスト値、修理の価格と場所。
- 耐久が残りコスト未満のとき、最後の1回を使って0にするか、使用不可にするか。
- 魔法武器の具体的な威力・命中補正と、武器固有魔法の一覧。
- 魔核側の属性適性を、一族ごと・本人ごとのどちらで持つか。

未決:

- 個々の剣・槍・斧の威力・命中・必殺・重さ・価格・固有効果。ただし武器種間の基礎性能差と三すくみは作らない。
- **物理武器にも命中補正を付ける**（原作者 2026-10-02）。値は個々の武器ごとに決める（魔法武器の命中補正と釣り合わせる）。

## 5. 敵（モブ）の能力値の作り方（採用・数値は未決）

モブ（名のない一般兵）は、**兵種ごとの「型」**から計算して置く。

```text
型 = その兵種のモブの 因果Lv1基礎値（基本8ステータス）＋ 型の成長率
配置する因果Lv L での能力値（期待値）
   = 因果Lv1基礎値 + (L − 1) × 実効成長率
実効成長率 = 型の成長率 + 汎用兵種の兵種成長率補正（GENERIC_CLASS_GROWTH_RATES.md）
           + floor((幸運 + 最大勇気) / 40)%
```

- マップの難しさは、主に置く因果Lvで調える。隊長・将軍も同じ型で、因果Lvを上げて作る。
- 型の候補: SDの絵があるモブ（アルストロの槍兵・魔法兵・弓兵・将軍、オルクスの剣兵・弓兵・魔法兵・騎乗兵・将軍、貧しい町の人）。
- ネームドの敵（オルクス・アルストロの名のある人物・サタン）は、型ではなく `SRPG_CHARACTER_STAT_GROWTH_STANDARD.md` の本人の値を使う。

- 型の数値（因果Lv1基礎値・成長率・種族の補正・期待値の表）は `MOB_TEMPLATES.md`（採用値・調整可能、2026-10-01）。

未決:

- 期待値の端数の扱い（いまは四捨五入）・能力上限（`MOB_TEMPLATES.md` §4）。
- モブの兵種スキル・兵種戦技・持たせる武器。

- ダメージ式・武器威力は、`trialStatSystem.js` にすでに同じ内容がある（試験の名前のまま）。
- **2026-10-02 に試験の戦闘へ入れた（第1段）**: ブラウザ版（`trialStatSystem.js`・`battlePlan.js`・`game.js`）と Unity版（`TrialRules.cs`・`BattlePlan.cs`・`Battle3DController.cs`）の両方。
  - 魔法の威力 = 基本魔法の固有の威力3（魔法の戦技は仮に6）＋装備中の魔法武器の威力（`trialMagicPower`）。
  - 試験の「火の魔核」などの装備品を、魔法武器「火の杖」「治癒の杖」「星の杖」「仮の杖」に変えた（仮の値: 威力6・命中+5・耐久30。コードの種類名 `grimoire` と id は変えていない）。魔法を使うと MP と耐久を同じだけ減らし、0 で壊れる（威力・命中補正と付属の魔法を失う。壊れた杖の魔法は一覧に「壊れた」と出て選べない）。耐久は戦闘の始めに満タン（持ち越し・修理は未実装）。
  - 物理武器（試験の剣）に命中+5（仮）。
  - 物理戦技は1戦闘2回（仮。`TRIAL_PHYSICAL_ART_USES`）。残り回数をボタンに出し、0 で選べない。
  - 耐久が MP の消費より少ないときは、残りの分だけ減って 0 になる（最後の1回は撃てる。未決事項の仮の扱い）。
  - Unity版の武器の欄はブラウザ版の表示を書き出した値なので、耐久の今の値はまだ出ない（戦闘の記録には出る）。
- 武器種・モブの型・魔核の枠（§4.2）は、まだコードにない（第2段。基本魔法の一覧が決まってから）。
