# 会話UIの採用方針 — 銀細工と左右立ち絵

採用版 v1.0 / 2026-10-03
状態: **正式採用（意匠・見せ方の方向性）**。Unityへの移植・公開は未実施、別途指示待ち。
根拠: 原作者「そしたら採用方針でいこう。Claudcodeにも共有できるようにしておこう」。

## 1. 採用したこと

- 現在の探索背景を残し、その上のUI層に左右の立ち絵と台詞枠を重ねる。横画面を維持する。
- 銀細工の会話HTML見本を今後の実装基準にする。本文は落ち着いた半透明の下地、細い銀縁、四隅の独立した銀細工。飾りを引き伸ばして歪ませない。
- 名前札は両端が尖った形、不透明な下地、輪郭に沿う細い内縁。名前札には角飾りを付けず、本文の線や銀細工が透けて横切らないようにする。
- 小さな吹き出し尾を話者側へ向ける。本文と尾は同じ色・太さの一続きの輪郭にし、継ぎ目や重ね塗りを目立たせない。尾の左右位置を調整できるようにする。
- 聞き手の立ち絵は透かさず、画像の輪郭内だけを少し暗くして話者と区別する。
- 上置きを基本の見本とする。ただし文章量・視点・重要な背景や人物に応じて、枠の位置・寸法を調整できる前提にする。長文は文字を極端に小さくせずページ送りで読む。

## 2. 固定仕様ではないもの

- 408×100、丸み24、透過20%、各色、飾りlarge、左右の尾17は作者調整の基準値。全場面・全画面共通の不変値ではない。
- 最新値は `prototypes/silver-ui-extension/dialogue-portrait-author-settings-20261003.json`。旧暫定JSONや比較撮影用の既定値より優先する。
- 全画面の銀色テーマへの統一、世界観の色の変更、全場面の自動配置・顔回避は決定していない。
- 表示テスト用の台詞・2人の固定配役・仮立ち絵・回廊の仮の右端・未接続の出口は正式なシナリオや素材の採用を意味しない。
- ナレーション、携帯端末や声だけの話者、3〜4人会話の詳細は現行処理を調べてから確認する。HTMLの試験表示をそのまま正史へ追加しない。
