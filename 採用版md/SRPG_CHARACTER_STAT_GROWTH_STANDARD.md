# SRPGキャラクターステータス換算・成長標準

採用版 v1.3 / 2026-09-24

- v1.3: メイン3人の個人成長率を改定。実効成長率へ幸運・勇気補正 `floor((幸運 + 勇気) / 40)%` を加える方式を採用。メイン3人の長期的な設計像を追記。成長期待値・上限到達時期を再計算。
- v1.2: 因果Lv上限を設けないことを採用。能力上限の目的（やりこみ要素）と本編想定レベル帯を追記。§9.1の式へ個人上限を明記。
- v1.1: 能力上限と兵種成長率の整理を反映。

## 0. この文書の位置付け

この文書は、TRPG版のキャラクターを自作SRPGへ登場させる際の、初期能力換算、因果Lv成長、能力上限の標準形式を定める。

ゲームコードへの実装仕様そのものではないが、今後 `statConversion.js`、キャラクターデータ、成長処理、セーブ形式を変更するときの正典とする。既存コードにはまだ反映していない。

過去資料 `docs/10-design/battle/TRPG_TO_SRPG_STAT_CONVERSION.md` v0.3 には、リングホルムとアルバスのTRPG Lv5資料をそのまま加入時能力へ換算する旧案が残っている。メイン3人の因果Lv1基礎値と個人成長については、本書を新しい基準として優先する。

### 状態の読み方

- **採用**: 今後の設計と実装の基準にする。
- **採用値・調整可能**: 現在の比較基準として使うが、戦闘テストで数値だけを調整できる。
- **未決**: 実装前に別途決める。

## 1. 採用する全体構造

```text
TRPG原資料
  -> 初回だけ換算
因果Lv1基礎ステ
  -> 個人成長率による永久成長
本人現在ステ
  -> 現在兵種・装備・スキル・一時効果
戦闘時ステ
  -> 共通の戦闘計算
命中率・回避・必殺・ダメージなどの派生値
```

### 1.1 各層の責務

| 層 | 保持・計算するもの | 原則 |
| --- | --- | --- |
| TRPG原資料 | HP、STR、CON、DEX、POW、APP、SIZ、勇気、幸運、技能、資料Lv | 換算根拠として保存し、戦闘中に直接参照しない |
| 因果Lv1基礎ステ | HP、力、防御、魔攻、魔防、技、速さ、魅力 | キャラクター本人のSRPG上の出発点 |
| 永久成長 | 因果Lv上昇で得た各能力の上昇量 | 転職しても失わない |
| 本人現在ステ | 因果Lv1基礎ステ + 永久成長 | セーブ対象とする |
| 戦闘時ステ | 本人現在ステ + 現在兵種 + 装備 + スキル + 一時効果 | 戦闘開始時の計算入力 |
| 派生値 | 命中率、回避、必殺、必殺回避、追撃、ダメージ等 | 予測・実戦闘・敵AIで共通計算器を使う |

この分離により、TRPG換算、永久育成、転職、装備、戦闘中の一時効果を混同しない。

## 2. レベルの分離

| レベル | 役割 | 採用方針 |
| --- | --- | --- |
| TRPG資料Lv | 原資料がどの時点の人物かを示す | 出典情報のみ。SRPGの育成値へ変換しない |
| 因果Lv | キャラクター本人の永久成長 | 基本8ステの成長、因果スキル・戦技の習得に使用 |
| 兵種Lv | 兵種への習熟 | 兵種スキル・戦技・マスタースキルの習得に使用 |

TRPG Lv4やLv5を、そのまま因果Lv4やLv5として扱わない。TRPGで完成済みの人物も、共通の因果Lv1基礎値と個人成長率からSRPG上の成長曲線を作る。

リングホルムやアルバスのような経験豊富な人物は、物語上の加入時因果Lvを高めに設定することで強さを表す。加入時因果Lvの正式値は未決とする。

### 2.1 因果Lvの上限

**採用**: 因果Lvには上限を設けない。成長の打ち止めは、§8のキャラクター別能力上限だけで表す。

- 本編のラスボス戦に挑むレベル帯は、因果Lv40〜50程度を想定する。
- 本編中は能力上限に届かず、個人成長率どおりの伸びでキャラクター像を表す。
- 本編想定を超えて経験値を稼ぎ続けるやりこみ要素として、能力上限を最終到達点にする。

## 3. 基本8ステータス

| 基本ステ | 主な役割 |
| --- | --- |
| HP | 最大HP、生命力 |
| 力 | 物理攻撃の基礎 |
| 防御 | 物理ダメージへの耐久 |
| 魔攻 | 魔法攻撃・魔法効果の基礎 |
| 魔防 | 魔法ダメージへの耐久 |
| 技 | 命中、必殺、技巧系効果の基礎 |
| 速さ | 追撃、回避の基礎 |
| 魅力 | APPを根拠とする存在感。必殺回避・支援等の候補 |

名称は次のように統一する。

- 基本ステータスは「攻撃」ではなく「力」とする。
- 基本ステータスは「命中」ではなく「技」とする。
- 最終命中率は技などから計算する派生値であり、基本ステータスとして直接成長させない。

### 3.1 基本8ステータスに含めない値

| 項目 | 区分 | 方針 |
| --- | --- | --- |
| 勇気 | 独立した人物値・戦闘資源 | 魅力とは別物。最大値と現在値を分ける方向。最大勇気は成長率補正に使う（§6.1） |
| 幸運 | 独立した人物値 | 原資料を保持する。成長率補正に使う（§6.1）。戦闘用途は未決 |
| MP | 戦闘資源 | 魔法システム確定後に尺度を決める |
| SIZ | 換算・派生回避用の原資料 | 基本速さや追撃を直接下げない |
| TRPG技能 | 初期設計の根拠 | SRPGの修練度として成長させない |

## 4. 因果Lv1基礎ステータスの換算

### 4.1 現在の標準式

| SRPG項目 | 現在の換算基準 | 状態 |
| --- | --- | --- |
| HP | `TRPG HP x 2` | 採用値・調整可能 |
| 力 | `STR` | 採用 |
| 防御 | `floor((STR + SIZ) / 2)` | 採用値・調整可能 |
| 魔攻 | `POW` | 採用 |
| 魔防 | `floor((POW + CON) / 2)` | 採用値・調整可能 |
| 技 | `floor(DEX / 2)` | 採用値・調整可能 |
| 速さ | DEXを目安にし、人物の機動性・戦い方を個別補正して決める | 採用 |
| 魅力 | `APP` | 採用 |

### 4.2 速さの扱い

速さはTRPGの回避技能をそのまま足し込む単純式にはしない。

- DEXは反応・精密さを見る基礎資料にする。
- TRPG回避技能は、訓練・ビルド・習得済み能力の証拠として扱う。
- SIZは基本速さへ入れず、最終回避の体格補正でだけ参照する。
- 人物像と実際の戦い方がDEXだけでは表せない場合、個別の機動性補正を記録する。

メイン3人の因果Lv1速さは、幼アルシェ10、リングホルム12、アルバス9を採用値とする。

## 6. 個人成長率

次の値をメイン3人の個人成長率として採用する。戦闘バランス試験で数値調整は可能だが、得意分野の関係は維持する。

| ステータス | 幼アルシェ | リングホルム | アルバス |
| --- | ---: | ---: | ---: |
| HP | 70% | 45% | 65% |
| 力 | 60% | 75% | 40% |
| 防御 | 55% | 45% | 50% |
| 魔攻 | 55% | 65% | 80% |
| 魔防 | 50% | 65% | 75% |
| 技 | 70% | 75% | 80% |
| 速さ | 70% | 70% | 55% |
| 魅力 | 60% | 60% | 70% |
| 合計 | 490% | 500% | 515% |

v1.2からの変更: 幼アルシェは魔攻45→55%、技65→70%、魅力55→60%。リングホルムはHP50→45%、魔攻45→65%、速さ75→70%、魅力50→60%。アルバスは変更なし。

合計は、各能力を独立した確率で+1成長させた場合の平均ピン数に対応する。個人成長率だけなら、幼アルシェは平均4.90ピン、リングホルムは5.00ピン、アルバスは5.15ピン相当となる。

現行の成長率では、3人とも魔防成長率が魔攻成長率以下である。高因果Lvで魔法ダメージが通らなくなる問題を避けるため、この関係を保つことが望ましい。

### 6.1 幸運・勇気の成長率補正

**採用**: 因果Lv上昇時の実効成長率へ、幸運と勇気から求める補正を加える。

```text
幸運・勇気補正 = floor((幸運 + 最大勇気) / 40)%
```

- 基本8ステータスすべてへ同じ値を加える。
- 勇気は、戦闘中に減る現在勇気ではなく、戦闘で変動しない最大勇気（基礎値）を使う。
- 幸運と勇気はTRPG原資料の値を使う。

| キャラクター | 幸運 | 勇気 | 補正 | 1因果Lvあたりの平均ピン増加 | 個人成長率＋補正の合計 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 幼アルシェ | 90 | 90 | +4% | +0.32 | 522% |
| リングホルム | 35 | 90 | +3% | +0.24 | 524% |
| アルバス | 65 | 65 | +3% | +0.24 | 539% |

成長型主人公の幼アルシェは補正が最も大きい。リングホルムとアルバスは、個人成長率の高さで強さを保つ。

確率成長、固定成長、乱数補正付き成長のどれを実際に採用するかは未決である。以下の比較表では、成長率どおりに伸びた期待値を四捨五入して表示する。

```text
Lv時点の期待値 = 因果Lv1基礎値 + (個人成長率 + 幸運・勇気補正) x (因果Lv - 1)
```

## 8. 能力上限

TRPG資料の `現在値/上限値` にある上限値を、キャラクター本人の潜在能力上限として使用する。初期能力をSRPG向けに圧縮する式と、潜在上限の対応は分けて扱う。

例えば幼アルシェの初期技は9だが、技上限はDEX71を半減せず、INT上限87をそのまま使用する。

### 8.1 基本8ステータスの上限対応

| SRPGステータス | TRPG上限の参照元 |
| --- | --- |
| HP | `ceil((CON上限 + SIZ) / 2) x 2` |
| 力 | STR上限 |
| 防御 | CON上限 |
| 魔攻 | POW上限 |
| 魔防 | EDU上限 |
| 技 | INT上限 |
| 速さ | DEX上限 |
| 魅力 | INT上限 + 現在APP |

HPはTRPGの基本HP式と、SRPGのHP2倍換算を同じ順番で上限へ適用する。APPには原資料上の潜在上限が記録されていないため、魅力上限では現在APPをINT上限へ加える。

### 8.2 メイン3人の能力上限

| キャラクター | HP | 力 | 防御 | 魔攻 | 魔防 | 技 | 速さ | 魅力 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 幼アルシェ | 122 | 90 | 108 | 104 | 106 | 87 | 71 | 102 |
| リングホルム | 104 | 94 | 94 | 110 | 106 | 96 | 91 | 112 |
| アルバス | 104 | 80 | 89 | 110 | 108 | 98 | 108 | 115 |

能力上限は、因果Lvで得る本人の永久能力へ適用する。現在兵種、装備、スキル、一時効果による戦闘中の補正は、この上限を一時的に超えてよい。

### 8.3 能力上限の目的と到達時期

能力上限は本編のバランス調整用ではなく、やりこみ要素の到達点である（§2.1）。

個人成長率と幸運・勇気補正で期待値どおりに伸びた場合、全能力が上限へ届く因果Lvの目安は次のとおり。兵種成長率補正が加わる分、実際はこれより早くなる。

| キャラクター | 全能力上限到達の目安 | 最後に上限へ届く能力 |
| --- | ---: | --- |
| 幼アルシェ | 因果Lv170前後 | 魔防 |
| リングホルム | 因果Lv170前後 | 防御 |
| アルバス | 因果Lv172前後 | 速さ |

本編想定の因果Lv50では、どの能力も上限に届かない。

速さ上限はアルバス108、リングホルム91、幼アルシェ71で、因果Lv50時点の速さの順位（リングホルム＞幼アルシェ＞アルバス）と逆になる。個人成長率と幸運・勇気補正による期待値では、アルバスが幼アルシェの速さを上回るのは因果Lv108前後、リングホルムを上回るのは因果Lv143前後であり、本編の範囲では起きない。やりこみ帯でのこの逆転を許容するかは未決とする（§11）。

```text
本人現在ステ = min(因果Lv1基礎ステ + 永久成長, 個人上限)

戦闘時ステ = 本人現在ステ
             + 現在兵種補正
             + 装備補正
             + スキル補正
             + 一時効果
```

## 9. 因果Lvと兵種Lvの分担

| 項目 | 担当 |
| --- | --- |
| 因果Lv | 本人の永久ステータス成長、因果スキル・因果戦技の習得 |
| 個人成長率 | 因果Lv上昇時に、どの能力が伸びやすいか |
| 兵種Lv | 兵種スキル・兵種戦技・マスタースキルの習得 |
| 現在兵種 | 能力の加減算、移動、騎乗・飛行、武器や魔法の利用条件 |
| 装備 | 威力、射程、属性、明記された補正・特殊効果 |
| 支援 | Dual発生率、連携効果 |

### 9.1 兵種補正の原則

```text
本人現在ステ = min(因果Lv1基礎ステ + 永久成長, 個人上限)

戦闘時ステ = 本人現在ステ
             + 現在兵種補正
             + 装備補正
             + スキル補正
             + 一時効果
```

- 因果Lvで得た永久成長は転職しても失わない。
- 現在兵種補正は転職時に入れ替わる可逆的な補正にする。
- 兵種Lv上昇のたびに別枠で永久能力を加算する方式にはしない。
- 因果Lv上昇時の実効成長率は、キャラクター個人成長率へ、現在兵種の兵種成長率補正と幸運・勇気補正（§6.1）を加えて求める。
- 兵種成長率と幸運・勇気補正は、倍率ではなくパーセントポイント加算とする。
- 兵種成長率によって得た上昇も本人の永久成長として保存し、転職後も失わない。

```text
実効成長率 = キャラクター個人成長率
           + 現在兵種の兵種成長率補正
           + floor((幸運 + 最大勇気) / 40)%
```

兵種成長率の採用値は `GENERIC_CLASS_GROWTH_RATES.md` を参照する。成長率が100%を超えた場合の処理と、レベルアップ直前の転職による調整をどこまで許容するかは未決とする。

## 10. 実装時のデータ分離案

コード化するときは、最低限次の情報を分けて保持する。

| データ | 内容 | セーブ |
| --- | --- | --- |
| sourceReference | TRPG資料名、資料Lv、換算根拠 | 任意。デバッグ用 |
| causeLevel | 現在の因果Lv | 必須 |
| baseStats | 因果Lv1基礎ステ8項目 | キャラ定義側。必要なら保存 |
| personalGrowthRates | 個人成長率8項目 | キャラ定義側 |
| luck / maxCourage | 幸運・勇気補正（§6.1）の計算元 | キャラ定義側 |
| statCaps | 個人能力上限8項目 | キャラ定義側 |
| classGrowthRates | 兵種成長率補正8項目 | 兵種定義側 |
| permanentGrowth | 因果Lvで実際に得た上昇量8項目 | 必須 |
| currentClassId | 現在兵種 | 必須 |
| classLevels | 兵種ごとの兵種Lv | 必須 |
| learnedSkills | 習得済みスキル・戦技 | 必須 |
| equippedSkills | 装備中スキル | 必須 |
| bondAffinities | 縁適性・支援関係 | 必須 |

現在能力をレベルと成長率だけから毎回再計算すると、ランダム成長の履歴や将来の調整でセーブが変化する。実装時は、実際に得た永久成長量または現在の本人能力を保存する。

## 11. 実装前に残る決定

1. レベルアップを確率成長、固定成長、または両方の選択式にするか。
2. リングホルムとアルバスの正式な加入時因果Lv。
3. 加入前成長を固定期待値、作者指定値、乱数のどれで作るか。
4. 兵種ごとの一時能力補正値と、因果Lvに応じて補正量を変えるか。
5. 実効成長率が100%を超えた場合の処理。現在のメイン3人は、最大のアルバス（技・魔攻80%＋幸運・勇気補正3%）へ兵種補正+10%を加えても93%で、まだ発生しない。
6. 魅力の最終用途。特にアルバスの70%成長をDualや支援へどこまで影響させるか。
7. 命中、回避、必殺、必殺回避、追撃、ダメージ式との最終的な数値検証。
8. 乱数成長を採用する場合の下振れ救済と上振れ制御。
9. 既存セーブから新データ構造への補完規則。
10. やりこみ帯（因果Lv114前後以降）で速さの順位が逆転することを許容するか（§8.3）。
11. 上限なしの因果Lvに合わせた、本編後の経験値曲線。

## 12. 実装時の確認順

1. 換算関数と因果Lv1基礎値を、ゲーム本流から独立したテストで固定する。
2. 成長率から期待値表が再現できることを確認する。
3. 仮の固定成長でLv20、Lv30、Lv50の戦闘能力を比較する。
4. 現在兵種補正を加え、転職前後で永久能力が変わらないことを確認する。
5. 派生値計算を戦闘予測、実戦闘、敵AIで共有する。
6. セーブとロードで因果Lv、永久成長、兵種Lv、習得・装備状態が一致することを確認する。
