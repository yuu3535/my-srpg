# 汎用兵種の成長率補正

採用版 v1.0 / 2026-09-24

## 1. 位置付け

この文書は、因果Lv上昇時にキャラクター個人成長率へ加える、汎用兵種の兵種成長率補正を定める。

兵種成長率は、現在兵種を装備している間だけ表示能力へ加える一時補正ではない。因果Lv上昇時の成長判定へ影響し、成功して得た能力は本人の永久成長として転職後も残る。

```text
実効成長率 = キャラクター個人成長率 + 現在兵種の兵種成長率補正
```

補正は倍率ではなくパーセントポイント加算とする。例えば個人成長率75%へ兵種補正+10%を加えた場合、実効成長率は85%となる。

## 3. 成長処理上の原則

- 因果Lv上昇時に、キャラクター個人成長率と現在兵種の補正を合算する。
- 基本8ステータスをそれぞれ独立して成長判定する方向とする。
- 成功時は原則として対象能力を+1する。
- 兵種成長率による上昇も本人の永久成長へ含める。
- 転職しても、過去に得た永久成長は失わない。
- 現在兵種による一時能力補正とは別のデータとして扱う。
- 個人能力上限へ達した能力は、それ以上永久成長しない。

## 4. 補正合計の設計

- 下級兵種は合計+10%を基準とする。
- 下級騎兵は合計+15%とする。
- 上級兵種はすべて合計+25%とする。
- 飛行上級のHP補正は0%とし、合計+25%に揃える。

合計値は、その兵種で1回因果Lvが上がったときに増える平均ピン数への追加量を表す。合計+25%なら、個人成長だけの場合より平均0.25ピン多くなる。

## 5. 未決事項

- 実効成長率が100%を超えた場合、100%で打ち止めるか、100%超過分でもう一度判定するか。
- 完全ランダム成長、固定成長、下振れ救済付き成長のどれを採用するか。
- レベルアップ直前の転職による兵種成長率の調整を許容するか。
- 加入前の因果Lv成長を、固定期待値、作者指定値、乱数のどれで作るか。
- 汎用兵種とは別に、因果兵種・専用兵種へどの成長率補正を設定するか。
