# 立ち絵スタジオ (tachie_studio.py)

AI生成キャラ絵（白背景）をゲーム用の透過立ち絵に変換するツール。
**自動透過 → ブラウザ上でタップお直し → PNG保存** までを1画面で行う。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `tools/tachie_studio.py` | **メインツール**。自動透過＋タップお直しの統合スタジオ（ブラウザUI） |
| `tools/tachie_clear_v5.py` | CLIバッチ版。フォルダ一括処理用（`python tools/tachie_clear_v5.py raw processed`） |
| `tools/tap-clear.html` | お直し単体版。ブラウザで開くだけで動く（Python不要、透過済みPNG専用）。線画仕上げボタンあり |
| `tools/TACHIE_STUDIO.md` | この説明書 |
| `tools/requirements.txt` | 必要ライブラリ一覧 |

迷ったら **tachie_studio.py を使う**。他の2つは特定用途のサブウェポン。

## 使い方

```bash
py -3.12 -m pip install -r tools/requirements.txt   # 初回のみ
py -3.12 tools/tachie_studio.py
# → http://localhost:8787 が自動で開く
# → 白背景画像をドロップ → 自動透過 → 気になる所をタップ修正 → PNG保存
```

初回実行時に isnet-anime モデル(約176MB)が `~/.u2net/` に自動DLされる。
リポジトリには含めない。
WindowsではDirectMLを使い、対応GPUがあれば自動的にGPU推論へ切り替わる。
起動ログの `推論プロバイダー` が `DmlExecutionProvider` ならGPU動作。

## 出力の置き場所（my-srpg での運用）

- 保存されるファイル名: `元ファイル名_clear.png`
- 自動処理直後の未完成素材は `立ち絵透過下処理/` に置く
- 現在のゲームで使う立ち絵は `立ち絵透過済み/` に置く
- 既存参照は `_transparent.png` が多いため、差し替え時はファイル名と参照先を一緒に確認する

未処理の白背景素材だけをまとめて下処理する場合:

```powershell
py -3.12 tools/prepare_tachie_batch.py 立ち絵AI生成 立ち絵透過下処理 --existing-dir 立ち絵透過済み
```

## 処理パイプライン（AIエージェント向けの背景知識）

1. **isnet-anime でセグメンテーション** — アニメキャラ特化モデルをONNX Runtimeで直接実行。
   汎用モデル(u2net)はマスクが2〜3px外に膨らみ白フチが出るが、isnet-animeは輪郭に密着する。
2. **賢い穴埋め** — 閉じた領域のうち「ほぼ純白」= 服と体の隙間として透過、
   「有色」= 衣装内部として保護。白い衣装のキャラで内部が抜ける事故を防ぐ。
3. **輪郭スムージング**（デフォルト1.5）
4. **縁取り＋境界の色ムラ塗り潰し** — 縁色（デフォルト濃紺 #1e2440）を外側0.5px＋
   内側1.0pxに引く。境界に白ピクセルが点在して濃色背景でギャザギャザ見える現象への対策。
5. **離れたパーツを保持** — 魔法、炎、光輪など人物から離れたパーツも標準で残す。
   背景ノイズまで残る画像だけチェックを外す。

## パラメーター調整の指針

| 症状 | 対処 |
|---|---|
| 1pxの白いギザギザが残る | プリセット「線画仕上げ」または「線画・太」を使う（縁を太くして輪郭線として飲み込む） |
| 白フチが残る | 「収縮」を上げる（u2net系の膨らみ対策。isnetでは通常0でよい） |
| 細いパーツ（鎖・髪先）が欠ける | 収縮を下げる |
| エッジがギャザギャザ | 「縁の食い込み」を上げる（1.0→1.5） |
| 縁が太く感じる | 縁の食い込みを下げる（1.0→0.5） |
| 角が丸まりすぎる | 「輪郭平滑」を下げる |
| 暖色系キャラで縁が浮く | 縁色を焦げ茶 #3a2a20 などに変更 |

## 既知の限界

- 色ベースの判定を含むため、**背景と同色の小さな閉じ隙間**は稀に取り切れない
  → タップお直し（魔法の杖）で対応する前提の設計
- モデル推論があるためブラウザ単体では動かない（Pythonサーバー必須）
- 高解像度画像はCPU推論に数分かかる場合がある。複数画像を同時実行しない
- 独立エフェクト保持をOFFにすると、人物から離れた輪・魔法・粒子も消える

## 開発経緯（同じ轍を踏まないためのメモ）

- v1: 白色フラッドフィル方式 → 白衣装キャラでアンチエイリアス伝いに内部まで透過して失敗
- v2-v3: u2net分離＋収縮補正 → マスクの膨らみ(2〜3px)対策は成功したが隙間が取れない
- v4: isnet-animeへ変更＋賢い穴埋め → 隙間解決
- v5: エッジ均一化（境界の色ムラ塗り潰し） → ギャザギャザ解消
- studio: v5パイプライン＋タップお直しUIを統合
- studio改: 縁太さスライダー＋線画プリセット追加（1px白ギザの最終解決）
